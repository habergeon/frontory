# 실행 예제 확장

학습 문서의 과제와 연결되는 실제 실행 코드를 제공한다. 기존 코드·필기·진행 상태·JSON 백업 ID는 유지한다. 예제 추가는 기존 저장 내용을 덮어쓰지 않는다. 이전에 빈 코드가 저장된 단위에서는 사용자가 원본 코드 복원을 선택해 새 예제를 불러온다.

예제는 mount(context)에서 장면 또는 DOM을 구성하고 자원을 정리하는 함수를 반환한다. 실행에 사용하는 전체 예제 소스를 편집기에 제공한다. 공통 Three.js 초기화 코드도 소스에 포함해 관찰할 수 있게 한다. 원격 CDN에 의존하지 않는다.

브라우저 실행, 원리 시각화, 별도 환경 실행을 구분한다. Gaussian의 원리 시각화를 실제 학습된 3DGS 데이터 뷰어로 표시하거나 다른 프레임워크를 일반 DOM 코드로 대체하지 않는다. 지원 GPU·브라우저·런타임 조건은 각 단위에 명시한다.

검증은 소스 구문 검사, 저장 호환 회귀 테스트, 타입 검사·빌드와 브라우저 렌더·입력·오류 복구로 수행한다. 배포와 외부 인증은 이번 작업 범위에서 제외한다.
