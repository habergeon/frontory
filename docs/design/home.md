# Frontory 홈

## 목적과 동선

처음 방문한 사용자가 서비스의 목적과 사용 방식을 이해하고 관심 있는 시리즈를 고른 뒤 실습을 시작한다. 홈은 소개, 학습 방식, 시리즈 탐색 순으로 구성한다. 실제 제공되는 23개 시리즈와 94개 단위만 안내하며 학습 성과를 보장하지 않는다.

- `/`와 빈 hash는 홈. 기존 `#01-scene` 등 단위 링크는 유지한다.
- 홈의 시리즈 선택은 해당 시리즈의 진행 중인 단위, 없으면 첫 단위를 연다.
- 실습 화면에 홈 이동을 제공한다. 브라우저 뒤로/앞으로 이동을 지원한다.
- 문서, 코드, 필기, 진행 상태와 JSON 백업 형식은 보존한다.
- 홈에서는 실습 Workspace를 지연 로딩한다.

## 디자인

기존 청록색 `#176b64`, slate `#203246`, cool gray `#f3f5f7`을 사용한다. 밝은 배경, 넓은 여백, 큰 한국어 제목을 중심으로 구성한다. 도입부 오른쪽의 Learn / Experiment / Archive는 HTML 타이포그래피이며 가짜 편집기나 작동하지 않는 버튼을 넣지 않는다.

헤드라인: “배운 것을, 직접 만드는 경험으로.”
설명: “문서를 읽고, 코드를 바꾸고, 나의 언어로 기록하세요.”
주요 행동: “시리즈 둘러보기”.

학습 방식은 개념 읽기 → 코드 실험 → 경험 기록의 3단계다. 탐색은 분야 필터와 검색, 전체 너비의 단일 열 목록 행을 사용한다. 모바일에서는 소개와 목록이 한 열로 배치된다. 행마다 실제 단위 수와 수동 완료 상태를 표시한다. 저장 실패나 비어 있는 검색 결과도 처리한다.

## 검증

홈 진입, 시리즈 검색·필터, 시리즈 선택, 단위 직접 링크, 홈 복귀, 브라우저 뒤로/앞으로 이동, 기존 기록 보존을 확인한다. 작은 화면의 가로 넘침과 키보드 포커스를 확인한다. 타입 검사·기존 저장 회귀 테스트·빌드 후 배포한다.

## 시안 대비 구현 및 검증

- 이미지 시안의 2열 소개, Learn / Experiment / Archive 패널, 청록색 강조와 3단계 학습 안내를 구현했다.
- 시리즈 목록은 한 행에 분야·제목·선수 지식·단위 수·시작 버튼을 배치한다. 시안의 샘플 대신 실제 23개 시리즈 데이터를 사용한다.
- 실제 저장된 진행 상태에만 이어가기와 완료 개수를 표시한다.
- 모바일에서는 소개와 학습 안내가 세로로 쌓이고 목록의 시작 버튼과 단위 수가 오른쪽에 배치된다.
- 내장 브라우저에서 데스크톱과 모바일 화면을 직접 비교했다. 모바일 가로 넘침 없음, 검색·빈 결과·초기화·분야 필터·학습 진입·뒤로/앞으로 이동·진행 상태 이어가기를 확인했다.
- 시안 PNG는 로컬 파일로 확인했고 실제 화면은 브라우저 스크린샷으로 확인했다. 렌더 스크린샷의 별도 파일 저장은 수행하지 않았다.
