# Example guide by learning unit

Original examples are linked to all 644 learning units. The table below lists the existing 94 examples; see the separate list for the [550 additional examples and their execution scope](examples-expanded.md). Existing 01, 02, and 03 storage IDs remain at positions 1, 14, and 28 in the expanded sequence (WebGL keeps its existing order).

Editing the linked example's JS/TS code updates the actual preview. HTML, CSS, GLSL, and WGSL strings are handled by the relevant browser APIs, separately from Monaco JS/TS diagnostics. An example's availability does not mean that the exercise or the learner's study is complete.

Existing saved code and notes are not overwritten automatically. To use a new example, back up your JSON and choose **Use original code**. Notes are preserved.

## Execution scope

- React runs with createElement; Vue runs with the h render function. No JSX/SFC compiler is built in.
- Svelte runs with stores and a DOM adapter. Expanded units provide actual .svelte files to compile in a separate project.
- WebAssembly 02 and 03 include small, actually compiled modules and Node benchmarks. The iframe CSP is not relaxed.
- The 28 Playwright units provide source for a separate Node testing environment. The screen does not claim that tests have passed.
- The GS loader is a CPU educational viewer for .splat/ASCII GS PLY files up to 1 MiB and 512 splats. Ordinary PLY may not contain GS data. Spark and large-data loading are not included.
- WebGPU/WGSL/OffscreenCanvas check browser support. Measure actual performance in each environment, and do not interpret renderer.info as total GPU VRAM.

## Running separate tools

WebAssembly: `node src/labs/webassembly-03/benchmark.mjs` (no additional packages required).

Playwright: In a separate test folder, run `npm init -y`, `npm install -D @playwright/test`, and `npx playwright install chromium`, then copy the example's `lesson.spec.mjs`. Start the Frontory server, set its address in the `FRONTORY_TEST_ORIGIN` environment variable, and run `npx playwright test lesson.spec.mjs`. Review the results before creating visual baselines with `--update-snapshots`.
