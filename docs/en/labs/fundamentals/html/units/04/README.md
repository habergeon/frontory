## Key concepts and explanations

### Paragraph Boundaries

p represents a paragraph. Repeating br to adjust spacing mixes document structure with presentation.

### Emphasis Semantics

strong expresses importance, and em expresses stress within a sentence. Use CSS when you only need bold or italic styling.
