# 대표 예제 검증 기록

2026-10-21 로컬 검증이며 학습자의 과제 완료나 성능 개선 결과는 아닙니다.

- 23개 시리즈에 29개 예제 소스 연결 및 구문 검사.
- 회귀 테스트 23개 통과: 저장·백업·문서 링크·예제 카탈로그·동기/비동기 자원 정리.
- 타입 검사와 프로덕션 빌드 통과. lockfile 고정 설치 확인.
- 독립된 로컬 preview 주소에서 29개 예제의 Monaco 검사 통과와 실행 상태 확인.
- React/Vue 버튼 클릭에 따른 상태 변경 확인.
- WebGPU 삼각형 렌더링, Worker 합계 메시지와 WebAssembly Memory 출력 확인.
- 편집 코드 변경 → 실제 미리보기 반영, 구문 오류 → 마지막 정상 화면 유지, 원본 복원 → 실행 복구 확인.
- React/Vue 필기 분리와 새로고침 복원, 코드 복원 시 필기 유지 확인.
- 대표 예제 순회 중 브라우저 콘솔 오류 없음.

Playwright는 테스트 소스 표시만 검증했으며 별도 Node 테스트 실행은 하지 않았습니다. 모든 예제의 모든 변수 조합, 다른 브라우저/GPU, 장시간 메모리 사용은 검증하지 않았습니다. Svelte 컴포넌트 컴파일·WebAssembly 모듈 실행·실제 3DGS 파일 로딩은 현재 대표 예제 범위가 아닙니다. 프레임워크 런타임을 함께 묶으므로 초기 다운로드와 iframe 재실행 비용은 후속 최적화 대상입니다. 웹 배포는 진행하지 않았습니다.
