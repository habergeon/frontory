# Frontory 기반 검증 기록

2026-10-21 로컬 검증입니다. 학습자의 학습 완료나 성능 실험 결과를 대신 기록한 문서가 아닙니다.

## 콘텐츠와 호환성

- 23개 시리즈, 94개 고유 단위: 기존 WebGL 28개와 추가 22개 × 3단위.
- 기존 문서를 `docs/labs/graphics/webgl/<단위>/README.md`로 이동하고 로컬 Markdown 링크를 검사했다.
- 모든 단위의 선수 지식·개념·실습·완료 조건·공식 참고·실험 기록 절을 검사했다.
- WebGL 저장 ID와 `web-gl-study:*` 저장 키를 유지했다.
- Frontory v2 전체 백업과 WebGL v1 백업을 구분해 검증했다.

## 브라우저 검증

사용자 개발 origin인 5173 포트 대신 별도 production preview 4175 포트에서 확인했다.

- WebGL 첫 단위에서 완료 표시 → 시리즈 1/28 및 4% 반영.
- GLSL 단계 이동 → 이전 08 단위 문서 정상 열람.
- 시리즈 검색 → React 선택 → 새 문서 열람·필기 입력·진행 중 표시.
- 새로고침 후 React 필기·진행 상태 복원.
- 실제 WebGL v1 JSON 파일 가져오기 → 새 React 필기·진행 상태 보존.
- Frontory v2 JSON 실제 다운로드 → format/version/94개 단위/현재 목차/React 필기·상태 확인 → 다시 가져오기 성공.
- WebGL 첫 장면 실행 상태 확인, 콘솔 오류·경고 없음.
- 390px viewport에서 단계 4개 표시, 문서 가로 넘침 없음. override는 해제했다.

## 한계

새 22개 기술의 실행기와 내장 예제는 아직 구현하지 않았다. 문서의 실습 과제는 학습자가 수행할 작업이며 결과는 비워 두었다. 모든 브라우저·GPU·키보드 조합을 전수 검사하지 않았다. Monaco/Three.js 번들 크기 경고는 남는다. 공개 배포와 원격 push는 하지 않았다.
