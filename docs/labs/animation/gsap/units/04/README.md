## 선수 지식

3단위 「Ease의 시간 곡선」의 정규화 시간 및 속도 분포 실습 결과를 준비한다.

## 핵심 개념과 설명

### Transform

x 이동은 문서 흐름을 유지한다. width 변경은 이웃 배치에 영향을 줄 수 있다.

### 측정

비용은 속성 이름만으로 확정할 수 없다. Performance 기록의 layout 발생을 비교한다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-4.js에 x와 width 애니메이션을 만들고 성능 패널 기록을 저장한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 인접 카드 10개. 기준: x. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-4.md에 남긴다.
3. 변경 변수: 속성. 변경값: width. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 이웃 위치와 layout 이벤트 기록. 확인할 가설: 이웃 배치와 layout 기록이 달라질 수 있다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 속성 | x | width | 이웃 배치와 layout 기록이 달라질 수 있다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
