# GSAP · 12 Pin과 문서 흐름

단계: 스크롤과 수명주기 · 편집 가능한 예제 · 저장 ID: `gsap-step-12`

## 목표와 학습 후 역량

- 학습 결과: Pin의 역할을 설명한다. 입력 사례: 스크롤과 Tab.
- 산출물: 후속 section 위치와 포커스 가림 표. 포커스 처리 근거를 코드와 연결해 설명한다.

## 선수 지식

11단위 「Scrub 추종」의 Scrub 및 읽기 실습 결과를 준비한다.

## 핵심 개념과 설명

### Pin

pin은 일정 구간에서 요소를 고정한다. 고정 공간은 뒤 콘텐츠의 배치와 연결된다.

### 포커스

고정 영역이 포커스를 가릴 수 있다. Tab 이동도 별도로 검사한다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-12.js에 pinSpacing을 바꾸고 고정 section에 링크 세 개를 둔다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 스크롤과 Tab. 기준: true. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-12.md에 남긴다.
3. 변경 변수: pinSpacing. 변경값: false. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 후속 section 위치와 포커스 가림 표. 확인할 가설: 뒤 콘텐츠와 겹칠 가능성이 바뀐다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| pinSpacing | true | false | 뒤 콘텐츠와 겹칠 가능성이 바뀐다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 필수 산출물: 후속 section 위치와 포커스 가림 표. 기준 및 변경 조건 각각의 결과가 있어 총 2조건을 비교할 수 있고, 입력값과 실행 환경을 함께 기록했다.
- [ ] 두 조건의 차이에 관한 설명에 다음 개념을 모두 연결했다: Pin, 포커스. 예상과 다른 항목은 원인 또는 미해결 이유를 1개 이상 적었다.
