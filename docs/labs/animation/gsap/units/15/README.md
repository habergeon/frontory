## 선수 지식

14단위 「Scroll과 수명주기」의 기존 예제 범위 및 정리 실습 결과를 준비한다.

## 핵심 개념과 설명

### 반응형 모션

matchMedia는 조건별 모션을 구성한다. 조건 변경 때 이전 설정도 정리한다.

### 거리 단위

고정 px는 작은 화면을 넘을 수 있다. 함수형 값은 기준 크기를 명시해야 한다.

## 실습 준비

기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-15.js에 600px 경계로 이동 거리를 나누고 모션 감소 조건을 추가한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 폭 375·1024px. 기준: 1024px. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-15.md에 남긴다.
3. 변경 변수: 화면 폭. 변경값: 375px. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 폭별 최종 위치와 정리 횟수. 확인할 가설: 카드가 작은 컨테이너 안에 남는다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 화면 폭 | 1024px | 375px | 카드가 작은 컨테이너 안에 남는다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 필수 산출물: 폭별 최종 위치와 정리 횟수. 기준 및 변경 조건 각각의 결과가 있어 총 2조건을 비교할 수 있고, 입력값과 실행 환경을 함께 기록했다.
- [ ] 두 조건의 차이에 관한 설명에 다음 개념을 모두 연결했다: 반응형 모션, 거리 단위. 예상과 다른 항목은 원인 또는 미해결 이유를 1개 이상 적었다.
