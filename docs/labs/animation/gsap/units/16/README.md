# GSAP · 16 연속 입력과 Overwrite

## 목표와 학습 후 역량

- 학습 결과: 경합의 역할을 설명한다. 입력 사례: 교차 클릭 10회.
- 산출물: 마지막 목표와 최종 x 값. Overwrite 처리 근거를 코드와 연결해 설명한다.

## 선수 지식

15단위 「MatchMedia 분기」의 반응형 모션 및 거리 단위 실습 결과를 준비한다.

## 핵심 개념과 설명

### 경합

여러 tween이 같은 속성을 쓰면 목표가 충돌한다. 마지막 입력 우선 여부를 먼저 정한다.

### Overwrite

overwrite:auto는 충돌 속성을 정리한다. 독립 속성의 모션까지 중단할 필요는 없다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-16.js에 좌우 버튼의 x tween에 overwrite:auto를 적용한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 교차 클릭 10회. 기준: 800ms. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-16.md에 남긴다.
3. 변경 변수: 입력 간격. 변경값: 80ms. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 마지막 목표와 최종 x 값. 확인할 가설: 빠른 입력에도 마지막 목표에 도달한다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 입력 간격 | 800ms | 80ms | 빠른 입력에도 마지막 목표에 도달한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 필수 산출물: 마지막 목표와 최종 x 값. 기준 및 변경 조건 각각의 결과가 있어 총 2조건을 비교할 수 있고, 입력값과 실행 환경을 함께 기록했다.
- [ ] 두 조건의 차이에 관한 설명에 다음 개념을 모두 연결했다: 경합, Overwrite. 예상과 다른 항목은 원인 또는 미해결 이유를 1개 이상 적었다.
