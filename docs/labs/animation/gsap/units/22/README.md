## 핵심 개념과 설명

### Attr

SVG 수치 속성과 CSS 스타일은 다르다. attr로 변경 대상을 명시할 수 있다.

### ViewBox

viewBox는 사용자 좌표계를 만든다. 표시 크기와 좌표 값은 동일하지 않다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-22.js에 circle의 attr cx·r과 opacity를 각각 tween한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: viewBox 0 0 200 100. 기준: 200px. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-22.md에 남긴다.
3. 변경 변수: 표시 폭. 변경값: 400px. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 끝점 속성과 표시 위치 표. 확인할 가설: 속성은 같고 표시 크기만 달라진다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 표시 폭 | 200px | 400px | 속성은 같고 표시 크기만 달라진다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
