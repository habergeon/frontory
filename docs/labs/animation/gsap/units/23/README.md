## 선수 지식

22단위 「SVG 속성 제어」의 Attr 및 ViewBox 실습 결과를 준비한다.

## 핵심 개념과 설명

### 객체 값

GSAP은 일반 객체 값도 보간한다. Canvas는 값이 바뀌면 다시 그려야 한다.

### Ticker

ticker 등록은 반복 작업을 만든다. dispose에서 같은 함수를 제거해야 한다.

## 실습 준비

기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-23.js에 점 x를 tween하고 gsap.ticker.add/remove로 Canvas를 그린다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 시작·정지·해제. 기준: 1회. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-23.md에 남긴다.
3. 변경 변수: 재마운트. 변경값: 5회. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 그리기 호출 수와 최종 좌표. 확인할 가설: 해제 뒤 그리기가 멈추고 중복 등록이 없다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
