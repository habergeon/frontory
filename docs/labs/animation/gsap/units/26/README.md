## 선수 지식

25단위 「숨김과 복귀」의 백그라운드 및 재개 정책 실습 결과를 준비한다.

## 핵심 개념과 설명

### 의미

시간과 거리에 이름을 붙여 공유한다. 모든 효과를 똑같이 만들 필요는 없다.

### 변경 영향

토큰 변경은 사용처로 전파된다. 강조 동작과 짧은 피드백을 분리한다.

## 실습 준비

기존 gsap-01·02·03은 시작 예제다. 새 단위는 별도 로컬 GSAP 프로젝트에서 작성한다. gsap-02 미리보기는 기본 scroll 이벤트를 사용하며 ScrollTrigger는 외부 프로젝트에서 설치·등록한다. CSP와 iframe 격리는 유지한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-26.js에 motionTokens 객체를 만들고 short·emphasis를 적용한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 세 단계의 같은 버튼 입력. 기준: 0.2초. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-26.md에 남긴다.
3. 변경 변수: short 시간. 변경값: 0.4초. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 토큰 사용처와 설정 표. 확인할 가설: short 사용 동작만 길어진다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| short 시간 | 0.2초 | 0.4초 | short 사용 동작만 길어진다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 필수 산출물: 토큰 사용처와 설정 표. 기준 및 변경 조건 각각의 결과가 있어 총 2조건을 비교할 수 있고, 입력값과 실행 환경을 함께 기록했다.
- [ ] 두 조건의 차이에 관한 설명에 다음 개념을 모두 연결했다: 의미, 변경 영향. 예상과 다른 항목은 원인 또는 미해결 이유를 1개 이상 적었다.
