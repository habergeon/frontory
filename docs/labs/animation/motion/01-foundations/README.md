## 핵심 개념과 설명

### 목표 상태

UI 상태는 도착할 값을 결정한다. 중간 프레임을 React 상태에 저장할 필요는 없다.

### API 경계

기존 미리보기는 Motion JS animate API다. React 실습은 별도 프로젝트에서 motion/react를 사용한다.

## 실습 준비

기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-1.tsx에 React 프로젝트에 motion을 설치하고 motion.div의 animate를 선택 상태에 연결한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 선택·해제 카드. 기준: 0.3초. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-1.md에 남긴다.
3. 변경 변수: duration. 변경값: 0.8초. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 상태값과 최종 opacity·x 표. 확인할 가설: 최종 상태는 같고 중간 전환만 길어진다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| duration | 0.3초 | 0.8초 | 최종 상태는 같고 중간 전환만 길어진다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
