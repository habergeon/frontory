## 핵심 개념과 설명

### 동등한 기능

drag와 hover는 유일한 조작 수단이 되어서는 안 된다. 버튼과 키보드로 같은 결과를 제공한다.

### 종합 검증

모션 감소는 이동을 단순화한다. 최종 데이터·포커스·안내는 유지되어야 한다.

## 실습 준비

기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-28.tsx에 기존 motion-03 JS 예제의 의도를 참고해 React 카드 보드를 완성한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 포인터 없는 재정렬·연속 삭제·reduce. 기준: drag. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-28.md에 남긴다.
3. 변경 변수: 조작 방식, 변경값: 키보드 버튼. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 입력별 ID 배열과 포커스·내용 검증 보고서. 확인할 가설: 같은 완료 상태를 확인할 수 있다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
