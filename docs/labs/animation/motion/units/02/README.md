## 핵심 개념과 설명

### Initial

initial은 처음 나타날 때의 출발 상태다. 현재 선택 상태와 항상 같지는 않다.

### 첫 표시

초기 모션을 생략할 때 initial=false를 사용할 수 있다. 재마운트와 일반 렌더를 구분한다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-2.tsx에 motion.div의 initial·animate와 initial=false 버전을 만든다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 첫 마운트와 상태 변경. 기준: 명시적 시작값. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-2.md에 남긴다.
3. 변경 변수: initial. 변경값: false. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 최초·전환 후 스타일 표. 확인할 가설: 첫 등장은 생략하고 후속 상태 전환은 유지된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |

| initial | 명시적 시작값 | false | 첫 등장은 생략하고 후속 상태 전환은 유지된다. |
