## 목표와 학습 후 역량

- 학습 결과: 키프레임의 역할을 설명한다. 입력 사례: 0→100→60 위치.
- 산출물: 각 지정 시점의 위치 표. Times 처리 근거를 코드와 연결해 설명한다.

## 선수 지식

4단위 「Spring의 물리 변수」의 Stiffness 및 Damping 실습 결과를 준비한다.

## 핵심 개념과 설명

### 키프레임

배열은 중간 목표를 정의한다. 시작과 끝만 있는 전환과 궤적이 달라진다.

### Times

times는 각 목표의 정규화 시점을 정한다. 배열 길이와 순서가 맞아야 한다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-5.tsx에 animate의 x 배열과 transition.times를 구성한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 0→100→60 위치. 기준: 0.5. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-5.md에 남긴다.
3. 변경 변수: 중간 시점. 변경값: 0.2. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 각 지정 시점의 위치 표. 확인할 가설: 중간 목표에 더 일찍 도달한다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 중간 시점 | 0.5 | 0.2 | 중간 목표에 더 일찍 도달한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 두 조건의 차이에 관한 설명에 다음 개념을 모두 연결했다: 키프레임, Times. 예상과 다른 항목은 원인 또는 미해결 이유를 1개 이상 적었다.
