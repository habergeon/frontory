- 산출물: 부모·자식 목표 상태 표. 전파 처리 근거를 코드와 연결해 설명한다.

## 선수 지식

5단위 「Keyframes」의 키프레임 및 Times 실습 결과를 준비한다.

## 핵심 개념과 설명

### 이름 있는 상태

variants는 시각 상태를 이름으로 묶는다. 도메인 상태에서 이름을 선택할 수 있다.

### 전파

부모 variant는 자식에게 전달될 수 있다. 자식에 독립 animate를 주면 관계가 달라진다.

## 실습 준비

기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-6.tsx에 idle·selected variants를 카드와 아이콘에 정의한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 두 카드 선택 변경. 기준: 부모 상속. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-6.md에 남긴다.
3. 변경 변수: 자식 제어. 변경값: 독립 animate. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 부모·자식 목표 상태 표. 확인할 가설: 자식의 상태 전파 경로가 달라진다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
