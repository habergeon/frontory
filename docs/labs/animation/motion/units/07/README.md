### Orchestration

### Stagger

stagger는 자식 시작 시점을 벌린다. 긴 목록에 큰 지연을 주면 끝 항목이 늦게 보인다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-7.tsx에 현대 Motion stagger 함수와 delayChildren으로 카드 등장을 구성한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 카드 4개와 12개. 기준: 0.05초. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-7.md에 남긴다.
3. 변경 변수: 간격. 변경값: 0.2초. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 첫·마지막 카드 등장 시각. 확인할 가설: 마지막 카드의 대기 시간이 증가한다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
