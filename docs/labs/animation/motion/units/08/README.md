## 핵심 개념과 설명

### Layout

layout은 이전과 다음 레이아웃 차이를 애니메이션한다. 최종 문서 배치는 React와 CSS가 결정한다.

### Transform 보간

시각적 이동과 실제 배치를 구별해야 한다. 크기 변화는 자식 콘텐츠에 왜곡을 줄 수 있다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-8.tsx에 motion 카드에 layout을 넣고 Grid 열 수를 변경한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 1열·3열 토글. 기준: 3열. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-8.md에 남긴다.
3. 변경 변수: 열 수, 변경값: 1열. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 최종 배치와 전환 중 텍스트 관찰 기록. 확인할 가설: 배치는 바뀌고 카드가 새 위치로 보간된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 열 수 | 3열 | 1열 | 배치는 바뀌고 카드가 새 위치로 보간된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
