## 핵심 개념과 설명

### DOM 수명

exit 중인 요소는 화면에 남을 수 있다. 데이터상 제거된 카드에 추가 조작을 허용할지 결정해야 한다.

### 포커스 복구

삭제한 버튼의 포커스는 다음 유효 위치로 옮긴다. 애니메이션 완료만 기다리면 조작 공백이 생긴다.

## 실습 준비

기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-13.tsx에 삭제 버튼에 ref를 두고 다음 카드 또는 추가 버튼으로 포커스를 옮긴다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 첫·중간·마지막 카드 삭제. 기준: 중간. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-13.md에 남긴다.
3. 변경 변수: 삭제 위치. 변경값: 마지막. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 삭제 위치별 activeElement 기록. 확인할 가설: 남은 유효 조작으로 포커스가 이동한다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
