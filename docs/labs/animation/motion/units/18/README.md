## 핵심 개념과 설명

### Momentum

드래그 종료 뒤 관성이 이어질 수 있다. 드롭 완료 시점과 움직임 정지 시점이 다르다.

### Elastic

elastic은 경계 밖으로 당기는 정도를 조절한다. 허용 범위를 데이터 좌표와 혼동하지 않는다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-18.tsx에 dragMomentum·dragElastic을 조합하고 종료 좌표를 기록한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 같은 방향의 짧은 드래그. 기준: true. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-18.md에 남긴다.
3. 변경 변수: momentum, 변경값: false. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 포인터 해제·최종 위치 표. 확인할 가설: 해제 뒤 추가 이동이 줄어든다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
