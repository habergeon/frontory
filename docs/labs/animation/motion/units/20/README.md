## 핵심 개념과 설명

### 별도 값

MotionValue는 매 프레임 React 렌더 없이 갱신할 수 있다. UI의 영속 데이터와 역할이 다르다.

### 구독

값 변경 구독은 수명에 맞게 정리해야 한다. 모든 프레임을 state로 복사하면 이점이 줄어든다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-20.tsx에 useMotionValue와 useMotionValueEvent로 x를 추적하고 렌더 횟수를 센다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 드래그 1회. 기준: 매 변경 setState. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-20.md에 남긴다.
3. 변경 변수: 저장 방식. 변경값: MotionValue. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 값 변경 수와 React 렌더 수. 확인할 가설: 값 변경과 렌더 횟수가 분리된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
