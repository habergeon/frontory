## 핵심 개념과 설명

### InView

화면 진입 감지는 요소가 보이는 조건을 다룬다. 렌더 여부와 같은 의미가 아니다.

### Once

once는 최초 진입만 실행하도록 한다. 반복 노출 콘텐츠의 의도와 맞춰야 한다.

## 실습 준비

기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-23.tsx에 whileInView와 viewport.once를 설정한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 스크롤로 진입·이탈 3회. 기준: false. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-23.md에 남긴다.
3. 변경 변수: once. 변경값: true. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 회차별 실행 횟수. 확인할 가설: 두 번째 진입부터 반복 모션이 생략된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
