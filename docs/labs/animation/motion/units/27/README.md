## 핵심 개념과 설명

### 수명

컴포넌트 제거는 구독과 모션의 수명을 끝낸다. 데이터 저장 위치는 별도로 정한다.

### 복구

다시 보일 때 이전 순서를 유지할지 정해야 한다. key 변경을 임의 초기화 수단으로 남용하지 않는다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 motion-01·02·03은 Motion JS animate 기반의 제한된 예제다. React layout·AnimatePresence·hooks는 별도 로컬 React 프로젝트에 motion을 설치하고 motion/react에서 가져와 실습한다. 편집기에서 JSX가 바로 실행된다고 가정하지 않으며 CSP와 격리를 유지한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-27.tsx에 보드 표시 토글과 상위 순서 상태를 연결하고 5회 재마운트한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 재정렬 후 숨김·표시. 기준: 카드 내부. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-27.md에 남긴다.
3. 변경 변수: 상태 위치, 변경값: 보드 상위. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 순서·구독·포커스 복구 표. 확인할 가설: 보드 재표시 뒤 순서가 보존된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
