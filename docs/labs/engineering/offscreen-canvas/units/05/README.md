## 선수 지식

4단위 「Context 생성 실패」의 Context 및 복구 Canvas 실습 결과를 준비한다.

## 핵심 개념과 설명

### CSS 크기

CSS 크기는 화면 배치를 정한다. 실제 픽셀 저장소 크기와 다르다.

### DPR

DPR은 CSS 픽셀과 저장소 픽셀의 비율이다. 렌더와 입력이 같은 단위를 사용해야 한다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 기존 offscreen-canvas-01·02·03은 지원 브라우저에서 사용하는 시작 예제다. 새 단위는 별도 로컬 HTTP 프로젝트의 메인·Worker 파일에서 구현한다. API와 context 지원을 확인하고 이전 실패 시 새 Canvas의 메인 fallback을 제공한다. CSP와 격리는 유지하며 성능 수치를 직접 기록한다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-5.js에 CSS 크기와 DPR로 buffer 크기를 설정하고 setTransform을 적용한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 100 CSS px 정사각형. 기준: 1. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-5.md에 남긴다.
3. 변경 변수: DPR. 변경값: 2. 같은 입력 경로로 다시 실행한다. 저장할 산출물: CSS·buffer 크기와 도형 폭. 확인할 가설: 도형의 화면 크기는 같고 저장소 해상도는 증가한다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| DPR | 1 | 2 | 도형의 화면 크기는 같고 저장소 해상도는 증가한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
