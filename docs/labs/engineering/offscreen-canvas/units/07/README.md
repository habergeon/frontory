# OffscreenCanvas · 07 기초 렌더 검증

단계: 제어권과 첫 렌더 · 문서 기반 직접 구현 · 저장 ID: `offscreen-canvas-step-07`

## 목표와 학습 후 역량

- 학습 결과: 동등성의 역할을 설명한다. 입력 사례: 동일 seed와 입자 10개.
- 산출물: 좌표 배열과 정지 화면 기록. 검증 범위 처리 근거를 코드와 연결해 설명한다.

## 선수 지식

6단위 「프레임 시간」의 Delta 및 큰 간격 실습 결과를 준비한다.

## 핵심 개념과 설명

### 동등성

같은 초기 상태로 비교해야 실행 위치의 차이를 볼 수 있다. 랜덤 초기값은 seed를 고정한다.

### 검증 범위

픽셀 비교는 환경 차이의 영향을 받는다. 좌표와 색상 같은 상태 검증도 함께 사용한다.

## 실습 준비

기존 offscreen-canvas-01·02·03은 지원 브라우저에서 사용하는 시작 예제다. 새 단위는 별도 로컬 HTTP 프로젝트의 메인·Worker 파일에서 구현한다. API와 context 지원을 확인하고 이전 실패 시 새 Canvas의 메인 fallback을 제공한다. CSP와 격리는 유지하며 성능 수치를 직접 기록한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-7.js에 seed와 draw 함수를 공유해 두 모드의 정지 장면을 출력한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 동일 seed와 입자 10개. 기준: 7. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-7.md에 남긴다.
3. 변경 변수: seed. 변경값: 11. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 좌표 배열과 정지 화면 기록. 확인할 가설: 같은 seed끼리는 같고 다른 seed는 다른 배치를 만든다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| seed | 7 | 11 | 같은 seed끼리는 같고 다른 seed는 다른 배치를 만든다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
