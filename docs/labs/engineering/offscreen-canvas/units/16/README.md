## 핵심 개념과 설명

### TypedArray

입자 속성을 연속 배열로 저장할 수 있다. 속성별 stride와 offset을 명확히 정한다.

### 소유권

transfer한 배열은 메인에서 재사용하지 않는다. UI에 필요한 요약은 별도 메시지로 받는다.

## 실습 준비

기존 offscreen-canvas-01·02·03은 지원 브라우저에서 사용하는 시작 예제다. 새 단위는 별도 로컬 HTTP 프로젝트의 메인·Worker 파일에서 구현한다. API와 context 지원을 확인하고 이전 실패 시 새 Canvas의 메인 fallback을 제공한다. CSP와 격리는 유지하며 성능 수치를 직접 기록한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-16.js에 Float32Array 위치를 transfer하고 Worker에서 입자를 그린다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 입자 100개. 기준: 복사. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-16.md에 남긴다.
3. 변경 변수: 전송. 변경값: transfer. 같은 입력 경로로 다시 실행한다. 저장할 산출물: byteLength와 입자 좌표 범위. 확인할 가설: 이전 후 메인 buffer가 detach된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
