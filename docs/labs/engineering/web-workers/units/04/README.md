## 핵심 개념과 설명

### 복사

postMessage의 일반 객체는 구조화 복제된다. 송신 뒤 객체를 수정해도 수신 객체와 별개다.

### 복제 제한

함수와 DOM 노드는 일반 메시지로 복제할 수 없다. 실패를 전송 단계에서 처리해야 한다.

## 실습 준비

기존 web-workers-01·02·03은 시작 예제이며 새 과제는 별도 로컬 HTTP 프로젝트의 main.js와 worker.js로 작성한다. CSP와 iframe 격리를 유지한다. SharedArrayBuffer는 자신이 통제하는 외부 서버의 COOP·COEP 조건을 확인하며 미충족 시 transfer 경로를 사용한다. 성능 수치는 직접 측정한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-4.js에 중첩 객체를 전송한 뒤 원본을 수정하고 함수 포함 메시지도 시도한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 객체와 함수 필드. 기준: 숫자. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-4.md에 남긴다.
3. 변경 변수: 필드. 변경값: 함수. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 송수신 값 및 DataCloneError 기록. 확인할 가설: 복제 불가능한 값은 전송 오류로 분리된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
