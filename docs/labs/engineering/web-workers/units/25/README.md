## 핵심 개념과 설명

### 왕복 비용

Worker 내부 계산만 재면 직렬화와 대기 비용을 놓친다. 요청 전송부터 UI 반영까지 측정한다.

### 시계 기준

문맥별 시계 원점은 구분해야 한다. 메인 왕복과 Worker 내부 duration을 별도로 기록한다.

## 실습 준비

기존 web-workers-01·02·03은 시작 예제이며 새 과제는 별도 로컬 HTTP 프로젝트의 main.js와 worker.js로 작성한다. CSP와 iframe 격리를 유지한다. SharedArrayBuffer는 자신이 통제하는 외부 서버의 COOP·COEP 조건을 확인하며 미충족 시 transfer 경로를 사용한다. 성능 수치는 직접 측정한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-25.js에 메인 performance.now와 Worker 계산 duration을 응답에 담는다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 세 배열 크기. 기준: 작은 배열. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-25.md에 남긴다.
3. 변경 변수: 데이터 크기. 변경값: 큰 배열. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 왕복·계산·잔여 구간 표. 확인할 가설: 통신과 계산의 비중이 달라질 수 있다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
