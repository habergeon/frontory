## 핵심 개념과 설명

### 수명 관리

페이지 기능 종료 시 Worker·타이머·포트를 정리한다. 이미 종료된 요청도 pending에서 제거한다.

### 반복 실행

새 세대 ID는 이전 응답과 구분된다. dispose를 두 번 호출해도 안전해야 한다.

## 실습 준비

기존 web-workers-01·02·03은 시작 예제이며 새 과제는 별도 로컬 HTTP 프로젝트의 main.js와 worker.js로 작성한다. CSP와 iframe 격리를 유지한다. SharedArrayBuffer는 자신이 통제하는 외부 서버의 COOP·COEP 조건을 확인하며 미충족 시 transfer 경로를 사용한다. 성능 수치는 직접 측정한다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 별도 실습 프로젝트의 src/day-27.js에 dispose에서 terminate·clearTimeout·port.close를 수행하고 재시작한다. 기존 1·14·28단위 예제는 출발점으로만 참고한다.
2. 입력 조건: 실행·해제·재시작 5회. 기준: 완료 뒤. 기준 조건에서 실행한 뒤 관찰값과 오류를 notes/day-27.md에 남긴다.
3. 변경 변수: 해제 시점. 변경값: 계산 중. 같은 입력 경로로 다시 실행한다. 저장할 산출물: 세대별 완료 ID와 잔여 자원 수. 확인할 가설: 중단 작업이 남지 않고 새 작업은 정상 완료된다. 실제 결과와 비교해 일치 여부 및 차이의 원인을 기록한다.
