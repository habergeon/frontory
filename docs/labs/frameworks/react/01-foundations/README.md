# React · 01 상태와 소유권

## 목표와 학습 후 역량

하나의 변경이 목록과 합계에 일관되게 반영된다. 이를 자신의 말로 설명하고 작은 결과물로 재현하는 것이 목표입니다.

## 선수 지식

JavaScript·TypeScript, DOM 이벤트.

## 핵심 개념과 설명

render는 UI 계산이며 effect는 외부 시스템과의 동기화입니다. 파생 값은 불필요한 별도 상태로 중복하지 않습니다.

## 실습 준비

이 단위는 Frontory에서 대표 예제를 편집하고 실행할 수 있습니다. 문서의 확장 과제는 직접 구현하세요. JSX·Vue SFC·Svelte 컴포넌트를 그대로 입력하는 범용 컴파일러는 아니며 지원 범위는 아래 연결된 예제 안내에 명시합니다.

## 실습 과제

1. 공식 참고에서 이번 개념과 API의 입력·출력을 찾아 필기에 요약합니다.
2. 학습 목록과 필터를 컴포넌트로 나누고 완료 수를 파생하세요. props와 로컬 상태의 소유권을 그림으로 적으세요.
3. 아래 변수 중 하나만 바꾸기 전에 예상 결과를 적고, 실행 후 스크린샷·로그 또는 측정값과 비교합니다.
4. 원래 조건으로 되돌려 같은 결과를 재현하고 오류·지원 제한도 남깁니다.

## 관찰할 변수

선택 항목, 필터, 상태 위치. 비교 시 다른 변수와 브라우저·viewport 조건은 고정합니다.

## 완료 조건

- [ ] 하나의 변경이 목록과 합계에 일관되게 반영된다.
- [ ] 최소 두 조건의 예상과 실제 결과를 구분해 기록했다.
- [ ] 오류 또는 경계 조건 한 가지를 재현하고 복구 방법을 적었다.
- [ ] 실제로 수행한 내용을 기준으로 완료 상태를 직접 표시했다.

## 자가 점검

1. 상태와 소유권에서 입력이 결과로 이어지는 경로를 설명할 수 있나요?
2. 선택 항목, 필터, 상태 위치 중 어떤 변수가 예상과 다르게 동작했으며 이유는 무엇인가요?
3. 하나의 변경이 목록과 합계에 일관되게 반영된다. 이 조건이 깨지는 사례와 확인 방법은 무엇인가요?
