## 핵심 개념과 설명

### 보존 정책

key는 에디터의 정체성을 결정합니다. 필기 데이터는 단위 id로 저장하고 임시 UI 상태의 초기화 규칙을 따로 정합니다.

### 근거 있는 개선

성능 변경은 동일 데이터와 입력에서 비교해야 합니다. 빠르다는 주장 대신 측정값과 남은 병목을 기록합니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. 기존 react-03 미리보기는 출발점입니다. 본문의 확장 결과물은 별도 프로젝트에서 구현합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/StudyWorkspace.jsx에서 A·B 전환과 초안 복원을 최종 점검하세요.
2. 21단위 측정 절차로 1000개 카드 입력을 기록하고 memo 또는 페이지 정책 한 가지만 바꾸세요.
3. notes/final.md에 상태 소유권·자원 해제표·전후 Profiler 기록·실패 사례를 묶어 제출하세요.
