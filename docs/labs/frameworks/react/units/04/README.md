## 선수 지식

4단위는 3단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 불변 갱신

객체를 직접 수정하면 이전 렌더의 스냅샷도 오염됩니다. 변경 경로를 복사해 새 참조를 전달합니다.

### 부분 변경

map은 대상 id만 새 객체로 바꾸는 데 적합합니다. 변경하지 않은 항목의 참조는 유지할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/model.js에 toggle(items,id)를 작성하세요.
2. App.jsx의 setter에 함수형 갱신을 사용해 toggle을 연결하세요.
3. 입력 배열을 복사해 보관하고 대상·비대상 객체의 참조와 done을 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 변경 대상 | id 1 | id 2 | 선택한 항목의 객체만 새 참조가 된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
