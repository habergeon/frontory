## 선수 지식

7단위는 6단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 제어 입력

value와 onChange를 함께 제공하면 React 상태가 입력 원본이 됩니다. 초기값을 빈 문자열로 두어 제어 여부가 바뀌지 않게 합니다.

### 폼 제출

form의 submit 이벤트는 Enter와 버튼 제출을 함께 처리합니다. 검증 실패는 입력을 지우지 않고 사용자가 고칠 위치를 알려야 합니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/AddCardForm.jsx에 label·input·submit 버튼을 작성하세요.
2. 공백을 제거한 제목이 비면 오류를 표시하고 유효하면 새 id로 카드를 추가하세요.
3. 공백 입력과 한글 제목을 Enter로 제출해 목록 개수를 기록하세요.
