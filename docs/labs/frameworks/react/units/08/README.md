- 제목 수정이 목록과 상세에 함께 반영된다.

## 선수 지식

8단위는 7단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 공유 상태

형제 컴포넌트가 같은 선택을 보여 주면 공통 부모가 상태를 소유합니다. 자식은 콜백으로 변경 의도를 알립니다.

### 최소 상태

선택 객체 전체보다 id를 저장하면 목록 변경과 동기화하기 쉽습니다. 선택 상세는 현재 목록에서 찾아 계산합니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/App.jsx에 selectedId를 두고 List와 Detail에 전달하세요.
2. List 클릭으로 선택을 바꾸고 Detail에서 제목을 수정하는 콜백을 연결하세요.
3. 선택한 카드를 삭제할 때 빈 상세로 돌아가는 규칙을 구현하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 선택 저장값 | 객체 사본 | id | 제목 수정 후 목록과 상세가 같은 최신 제목을 보여 준다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
