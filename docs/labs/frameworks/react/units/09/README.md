## 핵심 개념과 설명

### reducer

reducer는 현재 상태와 action으로 다음 상태를 계산합니다. 같은 입력에는 같은 출력을 반환하고 저장이나 타이머를 실행하지 않습니다.

### action 설계

action은 add·toggle·remove처럼 사용자 의도를 표현합니다. 여러 필드를 함께 바꿔야 하는 규칙을 한 곳에서 검토할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/reducer.js에 add·toggle·remove action을 구현하세요.
2. useReducer로 App의 카드와 selectedId를 함께 관리하세요.
3. 선택 카드 삭제 action을 실행하고 카드 제거와 선택 해제를 동시에 확인하세요.

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
