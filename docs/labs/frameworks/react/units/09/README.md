## 핵심 개념과 설명

### reducer

reducer는 현재 상태와 action으로 다음 상태를 계산합니다. 같은 입력에는 같은 출력을 반환하고 저장이나 타이머를 실행하지 않습니다.

### action 설계

action은 add·toggle·remove처럼 사용자 의도를 표현합니다. 여러 필드를 함께 바꿔야 하는 규칙을 한 곳에서 검토할 수 있습니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/reducer.js에 add·toggle·remove action을 구현하세요.
2. useReducer로 App의 카드와 selectedId를 함께 관리하세요.
3. 선택 카드 삭제 action을 실행하고 카드 제거와 선택 해제를 동시에 확인하세요.
