## 핵심 개념과 설명

### ref

useRef는 렌더 사이에 값을 보관하지만 변경만으로 렌더를 요청하지 않습니다. 화면에 표시할 데이터와 DOM 핸들을 구분합니다.

### DOM 접근

ref.current는 DOM이 연결된 뒤 사용할 수 있습니다. 포커스 이동은 렌더 함수 안에서 수행하지 않습니다.
