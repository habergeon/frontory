## 선수 지식

11단위는 10단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### ref

useRef는 렌더 사이에 값을 보관하지만 변경만으로 렌더를 요청하지 않습니다. 화면에 표시할 데이터와 DOM 핸들을 구분합니다.

### DOM 접근

ref.current는 DOM이 연결된 뒤 사용할 수 있습니다. 포커스 이동은 렌더 함수 안에서 수행하지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/AddCardForm.jsx의 input에 ref를 연결하세요.
2. 추가 성공 후 입력을 비우고 focus를 호출하세요.
3. ref 카운터와 state 카운터를 나란히 두고 각 버튼 입력의 화면 갱신을 비교하세요.

| 카운터 저장소 | ref       | state     | state 변경만 즉시 카운터 텍스트를 갱신한다. |
