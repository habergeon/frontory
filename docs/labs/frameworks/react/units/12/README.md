- 활성 연결 수가 표시 중 1·제거 후 0이다.

## 선수 지식

12단위는 11단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 동기화

Effect는 렌더 결과를 외부 시스템과 맞춥니다. 계산 가능한 파생 값에는 Effect가 필요하지 않습니다.

### 정리 순서

의존성이 바뀌면 이전 설정의 cleanup 후 새 설정을 시작합니다. 개발 StrictMode의 추가 실행은 정리 누락을 드러내는 검사입니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Connection.jsx에 channel prop을 받아 연결·해제 로그를 내는 Effect를 만드세요.
2. 의존성 배열에 channel을 넣고 A→B→A로 바꾸세요.
3. 조건부 렌더로 컴포넌트를 제거해 마지막 연결도 해제되는지 세세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| channel | A 유지 | B로 변경 | A 해제 뒤 B 연결 로그가 나온다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
