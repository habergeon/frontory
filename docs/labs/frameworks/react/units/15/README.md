## 선수 지식

15단위는 14단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 로직 재사용

커스텀 Hook은 상태 있는 로직을 묶습니다. Hook을 두 번 호출하면 기본적으로 서로 다른 상태와 Effect가 생깁니다.

### 호출 규칙

Hook은 컴포넌트나 Hook의 최상위에서 호출합니다. 조건은 Hook 내부 로직에서 처리해 호출 순서를 유지합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/useWindowSize.js로 resize 구독과 cleanup을 추출하세요.
2. 크기를 표시하는 패널 두 개에서 Hook을 호출하세요.
3. 한 패널을 제거하고 남은 패널의 갱신과 구독 수를 확인하세요.

## 관찰할 변수

| Hook 소비자 | 1개 | 2개 | 독립 호출마다 구독이 생기므로 제거 시 하나씩 정리된다. |
