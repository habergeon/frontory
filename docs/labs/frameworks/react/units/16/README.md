## 목표와 학습 후 역량

- 새로 열었을 때 저장한 단위별 초안이 복원된다.
- 잘못된 JSON에도 편집 입력이 가능하다.

## 선수 지식

16단위는 15단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 지연 초기화

useState 초기화 함수는 초기 상태 계산을 분리합니다. 저장된 JSON은 형식 검증 후 상태로 사용해야 합니다.

### 외부 저장

localStorage 쓰기는 실패할 수 있는 외부 동작입니다. 화면 초안과 저장 성공 여부를 구분하면 실패를 숨기지 않습니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/storage.js에 버전·단위 id·문자열을 검사하는 읽기 함수를 만드세요.
2. useNotes.js에서 초기 복원과 변경 후 저장을 연결하세요.
3. 정상 JSON·깨진 JSON·저장 예외를 각각 주입해 초안과 오류 문구를 확인하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 저장 데이터 | 유효 JSON | 깨진 JSON | 빈 초안과 오류 안내로 복구하며 화면이 계속 작동한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
