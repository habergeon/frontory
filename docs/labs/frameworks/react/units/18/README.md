## 핵심 개념과 설명

### 합성

children은 부모가 전달한 UI를 배치하는 입력입니다. 레이아웃이 카드 데이터 구조를 몰라도 내용을 감쌀 수 있습니다.

### 책임 제한

여러 boolean으로 모든 화면을 처리하면 조합이 급격히 늘어납니다. 슬롯 역할의 props나 children으로 공통 레이아웃과 내용을 분리합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Panel.jsx에 제목·도구 영역·children을 배치하세요.
2. 목록 패널과 필기 패널에 같은 Panel을 사용하세요.
3. 한 패널에만 저장 버튼을 전달하고 다른 패널에 빈 공간이 남는지 확인하세요.
