## 목표와 학습 후 역량

- 두 조건 각각 10회 기록이 있다.
- React 렌더 비용과 Canvas 비용을 혼동하지 않고 적는다.

## 선수 지식

21단위는 20단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 측정 범위

Profiler는 React 커밋의 렌더 비용을 관찰합니다. GPU 렌더 시간이나 네트워크 시간을 대신 측정하지 않습니다.

### 비교 조건

개발 모드와 입력 데이터가 다르면 시간 비교가 왜곡됩니다. 같은 동작을 여러 번 기록해 범위와 편차를 남깁니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/App.jsx에서 목록을 Profiler로 감싸 onRender 기록을 저장하세요.
2. 동일한 1000개 카드로 입력 10회와 선택 10회를 따로 수행하세요.
3. notes/profile.md에 actualDuration·커밋 수·환경을 정리하고 가장 큰 경로 하나를 고르세요.
