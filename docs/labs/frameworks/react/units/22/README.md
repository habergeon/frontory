## 핵심 개념과 설명

### memo

memo는 props가 같을 때 자식 렌더를 건너뛸 수 있게 합니다. 매번 새 객체나 함수를 전달하면 비교 결과가 달라질 수 있습니다.

### 캐시 비용

useMemo와 useCallback도 의존성 관리와 저장 비용이 있습니다. 성능 최적화 여부는 동일 조건 측정으로 판단합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/CardRow.jsx의 병목 후보에 memo를 적용하세요.
2. 필요한 props만 전달하고 이벤트 함수의 정체성을 확인하세요.
3. 21단위 입력을 반복해 전후 커밋·시간을 비교하고 효과가 없으면 이유를 적으세요.
