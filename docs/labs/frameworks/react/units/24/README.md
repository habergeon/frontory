## 선수 지식

24단위는 23단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 이벤트 전파

자식 버튼 클릭은 부모 클릭 핸들러로 전파될 수 있습니다. 중첩된 상호작용은 역할을 분리하거나 의도적으로 전파를 제어합니다.

### 네이티브 조작

button은 키보드 동작과 포커스를 기본 제공받습니다. div에 클릭만 붙이면 같은 사용 경로가 생기지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/CardRow.jsx의 선택과 삭제를 별도 button으로 나누세요.
2. 삭제 클릭이 선택 변경까지 일으키는지 로그로 확인하세요.
3. Tab·Enter·Space만으로 선택과 삭제를 수행하고 포커스 복귀를 구현하세요.
