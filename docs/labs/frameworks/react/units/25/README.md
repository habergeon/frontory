## 선수 지식

25단위는 24단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 외부 저장소

React 밖에서 갱신되는 저장소는 구독과 스냅샷 읽기가 필요합니다. useSyncExternalStore는 React가 이 계약을 이용해 읽도록 합니다.

### 스냅샷 안정성

변경이 없으면 getSnapshot은 같은 값을 반환해야 합니다. 매번 새 객체를 만들면 변경을 구분하기 어렵습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/store.js에 getSnapshot·subscribe·update를 구현하세요.
2. useSyncExternalStore로 두 패널에 같은 선택 id를 표시하세요.
3. 외부 update를 호출하고 패널을 차례로 제거해 구독 수를 확인하세요.

## 관찰할 변수

| 변수   | 기준 조건    | 바꿀 조건         | 예상할 변화·검증 가설                               |
| ------ | ------------ | ----------------- | --------------------------------------------------- |
| 스냅샷 | 매번 새 객체 | 변경 때만 새 객체 | 변경이 없는 읽기가 불필요한 갱신을 유발하지 않는다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
