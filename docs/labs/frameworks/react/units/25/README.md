## 선수 지식

## 핵심 개념과 설명

### 외부 저장소

React 밖에서 갱신되는 저장소는 구독과 스냅샷 읽기가 필요합니다. useSyncExternalStore는 React가 이 계약을 이용해 읽도록 합니다.

### 스냅샷 안정성

변경이 없으면 getSnapshot은 같은 값을 반환해야 합니다. 매번 새 객체를 만들면 변경을 구분하기 어렵습니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/store.js에 getSnapshot·subscribe·update를 구현하세요.
2. useSyncExternalStore로 두 패널에 같은 선택 id를 표시하세요.
3. 외부 update를 호출하고 패널을 차례로 제거해 구독 수를 확인하세요.
