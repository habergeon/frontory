## 선수 지식

## 핵심 개념과 설명

### 통합 경계

필기·검색·Canvas는 갱신 속도와 수명이 다릅니다. 각 영역의 소유자를 나누면 전환 중 데이터와 자원을 추적하기 쉽습니다.

### 감사 기록

생성·해제 횟수만 같아도 아직 살아 있는 자원을 놓칠 수 있습니다. 최종 활성 수와 기능 복원을 함께 확인합니다.

## 실습 준비

별도 React Vite 프로젝트의 JSX 실습입니다. Node와 패키지 버전·lockfile을 기록하고 프로젝트 개발 서버에서 실행하세요. 내장 편집기는 범용 JSX 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/StudyWorkspace.jsx에 목록·필기·ThreeScene을 합치세요.
2. 단위 10회 전환 중 입력과 Canvas 숨김을 섞어 실행하세요.
3. notes/audit.md에 초안 id·활성 루프·리스너·저장 오류 처리 결과를 기록하세요.
