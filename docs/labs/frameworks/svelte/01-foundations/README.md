# Svelte · 01 컴파일과 반응성

## 목표와 학습 후 역량

파생 값을 중복 저장하지 않고 갱신 과정을 설명한다. 이를 자신의 말로 설명하고 작은 결과물로 재현하는 것이 목표입니다.

## 선수 지식

JavaScript·HTML·CSS.

## 핵심 개념과 설명

Svelte의 컴파일 기반 UI와 runes의 상태·파생 값을 구분합니다. React의 재실행 모델과 동일하다고 가정하지 않습니다.

## 실습 준비

이 단위는 Frontory에서 대표 예제를 편집하고 실행할 수 있습니다. 문서의 확장 과제는 직접 구현하세요. JSX·Vue SFC·Svelte 컴포넌트를 그대로 입력하는 범용 컴파일러는 아니며 지원 범위는 아래 연결된 예제 안내에 명시합니다.

## 실습 과제

1. 공식 참고에서 이번 개념과 API의 입력·출력을 찾아 필기에 요약합니다.
2. 별도 Svelte Vite 실습에서 $state와 $derived로 목록·필터·합계를 구현하세요.
3. 아래 변수 중 하나만 바꾸기 전에 예상 결과를 적고, 실행 후 스크린샷·로그 또는 측정값과 비교합니다.
4. 원래 조건으로 되돌려 같은 결과를 재현하고 오류·지원 제한도 남깁니다.

## 관찰할 변수

필터, 상태 갱신 위치. 비교 시 다른 변수와 브라우저·viewport 조건은 고정합니다.

## 완료 조건

- [ ] 파생 값을 중복 저장하지 않고 갱신 과정을 설명한다.
- [ ] 최소 두 조건의 예상과 실제 결과를 구분해 기록했다.
- [ ] 오류 또는 경계 조건 한 가지를 재현하고 복구 방법을 적었다.
- [ ] 실제로 수행한 내용을 기준으로 완료 상태를 직접 표시했다.

## 자가 점검

1. 컴파일과 반응성에서 입력이 결과로 이어지는 경로를 설명할 수 있나요?
2. 필터, 상태 갱신 위치 중 어떤 변수가 예상과 다르게 동작했으며 이유는 무엇인가요?
3. 파생 값을 중복 저장하지 않고 갱신 과정을 설명한다. 이 조건이 깨지는 사례와 확인 방법은 무엇인가요?
