## 핵심 개념과 설명

### 컴파일

Svelte는 .svelte 소스의 템플릿과 반응형 선언을 컴파일합니다. store와 DOM을 연결한 내장 어댑터는 컴파일된 컴포넌트가 아닙니다.

### runes

$state는 변하는 값을 선언하고 $derived는 계산 가능한 값을 표현합니다. 완료 수를 따로 저장하지 않으면 목록과 합계의 불일치를 줄입니다.

## 실습 준비

별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다. 기존 svelte-01 미리보기는 출발점입니다. 본문의 확장 결과물은 별도 프로젝트에서 구현합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 Svelte Vite 프로젝트 src/App.svelte에 카드 3개를 $state로 선언하세요.
2. $derived로 미완료 필터 결과와 완료 수를 계산하고 버튼을 연결하세요.
3. 내장 svelte-01의 writable 구독과 실제 컴포넌트의 갱신 경로를 notes/day01.md에서 구분하세요.
