## 목표와 학습 후 역량

주관적 선호와 관찰한 구현 차이를 구분한 비교 기록이 있다. 이를 자신의 말로 설명하고 작은 결과물로 재현하는 것이 목표입니다.

## 선수 지식

이 시리즈 2단위의 결과물과 기록.

## 핵심 개념과 설명

같은 요구사항으로 구현해야 프레임워크의 차이를 공정하게 비교할 수 있습니다.

## 실습 준비

현재 Frontory 안에서는 이 문서를 읽고 단위별 필기를 저장합니다. 이 시리즈의 내장 실행기는 아직 제공하지 않습니다. 외부 패키지는 아래 공식 설치 안내에 맞춰 별도 로컬 Vite 실습에 구성하고 버전과 lockfile을 기록하세요. 브라우저 API는 먼저 지원 여부를 확인합니다. 현재 WebGL 편집기에 JSX·Vue SFC·WGSL을 그대로 넣어 실행할 수 있다는 뜻은 아닙니다.

## 실습 과제

1. 공식 참고에서 이번 개념과 API의 입력·출력을 찾아 필기에 요약합니다.
2. React·Vue·Svelte의 학습 카드 구현을 비교하고 상태·구독·정리 코드를 표로 작성하세요.
3. 아래 변수 중 하나만 바꾸기 전에 예상 결과를 적고, 실행 후 스크린샷·로그 또는 측정값과 비교합니다.
4. 원래 조건으로 되돌려 같은 결과를 재현하고 오류·지원 제한도 남깁니다.

## 관찰할 변수

동일한 데이터·기능. 비교 시 다른 변수와 브라우저·viewport 조건은 고정합니다.

## 완료 조건

- [ ] 주관적 선호와 관찰한 구현 차이를 구분한 비교 기록이 있다.
- [ ] 최소 두 조건의 예상과 실제 결과를 구분해 기록했다.
- [ ] 오류 또는 경계 조건 한 가지를 재현하고 복구 방법을 적었다.
- [ ] 실제로 수행한 내용을 기준으로 완료 상태를 직접 표시했다.

## 자가 점검

1. 프레임워크 비교에서 입력이 결과로 이어지는 경로를 설명할 수 있나요?
2. 동일한 데이터·기능 중 어떤 변수가 예상과 다르게 동작했으며 이유는 무엇인가요?
3. 주관적 선호와 관찰한 구현 차이를 구분한 비교 기록이 있다. 이 조건이 깨지는 사례와 확인 방법은 무엇인가요?
