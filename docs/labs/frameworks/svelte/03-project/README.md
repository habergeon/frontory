## 핵심 개념과 설명

### 실행 모델 비교

React의 렌더 계산·Vue의 반응성·Svelte의 컴파일 갱신은 같은 내부 모델이 아닙니다. 같은 UI 계약을 구현한 코드와 관찰 결과로 차이를 설명합니다.

### 증거와 선호

한 실험 결과는 사용한 데이터와 환경에 한정됩니다. 측정값·확인한 수명·개인 선호를 분리해 기록합니다.

## 실습 준비

별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다. 기존 svelte-03 미리보기는 출발점입니다. 본문의 확장 결과물은 별도 프로젝트에서 구현합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 프로젝트의 실제 Svelte 컴포넌트와 React·Vue 카드 구현에 같은 조작 10회를 실행하세요.
2. 상태·파생·구독·정리 코드와 A/B 초안 복귀 결과를 notes/final.md에 표로 쓰세요.
3. 내장 svelte-03은 store 어댑터임을 표시하고 미실행·실패·측정 한계를 함께 제출하세요.
