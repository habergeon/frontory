# Svelte · 04 $derived로 필터 계산하기

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 컴파일과 runes 기초 · 문서 기반 직접 구현 · 저장 ID: `svelte-step-04`

## 목표와 학습 후 역량

- 필터 결과 수가 일치하는 제목 수와 같다.
- 정렬 뒤 원본 id 순서가 변하지 않는다.

## 선수 지식

4단위는 3단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 의존성 추적

$derived는 계산 중 읽은 반응형 값에 의존합니다. 저장이나 요청 같은 부수 효과를 계산식 안에 넣지 않습니다.

### 여러 단계 계산

$derived.by는 여러 문장이 필요한 계산을 표현합니다. 결과를 반환하고 원본 배열을 변경하지 않아야 합니다.

## 실습 준비

별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/App.svelte에 query와 onlyOpen을 추가하세요.
2. $derived.by에서 필터 후 복사 배열을 정렬하세요.
3. 검색과 완료 토글을 조합하고 원본 순서와 결과 순서를 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 검색어 | 빈 문자열 | 카드 제목 일부 | 일치하는 카드만 보이고 원본 배열 순서는 유지된다. |
