# Svelte · 07 폼 바인딩과 검증

## 목표와 학습 후 역량

- 공백 제출 후 카드 수가 그대로다.
- Enter 제출 뒤 제목이 같은 카드가 1개 추가된다.

## 선수 지식

7단위는 6단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### bind:value

bind:value는 입력과 상태를 연결합니다. 숫자·빈 입력의 실제 값과 타입을 확인해 검증 규칙을 정합니다.

### 제출 경로

form 제출은 키보드와 버튼을 같은 경로로 처리합니다. 실패 입력을 남겨 사용자가 수정할 수 있게 합니다.

## 실습 준비

별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/AddCard.svelte에 label·bind:value·onsubmit을 작성하세요.
2. submit에서 preventDefault하고 공백 제목을 거절하세요.
3. 빈 제목·한글 제목·Enter 제출을 각각 실행해 카드 수를 적으세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 제목 | 공백 | 새 카드 | 공백은 거절하고 새 카드는 한 번 추가한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
