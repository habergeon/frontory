## 선수 지식

9단위는 8단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 양방향 연결

$bindable은 부모가 바인딩할 수 있는 prop을 명시합니다. 모든 prop을 양방향으로 만들면 변경 경로가 흐려집니다.

### 편집 데이터

단위별 초안은 에디터 수명보다 오래 보관할 수 있어야 합니다. 부모가 문자열을 소유하고 편집기가 변경을 전달하도록 구성합니다.

## 실습 준비

별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/NoteEditor.svelte에서 value = $bindable('')를 선언하세요.
2. textarea bind:value와 부모의 bind:value={draft}를 연결하세요.
3. 같은 draft를 읽는 출력 패널을 만들고 입력·제거·재표시 결과를 확인하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 값 전달 | 일반 prop | bindable 바인딩 | 편집 입력이 부모 초안에 반영된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
