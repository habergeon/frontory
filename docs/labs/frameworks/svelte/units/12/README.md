## 선수 지식

12단위는 11단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 외부 동기화

$effect는 Canvas나 외부 구독과 상태를 동기화할 때 사용합니다. 파생 텍스트는 $derived로 계산해 불필요한 쓰기를 줄입니다.

### 동기 추적

Effect가 동기적으로 읽은 반응형 값이 의존성이 됩니다. 반환한 정리 함수는 재실행 전과 종료 시 기존 작업을 해제합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Clock.svelte에 period를 읽는 $effect와 setInterval을 만드세요.
2. Effect에서 clearInterval 함수를 반환하세요.
3. period 100→500→100으로 바꾸고 활성 타이머 수와 tick 간격을 기록하세요.

## 관찰할 변수

| 변수   | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                              |
| ------ | --------- | --------- | -------------------------------------------------- |
| period | 100ms     | 500ms     | 기존 타이머를 정리한 뒤 느린 타이머 하나만 남는다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
