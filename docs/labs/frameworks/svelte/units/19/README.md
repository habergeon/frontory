## 선수 지식

19단위는 18단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### Promise 표시

{#await}는 Promise의 대기·성공·실패 화면을 나눕니다. 빈 배열도 성공 결과의 한 종류로 처리합니다.

### 사용자 복구

실패 안내에는 재시도나 다른 입력 경로가 필요합니다. 이전 결과를 유지할지 비울지도 화면 계약으로 정합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Results.svelte에 pending·then·catch 블록을 작성하세요.
2. fakeSearch에서 지연 성공·빈 배열·실패를 선택하는 입력을 만드세요.
3. 실패 후 재시도를 연결하고 세 출력 상태를 기록하세요.
