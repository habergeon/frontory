# Svelte · 20 초안 저장과 복원

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: store와 작업공간 상태 · 외부 실행 예제 · 미리보기 안내 · 저장 ID: `svelte-step-20`

## 목표와 학습 후 역량

- 정상 A·B 초안이 각각 복원된다.
- 쓰기 실패 뒤 입력한 문자열이 화면에 남는다.

## 선수 지식

20단위는 19단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 저장 형식

JSON에는 버전과 단위별 문자열을 저장합니다. Proxy를 외부로 전달할 때는 $state.snapshot 등 명시적인 데이터 경계를 검토합니다.

### 실패 유지

저장 실패가 편집 실패가 되어서는 안 됩니다. 메모리 초안을 남기고 실패 메시지와 재시도 경로를 분리합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/persistence.js에 버전·문자열 검증과 읽기·쓰기를 만드세요.
2. App.svelte 초기화에서 복원하고 변경 후 저장 상태를 표시하세요.
3. 정상 JSON·잘린 JSON·쓰기 실패를 주입해 초안과 오류 출력을 확인하세요.

## 관찰할 변수
