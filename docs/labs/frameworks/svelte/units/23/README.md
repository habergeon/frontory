## 선수 지식

## 핵심 개념과 설명

### 스타일 범위

Svelte 컴포넌트 스타일은 해당 마크업 범위로 제한됩니다. 전역 규칙을 쓰면 다른 컴포넌트에 미치는 영향을 확인해야 합니다.

### 키보드 계약

클릭 가능한 항목은 네이티브 버튼으로 표현합니다. 컴파일러 접근성 경고는 실제 키보드 확인과 함께 읽습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Card.svelte의 클릭 div를 button으로 바꾸고 aria-pressed를 연결하세요.
2. 포커스 스타일을 컴포넌트 CSS에 추가하세요.
3. Tab·Enter·Space로 카드 선택과 완료 토글을 수행하고 경고 출력을 검토하세요.
