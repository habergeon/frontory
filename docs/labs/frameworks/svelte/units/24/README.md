## 선수 지식

## 핵심 개념과 설명

### 전환

transition은 요소가 나타나거나 사라질 때 시각 변화를 적용합니다. 시각적으로 사라지는 시간과 데이터 변경 시점을 구분합니다.

### 동작 선호

모션 감소 선호를 반영하면 필수 기능을 움직임 없이 사용할 수 있습니다. 전환 종료를 저장 완료 조건으로 사용하지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/EditorPanel.svelte에 fade 전환을 추가하세요.
2. 모션 감소 조건에서는 duration을 0으로 설정하세요.
3. 빠르게 표시·숨김을 반복하고 DOM·자원 정리 시점과 필기 보존을 기록하세요.

| duration | 300ms | 0ms | 기능과 초안은 같고 시각 전환 시간만 달라진다. |
