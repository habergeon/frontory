## 선수 지식

25단위는 24단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 컴파일 산출물

소스 길이와 브라우저가 실행하는 결과는 다릅니다. 빌드 결과를 보고 어떤 코드와 의존성이 포함되는지 확인합니다.

### 공정한 측정

같은 데이터·입력·빌드 모드에서 비교해야 합니다. React의 Profiler 수치를 Svelte 전체 렌더 시간과 같은 지표로 취급하지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 프로젝트를 빌드하고 dist 자산 크기와 설정을 notes/build.md에 기록하세요.
2. 100개와 1000개 카드에서 같은 필터 입력 10회를 측정하세요.
3. 브라우저 성능 기록에서 스크립트·레이아웃 구간을 구분하세요.
