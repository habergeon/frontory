## 선수 지식

26단위는 25단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 동작 계약

추가·토글·필터·초안 보존을 입력과 출력으로 정의합니다. 세 프레임워크가 같은 계약을 충족해야 비교가 의미 있습니다.

### 테스트 독립성

각 실행은 같은 초기 데이터에서 시작해야 합니다. 저장소 잔여값과 타이머를 정리해 이전 실행의 영향을 제거합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. tests/workspace.spec.js에 카드 3개와 고정 id를 준비하세요.
2. 추가·토글·미완료 필터·A/B 초안 복귀를 검사하세요.
3. Canvas 숨김·재표시 후 이벤트 1회와 루프 1개도 확인하세요.
