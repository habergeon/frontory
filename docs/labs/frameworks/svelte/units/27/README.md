## 핵심 개념과 설명

### 동일 입력

비교 데이터의 id·제목·완료 상태와 조작 순서를 고정합니다. 기능이 다르면 코드량과 반응 속도 비교의 근거가 약해집니다.

### 관찰 분리

구현 차이와 개인 선호는 별도로 기록합니다. 실제 실행하지 못한 항목은 미실행으로 표시합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Svelte 5 Vite 프로젝트에서 .svelte 파일을 컴파일해 실행합니다. 패키지 버전과 lockfile을 기록하세요. Frontory의 Svelte 미리보기는 실제 writable와 명시적 DOM 어댑터이며 .svelte 컴파일러나 runes 실행기가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. notes/comparison-plan.md에 카드 3개·토글·필터·A/B 필기 계약을 적으세요.
2. React·Vue 별도 프로젝트에 같은 데이터를 공급하고 실행 환경을 기록하세요.
3. 상태·파생·이벤트·cleanup의 대응 코드 위치를 모으세요.
