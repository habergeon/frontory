## 핵심 개념과 설명

### ref

ref는 반응형 값을 감싸며 스크립트에서는 .value로 읽고 씁니다. 템플릿에서는 최상위 ref를 자동으로 풀어 표시합니다.

### computed

computed는 읽은 반응형 값에서 결과를 계산합니다. 완료 수처럼 원본에서 구할 값은 별도 ref에 복사하지 않습니다.

## 실습 준비
