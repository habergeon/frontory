## 목표와 학습 후 역량

- A 입력 후 B 전환에도 B 저장값이 오염되지 않는다.
- 연속 입력 5회 뒤 마지막 값만 저장 완료된다.

## 선수 지식

14단위는 13단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 초안과 저장

부모가 단위별 초안을 소유하면 에디터 교체에도 문자열을 보존합니다. 저장 대기 상태는 실제 저장 완료와 구분해야 합니다.

### 지연 작업의 식별

타이머가 실행될 때 현재 단위를 읽으면 다른 필기를 덮을 수 있습니다. 시작 시 id와 문자열을 캡처하고 이전 타이머를 정리합니다.

## 실습 준비

별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다. 기존 vue-02 미리보기는 출발점입니다. 본문의 확장 결과물은 별도 프로젝트에서 구현합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/NoteEditor.vue를 props/emits로 연결하고 draftsById를 부모에 만드세요.
2. watch의 입력에서 id·text·delay를 캡처해 지연 저장하고 onCleanup으로 clearTimeout하세요.
3. A 입력 직후 B로 전환한 뒤 savedById와 draftsById를 비교하세요.
