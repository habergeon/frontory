## 선수 지식

2단위는 1단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### SFC

.vue 파일은 템플릿·로직·스타일을 한 컴포넌트로 컴파일합니다. 런타임 h 함수 예제와 빌드가 필요한 SFC를 구분합니다.

### 바인딩

v-bind는 속성에 표현식 결과를 전달합니다. 문자열 속성과 동적 boolean 속성은 브라우저에서 의미가 다릅니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Card.vue에 script setup과 template을 작성하세요.
2. :disabled와 :aria-pressed를 완료 상태에 연결하세요.
3. 고정 문자열 disabled와 boolean 바인딩을 비교하고 DOM 속성을 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| disabled 값 | false | true | 버튼의 실제 조작 가능 여부가 바뀐다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] false 바인딩에서 버튼을 클릭할 수 있다.
- [ ] true 바인딩에서 버튼이 비활성이다.
