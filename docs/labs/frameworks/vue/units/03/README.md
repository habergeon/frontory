## 핵심 개념과 설명

### reactive

reactive는 객체 속성 접근을 추적하는 Proxy를 만듭니다. 반응형 객체를 일반 값으로 구조 분해하면 연결이 끊길 수 있습니다.

### ref 선택

ref는 객체 교체를 포함한 하나의 값에 적합합니다. 객체 속성을 따로 전달해야 한다면 toRefs 같은 연결 수단을 검토합니다.

## 실습 준비

별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/Filters.vue에 reactive({query:'',onlyOpen:false})를 만드세요.
2. 구조 분해한 query와 toRefs로 받은 query를 각각 표시하세요.
3. 입력에서 원본 query를 바꾸고 두 표시의 차이를 기록하세요.
