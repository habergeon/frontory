## 선수 지식

4단위는 3단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 파생 계산

computed getter는 의존성이 바뀔 때 계산 결과를 갱신합니다. getter 안에서 저장이나 원본 변경을 수행하지 않습니다.

### 캐시

반응형 의존성이 바뀌지 않으면 계산 결과를 재사용합니다. 일반 함수 호출과 구분해 비용과 의미를 판단합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/App.vue에 query와 items를 읽는 filteredCards computed를 작성하세요.
2. 계산 횟수 로그를 넣고 관련 없는 theme ref를 변경하세요.
3. query를 바꾼 뒤 결과와 계산 로그가 어떻게 달라지는지 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 변경 대상 | theme | query | query 변경이 필터 계산의 의존성을 갱신한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
