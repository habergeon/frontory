## 핵심 개념과 설명

### 이벤트

v-on은 템플릿 이벤트를 함수에 연결합니다. 이벤트 객체와 직접 전달한 인자를 구분해 변경 의도를 명확히 합니다.

### 입력 모델

v-model은 입력값과 상태의 연결을 간결하게 표현합니다. 숫자 입력과 빈 문자열은 별도 경계 조건이므로 변환 결과를 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/CardForm.vue에 제목 v-model과 목표 횟수 v-model.number를 만드세요.
2. form @submit.prevent에서 공백 제목을 거절하고 새 카드를 추가하세요.
3. 횟수 3·빈 입력·한글 제목을 제출해 저장한 값과 타입을 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 횟수 입력 | 3 | 빈 문자열 | 빈 입력을 숫자 0으로 무조건 가정하지 않고 검증한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
