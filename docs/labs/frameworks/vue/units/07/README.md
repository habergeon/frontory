## 핵심 개념과 설명

### 선언적 스타일

class와 style 바인딩은 상태에서 표시를 계산합니다. DOM 클래스를 직접 수정하면 다음 렌더 결과와 충돌할 수 있습니다.

### 의미 전달

색상만으로 완료를 표시하면 의미를 놓칠 수 있습니다. 텍스트와 aria 속성도 같은 상태에서 계산합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Card.vue에서 :class에 done과 selected 조건을 전달하세요.
2. 완료 텍스트와 aria-pressed를 연결하고 scoped CSS로 두 상태를 구분하세요.
3. 완료·선택의 네 조합을 만들어 스크린샷과 DOM 값을 적으세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 상태 조합 | 완료 false·선택 false | 완료 true·선택 true | 두 상태가 충돌하지 않고 각각 표현된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
