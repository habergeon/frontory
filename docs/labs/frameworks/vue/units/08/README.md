## 목표와 학습 후 역량

- 자식 코드에 props 직접 대입이 없다.
- 부모 제목 변경 후 자식 제목이 일치한다.

## 선수 지식

8단위는 7단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### props

props는 부모가 소유한 입력입니다. 자식이 직접 변경하면 소유권과 변경 경로를 추적하기 어렵습니다.

### 기본값과 검증

props의 타입과 기본값은 컴포넌트 사용 조건을 드러냅니다. 런타임 데이터 검증 전체를 자동으로 대신하지는 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Card.vue에서 defineProps로 id·title·done을 선언하세요.
2. 부모가 입력을 바꾸면 자식 표시가 달라지도록 연결하세요.
3. 자식 내부 직접 변경 코드를 제거하고 읽기 전용 역할을 notes/contracts.md에 적으세요.

## 관찰할 변수

| 변수       | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설             |
| ---------- | --------- | --------- | --------------------------------- |
| title 입력 | 상태      | 반응성    | 부모 변경이 자식 제목에 반영된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
