# Vue · 08 props의 단방향 계약

## 목표와 학습 후 역량

- 자식 코드에 props 직접 대입이 없다.
- 부모 제목 변경 후 자식 제목이 일치한다.

## 선수 지식

8단위는 7단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### props

props는 부모가 소유한 입력입니다. 자식이 직접 변경하면 소유권과 변경 경로를 추적하기 어렵습니다.

### 기본값과 검증

props의 타입과 기본값은 컴포넌트 사용 조건을 드러냅니다. 런타임 데이터 검증 전체를 자동으로 대신하지는 않습니다.

## 실습 준비

별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/Card.vue에서 defineProps로 id·title·done을 선언하세요.
2. 부모가 입력을 바꾸면 자식 표시가 달라지도록 연결하세요.
3. 자식 내부 직접 변경 코드를 제거하고 읽기 전용 역할을 notes/contracts.md에 적으세요.

## 관찰할 변수
