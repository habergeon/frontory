# Vue · 09 emits로 변경 의도 전달

## 목표와 학습 후 역량

- 클릭 1회에 toggle 이벤트가 1개 발생한다.
- 정렬 후 클릭한 카드만 완료 상태가 바뀐다.

## 선수 지식

9단위는 8단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 컴포넌트 이벤트

defineEmits는 자식이 알릴 사건을 선언합니다. 부모는 사건을 받아 실제 상태 변경을 결정합니다.

### payload

이벤트에는 변경 대상 id와 필요한 값을 전달합니다. DOM 이벤트 객체 전체를 넘기는 것보다 계약이 분명해집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Card.vue에 toggle 이벤트를 선언하고 id를 전달하세요.
2. App.vue의 @toggle에서 해당 id의 done만 바꾸세요.
3. 세 카드의 이벤트 로그를 남기고 클릭한 id와 변경한 id를 대조하세요.

## 관찰할 변수

| 변수    | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설             |
| ------- | --------- | --------- | --------------------------------- |
| payload | 배열 순번 | 카드 id   | 정렬 후에도 같은 대상이 변경된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
