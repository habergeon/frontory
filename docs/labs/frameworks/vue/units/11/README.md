## 선수 지식

11단위는 10단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 슬롯

슬롯은 부모가 제공한 내용을 자식 레이아웃에 배치합니다. 부모가 쓴 템플릿 표현식은 부모 범위를 사용합니다.

### 범위 슬롯

자식 데이터를 부모가 렌더해야 할 때 슬롯 props로 전달합니다. 데이터 소유권과 표시 책임을 나누어 재사용합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/Panel.vue에 header·default·footer 슬롯을 만드세요.
2. 목록과 메모 패널에 서로 다른 header와 footer를 넣으세요.
3. CardList의 item 슬롯으로 부모가 제목과 완료 배지를 그리게 하세요.
