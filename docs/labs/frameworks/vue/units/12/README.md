## 목표와 학습 후 역량

- theme 변경은 검색 요청을 시작하지 않는다.
- query 변경 후 요청 로그에 최신 문자열이 남는다.

## 선수 지식

12단위는 11단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 명시적 감시

watch는 지정한 반응형 소스 변화에 부수 효과를 실행합니다. 계산 결과 자체가 필요하면 computed가 더 직접적입니다.

### 감시 범위

객체 전체의 깊은 감시는 많은 변경에 반응할 수 있습니다. getter로 필요한 필드만 읽으면 감시 의도를 좁힐 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/useSearch.js에서 watch(() => filters.query, ...)를 작성하세요.
2. query 변경 횟수와 요청 시작 로그를 표시하세요.
3. theme·onlyOpen·query를 차례로 바꾸고 감시가 실행된 항목을 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건              | 바꿀 조건    | 예상할 변화·검증 가설                 |
| --------- | ---------------------- | ------------ | ------------------------------------- |
| 감시 소스 | 전체 filters 깊은 감시 | query getter | 검색어 변경에만 요청 시작이 연결된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
