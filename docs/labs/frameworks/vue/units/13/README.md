## 목표와 학습 후 역량

- 최종 결과가 최신 B 입력과 일치한다.
- 컴포넌트 제거 후 요청 갱신이 반영되지 않는다.

## 선수 지식

13단위는 12단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### cleanup

watch 콜백의 onCleanup은 이전 작업을 정리할 함수를 등록합니다. 재실행 전에 타이머나 요청을 취소해 이전 작업의 영향을 제한합니다.

### 응답 정합성

늦은 응답이 최신 검색 결과를 덮을 수 있습니다. 요청 id를 함께 검사하면 취소만으로 처리하지 못한 완료 경로도 구분합니다.

## 실습 준비

별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/useSearch.js에 AbortController와 onCleanup을 추가하세요.
2. fakeSearch에서 A 800ms·B 100ms 지연을 만드세요.
3. A 다음 B를 입력하고 최종 query·결과 id·취소 기록을 대조하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 응답 지연 | 동일 100ms | A 800ms·B 100ms | B 결과를 늦은 A가 덮지 않는다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
