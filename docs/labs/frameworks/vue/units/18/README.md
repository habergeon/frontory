## 목표와 학습 후 역량

- 두 작업공간이 서로 다른 문자열을 보존한다.
- reset이 지정한 작업공간만 비운다.

## 선수 지식

18단위는 17단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 공유 반응성

모듈 범위 reactive는 여러 컴포넌트가 같은 객체를 읽게 합니다. 컴포넌트별 초기화 함수와는 수명이 다릅니다.

### 초기화 경계

테스트나 여러 앱 인스턴스가 같은 모듈 상태를 공유하면 데이터가 섞일 수 있습니다. store factory로 범위를 명시할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/createNotesStore.js에 drafts·update·reset을 반환하는 함수를 작성하세요.
2. Workspace마다 저장소를 만들고 provide하세요.
3. 서로 다른 두 Workspace에 같은 단위 id로 다른 문자열을 입력하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 저장소 생성 | 모듈 한 개 | Workspace별 factory | 같은 id라도 두 작업공간의 초안이 분리된다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
