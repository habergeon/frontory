# Vue · 19 저장 복원과 데이터 검증

## 목표와 학습 후 역량

- 유효한 A·B 초안이 각각 복원된다.
- 잘못된 데이터에서도 새 입력을 유지한다.

## 선수 지식

19단위는 18단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 직렬화

JSON에는 반응형 Proxy 자체보다 저장할 데이터 구조를 기록합니다. 버전과 필드 검증을 거쳐야 오래된 데이터를 안전하게 읽습니다.

### 실패 대응

저장소 쓰기는 예외를 던질 수 있습니다. 메모리 초안을 유지하고 저장 실패를 별도로 알려야 입력을 잃지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/persistence.js에 버전 있는 notes JSON 읽기·쓰기 함수를 만드세요.
2. 초기 로딩 때 유효한 데이터만 store에 넣으세요.
3. 깨진 JSON과 쓰기 예외를 주입하고 화면 오류·초안 유지 결과를 적으세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 복원 입력 | 정상 JSON | 잘린 JSON | 오류를 알리고 빈 저장소로 편집을 계속한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
