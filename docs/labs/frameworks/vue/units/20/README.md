## 핵심 개념과 설명

### 지연 로딩

defineAsyncComponent는 컴포넌트 코드 로딩을 지연합니다. 데이터 요청 상태와 코드 로딩 상태는 서로 다른 실패 경로입니다.

### 오류 경계

로딩·오류 컴포넌트는 사용자에게 현재 상태를 설명합니다. 실패했을 때 돌아갈 화면이나 재시도 정책이 있어야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/App.vue에서 무거운 PreviewPanel.vue를 defineAsyncComponent로 불러오세요.
2. loadingComponent와 errorComponent를 지정하세요.
3. 모의 import Promise에 지연과 실패를 각각 넣고 안내 상태를 기록하세요.
