## 핵심 개념과 설명

### 업데이트 범위

props 안정성과 computed 의존성이 갱신 범위에 영향을 줍니다. 최적화 전에 어떤 컴포넌트가 바뀌는지 확인해야 합니다.

### 측정 조건

개발 도구 로그 자체도 실행 비용을 만듭니다. 같은 데이터·입력·빌드 조건으로 비교하고 측정 한계를 기록합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/CardList.vue에 1000개 카드를 공급하고 업데이트 횟수를 계측하세요.
2. 선택 id 전체 대신 행별 selected boolean을 전달하는 대조를 만드세요.
3. 선택 10회의 업데이트 수와 시간을 notes/performance.md에 적으세요.
