## 선수 지식

26단위는 25단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 사용자 흐름

컴포넌트 계약은 입력과 관찰 가능한 출력으로 확인합니다. 내부 ref 이름에 의존하면 구현 변경 때 검증이 쉽게 깨집니다.

### 시간 제어

지연 저장은 빠른 전환에서 다른 단위를 덮지 않아야 합니다. 고정 대기보다 저장 완료 조건이나 제어된 타이머를 사용합니다.

## 실습 준비

별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. tests/workspace.spec.js에 추가·토글·검색·A/B 초안 전환을 작성하세요.
2. 저장 지연 1000ms에서 A 입력 후 B 전환을 재현하세요.
3. Canvas 제거 후 활성 루프 0과 재표시 후 1도 검증하세요.
