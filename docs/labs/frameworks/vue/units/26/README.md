## 선수 지식

## 핵심 개념과 설명

### 사용자 흐름

컴포넌트 계약은 입력과 관찰 가능한 출력으로 확인합니다. 내부 ref 이름에 의존하면 구현 변경 때 검증이 쉽게 깨집니다.

### 시간 제어

지연 저장은 빠른 전환에서 다른 단위를 덮지 않아야 합니다. 고정 대기보다 저장 완료 조건이나 제어된 타이머를 사용합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 Vue Vite 프로젝트에서 .vue SFC와 script setup을 사용합니다. 패키지 버전과 lockfile을 기록하고 개발 서버에서 실행하세요. 내장 Vue 예제는 h 함수 기반이며 범용 SFC 컴파일러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. tests/workspace.spec.js에 추가·토글·검색·A/B 초안 전환을 작성하세요.
2. 저장 지연 1000ms에서 A 입력 후 B 전환을 재현하세요.
3. Canvas 제거 후 활성 루프 0과 재표시 후 1도 검증하세요.
