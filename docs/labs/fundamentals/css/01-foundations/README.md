## 핵심 개념과 설명

### 선언 선택

cascade는 출처·중요도·레이어·우선순위 등의 규칙으로 선언을 선택합니다. 개발자 도구의 계산값으로 실제 적용 이유를 확인합니다.

### 배치 모델

Grid는 행과 열의 관계를, Flex는 한 축의 항목 배치를 다룹니다. 항목의 최소 크기 때문에 긴 텍스트가 넘칠 수 있습니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 긴 제목 카드와 360px·1000px 컨테이너 조건의 콘텐츠를 준비하고 layout.css를 연결하세요.
2. 같은 카드 6개를 Grid와 Flex로 배치하고 min-width:0 전후와 승리한 선언을 확인하세요.
3. 긴 제목 카드와 360px·1000px 컨테이너 조건으로 실행하세요. 확인할 결과: 두 배치 방식의 넘침 원인을 계산값으로 설명한다. 360px에서 카드 제목과 조작이 잘리지 않는다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                                                               |
| --------- | --------- | --------- | ------------------------------------------------------------------------------------------------------------------- |
| 최소 너비 | auto      | 0         | 실행 전 가설: 항목이 줄어들어 가로 넘침이 줄어들 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
