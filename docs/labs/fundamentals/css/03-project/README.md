## 선수 지식

27단위 「contain과 오프스크린 콘텐츠」의 결과물과 실험 기록

## 핵심 개념과 설명

### 디자인 결정

색상·간격 토큰은 여러 요소에 같은 결정을 적용합니다. 테마를 바꿔도 텍스트 대비와 상태 구분을 유지해야 합니다.

### 근거 있는 조정

성능 개선은 실제 레이아웃과 페인트 기록으로 판단합니다. 요소 수와 속도가 다른 결과를 직접 비교하지 않습니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 카드 50개, 500ms 전환, 밝은·어두운 테마 조건의 콘텐츠를 준비하고 theme-report.css를 연결하세요.
2. 토큰 기반 두 테마를 완성하고 width·transform 전환을 같은 조건에서 기록해 report.md로 비교하세요.
3. 카드 50개, 500ms 전환, 밝은·어두운 테마 조건으로 실행하세요. 확인할 결과: 동일 조건의 두 성능 기록과 단계별 관찰이 있다. 두 테마의 본문 대비와 키보드 포커스를 문서화한다. 예상과 실제 결과는 구분해 기록하세요.
