## 핵심 개념과 설명

### 선택자 범위

선택자는 스타일을 적용할 요소를 찾습니다. 자손과 자식 결합자는 서로 다른 범위를 선택합니다.

### 우선순위

같은 cascade 조건 안에서는 specificity가 선언 선택에 관여합니다. !important를 반복하면 이후 조정이 어려워질 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 중첩 버튼 2개와 바깥 버튼 1개 조건의 콘텐츠를 준비하고 selectors.css를 연결하세요.
2. 카드 안 버튼과 바깥 버튼에 자손·자식·클래스 선택자를 적용해 매칭을 비교하세요.
3. 중첩 버튼 2개와 바깥 버튼 1개 조건으로 실행하세요. 확인할 결과: 각 선택자의 매칭 개수를 기록한다. 충돌 선언 두 개의 승리 이유를 specificity로 설명한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 결합자 | 공백 | 직접 자식 기호 | 실행 전 가설: 중첩 버튼 일부가 선택 대상에서 빠질 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
