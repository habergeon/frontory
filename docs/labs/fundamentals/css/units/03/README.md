## 핵심 개념과 설명

### 상속 속성

글자색 같은 속성은 부모에서 이어받을 수 있습니다. margin 같은 속성은 일반적으로 자동 상속되지 않습니다.

### 초기화 키워드

inherit·initial·unset은 서로 다른 초기화 규칙을 따릅니다. 속성이 상속되는지에 따라 unset의 결과가 달라집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 부모 1개와 자식 3개 조건의 콘텐츠를 준비하고 inheritance.css를 연결하세요.
2. 부모에 color와 border를 지정하고 자식에 세 초기화 키워드를 번갈아 적용하세요.
3. 부모 1개와 자식 3개 조건으로 실행하세요. 확인할 결과: color와 border의 계산값 6개를 기록한다. unset이 상속 속성과 비상속 속성에서 다르게 작동함을 확인한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 초기화 | initial | inherit | 실행 전 가설: 부모의 계산값을 따를 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 연결된 예제와 실행 범위

[예제 원본](../../../../../../src/labs/css-step-03/example.js) · [실행 환경과 제한](../../../../../examples.md)

initial, inherit, unset을 각각 바꾸고 계산된 color·border를 확인하세요. Shadow DOM에서 문서 body/html 선택자를 범위화합니다. @media는 외부 미리보기 viewport에 반응하며 폭 슬라이더는 컨테이너만 변경합니다. 네트워크·폼 이동·iframe 실행은 제한됩니다.


원본 코드·기록은 자동으로 덮어쓰지 않습니다. 기존 예제를 초기화할 때도 필기는 유지됩니다.
