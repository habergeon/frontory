## 핵심 개념과 설명

### 크기 합산

content-box의 width는 콘텐츠 영역 크기입니다. padding과 border가 바깥 크기에 더해집니다.

### 포함 계산

border-box는 지정 크기에 padding과 border를 포함합니다. margin은 여전히 외부 간격입니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 동일 카드 두 개 조건의 콘텐츠를 준비하고 box.css를 연결하세요.
2. width 200px 카드에 padding 20px와 border 2px를 넣고 getBoundingClientRect로 너비를 재세요.
3. 동일 카드 두 개 조건으로 실행하세요. 확인할 결과: 두 카드의 실제 너비를 기록한다. 콘텐츠·padding·border·margin 영역을 도구에서 구분한다. 예상과 실제 결과는 구분해 기록하세요.
