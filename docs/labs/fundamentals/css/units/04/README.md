## 핵심 개념과 설명

### 크기 합산

content-box의 width는 콘텐츠 영역 크기입니다. padding과 border가 바깥 크기에 더해집니다.

### 포함 계산

border-box는 지정 크기에 padding과 border를 포함합니다. margin은 여전히 외부 간격입니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 동일 카드 두 개 조건의 콘텐츠를 준비하고 box.css를 연결하세요.
2. width 200px 카드에 padding 20px와 border 2px를 넣고 getBoundingClientRect로 너비를 재세요.
3. 동일 카드 두 개 조건으로 실행하세요. 확인할 결과: 두 카드의 실제 너비를 기록한다. 콘텐츠·padding·border·margin 영역을 도구에서 구분한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| box-sizing | content-box | border-box | 실행 전 가설: 바깥 너비가 244px에서 200px로 바뀔 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 연결된 예제와 실행 범위

[예제 원본](../../../../../../src/labs/css-step-04/example.js) · [실행 환경과 제한](../../../../../examples.md)

box-sizing을 border-box로 바꿔 실측 너비 244px와 200px를 비교하세요. Shadow DOM에서 문서 body/html 선택자를 범위화합니다. @media는 외부 미리보기 viewport에 반응하며 폭 슬라이더는 컨테이너만 변경합니다. 네트워크·폼 이동·iframe 실행은 제한됩니다.
