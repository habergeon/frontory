## 핵심 개념과 설명

### 상대 단위

rem은 루트 글자 크기를 기준으로 합니다. em은 사용한 속성과 요소의 글자 크기 관계를 확인해야 합니다.

### 범위 제한

clamp는 최소·선호·최대 크기를 정합니다. 화면 폭만 따라 글자를 작게 만들지 않도록 최소값을 둡니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 360px·1200px 화면과 루트 16px 조건의 콘텐츠를 준비하고 units.css를 연결하세요.
2. 제목에 clamp를 쓰고 간격을 rem으로 지정해 루트 크기와 뷰포트를 바꾸세요.
3. 360px·1200px 화면과 루트 16px 조건으로 실행하세요. 확인할 결과: 두 화면에서 제목 크기가 지정 범위 안에 있다. 루트 변경 전후 글자와 간격 계산값을 기록한다. 예상과 실제 결과는 구분해 기록하세요.
