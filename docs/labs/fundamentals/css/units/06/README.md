## 핵심 개념과 설명

### 일반 흐름

블록 요소는 문서 흐름에 따라 쌓입니다. 위치 지정 없이도 콘텐츠 높이에 따라 뒤 요소가 이동합니다.

### 마진 상쇄

일부 블록의 세로 margin은 합쳐질 수 있습니다. 레이아웃 맥락이 달라지면 상쇄 여부도 달라집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 문단 2개와 배경 있는 부모 조건의 콘텐츠를 준비하고 flow.css를 연결하세요.
2. 연속 문단의 margin을 20px와 30px로 두고 부모에 flow-root 전후를 비교하세요.
3. 문단 2개와 배경 있는 부모 조건으로 실행하세요. 확인할 결과: 형제 간격과 부모 경계 위치를 각각 측정한다. 합산되지 않은 margin 사례를 설명한다. 예상과 실제 결과는 구분해 기록하세요.

[예제 원본](../../../../../../src/labs/css-step-06/example.js) · [실행 환경과 제한](../../../../../examples.md)

부모 flow-root는 부모/자식 마진 상쇄를 막지만 형제 문단끼리의 상쇄는 그대로입니다. Shadow DOM에서 문서 body/html 선택자를 범위화합니다. @media는 외부 미리보기 viewport에 반응하며 폭 슬라이더는 컨테이너만 변경합니다. 네트워크·폼 이동·iframe 실행은 제한됩니다.


원본 코드·기록은 자동으로 덮어쓰지 않습니다. 기존 예제를 초기화할 때도 필기는 유지됩니다.
