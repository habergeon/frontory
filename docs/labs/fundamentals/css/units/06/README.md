## 핵심 개념과 설명

### 일반 흐름

블록 요소는 문서 흐름에 따라 쌓입니다. 위치 지정 없이도 콘텐츠 높이에 따라 뒤 요소가 이동합니다.

### 마진 상쇄

일부 블록의 세로 margin은 합쳐질 수 있습니다. 레이아웃 맥락이 달라지면 상쇄 여부도 달라집니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 문단 2개와 배경 있는 부모 조건의 콘텐츠를 준비하고 flow.css를 연결하세요.
2. 연속 문단의 margin을 20px와 30px로 두고 부모에 flow-root 전후를 비교하세요.
3. 문단 2개와 배경 있는 부모 조건으로 실행하세요. 확인할 결과: 형제 간격과 부모 경계 위치를 각각 측정한다. 합산되지 않은 margin 사례를 설명한다. 예상과 실제 결과는 구분해 기록하세요.
