## 핵심 개념과 설명

### 최소 크기

min-content와 max-content는 콘텐츠 기반 크기를 표현합니다. 긴 단어는 예상보다 큰 최소 너비를 만들 수 있습니다.

### 넘침 정책

overflow는 넘친 내용을 보이거나 자르거나 스크롤하도록 정합니다. hidden만 적용하면 핵심 내용이 사라질 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 80자 URL과 280px 카드 조건의 콘텐츠를 준비하고 overflow.css를 연결하세요.
2. 긴 URL 카드에 overflow-wrap과 min-width를 조합하고 스크롤 영역을 따로 만드세요.
3. 80자 URL과 280px 카드 조건으로 실행하세요. 확인할 결과: URL 전체를 확인할 수 있고 페이지 가로 넘침이 없다. 자르기와 내부 스크롤의 차이를 두 화면으로 기록한다. 예상과 실제 결과는 구분해 기록하세요.
