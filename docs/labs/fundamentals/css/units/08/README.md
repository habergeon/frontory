## 핵심 개념과 설명

### 주축과 교차축

flex-direction이 주축을 정합니다. justify-content와 align-items는 서로 다른 축을 다룹니다.

### 분배 공간

정렬 결과는 남는 공간에 따라 달라집니다. 항목이 공간을 모두 쓰면 일부 정렬 차이가 보이지 않을 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 크기가 다른 버튼 3개와 높이 200px 조건의 콘텐츠를 준비하고 flex-axis.css를 연결하세요.
2. 툴바를 row와 column으로 바꾸고 두 정렬 속성의 축을 표시하세요.
3. 크기가 다른 버튼 3개와 높이 200px 조건으로 실행하세요. 확인할 결과: 두 방향의 주축·교차축을 스케치한다. 시작·중앙·끝 정렬의 위치를 측정한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 방향 | row | column | 실행 전 가설: 정렬이 적용되는 축이 바뀔 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
