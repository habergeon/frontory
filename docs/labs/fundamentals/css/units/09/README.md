## 핵심 개념과 설명

### 공간 분배

flex-grow는 남는 공간의 분배 비율을 정합니다. 실제 너비는 basis와 최소 크기도 함께 반영합니다.

### 축소 비율

flex-shrink는 부족한 공간을 줄이는 데 관여합니다. 긴 콘텐츠의 자동 최소 크기가 축소를 막을 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 컨테이너 900px와 420px 조건의 콘텐츠를 준비하고 flex-size.css를 연결하세요.
2. 세 패널의 basis를 200px로 두고 grow·shrink와 min-width를 조절하세요.
3. 컨테이너 900px와 420px 조건으로 실행하세요. 확인할 결과: 각 폭의 패널 실제 너비 3개를 기록한다. min-width:0의 효과를 shrink와 구분한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| shrink | 1 | 0 | 실행 전 가설: 좁은 컨테이너에서 넘침이 생길 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
