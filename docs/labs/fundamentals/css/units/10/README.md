## 핵심 개념과 설명

### 트랙 정의

grid-template-columns는 열의 크기와 개수를 정합니다. fr은 고정 크기와 간격을 제외한 공간 분배에 사용됩니다.

### 최소 제약

1fr에도 콘텐츠의 최소 크기가 영향을 줄 수 있습니다. minmax(0,1fr)로 축소 허용 범위를 명시할 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 긴 제목 포함 카드 6개 조건의 콘텐츠를 준비하고 grid-tracks.css를 연결하세요.
2. 3열 카드에 1fr과 minmax(0,1fr)을 비교하고 gap을 바꾸세요.
3. 긴 제목 포함 카드 6개 조건으로 실행하세요. 확인할 결과: 열 너비와 gap의 합을 컨테이너 폭과 비교한다. 좁은 폭에서 넘치는 요소를 식별하고 수정한다. 예상과 실제 결과는 구분해 기록하세요.
