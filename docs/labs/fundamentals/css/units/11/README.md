## 핵심 개념과 설명

### 자동 열

auto-fit과 auto-fill은 가능한 트랙 수를 계산합니다. 빈 트랙을 접는 방식이 달라 적은 카드에서 차이가 납니다.

### 최소 카드 폭

minmax로 카드의 최소·최대 범위를 정합니다. 최소 폭이 뷰포트보다 크면 넘침 대책이 필요합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 카드 2개와 8개, 컨테이너 1000px 조건의 콘텐츠를 준비하고 auto-grid.css를 연결하세요.
2. repeat와 minmax로 카드 목록을 만들고 auto-fit·auto-fill을 비교하세요.
3. 카드 2개와 8개, 컨테이너 1000px 조건으로 실행하세요. 확인할 결과: 카드 수별 열 개수와 카드 너비를 기록한다. 320px 컨테이너에서도 가로 스크롤이 없다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                                                                   |
| ---- | --------- | --------- | ----------------------------------------------------------------------------------------------------------------------- |
| 반복 | auto-fill | auto-fit  | 실행 전 가설: 적은 카드가 남은 공간을 더 넓게 사용할 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 연결된 예제와 실행 범위

[예제 원본](../../../../../../src/labs/css-step-11/example.js) · [실행 환경과 제한](../../../../../examples.md)

실제 CSS 문서를 렌더하고 DOM 치수와 계산 스타일을 검사합니다. Shadow DOM에서 문서 body/html 선택자를 범위화합니다. @media는 외부 미리보기 viewport에 반응하며 폭 슬라이더는 컨테이너만 변경합니다. 네트워크·폼 이동·iframe 실행은 제한됩니다.

원본 코드·기록은 자동으로 덮어쓰지 않습니다. 기존 예제를 초기화할 때도 필기는 유지됩니다.
