## 핵심 개념과 설명

### 자동 열

auto-fit과 auto-fill은 가능한 트랙 수를 계산합니다. 빈 트랙을 접는 방식이 달라 적은 카드에서 차이가 납니다.

### 최소 카드 폭

minmax로 카드의 최소·최대 범위를 정합니다. 최소 폭이 뷰포트보다 크면 넘침 대책이 필요합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 카드 2개와 8개, 컨테이너 1000px 조건의 콘텐츠를 준비하고 auto-grid.css를 연결하세요.
2. repeat와 minmax로 카드 목록을 만들고 auto-fit·auto-fill을 비교하세요.
3. 카드 2개와 8개, 컨테이너 1000px 조건으로 실행하세요. 확인할 결과: 카드 수별 열 개수와 카드 너비를 기록한다. 320px 컨테이너에서도 가로 스크롤이 없다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 반복 | auto-fill | auto-fit | 실행 전 가설: 적은 카드가 남은 공간을 더 넓게 사용할 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
