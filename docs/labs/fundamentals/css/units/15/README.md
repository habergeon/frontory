## 핵심 개념과 설명

### 컨테이너 기준

크기 쿼리는 지정한 조상 컨테이너의 크기를 기준으로 합니다. 같은 뷰포트에서도 배치된 영역에 따라 카드가 달라질 수 있습니다.

### 포함 범위

container-type은 크기 질의와 관련된 포함 규칙을 만듭니다. 적용할 요소와 자식의 관계를 확인해야 합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 300px 사이드바와 800px 본문 조건의 콘텐츠를 준비하고 container.css를 연결하세요.
2. wrapper에 container-type:inline-size를 두고 @container로 카드의 가로·세로 배치를 바꾸세요.
3. 300px 사이드바와 800px 본문 조건으로 실행하세요. 확인할 결과: 동일 뷰포트에서 두 카드가 서로 다른 배치를 보인다. 쿼리 컨테이너를 개발자 도구에서 식별한다. 예상과 실제 결과는 구분해 기록하세요.
