## 핵심 개념과 설명

### 논리 방향

inline과 block 축은 문서의 쓰기 방향에 맞춰집니다. left와 right 같은 물리 방향과 항상 같지는 않습니다.

### 방향 대응

margin-inline과 padding-block으로 관계를 표현합니다. 아이콘과 정렬도 RTL에서 자연스러운지 따로 검사합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 LTR과 RTL 카드 목록 조건의 콘텐츠를 준비하고 logical.css를 연결하세요.
2. 카드 여백과 테두리를 논리 속성으로 바꾸고 dir을 토글하세요.
3. LTR과 RTL 카드 목록 조건으로 실행하세요. 확인할 결과: 두 방향에서 시작 경계와 간격을 기록한다. 텍스트와 조작이 겹치거나 잘리지 않는다. 예상과 실제 결과는 구분해 기록하세요.
