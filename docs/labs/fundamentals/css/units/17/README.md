## 핵심 개념과 설명

### 행간

단위 없는 line-height는 글자 크기에 비례해 계산됩니다. 자식의 글자 크기가 달라도 비율을 유지하기 쉽습니다.

### 읽기 폭

줄 길이는 글자 크기와 컨테이너 폭의 조합으로 결정됩니다. 긴 본문은 카드 제목과 다른 최대 폭이 필요할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 한국어 장문과 영문 긴 단어 조건의 콘텐츠를 준비하고 type.css를 연결하세요.
2. 본문에 max-width와 단위 없는 행간을 적용하고 제목·본문·보조 텍스트를 비교하세요.
3. 한국어 장문과 영문 긴 단어 조건으로 실행하세요. 확인할 결과: 두 행간의 계산 높이와 총 본문 높이를 기록한다. 200% 확대에서 글줄과 조작이 겹치지 않는다. 예상과 실제 결과는 구분해 기록하세요.
