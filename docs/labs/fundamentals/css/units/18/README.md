## 핵심 개념과 설명

### 대비 관계

글자색은 배경색과 함께 평가해야 합니다. 같은 색도 배경에 따라 읽기 어려울 수 있습니다.

### 상태 전달

색만으로 오류나 선택을 표시하면 정보가 부족할 수 있습니다. 텍스트·아이콘·테두리 같은 표시를 함께 둡니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.html에 밝은 배경과 어두운 배경 조건의 콘텐츠를 준비하고 colors.css를 연결하세요.
2. 기본·선택·오류 카드의 색을 정하고 개발자 도구로 텍스트 대비를 확인하세요.
3. 밝은 배경과 어두운 배경 조건으로 실행하세요. 확인할 결과: 일반 본문 텍스트의 대비 목표 4.5:1 이상을 확인한다. 오류와 선택을 색 없이도 구분하는 표시가 있다. 예상과 실제 결과는 구분해 기록하세요.
