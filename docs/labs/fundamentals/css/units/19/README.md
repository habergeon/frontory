## 핵심 개념과 설명

### 포커스 표시

:focus-visible은 입력 방식 등의 판단에 따라 포커스 표시를 조절합니다. outline 제거 후 대체 표시가 없으면 위치를 잃습니다.

### 상태 선택자

disabled·checked·invalid는 서로 다른 상태를 나타냅니다. 오류 표시가 입력 시작 전부터 과도하지 않은지 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 키보드 이동, 체크 전환, 잘못된 입력 조건의 콘텐츠를 준비하고 states.css를 연결하세요.
2. 버튼·링크·입력에 focus-visible과 상태 스타일을 작성하고 Tab으로 탐색하세요.
3. 키보드 이동, 체크 전환, 잘못된 입력 조건으로 실행하세요. 확인할 결과: 모든 조작에서 포커스가 보이고 잘리지 않는다. checked·disabled·invalid 상태 3개를 기록한다. 예상과 실제 결과는 구분해 기록하세요.
