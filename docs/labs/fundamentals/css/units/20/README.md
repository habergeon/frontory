## 핵심 개념과 설명

### 위치 기준

absolute는 포함 블록을 기준으로 배치됩니다. 가장 가까운 positioned 조상이 흔한 기준이지만 다른 속성도 영향을 줄 수 있습니다.

### 고정과 부착

fixed와 sticky는 스크롤에서 서로 다른 동작을 합니다. sticky에는 임계 위치와 스크롤 맥락이 중요합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 긴 문서와 높이가 제한된 부모 조건의 콘텐츠를 준비하고 position.css를 연결하세요.
2. 카드 배지와 sticky 목차를 만들고 부모 position과 overflow를 바꾸세요.
3. 긴 문서와 높이가 제한된 부모 조건으로 실행하세요. 확인할 결과: 배지의 기준 요소와 계산 위치를 기록한다. 문서 스크롤과 부모 스크롤의 sticky 동작을 비교한다. 예상과 실제 결과는 구분해 기록하세요.
