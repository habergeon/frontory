## 핵심 개념과 설명

### 쌓임 맥락

z-index는 같은 맥락의 순서 안에서 해석합니다. 자식 값을 크게 해도 부모 맥락 바깥을 자유롭게 넘지 못합니다.

### 맥락 생성

transform이나 opacity 같은 속성이 새 맥락을 만들 수 있습니다. 의도하지 않은 겹침의 원인을 조상부터 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 카드 2개와 배지 z-index 999 조건의 콘텐츠를 준비하고 stacking.css를 연결하세요.
2. 겹치는 카드와 배지를 만들고 부모 transform 유무에서 z-index 효과를 비교하세요.
3. 카드 2개와 배지 z-index 999 조건으로 실행하세요. 확인할 결과: 겹침 순서를 조상 맥락까지 도식화한다. 최종 배지가 의도한 카드 위에 표시된다. 예상과 실제 결과는 구분해 기록하세요.
