## 핵심 개념과 설명

### 전환 대상

transition은 값 변화의 중간 상태를 표시합니다. all보다 필요한 속성을 지정하면 의도하지 않은 전환을 줄입니다.

### 중단 처리

사용자가 전환 도중 반대 동작을 할 수 있습니다. 끝 상태만 검사하면 빠른 입력에서 튀는 동작을 놓칩니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 연속 클릭 5회와 두 지속 시간 조건의 콘텐츠를 준비하고 transition.css를 연결하세요.
2. 선택 카드의 transform과 opacity만 전환하고 버튼을 빠르게 반복 조작하세요.
3. 연속 클릭 5회와 두 지속 시간 조건으로 실행하세요. 확인할 결과: 빠른 클릭 뒤 최종 선택 상태가 맞는다. 두 지속 시간의 중간 상태와 reduce 대체를 기록한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수     | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                                                                    |
| -------- | --------- | --------- | ------------------------------------------------------------------------------------------------------------------------ |
| duration | 150ms     | 800ms     | 실행 전 가설: 중간 상태에서 역전하는 구간이 더 잘 보일 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
