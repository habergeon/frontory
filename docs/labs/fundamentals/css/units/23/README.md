## 핵심 개념과 설명

### 시간 구간

@keyframes는 진행률별 속성 값을 정의합니다. 반복 횟수와 방향에 따라 전체 움직임이 달라집니다.

### 일시 정지

animation-play-state로 재생을 멈출 수 있습니다. 감소 모션 설정에서는 비필수 반복 자체를 없애는 방법도 고려합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 1회·무한 반복과 정지·재개 조건의 콘텐츠를 준비하고 keyframes.css를 연결하세요.
2. 진행 표시를 키프레임으로 만들고 정지 버튼 상태에 따라 재생을 전환하세요.
3. 1회·무한 반복과 정지·재개 조건으로 실행하세요. 확인할 결과: 정지 후 위치가 유지되고 재개 시 이어진다. reduce 조건에서 비필수 반복이 중지된다. 예상과 실제 결과는 구분해 기록하세요.
