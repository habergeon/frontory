## 핵심 개념과 설명

### 레이어 순서

@layer는 스타일 묶음의 우선순서를 명시합니다. 같은 중요도에서도 레이어와 비레이어 규칙의 우선순서를 확인해야 합니다.

### 변경 가능성

기본·컴포넌트·유틸리티 규칙을 나누면 충돌을 추적하기 쉽습니다. !important는 레이어 우선순서도 다르게 작동합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 동일 속성 선언 3개와 비레이어 선언 조건의 콘텐츠를 준비하고 layers.css를 연결하세요.
2. base·components·utilities 레이어를 선언하고 같은 버튼 색 충돌을 만들어 비교하세요.
3. 동일 속성 선언 3개와 비레이어 선언 조건으로 실행하세요. 확인할 결과: 일반 선언의 승리 레이어를 계산 스타일에서 확인한다. important 사례를 별도로 기록해 일반 규칙과 구분한다. 예상과 실제 결과는 구분해 기록하세요.

비레이어 background 선언 또는 !important를 각 레이어에 추가해 계산 스타일을 비교하세요. Shadow DOM에서 문서 body/html 선택자를 범위화합니다. @media는 외부 미리보기 viewport에 반응하며 폭 슬라이더는 컨테이너만 변경합니다. 네트워크·폼 이동·iframe 실행은 제한됩니다.
