## 핵심 개념과 설명

### 값 공유

CSS 사용자 정의 속성은 cascade와 상속에 참여합니다. 선언 위치에 따라 같은 이름의 값이 다르게 해석됩니다.

### 대체값

var의 fallback은 참조 변수가 없거나 유효하지 않을 때 사용됩니다. 최종 속성 문법에 맞지 않는 값은 계산 시 문제가 될 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 카드·입력·버튼과 두 테마 조건의 콘텐츠를 준비하고 tokens.css를 연결하세요.
2. 색상·간격·반경 토큰을 :root에 정의하고 data-theme로 어두운 테마를 덮으세요.
3. 카드·입력·버튼과 두 테마 조건으로 실행하세요. 확인할 결과: 세 요소의 색·간격 토큰 연결을 기록한다. 두 테마에서 본문 대비와 포커스 표시를 확인한다. 예상과 실제 결과는 구분해 기록하세요.
