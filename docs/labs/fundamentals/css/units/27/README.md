## 핵심 개념과 설명

### 포함 경계

contain은 요소의 계산·배치·그리기 관계를 제한합니다. 잘못 적용하면 넘치는 내용이나 크기 계산이 달라질 수 있습니다.

### 렌더 생략

content-visibility:auto는 화면 밖 콘텐츠의 렌더 작업을 줄일 수 있습니다. 예상 크기와 접근성 동작도 함께 점검합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에 콘텐츠를 만들고 link rel="stylesheet"로 실습 CSS를 연결하세요. 개발자 도구에서 뷰포트·계산 스타일·성능 기록을 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html에 높이가 다른 카드 200개 조건의 콘텐츠를 준비하고 containment.css를 연결하세요.
2. 긴 카드 목록에 content-visibility와 contain-intrinsic-size를 적용하고 스크롤을 비교하세요.
3. 높이가 다른 카드 200개 조건으로 실행하세요. 확인할 결과: 초기 기록과 스크롤 중 높이 변화를 비교한다. 검색·키보드 이동으로 화면 밖 카드에 도달한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건               | 예상할 변화·검증 가설                                                                                                                  |
| --------- | --------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 렌더 정책 | 기본      | content-visibility:auto | 실행 전 가설: 초기 렌더 작업이 줄 수 있으나 스크롤 크기 변화가 생길 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
