## 핵심 개념과 설명

### 제목 계층

heading은 글의 제목 관계를 표현합니다. 글자 크기를 바꾸려는 이유로 단계를 고르면 구조가 흐려집니다.

### 영역 의미

header·nav·main·article은 문서 안의 역할을 나타냅니다. 링크는 이동에, 버튼은 동작에 사용합니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. index.html 파일에 페이지 제목 1개와 주제 영역 3개 조건을 준비하세요.
2. 학습 페이지를 의미 있는 영역으로 나누고 링크 이동과 버튼 동작을 구분하세요.
3. 페이지 제목 1개와 주제 영역 3개 조건으로 실행하세요. 확인할 결과: 접근성 트리에 주 영역과 탐색 영역이 구분된다. 영역 3개의 제목 단계와 이동·동작 요소를 설명한다. 예상과 실제 결과는 구분해 기록하세요.
