## 핵심 개념과 설명

### 입력 이름

label은 입력의 이름을 제공합니다. placeholder는 입력 후 사라져 label을 대신하지 못합니다.

### 제약과 설명

required와 길이 제약은 기본 검증을 수행합니다. 오류 설명은 해당 입력과 연결해 원인을 알립니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. keyboard-form.html 파일에 빈 값, 짧은 제목, 정상 제목 조건을 준비하세요.
2. 필기 제목과 저장 폼에 required·minlength·aria-describedby를 연결하고 오류 안내를 작성하세요.
3. 빈 값, 짧은 제목, 정상 제목 조건으로 실행하세요. 확인할 결과: Tab과 Enter만으로 정상 제목을 저장한다. 실패 필드의 이름과 설명을 접근성 트리에서 확인한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 제목 길이 | 5자 | 1자 | 실행 전 가설: minlength 제약에 따라 제출이 막힐 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
