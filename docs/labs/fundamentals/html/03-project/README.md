## 목표와 학습 후 역량

- 이미지 없이 카드 6개의 주제와 이동 목적을 식별한다.
- 키보드로 목차 열기와 모든 카드 이동을 수행하고 순서를 기록한다.
- 제목 폼은 빈 값·짧은 값을 거부하고 정상 제목을 Tab과 Enter로 저장한다.

## 핵심 개념과 설명

### 구조 통합

카드 제목·설명·링크는 읽는 순서대로 배치합니다. 시각적 배치가 달라도 문서의 의미가 유지되어야 합니다.

### 조작 검증

네이티브 details와 버튼·링크를 목적에 맞게 조합합니다. 이미지 실패와 키보드 사용을 별도 시나리오로 검사합니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. cards.html 파일에 이미지 정상·실패와 100%·400% 확대 조건을 준비하세요.
2. 학습 카드 6개와 details 목차에 이미지 alt·제목 계층·목적 있는 링크를 통합하세요. 14단위 제목 저장 폼의 label·required·minlength·aria-describedby와 실패 안내를 재사용하세요.
3. 이미지 정상·실패와 100%·400% 확대에서 카드 주제와 이동 목적, 키보드 목차·카드 이동 순서를 기록하세요. 폼은 빈 값·짧은 값을 거부하는지 확인하고 정상 제목을 Tab과 Enter로 저장하세요. 예상과 실제 결과는 구분해 기록하세요.
