## 핵심 개념과 설명

### 문서 모드

DOCTYPE은 브라우저가 표준 모드로 해석하도록 합니다. 생략 시 호환 모드가 적용될 수 있습니다.

### 문자와 언어

charset은 문자의 해석을 지정하고 lang은 문서 언어를 알립니다. 두 속성은 서로 다른 문제를 다룹니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. document.html 파일에 한글 제목과 영문 인용문 조건을 준비하세요.
2. DOCTYPE·html lang·head·body와 UTF-8 선언을 작성하고 제목과 한글을 표시하세요.
3. 한글 제목과 영문 인용문 조건으로 실행하세요. 확인할 결과: document.compatMode가 CSS1Compat인지 확인한다. 한글 본문과 탭 제목을 확인하고 인코딩 값을 남긴다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| lang | ko | en | 실행 전 가설: 보조 기술의 언어 해석이 달라질 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
