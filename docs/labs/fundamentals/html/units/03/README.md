## 핵심 개념과 설명

### 탭 제목

title은 탭과 방문 기록 등에서 문서를 식별합니다. 화면의 h1과 일치할 필요는 없지만 목적은 연결되어야 합니다.

### 뷰포트

viewport 메타는 모바일의 레이아웃 뷰포트 설정에 관여합니다. 확대를 막는 설정은 읽기를 방해할 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. head.html 파일에 목록 페이지와 상세 페이지 두 파일 조건을 준비하세요.
2. 고유 title과 description, width=device-width·initial-scale=1 설정을 작성하세요.
3. 목록 페이지와 상세 페이지 두 파일 조건으로 실행하세요. 확인할 결과: 두 페이지의 탭 제목이 서로 구분된다. 모바일 에뮬레이션에서 설정 전후 화면 폭을 기록한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| viewport | 선언 없음 | 기본 모바일 선언 | 실행 전 가설: 좁은 화면에서 의도한 레이아웃 폭에 가까워질 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
