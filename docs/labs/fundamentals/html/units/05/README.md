## 핵심 개념과 설명

### 목록 순서

ol은 순서가 의미 있는 항목을 표현합니다. ul은 순서와 무관한 묶음에 적합합니다.

### 정의 목록

dl은 용어와 설명을 연결합니다. 단순 들여쓰기를 위해 dt와 dd를 선택하지 않습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. lists.html 파일에 실습 4단계, 준비물 3개, 용어 2개 조건을 준비하세요.
2. 실습 순서를 ol, 준비물을 ul, 용어집을 dl로 작성하세요.
3. 실습 4단계, 준비물 3개, 용어 2개 조건으로 실행하세요. 확인할 결과: 항목 수가 각각 4·3·2개인지 DOM에서 확인한다. 용어 두 개에 대응하는 설명이 연결된다. 예상과 실제 결과는 구분해 기록하세요.
