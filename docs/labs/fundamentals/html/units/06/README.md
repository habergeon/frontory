## 핵심 개념과 설명

### 경로 해석

상대 URL은 현재 문서의 기준 URL로 해석됩니다. 폴더를 옮기면 같은 문자열의 목적지가 바뀔 수 있습니다.

### 프래그먼트

id를 가리키는 링크는 문서 내부 위치로 이동합니다. 중복 id는 목적지 식별을 불명확하게 합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. links/index.html 파일에 하위 폴더 상세 페이지와 섹션 3개 조건을 준비하세요.
2. 상세 페이지 링크와 목차의 #section 링크를 만들고 링크 텍스트에 목적을 적으세요.
3. 하위 폴더 상세 페이지와 섹션 3개 조건으로 실행하세요. 확인할 결과: 세 목차 링크가 서로 다른 제목으로 이동한다. 네트워크에서 정상 경로와 실패 경로를 구분한다. 예상과 실제 결과는 구분해 기록하세요.
