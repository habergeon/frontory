## 핵심 개념과 설명

### 대체 정보

alt는 이미지가 전달하는 목적을 텍스트로 표현합니다. 장식 이미지는 빈 alt로 중복 정보를 줄입니다.

### 공간 예약

width와 height는 이미지의 비율 정보를 전달합니다. 적절한 크기 지정은 로딩 중 배치 변화를 줄일 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. images.html 파일에 정보 이미지 1개, 장식 1개, 링크 이미지 1개 조건을 준비하세요.
2. 설명 그림·장식 그림·링크 이미지에 목적에 맞는 alt와 크기를 지정하세요.
3. 정보 이미지 1개, 장식 1개, 링크 이미지 1개 조건으로 실행하세요. 확인할 결과: 정보·장식·링크 이미지의 alt 정책 3개를 기록한다. 이미지 실패 상태에서도 링크 목적과 본문 내용을 이해한다. 예상과 실제 결과는 구분해 기록하세요.
