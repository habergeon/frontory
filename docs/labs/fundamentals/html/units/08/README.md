## 핵심 개념과 설명

### 독립 자료

figure는 본문에서 참조하는 독립 자료를 묶습니다. 그림뿐 아니라 코드나 표도 문맥에 따라 포함할 수 있습니다.

### 캡션

figcaption은 figure의 설명을 제공합니다. 이미지 alt와 무조건 같은 문장을 반복할 필요는 없습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. figure.html 파일에 같은 장면의 전후 이미지와 본문 참조 조건을 준비하세요.
2. 실험 전후 이미지 두 개를 figure로 묶고 figcaption에 비교 조건을 적으세요.
3. 같은 장면의 전후 이미지와 본문 참조 조건으로 실행하세요. 확인할 결과: 자료 2개와 공통 비교 조건을 확인한다. 이미지 차이 설명과 캡션의 역할을 구분해 적는다. 예상과 실제 결과는 구분해 기록하세요.
