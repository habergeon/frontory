## 핵심 개념과 설명

### 데이터 표

table은 행과 열의 관계가 있는 자료에 사용합니다. 페이지 배치 목적으로 사용하면 읽기 관계가 어긋납니다.

### 헤더 연결

th와 scope는 셀의 헤더 방향을 표현합니다. 복잡한 표는 headers와 id 같은 추가 연결이 필요할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. table.html 파일에 실험 3행과 시간·메모리 2열 조건을 준비하세요.
2. caption·thead·tbody와 행·열 th를 사용해 실험 결과표를 작성하세요.
3. 실험 3행과 시간·메모리 2열 조건으로 실행하세요. 확인할 결과: 3행의 각 값이 어떤 헤더에 속하는지 확인한다. caption에 표 목적과 단위를 명시한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                                                             |
| --------- | --------- | --------- | ----------------------------------------------------------------------------------------------------------------- |
| 헤더 요소 | td        | th scope  | 실행 전 가설: 셀과 헤더 관계를 더 분명히 전달할 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
