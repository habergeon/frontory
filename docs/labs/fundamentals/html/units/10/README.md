## 핵심 개념과 설명

### 인용 표현

blockquote와 q는 인용 범위를 나타냅니다. cite 요소는 작품 제목에 쓰며 사람 이름 표기와 혼동하지 않습니다.

### 날짜 표현

time의 datetime은 기계가 읽을 값을 전달합니다. 보이는 지역 형식과 표준 값은 다르게 쓸 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. quotes.html 파일에 인용 1개와 2026-10-21 날짜 조건을 준비하세요.
2. 짧은 인용과 출처 링크를 넣고 학습 날짜를 time으로 표시하세요.
3. 인용 1개와 2026-10-21 날짜 조건으로 실행하세요. 확인할 결과: 인용 범위와 출처 링크를 구분한다. 표시 날짜와 datetime이 같은 날짜를 뜻한다. 예상과 실제 결과는 구분해 기록하세요.
