## 핵심 개념과 설명

### 폼 소유

form은 입력과 제출 동작을 묶습니다. 버튼 type을 생략하면 폼 안에서 제출 버튼이 될 수 있습니다.

### 전송 이름

name은 제출 데이터의 키가 됩니다. id는 label 연결 등에 쓰이며 name을 대신하지 않습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. form-basics.html 파일에 q 입력과 검색·초기화 동작 조건을 준비하세요.
2. GET 검색 폼에 label·name 있는 입력과 submit·button 버튼을 작성하세요.
3. q 입력과 검색·초기화 동작 조건으로 실행하세요. 확인할 결과: 검색 후 URL에 q 값이 나타난다. 보조 버튼이 의도치 않은 제출을 하지 않는다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수
