## 핵심 개념과 설명

### 그룹 이름

fieldset과 legend는 관련 입력 묶음의 이름을 전달합니다. 개별 label만으로 표현하기 어려운 질문을 그룹에 적습니다.

### 선택 규칙

같은 name의 radio는 한 그룹에서 하나를 선택합니다. checkbox는 독립적인 여러 선택을 표현합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. choices.html 파일에 난이도 3개와 주제 3개 조건을 준비하세요.
2. 난이도 radio와 관심 주제 checkbox를 fieldset으로 나누세요.
3. 난이도 3개와 주제 3개 조건으로 실행하세요. 확인할 결과: 올바른 그룹에서 radio 한 개만 선택된다. checkbox 두 개 선택 시 제출 값 두 개를 확인한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수       | 기준 조건  | 바꿀 조건      | 예상할 변화·검증 가설                                                                                      |
| ---------- | ---------- | -------------- | ---------------------------------------------------------------------------------------------------------- |
| radio name | 모두 level | 각각 다른 name | 실행 전 가설: 여러 radio가 동시에 선택될 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
