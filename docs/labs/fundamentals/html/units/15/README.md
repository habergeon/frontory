## 핵심 개념과 설명

### 비활성 입력

disabled 컨트롤은 일반적으로 제출 데이터에서 제외됩니다. 포커스 이동에서도 빠져 설명 확인에 영향을 줄 수 있습니다.

### 읽기 전용

지원하는 입력의 readonly는 편집을 막습니다. disabled와 달리 제출과 포커스 동작이 다를 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. readonly.html 파일에 값이 같은 텍스트 입력 3개 조건을 준비하세요.
2. 같은 식별자 입력을 일반·readonly·disabled 상태로 비교하고 FormData를 출력하세요.
3. 값이 같은 텍스트 입력 3개 조건으로 실행하세요. 확인할 결과: 세 입력의 제출 포함 여부를 기록한다. 키보드 이동에서 도달하는 입력을 기록한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 상태 | readonly | disabled | 실행 전 가설: 제출 데이터에서 해당 입력이 빠질 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
