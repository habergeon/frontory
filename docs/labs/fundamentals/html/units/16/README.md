## 핵심 개념과 설명

### 공개 상태

details는 네이티브로 열고 닫는 내용을 표현합니다. summary가 조작 이름과 표면을 제공합니다.

### 문서 흐름

접힌 내용은 필요한 시점에 펼쳐 읽도록 배치합니다. 핵심 안내를 숨겨 사용자가 놓치지 않는지 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. details.html 파일에 닫힌 상태와 열린 상태 조건을 준비하세요.
2. summary에 주제명을 적고 내부 목차 링크 4개를 작성하세요.
3. 닫힌 상태와 열린 상태 조건으로 실행하세요. 확인할 결과: 키보드로 두 번 토글해 원래 상태로 돌아간다. 열린 상태에서 목차 링크 4개에 도달한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                                                     |
| --------- | --------- | --------- | --------------------------------------------------------------------------------------------------------- |
| open 속성 | 없음      | 있음      | 실행 전 가설: 처음부터 내부 목차가 보일 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
