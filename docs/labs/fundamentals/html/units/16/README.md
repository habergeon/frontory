## 핵심 개념과 설명

### 공개 상태

details는 네이티브로 열고 닫는 내용을 표현합니다. summary가 조작 이름과 표면을 제공합니다.

### 문서 흐름

접힌 내용은 필요한 시점에 펼쳐 읽도록 배치합니다. 핵심 안내를 숨겨 사용자가 놓치지 않는지 확인합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. details.html 파일에 닫힌 상태와 열린 상태 조건을 준비하세요.
2. summary에 주제명을 적고 내부 목차 링크 4개를 작성하세요.
3. 닫힌 상태와 열린 상태 조건으로 실행하세요. 확인할 결과: 키보드로 두 번 토글해 원래 상태로 돌아간다. 열린 상태에서 목차 링크 4개에 도달한다. 예상과 실제 결과는 구분해 기록하세요.
