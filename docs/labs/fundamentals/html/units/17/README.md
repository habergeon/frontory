## 핵심 개념과 설명

### 모달 동작

showModal은 dialog를 최상위 레이어에 표시하고 바깥 상호작용을 제한합니다. open 속성만 설정하는 것과 모달 동작이 다릅니다.

### 포커스 복귀

대화상자를 닫은 뒤 원래 작업으로 돌아갈 수 있어야 합니다. 초기 포커스와 Escape 동작을 실제 브라우저에서 확인합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. dialog.html 파일에 키보드로 열기, 닫기, Escape 조건을 준비하세요.
2. 제목 있는 dialog와 열기·닫기 버튼을 만들고 보조 JS로 showModal과 close를 연결하세요.
3. 키보드로 열기, 닫기, Escape 조건으로 실행하세요. 확인할 결과: 모달 안에서 키보드 조작과 Escape 종료를 확인한다. 닫은 뒤 열기 버튼으로 포커스가 돌아오는지 기록한다. 예상과 실제 결과는 구분해 기록하세요.
