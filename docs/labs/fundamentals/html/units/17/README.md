## 핵심 개념과 설명

### 모달 동작

showModal은 dialog를 최상위 레이어에 표시하고 바깥 상호작용을 제한합니다. open 속성만 설정하는 것과 모달 동작이 다릅니다.

### 포커스 복귀

대화상자를 닫은 뒤 원래 작업으로 돌아갈 수 있어야 합니다. 초기 포커스와 Escape 동작을 실제 브라우저에서 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. dialog.html 파일에 키보드로 열기, 닫기, Escape 조건을 준비하세요.
2. 제목 있는 dialog와 열기·닫기 버튼을 만들고 보조 JS로 showModal과 close를 연결하세요.
3. showModal로 열어 닫기와 Escape, 열기 버튼으로의 포커스 복귀를 확인하세요. 모달을 닫고 open 속성을 추가한 뒤 열기 버튼을 다시 누르지 말고 바깥 요소를 조작하세요. open을 제거한 뒤 showModal로 다시 열어 비교하세요. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| --------- | --------- | --------- | ----------------------------------------------------------------------------------------------------------- |
| 열기 방식 | showModal | open 속성 | 실행 전 가설: 바깥 상호작용 제한이 달라질 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
