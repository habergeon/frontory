## 핵심 개념과 설명

### 미디어 제어

audio와 video의 controls는 네이티브 재생 UI를 제공합니다. 자동 재생에 의존하면 환경 정책과 사용자 선호에 영향을 받습니다.

### 시간 텍스트

track과 WebVTT로 자막을 연결합니다. 음성 정보는 대본으로도 접근할 수 있도록 구성합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. media.html 파일에 영상 파일, captions.vtt, 대본 조건을 준비하세요.
2. 로컬 짧은 영상에 controls와 한국어 자막 track을 연결하고 대본 링크를 추가하세요.
3. 영상 파일, captions.vtt, 대본 조건으로 실행하세요. 확인할 결과: 자막 큐 2개가 정한 시점에 표시된다. 영상 로딩 실패 때 대본 링크에 접근한다. 예상과 실제 결과는 구분해 기록하세요.
