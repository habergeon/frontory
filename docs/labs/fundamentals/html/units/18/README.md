## 핵심 개념과 설명

### 미디어 제어

audio와 video의 controls는 네이티브 재생 UI를 제공합니다. 자동 재생에 의존하면 환경 정책과 사용자 선호에 영향을 받습니다.

### 시간 텍스트

track과 WebVTT로 자막을 연결합니다. 음성 정보는 대본으로도 접근할 수 있도록 구성합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. media.html 파일에 영상 파일, captions.vtt, 대본 조건을 준비하세요.
2. 로컬 짧은 영상에 controls와 한국어 자막 track을 연결하고 대본 링크를 추가하세요.
3. 영상 파일, captions.vtt, 대본 조건으로 실행하세요. 확인할 결과: 자막 큐 2개가 정한 시점에 표시된다. 영상 로딩 실패 때 대본 링크에 접근한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| --------- | --------- | --------- | ---------------------------------------------------------------------------------------------------------------------- |
| 자막 경로 | 정상 파일 | 없는 파일 | 실행 전 가설: 영상은 재생되어도 자막은 표시되지 않을 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
