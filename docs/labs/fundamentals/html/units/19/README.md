## 핵심 개념과 설명

### 소스 후보

srcset은 해상도 또는 폭별 이미지 후보를 제공합니다. 브라우저는 화면 조건과 후보 정보를 함께 판단합니다.

### 표시 크기

sizes는 폭 기술자 후보를 선택할 때 예상 표시 폭을 알려줍니다. CSS의 실제 표시 크기와 어긋나면 불필요한 다운로드가 생길 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. responsive-images.html 파일에 좁은 화면과 넓은 화면, 캐시 비운 요청 조건을 준비하세요.
2. 폭이 다른 이미지 3개와 srcset·sizes를 작성하고 currentSrc와 요청 크기를 확인하세요.
3. 좁은 화면과 넓은 화면, 캐시 비운 요청 조건으로 실행하세요. 확인할 결과: 두 화면의 currentSrc와 실제 표시 폭을 기록한다. 모든 후보에 동일한 의미의 alt를 유지한다. 예상과 실제 결과는 구분해 기록하세요.
