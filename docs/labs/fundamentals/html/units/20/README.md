## 핵심 개념과 설명

### 아트 디렉션

picture의 media 조건으로 구도가 다른 이미지를 고를 수 있습니다. 단순 해상도 선택과 목적이 다릅니다.

### 대체 이미지

img는 picture의 기본 표시와 대체 경로를 담당합니다. source의 type은 브라우저가 지원 형식을 판단하는 데 쓰입니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. picture.html 파일에 좁은 구도와 넓은 구도 두 이미지 조건을 준비하세요.
2. 모바일 자르기 이미지와 넓은 구도를 source로 나누고 img 기본값을 작성하세요.
3. 좁은 구도와 넓은 구도 두 이미지 조건으로 실행하세요. 확인할 결과: 두 폭에서 선택 이미지와 구도를 기록한다. source 조건에 맞지 않아도 img가 표시된다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| media 조건 | 600px 미만 | 600px 이상 | 실행 전 가설: 정보를 유지한 다른 구도가 선택될 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
