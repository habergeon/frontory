## 핵심 개념과 설명

### 프레임 이름

iframe의 title은 포함된 영역의 목적을 식별합니다. 내부 페이지의 title과 역할이 다릅니다.

### 제한 정책

sandbox는 포함 문서의 허용 기능을 제한합니다. 필요한 권한만 선택하고 효과를 실제로 확인해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. embed.html 파일에 스크립트 없는 문서와 버튼 스크립트 포함 문서 조건을 준비하세요.
2. 로컬 안내 문서를 iframe으로 포함하고 title과 sandbox를 설정하세요.
3. 스크립트 없는 문서와 버튼 스크립트 포함 문서 조건으로 실행하세요. 확인할 결과: 프레임 목적을 접근성 이름으로 확인한다. 두 정책에서 버튼 실행 여부를 기록한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| sandbox | 빈 값 | allow-scripts | 실행 전 가설: 내부 스크립트 실행 여부가 달라질 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
