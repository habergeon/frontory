## 핵심 개념과 설명

### 비활성 템플릿

template 안의 내용은 바로 표시되지 않습니다. content를 복제해 문서에 삽입할 수 있습니다.

### 식별자 중복

복제한 노드에 같은 id가 남으면 연결이 모호해집니다. label과 설명 id도 함께 갱신해야 합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. template.html 파일에 카드 3개와 각 카드의 입력 label 조건을 준비하세요.
2. 학습 카드 template를 만들고 최소 JS로 3개 복제하며 id와 연결 속성을 갱신하세요.
3. 카드 3개와 각 카드의 입력 label 조건으로 실행하세요. 확인할 결과: 카드 3개가 표시되고 중복 id가 없다. 각 label 클릭이 해당 카드 입력에 포커스를 준다. 예상과 실제 결과는 구분해 기록하세요.
