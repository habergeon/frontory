## 핵심 개념과 설명

### 로딩 시점

일반 스크립트는 위치에 따라 파싱을 막을 수 있습니다. defer는 문서 파싱 후 순서대로 실행하도록 합니다.

### 독립 실행

async는 준비되는 시점에 실행해 문서 순서를 보장하지 않습니다. 모듈 스크립트의 기본 지연 동작도 구분합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. scripts.html 파일에 head의 스크립트와 body 아래 대상 요소 조건을 준비하세요.
2. DOM을 읽는 스크립트 두 개를 일반·defer·async 방식으로 비교하세요.
3. head의 스크립트와 body 아래 대상 요소 조건으로 실행하세요. 확인할 결과: 세 로딩 방식의 실행 로그와 요소 존재 여부를 기록한다. 의존하는 스크립트가 안정적으로 순서대로 실행되는 구성을 고른다. 예상과 실제 결과는 구분해 기록하세요.
