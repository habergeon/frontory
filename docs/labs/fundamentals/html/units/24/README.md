## 핵심 개념과 설명

### 이름 계산

접근성 이름은 조작을 식별합니다. 보이는 label과 aria-label이 다르면 사용자가 혼동할 수 있습니다.

### 설명 연결

aria-describedby는 추가 설명을 연결합니다. 이름을 대신하는 용도로 쓰지 않습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. names.html 파일에 보이는 저장 텍스트와 다른 aria-label 조건을 준비하세요.
2. 텍스트 버튼·아이콘 버튼·입력 세 종류의 이름과 설명을 접근성 패널에서 확인하세요.
3. 보이는 저장 텍스트와 다른 aria-label 조건으로 실행하세요. 확인할 결과: 세 조작의 이름과 설명을 표로 남긴다. 버튼의 화면 문구와 접근성 이름이 일치한다. 예상과 실제 결과는 구분해 기록하세요.
