## 핵심 개념과 설명

### 소스 순서

보조 기술과 키보드 이동은 문서 순서의 영향을 받습니다. 시각적 위치만 바꾸어도 논리 순서가 자동 정리되지는 않습니다.

### 바로가기

건너뛰기 링크는 반복 탐색을 지나 주요 내용으로 이동합니다. 목적지와 포커스 동작을 브라우저에서 확인합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. reading-order.html 파일에 긴 탐색 링크 10개와 본문 조건을 준비하세요.
2. 상단에 본문 바로가기 링크를 두고 main 목적지와 논리적인 카드 순서를 구성하세요.
3. 긴 탐색 링크 10개와 본문 조건으로 실행하세요. 확인할 결과: 첫 키보드 조작에서 바로가기 링크를 사용할 수 있다. 본문 이동 전후 포커스와 스크롤 위치를 기록한다. 예상과 실제 결과는 구분해 기록하세요.
