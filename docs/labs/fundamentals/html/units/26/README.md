## 핵심 개념과 설명

### 오류 복구

브라우저는 잘못된 마크업도 DOM으로 복구합니다. 화면이 보인다고 문법과 구조가 맞는 것은 아닙니다.

### 콘텐츠 모델

요소마다 허용되는 자식과 중첩 규칙이 있습니다. 잘못된 중첩은 소스와 실제 DOM을 다르게 만들 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. invalid.html 파일에 오류 2건과 수정본 조건을 준비하세요.
2. p 안의 div와 중첩 button 같은 오류 예제를 만들고 Elements 트리와 검증기 결과를 비교하세요.
3. 오류 2건과 수정본 조건으로 실행하세요. 확인할 결과: 오류 2개의 복구된 DOM을 기록한다. 수정본에서 해당 검증 오류가 0개다. 예상과 실제 결과는 구분해 기록하세요.
