## 핵심 개념과 설명

### 대체 경로

리소스가 없어도 핵심 정보와 조작 의미가 남아야 합니다. alt와 본문 설명은 장애 상황에서 함께 작동합니다.

### 확대 환경

확대하면 동시에 보이는 영역이 줄어듭니다. 잘린 내용과 포커스 이동 문제는 실제 조작으로 확인합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더에 HTML과 필요한 이미지·미디어 파일을 직접 준비하고 로컬 HTTP 서버로 여세요. Elements·접근성 패널과 실제 키보드 조작으로 확인합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. audit.html 파일에 카드 6개, 이미지 실패, 확대 두 배율 조건을 준비하세요.
2. 카드 페이지의 이미지 경로를 끊고 200%·400% 확대에서 키보드로 탐색하세요.
3. 카드 6개, 이미지 실패, 확대 두 배율 조건으로 실행하세요. 확인할 결과: 실패 이미지 6개에서도 카드 제목과 동작 목적이 남는다. 두 확대 배율에서 모든 조작에 도달한 기록이 있다. 예상과 실제 결과는 구분해 기록하세요.
