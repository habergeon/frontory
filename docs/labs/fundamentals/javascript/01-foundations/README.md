# JavaScript · 01 값과 상태

## 목표와 학습 후 역량

원본이 바뀌는 경우와 보존되는 경우를 재현한다. 이를 자신의 말로 설명하고 작은 결과물로 재현하는 것이 목표입니다.

## 선수 지식

HTML 요소와 이벤트.

## 핵심 개념과 설명

원시 값은 값으로 전달되지만 객체는 참조를 공유합니다. 상태 변경 위치를 분리해야 예측 가능한 UI를 만들 수 있습니다.

## 실습 준비

이 단위는 Frontory에서 대표 예제를 편집하고 실행할 수 있습니다. 문서의 확장 과제는 직접 구현하세요. JSX·Vue SFC·Svelte 컴포넌트를 그대로 입력하는 범용 컴파일러는 아니며 지원 범위는 아래 연결된 예제 안내에 명시합니다.

## 실습 과제

1. 공식 참고에서 이번 개념과 API의 입력·출력을 찾아 필기에 요약합니다.
2. 배열로 학습 목록을 만들고 filter/map으로 미완료 목록을 계산하세요. 원본 수정과 새 배열 생성의 차이를 로그로 비교하세요.
3. 아래 변수 중 하나만 바꾸기 전에 예상 결과를 적고, 실행 후 스크린샷·로그 또는 측정값과 비교합니다.
4. 원래 조건으로 되돌려 같은 결과를 재현하고 오류·지원 제한도 남깁니다.

## 관찰할 변수

객체 복사 깊이, 배열 길이. 비교 시 다른 변수와 브라우저·viewport 조건은 고정합니다.

## 완료 조건

- [ ] 원본이 바뀌는 경우와 보존되는 경우를 재현한다.
- [ ] 최소 두 조건의 예상과 실제 결과를 구분해 기록했다.
- [ ] 오류 또는 경계 조건 한 가지를 재현하고 복구 방법을 적었다.
- [ ] 실제로 수행한 내용을 기준으로 완료 상태를 직접 표시했다.

## 자가 점검

1. 값과 상태에서 입력이 결과로 이어지는 경로를 설명할 수 있나요?
2. 객체 복사 깊이, 배열 길이 중 어떤 변수가 예상과 다르게 동작했으며 이유는 무엇인가요?
3. 원본이 바뀌는 경우와 보존되는 경우를 재현한다. 이 조건이 깨지는 사례와 확인 방법은 무엇인가요?
