## 핵심 개념과 설명

### 참조 공유

객체를 대입하면 같은 객체를 가리키는 값이 복사됩니다. 얕은 복사에서는 중첩 객체를 계속 공유합니다.

### 파생 목록

filter와 map은 새 배열을 반환합니다. 콜백에서 내부 객체를 수정하면 원본도 바뀔 수 있습니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. state.js 파일에 완료 1개와 미완료 2개인 중첩 객체 배열 조건을 준비하세요.
2. filter/map으로 미완료 제목을 구하고 직접 수정과 새 객체 교체를 console.assert로 비교하세요.
3. 완료 1개와 미완료 2개인 중첩 객체 배열 조건으로 실행하세요. 확인할 결과: 미완료 제목 2개를 추출한다. 참조 동등성과 원본 값 비교 2쌍을 남긴다. 예상과 실제 결과는 구분해 기록하세요.
