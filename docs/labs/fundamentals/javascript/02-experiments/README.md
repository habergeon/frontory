## 선수 지식

13단위 「Promise와 실행 순서」의 결과물과 실험 기록

## 핵심 개념과 설명

### 응답 경합

요청 순서와 완료 순서는 다를 수 있습니다. 요청 id를 검사하면 오래된 응답의 반영을 막습니다.

### 취소 신호

AbortController의 signal로 취소를 전달합니다. 모의 함수도 signal을 처리해야 실제로 중단됩니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. search.js 파일에 100ms 간격 검색 두 번, 두 번째 응답 100ms 조건을 준비하세요.
2. 지연 모의 검색에 요청 id 검사와 signal 처리를 각각 구현하고 최종 결과를 표시하세요.
3. 100ms 간격 검색 두 번, 두 번째 응답 100ms 조건으로 실행하세요. 확인할 결과: 역순 완료에서도 두 번째 검색어가 화면에 남는다. 취소와 일반 실패 로그를 구분한다. 예상과 실제 결과는 구분해 기록하세요.
