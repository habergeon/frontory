## 핵심 개념과 설명

### 모듈 조합

상태·저장·DOM을 분리하면 각 경계를 따로 검증할 수 있습니다. main은 연결과 정리를 담당합니다.

### 흐름 검증

개별 기능의 성공만으로 전체 흐름을 보장하지 못합니다. 추가부터 내보내기와 복원까지 같은 데이터로 확인합니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. main.js 파일에 메모 10개, 재마운트 5회, 손상 파일 가져오기 조건을 준비하세요.
2. 메모 추가·필터·JSON 저장과 복원을 연결하고 이벤트 해제 후 재연결하세요.
3. 메모 10개, 재마운트 5회, 손상 파일 가져오기 조건으로 실행하세요. 확인할 결과: 추가·필터·내보내기·복원 네 흐름을 기록한다. 클릭 한 번에 한 건만 추가되고 실패 가져오기는 기존 상태를 보존한다. 예상과 실제 결과는 구분해 기록하세요.
