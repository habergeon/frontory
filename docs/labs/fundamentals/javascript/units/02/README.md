## 핵심 개념과 설명

### 입력 타입

input.value는 문자열입니다. 숫자로 바꾸기 전에는 덧셈이 이어 붙이기로 동작할 수 있습니다.

### 유효한 수

Number.isFinite는 유한한 숫자인지 검사합니다. 빈 문자열은 Number로 변환하면 0이므로 따로 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. numbers.js 파일에 15, 빈 문자열, 15px, -1 입력 조건을 준비하세요.
2. parseMinutes에서 trim과 Number 변환 뒤 성공 또는 오류 객체를 반환하세요.
3. 15, 빈 문자열, 15px, -1 입력 조건으로 실행하세요. 확인할 결과: 네 입력의 판정과 타입을 기록한다. 공백과 음수에서 저장 건수가 늘지 않는다. 예상과 실제 결과는 구분해 기록하세요.
