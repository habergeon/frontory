## 핵심 개념과 설명

### 동등 비교

===는 타입 강제 변환 없이 비교합니다. 객체는 내용이 같아도 참조가 다르면 다릅니다.

### 널 기본값

??는 null과 undefined에만 기본값을 적용합니다. 0과 빈 문자열을 유지할 때 논리 OR와 결과가 다릅니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. defaults.js 파일에 0, 빈 문자열, null, undefined와 객체 2개 조건을 준비하세요.
2. 논리 OR와 ??로 기본값 10을 적용하고 동일 내용 객체의 ===도 출력하세요.
3. 0, 빈 문자열, null, undefined와 객체 2개 조건으로 실행하세요. 확인할 결과: 기본값 출력 8개를 기록한다. 같은 참조와 다른 참조의 비교 결과를 설명한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| ------ | --------- | --------- | ----------------------------------------------------------------------------------------------- |
| 연산자 | 논리 OR   | ??        | 실행 전 가설: 0 설정이 유지될 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
