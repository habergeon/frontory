## 핵심 개념과 설명

### 경계 처리

조기 반환은 잘못된 입력을 함수 입구에서 처리합니다. 정상 경로의 중첩을 줄이면서 반환 형태를 맞춥니다.

### 분기 누락

switch의 default는 예상 밖의 값을 받습니다. 알 수 없는 값을 성공으로 바꾸면 원인이 숨겨집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. status.js 파일에 idle, running, done, null, paused 조건을 준비하세요.
2. 상태를 표시 문장으로 바꾸고 모든 경로에서 ok와 message를 반환하세요.
3. idle, running, done, null, paused 조건으로 실행하세요. 확인할 결과: 정상 3개와 오류 2개의 출력을 남긴다. 모든 반환 객체에 ok 필드가 있다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                                                     |
| ---- | --------- | --------- | --------------------------------------------------------------------------------------------------------- |
| 상태 | running   | paused    | 실행 전 가설: 명시적인 오류 결과가 나올 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
