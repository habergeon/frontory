## 선수 지식

4단위 「분기와 조기 반환」의 결과물과 실험 기록

## 핵심 개념과 설명

### 순수 계산

같은 입력에 같은 결과를 반환하고 외부 상태를 바꾸지 않습니다. DOM 표시는 별도 함수에 맡길 수 있습니다.

### 경계값

전체 수가 0이면 일반 나눗셈으로 비율을 정할 수 없습니다. 빈 목록 표시 정책을 함수 계약에 적습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. score.js 파일에 0/0, 1/4, 4/4 조건을 준비하세요.
2. 완료 비율 계산과 renderScore를 분리하고 console.assert로 계산만 검사하세요.
3. 0/0, 1/4, 4/4 조건으로 실행하세요. 확인할 결과: 세 입력에서 NaN과 Infinity가 표시되지 않는다. DOM 없이 계산한 결과 3건을 남긴다. 예상과 실제 결과는 구분해 기록하세요.
