## 핵심 개념과 설명

### 렉시컬 스코프

함수는 정의된 위치의 변수를 참조합니다. 호출 위치가 바뀌어도 참조하는 스코프는 같습니다.

### 독립 상태

팩토리 호출마다 지역 상태를 만들 수 있습니다. 전역 상태를 쓰면 서로 다른 위젯이 값을 공유합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. counter.js 파일에 A 두 번, B 한 번 클릭 조건을 준비하세요.
2. createCounter에서 증가·조회 함수를 반환하고 버튼 A와 B에 연결하세요.
3. A 두 번, B 한 번 클릭 조건으로 실행하세요. 확인할 결과: 독립 구현에서 A=2와 B=1을 확인한다. 공유 구현과 독립 구현의 로그를 비교한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건   | 바꿀 조건   | 예상할 변화·검증 가설                                                                                   |
| --------- | ----------- | ----------- | ------------------------------------------------------------------------------------------------------- |
| 상태 위치 | 팩토리 내부 | 모듈 최상위 | 실행 전 가설: 두 카운터가 값을 공유할 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
