## 목표와 학습 후 역량

- 선택 주제만 결과에 남고 원본 5개는 보존된다.
- 빈 배열 합계는 0이고 제목 목록은 빈 배열이다.

## 선수 지식

6단위 「스코프와 클로저」의 결과물과 실험 기록

## 핵심 개념과 설명

### 변환 순서

filter와 map의 순서는 중간 데이터 형태를 바꿉니다. 계산량뿐 아니라 최종 결과도 비교해야 합니다.

### 집계 초기값

reduce의 초기값은 빈 배열의 동작을 결정합니다. 초기값이 없으면 빈 배열에서 예외가 납니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. summary.js 파일에 기록 5개와 빈 배열 조건을 준비하세요.
2. 주제 필터·제목 변환·시간 합계를 독립 함수로 만들고 원본 보존을 검사하세요.
3. 기록 5개와 빈 배열 조건으로 실행하세요. 확인할 결과: 선택 주제만 결과에 남고 원본 5개는 보존된다. 빈 배열 합계는 0이고 제목 목록은 빈 배열이다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 배열 길이 | 5 | 0 | 실행 전 가설: 초기값 0을 둔 합계는 0일 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
