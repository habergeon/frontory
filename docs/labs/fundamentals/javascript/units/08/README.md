## 핵심 개념과 설명

### 구조 분해

속성을 지역 이름으로 꺼낼 수 있습니다. 기본값은 속성이 undefined일 때 적용됩니다.

### 선택적 접근

?.는 nullish 값에서 접근을 멈춥니다. 필수 필드 누락까지 조용히 숨기지 않도록 구분합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. profile.js 파일에 정상 작성자, contact 누락, name 누락 조건을 준비하세요.
2. 이름을 구조 분해하고 contact?.email로 보조 정보를 표시하세요.
3. 정상 작성자, contact 누락, name 누락 조건으로 실행하세요. 확인할 결과: 연락처 유무 모두 예외 없이 표시한다. 이름 누락은 정상 이름으로 저장되지 않는다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 연락처 | 객체 있음 | 없음 | 실행 전 가설: 보조 정보만 기본 안내로 바뀔 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
