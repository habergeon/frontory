## 핵심 개념과 설명

### 키 기반 조회

Map은 키와 값을 대응시킵니다. 같은 키를 set하면 기존 값이 교체됩니다.

### 중복 제거

Set은 같은 값을 한 번 보관합니다. 객체는 내용이 아니라 참조로 구분합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. index.js 파일에 중복 태그 6개와 메모 3개 조건을 준비하세요.
2. Set으로 태그를 줄이고 Map으로 메모를 조회한 뒤 같은 id를 갱신하세요.
3. 중복 태그 6개와 메모 3개 조건으로 실행하세요. 확인할 결과: 태그 중복 제거 전후 개수를 남긴다. 없는 id 조회와 기존 id 갱신을 각각 검증한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| set 키 | 새 id 4 | 기존 id 2 | 실행 전 가설: 크기는 그대로이고 id 2 값이 바뀔 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
