## 핵심 개념과 설명

### 예외 전파

throw는 가까운 catch로 제어를 넘깁니다. catch에서는 복구하거나 맥락을 더해 다시 전달합니다.

### 정리 보장

finally는 성공과 실패 뒤 실행됩니다. 여기서 return하면 원래 반환값이나 예외를 덮을 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. parse.js 파일에 정상 JSON과 닫는 괄호가 빠진 JSON 조건을 준비하세요.
2. JSON.parse를 try/catch로 감싸고 finally에서 진행 표시를 끄세요.
3. 정상 JSON과 닫는 괄호가 빠진 JSON 조건으로 실행하세요. 확인할 결과: 성공과 실패 모두 진행 상태가 종료된다. 실패 뒤 정상 입력을 다시 읽는다. 예상과 실제 결과는 구분해 기록하세요.
