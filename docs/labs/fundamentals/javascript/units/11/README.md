## 핵심 개념과 설명

### 노드 생성

createElement의 결과는 문서에 연결해야 보입니다. DocumentFragment로 여러 노드를 묶어 삽입할 수 있습니다.

### 텍스트 처리

textContent는 문자열을 텍스트로 다룹니다. 사용자 입력을 innerHTML로 넣으면 마크업으로 해석될 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. render.js 파일에 메모 3개와 <strong>실험</strong> 제목 조건을 준비하세요.
2. li를 생성해 제목을 textContent로 넣고 fragment를 ul에 연결하세요.
3. 메모 3개와 <strong>실험</strong> 제목 조건으로 실행하세요. 확인할 결과: 메모 3개에 대응하는 li 3개가 있다. 태그 입력으로 strong 요소가 생성되지 않는다. 예상과 실제 결과는 구분해 기록하세요.
