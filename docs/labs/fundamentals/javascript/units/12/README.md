## 핵심 개념과 설명

### 버블링

많은 이벤트는 대상에서 조상으로 전달됩니다. target과 currentTarget은 서로 다른 요소일 수 있습니다.

### 위임 처리

부모 리스너로 자식의 동작을 처리합니다. closest 결과가 해당 부모 내부인지 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. events.js 파일에 버튼 안 span 클릭과 동적 추가 항목 클릭 조건을 준비하세요.
2. ul에 click을 연결하고 data-action 버튼을 closest로 찾아 삭제하세요.
3. 버튼 안 span 클릭과 동적 추가 항목 클릭 조건으로 실행하세요. 확인할 결과: 추가 항목도 개별 리스너 없이 삭제된다. span 클릭 한 번에 처리 로그 한 줄이 남는다. 예상과 실제 결과는 구분해 기록하세요.
