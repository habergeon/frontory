## 핵심 개념과 설명

### 마이크로태스크

동기 코드가 끝난 뒤 Promise 반응 콜백을 처리합니다. 타이머 콜백과 다른 큐에서 실행 순서를 결정합니다.

### 체인 반환

then에서 Promise를 반환하면 다음 단계가 그 결과를 기다립니다. 반환을 빠뜨리면 내부 작업과 뒤 단계가 분리됩니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. order.js 파일에 지연 작업 두 개와 reject 한 개 조건을 준비하세요.
2. 동기·then·setTimeout 로그를 배치하고 반환 유무와 reject 전파를 비교하세요.
3. 지연 작업 두 개와 reject 한 개 조건으로 실행하세요. 확인할 결과: 세 종류 로그의 실제 순서를 기록한다. reject가 마지막 catch에서 한 번 처리된다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| then 반환 | Promise 반환 | 반환 생략 | 실행 전 가설: 뒤 단계가 내부 작업보다 먼저 진행할 수 있다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
