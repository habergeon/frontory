## 핵심 개념과 설명

### 응답 상태

fetch는 HTTP 오류에도 Response를 반환할 수 있습니다. response.ok로 성공 여부를 판단합니다.

### 본문 읽기

json은 본문을 읽는 비동기 메서드입니다. 이미 소비한 본문을 다시 읽는 동작에는 제한이 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. api.js 파일에 data.json과 없는 missing.json 조건을 준비하세요.
2. 같은 출처 파일을 fetch하고 ok 검사 후 json을 읽어 목록이나 오류를 표시하세요.
3. data.json과 없는 missing.json 조건으로 실행하세요. 확인할 결과: 성공 목록과 404 안내를 각각 확인한다. HTTP 오류와 JSON 파싱 오류를 구분해 기록한다. 예상과 실제 결과는 구분해 기록하세요.
