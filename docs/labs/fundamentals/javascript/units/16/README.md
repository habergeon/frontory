## 핵심 개념과 설명

### 전체 성공

Promise.all은 입력 순서로 성공 결과를 반환합니다. 하나가 거부되면 결과 Promise도 거부됩니다.

### 부분 결과

allSettled는 각 작업의 성공과 실패를 모읍니다. 성공 항목만 표시할지 제품 정책으로 정합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. batch.js 파일에 서로 다른 지연과 두 번째 작업 실패 조건을 준비하세요.
2. 지연 작업 3개를 all과 allSettled로 실행하고 결과 순서와 상태를 출력하세요.
3. 서로 다른 지연과 두 번째 작업 실패 조건으로 실행하세요. 확인할 결과: 완료 순서와 반환 배열 순서를 구분한다. 부분 실패 화면에 성공 항목 2개가 남는다. 예상과 실제 결과는 구분해 기록하세요.
