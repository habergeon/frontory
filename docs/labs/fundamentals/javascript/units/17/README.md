## 핵심 개념과 설명

### 입력 묶기

디바운스는 새 입력마다 이전 타이머를 취소합니다. 마지막 입력 이후 정한 시간이 지나면 실행합니다.

### 수명주기

화면을 제거할 때 대기 타이머도 해제합니다. 이미 시작한 요청 취소는 별도로 처리합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. debounce.js 파일에 100ms 간격 입력 5회와 대기 중 dispose 조건을 준비하세요.
2. clearTimeout으로 검색을 지연하고 dispose에서 대기 작업을 취소하세요.
3. 100ms 간격 입력 5회와 대기 중 dispose 조건으로 실행하세요. 확인할 결과: 300ms 조건에서 검색 호출이 1회다. dispose 이후 대기 검색 호출은 0회다. 예상과 실제 결과는 구분해 기록하세요.
