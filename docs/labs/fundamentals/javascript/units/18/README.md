## 핵심 개념과 설명

### 모듈 계약

export와 import는 파일의 공개 항목을 정합니다. 브라우저 로딩에는 경로와 MIME 타입도 영향을 줍니다.

### 책임 분리

계산 모듈이 DOM을 몰라도 호출될 수 있습니다. 화면 모듈은 계산 결과를 전달받아 표시합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. main.js 파일에 정상 상대 경로와 missing.js 경로 조건을 준비하세요.
2. state.js와 view.js를 분리해 import하고 HTTP 서버에서 모듈을 로드하세요.
3. 정상 상대 경로와 missing.js 경로 조건으로 실행하세요. 확인할 결과: state.js 계산을 DOM 없이 호출한다. 경로를 복원하면 초기 목록이 표시된다. 예상과 실제 결과는 구분해 기록하세요.
