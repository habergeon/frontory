## 핵심 개념과 설명

### 문자열 저장

localStorage는 문자열을 저장합니다. JSON 직렬화와 파싱 규칙이 저장 계약에 포함됩니다.

### 실패 표시

환경 정책이나 용량 때문에 저장이 실패할 수 있습니다. 메모리 갱신과 저장 성공을 구분해 안내합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. storage.js 파일에 메모 3개와 손상된 저장 문자열 조건을 준비하세요.
2. 실습 전용 키로 저장·복원하고 파싱 오류와 쓰기 실패를 catch로 표시하세요.
3. 메모 3개와 손상된 저장 문자열 조건으로 실행하세요. 확인할 결과: 새로고침 전후 메모 id 3개가 같다. 손상 데이터와 정상 빈 목록의 안내가 다르다. 예상과 실제 결과는 구분해 기록하세요.
