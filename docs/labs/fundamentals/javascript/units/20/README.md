## 핵심 개념과 설명

### 검색 매개변수

URLSearchParams는 쿼리 인코딩을 처리합니다. get과 getAll은 중복 키를 다르게 읽습니다.

### 히스토리

pushState는 새 기록을 추가합니다. 뒤로 가기의 popstate를 받아 화면도 동기화합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. route.js 파일에 주제 두 번 변경 후 뒤로 가기와 새로고침 조건을 준비하세요.
2. topic을 읽어 필터를 적용하고 변경 시 URL을 갱신하며 popstate를 처리하세요.
3. 주제 두 번 변경 후 뒤로 가기와 새로고침 조건으로 실행하세요. 확인할 결과: 새로고침 후 주소와 선택 필터가 같다. 뒤로 가기 후 이전 목록을 복원한다. 예상과 실제 결과는 구분해 기록하세요.
