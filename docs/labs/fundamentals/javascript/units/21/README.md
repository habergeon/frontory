## 핵심 개념과 설명

### 폼 수집

FormData는 name이 있는 성공적인 컨트롤 값을 수집합니다. 체크 해제 항목과 disabled 입력은 빠질 수 있습니다.

### 제품 규칙

네이티브 제약과 제품의 입력 규칙은 다릅니다. 공백 제목은 별도 정규화와 검사가 필요합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. form.js 파일에 공백 제목, 체크 해제, disabled 필드 조건을 준비하세요.
2. submit에서 FormData를 읽고 제목과 분을 검증한 뒤 메모를 추가하세요.
3. 공백 제목, 체크 해제, disabled 필드 조건으로 실행하세요. 확인할 결과: 공백 제목은 목록에 추가되지 않는다. 체크 여부에 따른 수집 항목 2쌍을 기록한다. 예상과 실제 결과는 구분해 기록하세요.
