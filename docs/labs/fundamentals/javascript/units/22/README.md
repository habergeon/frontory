## 핵심 개념과 설명

### 직렬화

JSON.stringify는 데이터를 문자열로 바꿉니다. 함수와 undefined는 기대한 방식으로 보존되지 않습니다.

### 객체 URL

Blob URL은 생성한 파일 데이터를 참조합니다. 사용을 마치면 revokeObjectURL로 해제합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. export.js 파일에 메모 3개와 한글·줄바꿈 제목 조건을 준비하세요.
2. 메모와 schemaVersion을 Blob으로 만들고 다운로드 링크로 notes.json을 저장하세요.
3. 메모 3개와 한글·줄바꿈 제목 조건으로 실행하세요. 확인할 결과: 내보낸 파일에 메모 3개와 버전 값이 있다. 생성한 객체 URL마다 해제 경로가 있다. 예상과 실제 결과는 구분해 기록하세요.
