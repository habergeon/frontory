## 핵심 개념과 설명

### 파일 읽기

File.text는 문자열을 반환하는 Promise입니다. 확장자만으로 내용의 유효성을 판단할 수 없습니다.

### 원자적 반영

전체 입력을 검증한 다음 상태를 교체합니다. 중간 오류가 기존 데이터를 일부만 덮지 않게 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 22단위에서 내려받은 notes.json({schemaVersion:1,notes:[...]})을 정상 파일로 사용하세요. import.js 과제에는 잘못된 버전, 숫자 title, 손상 JSON도 준비하세요.
2. 파일 루트가 객체인지, schemaVersion이 1인지, notes가 배열인지 확인한 뒤 notes의 id·title을 검사하세요. 별도 import.js에서는 전체 통과 뒤 상태를 교체하세요. 미리보기 textarea는 배열 검사 실험이며 실제 파일은 버전 객체를 받습니다.
3. 정상·한글/줄바꿈 파일의 항목 수와 내용을 확인하고 잘못된 버전·숫자 title·손상 JSON을 거부하세요. 기존 id 보존은 상태 반영을 구현한 import.js에서 검사하세요. starter의 accepted/committed 출력은 앱 상태 교체의 증거가 아닙니다.
