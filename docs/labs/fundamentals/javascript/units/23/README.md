### 파일 읽기

File.text는 문자열을 반환하는 Promise입니다. 확장자만으로 내용의 유효성을 판단할 수 없습니다.

### 원자적 반영

전체 입력을 검증한 다음 상태를 교체합니다. 중간 오류가 기존 데이터를 일부만 덮지 않게 합니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. import.js 파일에 정상 파일과 두 번째 title이 숫자인 파일 조건을 준비하세요.
2. 파일을 읽고 배열·id·title을 검사한 뒤 통과한 전체 배열만 반영하세요.
3. 정상 파일과 두 번째 title이 숫자인 파일 조건으로 실행하세요. 확인할 결과: 유효 파일의 항목 수를 그대로 복원한다. 거부 전후 기존 id 배열이 같다. 예상과 실제 결과는 구분해 기록하세요.
