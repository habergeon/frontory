## 핵심 개념과 설명

### 명령 모델

action으로 변경 이유를 표현합니다. reducer는 상태와 action을 받아 다음 상태를 계산합니다.

### 이력 보존

이전 상태를 보존하면 실행 취소가 가능합니다. 중첩 객체를 직접 수정하면 과거 이력도 바뀝니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. reducer.js 파일에 추가·완료·삭제 후 undo 3회 조건을 준비하세요.
2. add·toggle·remove와 history를 구현하고 undo 버튼을 연결하세요.
3. 추가·완료·삭제 후 undo 3회 조건으로 실행하세요. 확인할 결과: undo 3회 뒤 시작 id와 완료 값이 같다. 알 수 없는 action에서 상태가 보존된다. 예상과 실제 결과는 구분해 기록하세요.
