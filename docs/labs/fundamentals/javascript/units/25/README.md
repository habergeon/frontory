## 핵심 개념과 설명

### 시점 표현

Date는 시점을 밀리초로 표현합니다. 날짜만 필요한 정보와 시간대가 있는 시점은 구분합니다.

### 지역 표시

Intl.DateTimeFormat은 지정한 지역과 시간대로 표시합니다. 표시 문자열을 저장 형식으로 다시 파싱하면 모호해집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. date.js 파일에 정상 ISO 값과 잘못된 날짜 조건을 준비하세요.
2. 고정 ISO 시점을 저장하고 UTC와 Asia/Seoul formatter로 표시하세요.
3. 정상 ISO 값과 잘못된 날짜 조건으로 실행하세요. 확인할 결과: 두 표시값과 동일 epoch 값을 기록한다. 잘못된 날짜는 저장되지 않는다. 예상과 실제 결과는 구분해 기록하세요.
