## 핵심 개념과 설명

### 측정 범위

performance.now로 경과 시간을 구합니다. 데이터 크기와 실행 조건을 고정해야 비교할 수 있습니다.

### 입력 응답

긴 동기 작업은 메인 스레드 입력을 지연시킵니다. 분할은 총 처리 시간과 응답성에 다른 영향을 줄 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. perf.js 파일에 메모 10000개 검색을 각 3회 실행 조건을 준비하세요.
2. 검색을 동기 처리와 타이머 묶음 처리로 나누고 처리 중 버튼 응답을 관찰하세요.
3. 메모 10000개 검색을 각 3회 실행 조건으로 실행하세요. 확인할 결과: 동일 데이터의 두 경로를 각 3회 측정한다. 전체 시간과 입력 응답을 별도 항목으로 기록한다. 예상과 실제 결과는 구분해 기록하세요.
