## 핵심 개념과 설명

### 자원 소유

mount에서 만든 자원은 dispose에서 해제합니다. removeEventListener에는 동일 함수 참조가 필요합니다.

### 멱등 정리

dispose를 반복해도 부작용이 없어야 합니다. 해제 후 도착하는 비동기 콜백도 차단해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구로 확인하세요. 별도 폴더의 index.html에서 script type="module"로 실습 JS를 연결하고 로컬 HTTP 서버로 여세요. 콘솔·Network·Elements를 사용합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. lifecycle.js 파일에 마운트·해제 5회 후 클릭 한 번 조건을 준비하세요.
2. mount가 dispose를 반환하게 하고 리스너·타이머·진행 요청을 모두 정리하세요.
3. 마운트·해제 5회 후 클릭 한 번 조건으로 실행하세요. 확인할 결과: 5회 재마운트 뒤 처리 로그가 1개다. dispose 두 번 호출에서 예외와 남은 타이머가 없다. 예상과 실제 결과는 구분해 기록하세요.
