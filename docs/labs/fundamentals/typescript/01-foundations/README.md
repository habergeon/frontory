## 선수 지식

JavaScript 객체·함수·모듈

## 핵심 개념과 설명

### 정적 검사

타입은 실행 전에 코드의 관계를 검사합니다. 외부 JSON의 실제 내용을 자동으로 확인하지는 않습니다.

### 판별 유니온

공통 태그가 다른 객체들을 분기하면 필요한 필드로 좁힐 수 있습니다. 분기 밖에서 특정 상태의 필드에 접근하면 오류가 납니다.

## 실습 준비

Frontory의 기존 미리보기는 제한된 시작 예제이며 전체 과제의 완성본이 아닙니다. 추가 파일과 기능은 별도 로컬 프로젝트에서 직접 구현하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. state.ts 파일에 성공 데이터 접근과 idle에서 같은 접근 조건을 준비하세요.
2. idle·loading·success·error 유니온을 만들고 switch로 표시 문자열을 반환하세요.
3. 성공 데이터 접근과 idle에서 같은 접근 조건으로 실행하세요. 확인할 결과: 네 상태의 반환 문자열을 확인한다. 잘못된 접근의 컴파일 진단과 수정안을 남긴다. 예상과 실제 결과는 구분해 기록하세요.
