## 핵심 개념과 설명

### 타입 추론

초기값으로 변수 타입을 추론합니다. let과 const는 재대입 가능성 때문에 리터럴 보존이 다를 수 있습니다.

### 리터럴 보존

as const는 값의 타입을 좁게 보존합니다. 런타임 객체를 동결하는 기능은 아닙니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. literal.ts 파일에 ready만 받는 함수와 세 선언 방식 조건을 준비하세요.
2. 상태 문자열을 let·const·as const 객체로 선언하고 매개변수에 전달하세요.
3. ready만 받는 함수와 세 선언 방식 조건으로 실행하세요. 확인할 결과: 세 선언의 추론 타입을 기록한다. 잘못된 상태 문자열 호출은 컴파일에 실패한다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 선언 | let mode | const mode | 실행 전 가설: 리터럴 인수가 허용될 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
