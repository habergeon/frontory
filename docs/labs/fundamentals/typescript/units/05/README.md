## 핵심 개념과 설명

### 배열 원소

배열 타입은 모든 원소에 공통인 계약을 정합니다. 인덱스 접근은 실제 범위를 보장하지 않습니다.

### 튜플

튜플은 위치별 타입과 길이 관계를 표현합니다. 좌표처럼 순서가 의미인 작은 자료에 적합합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. coordinates.ts 파일에 두 좌표와 범위를 벗어난 인덱스 조건을 준비하세요.
2. 숫자 배열과 x·y 튜플을 만들고 위치를 바꾼 호출을 비교하세요.
3. 두 좌표와 범위를 벗어난 인덱스 조건으로 실행하세요. 확인할 결과: 정상 좌표 두 개의 거리를 계산한다. 잘못된 튜플 길이의 컴파일 진단을 남긴다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| ---- | ----------- | --------- | ---------------------------------------------------------------------------------------------------------------------- |
| 타입 | number 배열 | 좌표 튜플 | 실행 전 가설: 정해진 위치 바깥 접근을 더 일찍 발견할 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
