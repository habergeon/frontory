## 핵심 개념과 설명

### 함수 타입

매개변수와 반환 타입으로 호출 계약을 표현합니다. 반환 타입을 적으면 누락된 경로를 찾기 쉽습니다.

### 콜백 계약

콜백이 어떤 인수를 받는지 호출자가 정합니다. 선택 매개변수는 구현자의 편의만으로 붙이면 안 됩니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. functions.ts 파일에 빈 제목과 정상 제목, 인덱스 콜백 조건을 준비하세요.
2. 메모 변환 함수와 방문 콜백을 정의하고 모든 경로에서 결과를 반환하세요.
3. 빈 제목과 정상 제목, 인덱스 콜백 조건으로 실행하세요. 확인할 결과: 정상·빈 제목 결과가 같은 계약을 따른다. 잘못된 콜백 인수 타입이 거부된다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| --- | --- | --- | --- |
| 반환 경로 | 모든 경로 반환 | 한 분기 생략 | 실행 전 가설: 반환 타입 또는 noImplicitReturns 검사가 누락을 드러낼 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |
