## 핵심 개념과 설명

### unknown 경계

unknown은 확인 전 속성 접근을 막습니다. any는 검사 자체를 우회하므로 경계에서 정보를 잃습니다.

### 기본 가드

typeof와 null 검사를 조합해 값을 좁힙니다. typeof null이 object라는 점을 따로 처리합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. unknown.ts 파일에 문자열, 숫자, null, 객체 조건을 준비하세요.
2. unknown 값을 받아 문자열 길이를 반환하는 함수를 typeof 분기로 작성하세요.
3. 문자열, 숫자, null, 객체 조건으로 실행하세요. 확인할 결과: 네 입력의 성공·실패 결과를 기록한다. any와 무조건 단언 없이 tsc 검사를 통과한다. 예상과 실제 결과는 구분해 기록하세요.
