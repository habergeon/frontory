## 핵심 개념과 설명

### 명시적 결과

ok 태그로 성공값과 오류를 구분할 수 있습니다. 호출자는 결과를 좁힌 뒤 필요한 필드에 접근합니다.

### 예외 경계

예외를 Result로 바꾸면 예상 가능한 실패를 값으로 다룹니다. 프로그래밍 오류까지 무조건 숨기지 않도록 분류합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. result.ts 파일에 잘못된 JSON과 잘못된 구조 두 경우 조건을 준비하세요.
2. Result<T,E>와 parseNote를 만들고 오류 코드를 UI 문장으로 바꾸세요.
3. 잘못된 JSON과 잘못된 구조 두 경우 조건으로 실행하세요. 확인할 결과: 성공값은 Note로 추론된다. 두 실패 종류를 코드로 구분한다. 예상과 실제 결과는 구분해 기록하세요.
