## 핵심 개념과 설명

### 키 순회

Mapped Type은 키 유니온의 각 멤버에 타입을 대응합니다. 런타임 반복문을 생성하지는 않습니다.

### 변경자

readonly와 optional 변경자를 더하거나 제거할 수 있습니다. 파생 계약이 실제 사용 정책과 맞는지 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. mapped.ts 파일에 키 3개 설정과 새 키 1개 추가 조건을 준비하세요.
2. 설정 키별 오류 메시지 맵과 읽기 전용 설정 타입을 작성하세요.
3. 키 3개 설정과 새 키 1개 추가 조건으로 실행하세요. 확인할 결과: 모든 설정 키에 메시지가 대응한다. 새 키의 누락 진단과 수정 결과를 남긴다. 예상과 실제 결과는 구분해 기록하세요.

## 관찰할 변수

| --- | --- | --- | --- |
| 설정 키 수 | 3개 | 4개 | 실행 전 가설: 필수 맵 항목 누락이 드러날 것이다. 다른 조건은 고정하고 실행 후 실제 결과를 따로 기록합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
