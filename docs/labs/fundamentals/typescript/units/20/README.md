## 핵심 개념과 설명

### 타입 조건

조건부 타입은 타입 관계에 따라 결과를 선택합니다. 런타임 if와 별도로 동작합니다.

### 유니온 분배

나체 타입 매개변수의 조건은 유니온 멤버별로 적용될 수 있습니다. 튜플로 감싸면 분배를 제어할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. conditional.ts 파일에 문자열 배열, 숫자, 두 타입의 유니온 조건을 준비하세요.
2. 배열 원소 타입 추출과 분배·비분배 보조 타입을 만들고 대입으로 결과를 검사하세요.
3. 문자열 배열, 숫자, 두 타입의 유니온 조건으로 실행하세요. 확인할 결과: 세 입력의 결과 타입을 예제로 남긴다. 분배 여부에 따른 허용·거부 대입을 비교한다. 예상과 실제 결과는 구분해 기록하세요.
