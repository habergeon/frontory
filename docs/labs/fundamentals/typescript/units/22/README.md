## 핵심 개념과 설명

### DOM 조회

querySelector 결과는 요소가 없을 수 있습니다. 타입 인수만 지정해도 실제 요소 종류가 검증되지는 않습니다.

### 런타임 좁히기

instanceof HTMLInputElement로 입력 요소를 확인할 수 있습니다. EventTarget에도 같은 검사가 필요할 수 있습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. dom.ts 파일에 존재하는 input, 없는 선택자, div 대상 조건을 준비하세요.
2. 제목 입력을 조회해 instanceof로 좁힌 뒤 value를 읽고 오류 안내를 만드세요.
3. 존재하는 input, 없는 선택자, div 대상 조건으로 실행하세요. 확인할 결과: 세 대상 모두 처리 결과를 남긴다. non-null 단언 없이 tsc 검사를 통과한다. 예상과 실제 결과는 구분해 기록하세요.
