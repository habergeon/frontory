## 핵심 개념과 설명

### 타입 가져오기

import type은 타입 용도라는 뜻을 명시합니다. 런타임 의존성과 구분할 수 있습니다.

### 실행 환경

module과 moduleResolution은 실행·번들 환경에 맞춰야 합니다. 옵션만 바꿔 경로 문제가 자동 해결되지는 않습니다.

## 실습 준비

문서 안내형 단위이며 전용 내장 실행 예제는 제공하지 않습니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. contracts.ts 파일에 브라우저 번들 환경의 두 모듈 조건을 준비하세요.
2. 타입을 export하고 main.ts에서 import type으로 읽은 뒤 실제 함수 import와 출력 차이를 보세요.
3. 브라우저 번들 환경의 두 모듈 조건으로 실행하세요. 확인할 결과: 타입 전용 import의 출력 코드 차이를 남긴다. 실제 환경에서 모듈을 로드하고 오류가 없는지 확인한다. 예상과 실제 결과는 구분해 기록하세요.
