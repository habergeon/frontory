## 핵심 개념과 설명

### 공통 인터페이스

mount와 dispose 계약으로 구현의 경계를 정합니다. 컨텍스트에 필요한 DOM과 설정만 전달합니다.

### 생명주기

타입이 같아도 이벤트 누수는 생길 수 있습니다. 반복 마운트와 중복 해제를 런타임에서 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트에서 직접 구현하고 브라우저 개발자 도구와 tsc --noEmit로 확인하세요. 별도 TypeScript 프로젝트에서 설치한 tsc 버전을 기록하세요. tsconfig.json에 strict를 켜고 tsc --noEmit으로 검사한 뒤, 실행 실습은 컴파일 출력 또는 로컬 개발 서버로 여세요. TS 타입 표기를 브라우저가 직접 실행한다고 가정하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. plugin.ts 파일에 마운트 5회와 dispose 연속 2회 조건을 준비하세요.
2. Plugin과 Context를 정의하고 하나의 DOM 구현에서 자원 정리 목록을 작성하세요.
3. 마운트 5회와 dispose 연속 2회 조건으로 실행하세요. 확인할 결과: 정리 후 이벤트 처리 횟수가 0회다. 재마운트한 버튼의 클릭 처리 횟수는 1회다. 예상과 실제 결과는 구분해 기록하세요.
