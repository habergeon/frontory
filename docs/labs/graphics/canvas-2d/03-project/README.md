## 목표와 학습 후 역량

- 동일 조건의 전후 프레임 기록과 품질 이미지가 있다.
- 개선 효과와 남은 병목을 근거로 설명한다.

## 선수 지식

선수 개념: 입력 재현, 수명 정리. 27단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 비용의 세 축

입자 개수는 갱신량을, 해상도는 채울 픽셀을 늘립니다. 상태 변경 횟수도 영향을 주므로 하나의 숫자로 병목을 설명할 수 없습니다.

### 근거 있는 개선

정적 배경 분리는 반복 작업을 줄일 수 있습니다. 효과는 장면 구성과 브라우저에 달려 있으므로 같은 조건의 기록으로 판단합니다.

## 실습 준비

기존 내장 예제는 출발점만 제공합니다. 확장 요구사항 전체가 구현된 예제가 아니며 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-28.js와 index.html을 준비하세요. 기존 canvas-2d-03을 출발점으로 입자 수·DPR·배경 캐시를 조절하는 실험 화면을 완성하세요.
2. 입자 seed와 viewport를 고정하고 캐시 전후 프레임 분포, 화면 품질, 생성·삭제 후 상태를 보고서로 저장하세요.
3. 입력 조건 매 프레임 경로 그리기에서 출력을 저장한 뒤 정적 레이어 재사용 조건으로 다시 실행하세요. 예상: 반복 경로 비용이 줄 수 있으나 추가 합성 비용과 함께 비교해야 합니다. 실제 화면·로그와 대조하고 day-28-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| --------- | --------------------- | ------------------ | ------------------------------------------------------------------- |
| 배경 처리 | 매 프레임 경로 그리기 | 정적 레이어 재사용 | 반복 경로 비용이 줄 수 있으나 추가 합성 비용과 함께 비교해야 합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
