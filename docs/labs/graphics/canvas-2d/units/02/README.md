## 핵심 개념과 설명

### 경로 수명

beginPath는 현재 경로를 비웁니다. 이전 경로를 남기면 새 도형의 stroke가 기존 선까지 다시 그립니다.

### 선의 경계

lineCap과 lineJoin은 끝과 꺾임의 형태를 결정합니다. 굵기가 같은 선도 모서리에서 차지하는 범위가 달라집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-02.js와 index.html을 준비하세요. beginPath,moveTo,lineTo로 꺾인 선 세 개를 그리세요.
2. lineCap과 lineJoin을 입력 select에 연결하고 경로를 초기화하지 않은 비교 그림도 나란히 표시하세요.
3. 입력 조건 miter에서 출력을 저장한 뒤 round 조건으로 다시 실행하세요. 예상: 뾰족한 바깥 모서리가 둥글게 바뀝니다. 실제 화면·로그와 대조하고 day-02-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| lineJoin | miter | round | 뾰족한 바깥 모서리가 둥글게 바뀝니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
