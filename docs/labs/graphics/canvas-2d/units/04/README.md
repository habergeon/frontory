# Canvas 2D · 04 행렬과 회전 중심

## 목표와 학습 후 역량

- 두 변환 순서의 궤적을 구별한다.
- 회전 후 상태를 복원해 격자가 기울지 않는다.

## 선수 지식

선수 개념: 상태 스택, 함수 계약. 3단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 변환 순서

translate와 rotate의 순서는 결과에 영향을 줍니다. 원점 이동 뒤 회전하면 이동한 점이 도형의 회전 중심이 됩니다.

### 로컬 좌표

도형 중심을 원점으로 두면 회전 계산이 단순해집니다. 화면 좌표로 직접 그리는 방식과 비교하면 변환의 역할을 볼 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-04.js와 index.html을 준비하세요. translate(cx,cy),rotate(angle),fillRect(-w/2,-h/2,w,h)로 바늘을 그리세요.
2. 슬라이더를 angle에 연결하고 호출 순서를 바꾼 두 번째 바늘의 끝 좌표를 표시하세요.
3. 입력 조건 이동 후 회전에서 출력을 저장한 뒤 회전 후 이동 조건으로 다시 실행하세요. 예상: 도형이 자기 중심 대신 화면 원점을 따라 공전합니다. 실제 화면·로그와 대조하고 day-04-notes.md에 실제 결과와 차이의 원인을 남기세요.

| 변환 순서 | 이동 후 회전 | 회전 후 이동 | 도형이 자기 중심 대신 화면 원점을 따라 공전합니다 |
