## 핵심 개념과 설명

### 색 보간

createLinearGradient는 좌표 사이의 색 정지점을 연결합니다. 정지점 간격을 바꾸면 같은 두 색도 변화 속도가 달라집니다.

### 합성 알파

globalAlpha는 이후 그리기의 투명도를 곱합니다. 이미 투명한 색에 다시 적용하면 예상보다 옅어질 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-05.js와 index.html을 준비하세요. createLinearGradient와 addColorStop으로 수평 색 막대를 그리세요.
2. 반투명 원을 겹쳐 그리고 globalAlpha 적용 전후 중앙 픽셀 색을 화면으로 비교하세요.
3. 입력 조건 0.5에서 출력을 저장한 뒤 0.2 조건으로 다시 실행하세요. 예상: 중간 색에 도달하는 구간이 왼쪽으로 좁아집니다. 실제 화면·로그와 대조하고 day-05-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 중간 정지점 | 0.5 | 0.2 | 중간 색에 도달하는 구간이 왼쪽으로 좁아집니다 |
