## 선수 지식

선수 개념: 색 보간, 합성 알파. 5단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 비동기 이미지

이미지는 다운로드와 디코딩이 끝나야 그릴 수 있습니다. decode 실패를 처리하지 않으면 빈 화면의 원인을 알기 어렵습니다.

### 소스 사각형

drawImage의 아홉 인자는 원본 자르기와 출력 영역을 나눕니다. 두 영역의 비율이 다르면 그림이 늘어납니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-06.js와 index.html을 준비하세요. 로컬 sprite.png를 Image로 읽고 decode 이후 drawImage로 표시하세요.
2. 소스 x좌표를 슬라이더로 바꿔 프레임을 자르고 실패 경로에는 HTML 오류 문구를 출력하세요.
3. 입력 조건 64에서 출력을 저장한 뒤 32 조건으로 다시 실행하세요. 예상: 같은 출력 폭에서 잘린 부분이 두 배로 확대됩니다. 실제 화면·로그와 대조하고 day-06-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 소스 폭 | 64 | 32 | 같은 출력 폭에서 잘린 부분이 두 배로 확대됩니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
