# Canvas 2D · 07 텍스트와 배지 구성

## 목표와 학습 후 역량

- 텍스트 길이에 맞춰 배경 폭이 조절된다.
- 기준선을 바꾼 배치 차이를 기록한다.

## 선수 지식

선수 개념: 비동기 이미지, 소스 사각형. 6단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 텍스트 측정

measureText는 현재 폰트 설정의 측정값을 반환합니다. 문자열 길이만으로 계산하면 한글과 영문의 폭을 잘못 추정합니다.

### 기준선

textBaseline은 y좌표의 기준을 정합니다. 가운데 배치에는 글자 폭뿐 아니라 기준선도 고려해야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-07.js와 index.html을 준비하세요. font 설정 후 measureText로 배지 폭을 계산하고 fillText로 이름을 표시하세요.
2. 한글 이름과 긴 영문 이름을 입력받아 여백이 일정한 배지 PNG 모습을 비교하세요.
3. 입력 조건 가나에서 출력을 저장한 뒤 WWW iii 조건으로 다시 실행하세요. 예상: 문자 수가 비슷해도 배지 폭은 실제 글리프 폭에 따라 달라집니다. 실제 화면·로그와 대조하고 day-07-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 입력 문자열 | 가나 | WWW iii | 문자 수가 비슷해도 배지 폭은 실제 글리프 폭에 따라 달라집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
