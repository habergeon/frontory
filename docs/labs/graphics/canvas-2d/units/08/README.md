## 선수 지식

선수 개념: 텍스트 측정, 기준선. 7단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 시간 단위

requestAnimationFrame 콜백의 시간은 밀리초입니다. 초당 속도에 쓰려면 이전 시간과의 차이를 초로 바꿉니다.

### 시뮬레이션 분리

update는 위치를 바꾸고 draw는 현재 상태만 그립니다. 둘을 분리하면 같은 입력 시간으로 이동을 재현할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-08.js와 index.html을 준비하세요. update(dt)에서 x+=velocity*dt를 계산하고 draw에서 공을 그리세요.
2. requestAnimationFrame 시간 차이와 누적 이동거리를 output에 표시하세요.
3. 입력 조건 1/60초에서 출력을 저장한 뒤 1/30초 조건으로 다시 실행하세요. 예상: 한 번의 이동은 두 배지만 같은 총 시간의 거리는 같습니다. 실제 화면·로그와 대조하고 day-08-notes.md에 실제 결과와 차이의 원인을 남기세요.
