## 선수 지식

선수 개념: 시간 단위, 시뮬레이션 분리. 8단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 루프 소유권

애니메이션 요청 ID는 예약된 콜백을 취소하는 데 씁니다. 재개할 때 중복 예약을 만들면 같은 상태를 두 번 갱신합니다.

### 긴 시간 차이

탭이 숨겨진 동안 콜백이 지연될 수 있습니다. 재개 시 시계를 초기화할지 시간을 따라잡을지 정책을 정해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-09.js와 index.html을 준비하세요. 시작·정지 버튼에서 requestAnimationFrame과 cancelAnimationFrame을 관리하세요.
2. visibilitychange로 숨김 상태를 감지하고 재개 직후 dt를 0으로 재설정하세요.
3. 입력 조건 이전 시간 유지에서 출력을 저장한 뒤 이전 시간 초기화 조건으로 다시 실행하세요. 예상: 장시간 정지 뒤 공의 순간 이동을 막습니다. 실제 화면·로그와 대조하고 day-09-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| --- | --- | --- | --- |
| 재개 정책 | 이전 시간 유지 | 이전 시간 초기화 | 장시간 정지 뒤 공의 순간 이동을 막습니다 |
