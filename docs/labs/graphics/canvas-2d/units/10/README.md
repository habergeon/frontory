## 목표와 학습 후 역량

- 공이 벽 바깥에서 머물지 않는다.
- 높은 속도에서 남는 오차를 기록한다.

## 선수 지식

선수 개념: 루프 소유권, 긴 시간 차이. 9단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 반지름 경계

공의 중심만 검사하면 반지름만큼 벽을 뚫습니다. 중심을 반지름과 너비-반지름 사이로 제한해야 합니다.

### 초과 이동

긴 dt에서는 경계를 크게 넘을 수 있습니다. 위치 보정과 속도 반전을 함께 해야 벽에 붙는 현상을 피합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-10.js와 index.html을 준비하세요. 공의 x,y와 vx,vy를 갱신한 뒤 네 벽에서 반지름을 고려해 반사시키세요.
2. dt를 입력값으로 주는 단일 스텝 버튼을 만들어 큰 시간 간격의 충돌을 검사하세요.
3. 입력 조건 0.016초에서 출력을 저장한 뒤 0.2초 조건으로 다시 실행하세요. 예상: 이산 충돌의 초과 이동이 커져 보정 필요성이 드러납니다. 실제 화면·로그와 대조하고 day-10-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| dt | 0.016초 | 0.2초 | 이산 충돌의 초과 이동이 커져 보정 필요성이 드러납니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
