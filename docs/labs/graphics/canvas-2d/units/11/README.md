## 핵심 개념과 설명

### 좌표계 분리

clientX는 viewport 기준 좌표입니다. canvas의 경계 사각형을 빼고 논리 크기 비율을 적용해야 그림 좌표가 됩니다.

### 버퍼와 입력

DPR은 출력 해상도에 영향을 줍니다. CSS 논리 좌표로 그릴 때 포인터에 DPR을 다시 곱하면 선택 위치가 어긋납니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-11.js와 index.html을 준비하세요. pointerdown에서 getBoundingClientRect를 사용해 논리 x,y를 계산하세요.
2. 캔버스에 여백을 주고 CSS 크기를 절반으로 줄여 클릭 위치에 십자선을 그리세요.
3. 입력 조건 400px에서 출력을 저장한 뒤 200px 조건으로 다시 실행하세요. 예상: 동일한 그림 위치를 클릭하면 논리 좌표가 유지됩니다. 실제 화면·로그와 대조하고 day-11-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| CSS 표시 폭 | 400px | 200px | 동일한 그림 위치를 클릭하면 논리 좌표가 유지됩니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
