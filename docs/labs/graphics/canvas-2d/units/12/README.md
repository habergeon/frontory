- 빈 영역 클릭은 선택을 해제한다.
- 그리기와 선택이 같은 경로를 사용한다.

## 선수 지식

선수 개념: 좌표계 분리, 버퍼와 입력. 11단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 경로 재사용

Path2D는 도형 경로를 보관합니다. 화면의 픽셀 색을 읽지 않고 같은 경로로 선택 여부를 검사할 수 있습니다.

### 선택 순서

겹친 도형은 그리기 순서에 따라 가려집니다. 뒤에서 앞으로 검사하면 가장 위에 보이는 항목을 먼저 고를 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-12.js와 index.html을 준비하세요. 도형마다 Path2D와 id를 저장하고 isPointInPath로 클릭을 검사하세요.
2. 겹친 원과 사각형을 역순 순회하며 선택 id와 테두리를 출력하세요.
3. 입력 조건 앞에서 뒤에서 출력을 저장한 뒤 뒤에서 앞 조건으로 다시 실행하세요. 예상: 겹침 영역에서 화면 위쪽 도형이 선택됩니다. 실제 화면·로그와 대조하고 day-12-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 검사 순서 | 앞에서 뒤 | 뒤에서 앞 | 겹침 영역에서 화면 위쪽 도형이 선택됩니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
