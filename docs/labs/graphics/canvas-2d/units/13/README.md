## 핵심 개념과 설명

### 포인터 캡처

setPointerCapture는 포인터가 요소 밖으로 나가도 이벤트를 받을 수 있게 합니다. pointercancel도 종료 처리에 포함해야 상태가 남지 않습니다.

### 잡은 위치

중심과 클릭 위치의 차이를 보관하면 도형이 튀지 않습니다. 이동 때 그 차이를 빼면 잡은 지점을 유지합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-13.js와 index.html을 준비하세요. pointerdown에서 선택 id와 dragOffset을 저장하고 포인터를 캡처하세요.
2. pointermove에서 위치를 바꾸고 pointerup과 pointercancel에서 드래그를 종료하세요.
3. 입력 조건 도형 중심에서 출력을 저장한 뒤 도형 가장자리 조건으로 다시 실행하세요. 예상: offset 보정이 있으면 시작 순간 중심이 튀지 않습니다. 실제 화면·로그와 대조하고 day-13-notes.md에 실제 결과와 차이의 원인을 남기세요.
