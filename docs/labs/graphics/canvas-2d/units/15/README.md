## 핵심 개념과 설명

### 데이터 원본

Canvas는 개별 도형 객체를 보관하지 않습니다. 배열에 위치와 색을 저장해야 변경과 삭제 뒤 화면을 다시 만들 수 있습니다.

### 그리기 순수성

draw가 데이터를 수정하면 다시 그릴 때 결과가 바뀝니다. 렌더와 수정 함수를 분리해 재현성을 확보합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-15.js와 index.html을 준비하세요. 도형 배열을 입력받는 renderScene(ctx,items)를 작성하세요.
2. HTML 목록에서 id 하나를 삭제하고 clearRect 뒤 전체 장면을 다시 그리세요.
3. 입력 조건 마지막 도형에서 출력을 저장한 뒤 중간 도형 조건으로 다시 실행하세요. 예상: 배열 순서를 유지한 채 해당 그림만 사라집니다. 실제 화면·로그와 대조하고 day-15-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 삭제 대상 | 마지막 도형 | 중간 도형 | 배열 순서를 유지한 채 해당 그림만 사라집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
