## 선수 지식

선수 개념: 스냅샷, 명령 경계. 16단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 합성 연산

globalCompositeOperation은 새 픽셀과 기존 픽셀의 결합 규칙입니다. destination-out은 새 도형의 알파로 기존 영역을 지웁니다.

### 레이어 분리

지우개는 대상 캔버스의 픽셀에만 작동합니다. 배경을 함께 그렸다면 배경까지 지워질 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-17.js와 index.html을 준비하세요. 별도 잉크 canvas에 선을 그리고 지우개 모드에서 destination-out을 적용하세요.
2. 작업 뒤 source-over로 복원하고 투명 영역 아래 HTML 배경이 드러나는지 확인하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 0.3 조건으로 다시 실행하세요. 예상: 완전 삭제 대신 여러 번 지나가며 점차 옅어집니다. 실제 화면·로그와 대조하고 day-17-notes.md에 실제 결과와 차이의 원인을 남기세요.
