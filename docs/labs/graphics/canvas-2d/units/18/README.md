## 핵심 개념과 설명

### 클리핑 범위

clip은 이후 그림이 보이는 영역을 제한합니다. save와 restore로 묶지 않으면 다음 작업도 같은 영역에 갇힙니다.

### 그리기 순서

마스크 경로는 그림보다 먼저 설정합니다. 나중에 clip을 호출해도 이미 그린 픽셀을 소급해 자르지 않습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-18.js와 index.html을 준비하세요. 원 경로로 clip한 뒤 로컬 이미지를 drawImage로 채우세요.
2. 마스크 밖의 라벨은 restore 후 그려 원형 아바타와 설명을 구성하세요.
3. 입력 조건 60에서 출력을 저장한 뒤 30 조건으로 다시 실행하세요. 예상: 이미지 위치는 유지되고 노출 영역만 줄어듭니다. 실제 화면·로그와 대조하고 day-18-notes.md에 실제 결과와 차이의 원인을 남기세요.
