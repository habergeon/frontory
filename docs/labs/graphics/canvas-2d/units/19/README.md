## 선수 지식

선수 개념: 클리핑 범위, 그리기 순서. 18단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 픽셀 배열

getImageData는 RGBA 값을 가진 배열을 반환합니다. 픽셀 인덱스는 행 너비와 채널 수를 함께 고려해야 합니다.

### 직접 쓰기

putImageData는 픽셀 데이터를 기록합니다. 현재 변환을 따라 도형처럼 배치되지 않으므로 버퍼 좌표를 명시해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-19.js와 index.html을 준비하세요. 작은 로컬 이미지를 읽어 getImageData로 각 픽셀의 RGB 평균을 계산하세요.
2. 원본과 회색조를 putImageData로 별도 캔버스에 표시하고 알파는 유지하세요.
3. 입력 조건 전체 이미지에서 출력을 저장한 뒤 왼쪽 절반 조건으로 다시 실행하세요. 예상: 절반만 회색으로 바뀌고 투명도는 같습니다. 실제 화면·로그와 대조하고 day-19-notes.md에 실제 결과와 차이의 원인을 남기세요.
