## 핵심 개념과 설명

### 관찰 대상

ResizeObserver는 요소 크기 변화를 감지합니다. 창 크기가 같아도 패널 폭이 바뀌면 캔버스 버퍼를 조정해야 합니다.

### 해상도 예산

DPR 증가는 면적 기준으로 픽셀 수를 늘립니다. 품질과 비용을 비교해 상한을 정하고 그 선택을 기록합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-21.js와 index.html을 준비하세요. 컨테이너를 ResizeObserver로 관찰해 CSS 크기와 버퍼 크기를 재계산하세요.
2. DPR 상한 select를 추가하고 기존 도형 좌표를 유지한 채 재그리세요.
3. 실제 devicePixelRatio가 2 이상인 환경에서 DPR 상한 1과 2를 비교하세요. 예상: CSS 크기가 같으면 버퍼 픽셀 수가 네 배가 됩니다. 선명도와 프레임 기록을 day-21-notes.md에 남기고 실제 DPR이 1인 환경은 별도 조건으로 기록하세요.

## 관찰할 변수

| --- | --- | --- | --- |
| DPR 상한 | 실제 devicePixelRatio가 2 이상인 환경에서 DPR 상한 1 | 2 | 선은 선명해질 수 있지만 처리 픽셀 수가 네 배가 됩니다 |
