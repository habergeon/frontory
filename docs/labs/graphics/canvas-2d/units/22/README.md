## 핵심 개념과 설명

### 대체 표현

Canvas 내부 픽셀에는 도형의 의미가 없습니다. HTML 목록과 설명을 함께 제공해야 선택 대상과 상태를 읽을 수 있습니다.

### 공통 명령

포인터와 키보드가 같은 명령 함수를 호출하면 결과가 일치합니다. 시각적 강조만으로 선택을 알리지 말고 텍스트 상태도 갱신합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-22.js와 index.html을 준비하세요. 도형별 HTML button 목록과 선택 상태 output을 추가하세요.
2. 버튼 클릭과 화살표 이동을 selectItem 및 moveItem 함수에 연결하세요.
3. 입력 조건 포인터에서 출력을 저장한 뒤 키보드만 조건으로 다시 실행하세요. 예상: 동일 id가 선택되고 같은 이동 명령이 적용됩니다. 실제 화면·로그와 대조하고 day-22-notes.md에 실제 결과와 차이의 원인을 남기세요.
