## 핵심 개념과 설명

### 입자 수명

입자는 위치·속도·나이·수명을 가진 데이터입니다. 수명이 끝난 항목을 제거해야 개수가 계속 늘지 않습니다.

### 방출률

초당 생성량은 dt와 연결해야 합니다. 소수 누적량을 보관하면 낮은 프레임률에서도 평균 방출량을 맞출 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-24.js와 index.html을 준비하세요. emitAccumulator에 rate*dt를 더하고 정수 개수만 입자 배열에 추가하세요.
2. age가 lifetime을 넘으면 제거하고 살아 있는 개수를 output에 표시하세요.
3. 입력 조건 20개/s에서 출력을 저장한 뒤 80개/s 조건으로 다시 실행하세요. 예상: 같은 수명에서 평균 활성 입자 수가 늘어납니다. 실제 화면·로그와 대조하고 day-24-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 방출률 | 20개/s | 80개/s | 같은 수명에서 평균 활성 입자 수가 늘어납니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
