## 핵심 개념과 설명

### 객체 재사용

매 프레임 객체를 새로 만들면 가비지 수집 부담이 생길 수 있습니다. 풀은 죽은 입자의 슬롯을 다시 사용합니다.

### 측정 분리

할당 감소가 곧 프레임 개선을 보장하지는 않습니다. 그리기 비용이 더 크면 총 시간 변화가 작을 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-25.js와 index.html을 준비하세요. 고정 크기 pool과 active 플래그로 입자 생성·반납을 구현하세요.
2. 같은 seed와 방출률로 배열 생성 방식과 풀 방식의 프레임 기록을 비교하세요.
3. 입력 조건 매 방출 새 객체에서 출력을 저장한 뒤 비활성 슬롯 재사용 조건으로 다시 실행하세요. 예상: 할당량은 줄지만 프레임 개선 정도는 측정이 필요합니다. 실제 화면·로그와 대조하고 day-25-notes.md에 실제 결과와 차이의 원인을 남기세요.
