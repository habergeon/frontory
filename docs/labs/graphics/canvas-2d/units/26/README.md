- 측정 조건과 표본 수가 기록된다.

## 선수 지식

선수 개념: 객체 재사용, 측정 분리. 25단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 시간 분포

평균만 보면 간헐적인 긴 프레임을 놓칩니다. 중앙값과 긴 프레임의 빈도를 함께 보면 끊김을 설명하기 쉽습니다.

### 구간 측정

performance.now로 잰 JavaScript 시간은 GPU 전체 시간을 뜻하지 않습니다. update와 draw 호출 구간을 나누고 브라우저 프로파일과 대조합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-26.js와 index.html을 준비하세요. 프레임 간격과 update·draw 호출 시간을 배열에 모으세요.
2. 워밍업 후 같은 길이의 표본을 저장하고 중앙값과 95백분위수를 계산하세요.
3. 입력 조건 500에서 출력을 저장한 뒤 2000 조건으로 다시 실행하세요. 예상: 갱신과 그리기 중 어느 구간이 증가하는지 구별할 수 있습니다. 실제 화면·로그와 대조하고 day-26-notes.md에 실제 결과와 차이의 원인을 남기세요.

| 입자 수 | 500       | 2000      | 갱신과 그리기 중 어느 구간이 증가하는지 구별할 수 있습니다 |
