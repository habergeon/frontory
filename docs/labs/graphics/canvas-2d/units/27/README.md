## 핵심 개념과 설명

### 입력 재현

같은 명령 목록을 다시 적용하면 기능 회귀를 찾기 쉽습니다. 화면 비교 전 데이터 상태를 확인하면 원인을 좁힐 수 있습니다.

### 수명 정리

관찰자와 이벤트, 애니메이션 요청은 장면 밖 자원입니다. 재초기화 전에 정리해야 중복 동작이 남지 않습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-27.js와 index.html을 준비하세요. 격자·도형 편집·입자 미리보기를 하나의 상태 모델에 묶으세요.
2. 생성→드래그→취소→리사이즈→JSON 복원 명령을 재생하고 dispose에서 observer와 이벤트·루프를 해제하세요.
3. 입력 조건 1회에서 출력을 저장한 뒤 5회 조건으로 다시 실행하세요. 예상: 정리가 맞으면 입력당 명령 실행 횟수가 늘지 않습니다. 실제 화면·로그와 대조하고 day-27-notes.md에 실제 결과와 차이의 원인을 남기세요.
