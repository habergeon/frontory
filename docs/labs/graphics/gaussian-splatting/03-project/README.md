## 핵심 개념과 설명

### 공동 평가

해상도와 Gaussian 수는 비용과 시각 품질을 동시에 바꿉니다. 한 변수씩 바꾼 기록을 먼저 만든 뒤 조합을 평가합니다.

### 채택 판단

가장 빠른 설정이 목적에 가장 적합한 설정은 아닐 수 있습니다. 데이터 출처·기능 제한·관찰 품질을 포함해 선택 이유를 씁니다.

## 실습 준비

기존 gaussian-splatting-03 미리보기는 출발점입니다. 이후 과제 전체의 구현이나 검증을 대신하지 않습니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 최종 viewer.js에서 기준·해상도 감소·항목 감소 세 설정을 같은 경로로 실행하세요.
2. report.md에 프레임 분포·정렬 시간·ROI 이미지·출처 manifest 링크를 모으세요.
3. 채택 설정과 허용하지 않을 품질 손실을 정하고 오류 복구 및 dispose를 다시 확인하세요.
