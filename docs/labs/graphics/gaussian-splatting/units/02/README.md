## 핵심 개념과 설명

### 데이터 출처

파일을 열 수 있다는 사실은 재배포 허가를 뜻하지 않습니다. 원본 URL·저작자·라이선스·변환 이력을 별도로 기록합니다.

### 범위 제한

작은 합성 데이터로도 파서와 합성을 검증할 수 있습니다. 교육 뷰어의 용량 제한을 실서비스의 처리 능력으로 해석하지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. assets-manifest.json에 직접 만든 fixture의 출처와 허용 용도를 적으세요.
2. validateFile.js에 file.size 1 MiB와 Gaussian 512개 한도를 검사하는 함수를 만드세요.
3. 빈 파일과 한도 초과 메타데이터를 입력하여 로딩 전에 거절 메시지를 출력하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건  | 예상할 변화·검증 가설                                |
| --------- | --------- | ---------- | ---------------------------------------------------- |
| 파일 크기 | 1 KiB     | 1 MiB 초과 | 내용 해석 전에 크기 오류가 표시될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
