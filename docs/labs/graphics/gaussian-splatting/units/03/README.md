# Gaussian Splatting · 03 좌표계와 단위

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 표현과 투영의 기초 · 문서 기반 직접 구현 · 저장 ID: `gaussian-splatting-step-03`

## 목표와 학습 후 역량

- 데이터 좌표계를 명시한다.
- 축 변환을 수치로 검증한다.

## 선수 지식

2단위 결과물과 기록을 이어 사용합니다. 좌표계와 단위 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 기준 축

카메라와 데이터의 위쪽 축이 다르면 장면이 기울어집니다. 축 변환은 카메라 조작으로 숨기지 말고 데이터 변환 행렬로 명시합니다.

### 크기 기준

복원 결과의 길이 단위는 실제 미터와 일치하지 않을 수 있습니다. 기준 물체 또는 명시적인 가상 단위를 사용합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. coordinates.js에 원점과 X/Y/Z 표식 세 개를 만드세요.
2. 입력 점에 축 교환 행렬을 적용하고 변환 전후 좌표를 표로 출력하세요.
3. camera.json에 eye·target·up을 저장하고 동일 표식을 재투영하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| up 축 | Y-up | Z-up 데이터를 변환 없이 입력 | 세로 표식 방향이 어긋날 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 원점과 축 표식 세 개의 변환 좌표를 기록한다.
- [ ] 역변환 후 원래 점과의 최대 오차가 1e-6 이하이다.
