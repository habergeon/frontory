# Gaussian Splatting · 04 Quaternion과 비등방성

## 목표와 학습 후 역량

- 회전 성분을 안전하게 해석한다.
- scale과 회전의 결합을 설명한다.

## 선수 지식

3단위 결과물과 기록을 이어 사용합니다. Quaternion과 비등방성 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 회전 표현

quaternion은 단위 길이를 유지해야 회전으로 사용할 수 있습니다. 파일의 성분 순서는 라이브러리 생성자의 순서와 다를 수 있습니다.

### 비등방성

세 scale이 다르면 방향에 따라 폭이 달라집니다. 등방성 Gaussian에서는 회전을 바꿔도 같은 모양이 됩니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. shape.js에 정규화 함수와 성분 순서 변환 함수를 작성하세요.
2. scale [0.3,0.1,0.1]과 90도 회전을 CPU 투영 입력에 넣으세요.
3. 등방성 [0.1,0.1,0.1]에도 같은 회전을 적용하고 bounding box를 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 회전각 | 0도 | Z축 90도 | 비등방성 타원의 긴 축이 바뀌고 등방성은 유지될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 정규화한 quaternion 길이가 1에서 1e-6 이내이다.
- [ ] 등방성·비등방성 두 입력의 회전 결과를 각각 기록한다.
