# Gaussian Splatting · 05 공분산으로 형태 읽기

## 목표와 학습 후 역량

- 공분산 행렬을 구성한다.
- 형태 입력의 유효성을 검사한다.

## 선수 지식

4단위 결과물과 기록을 이어 사용합니다. 공분산으로 형태 읽기 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 공분산

회전과 축별 분산을 결합하면 공간상의 타원체를 나타낼 수 있습니다. scale을 표준편차로 해석할 때 분산에는 제곱이 들어갑니다.

### 대칭성

공분산은 대칭이어야 하며 유효한 분산은 음수가 될 수 없습니다. 잘못된 입력을 그대로 투영하면 수치 계산이 불안정해집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. covariance.js에서 R·diag(scale²)·Rᵀ를 계산하세요.
2. 대각 scale과 회전 scale의 3×3 결과를 JSON으로 저장하세요.
3. 대칭 오차와 음수 scale 입력 거절 결과를 출력하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 긴 축 scale | 0.1 | 0.2 | 해당 축의 분산은 네 배가 될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 대칭 원소의 최대 차이가 1e-6 이하이다.
- [ ] scale 두 배에 대한 분산 네 배 관계를 수치로 확인한다.

## 자가 점검

1. scale과 분산을 혼동하면 무엇이 달라지나요?
2. 공분산을 저장하면 회전 정보를 따로 필요로 하나요?
