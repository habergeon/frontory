# Gaussian Splatting · 06 카메라 투영과 화면 타원

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 표현과 투영의 기초 · 문서 기반 직접 구현 · 저장 ID: `gaussian-splatting-step-06`

## 목표와 학습 후 역량

- 월드 크기와 화면 크기를 구분한다.
- 투영 경계 사례를 처리한다.

## 선수 지식

5단위 결과물과 기록을 이어 사용합니다. 카메라 투영과 화면 타원 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 원근 투영

가까운 Gaussian은 같은 월드 크기라도 더 크게 보입니다. 화면 공분산은 투영의 국소 변화율을 반영해야 합니다.

### 근평면

카메라 뒤나 근평면 근처의 점은 단순 나눗셈으로 안전하게 처리되지 않습니다. 투영 전에 가시 범위와 유한값을 검사합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. project.js에 view 공간 변환과 perspective divide를 분리하세요.
2. 깊이 2와 4의 같은 Gaussian을 투영하고 화면 중심·반지름을 출력하세요.
3. 근평면 전후와 카메라 뒤 입력을 넣어 제외 여부를 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 카메라 거리 | 2 | 4 | 작은 Gaussian의 화면 폭이 대략 절반이 될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
