# Gaussian Splatting · 07 가우시안 커널과 알파

## 목표와 학습 후 역량

- 픽셀 알파를 계산한다.
- 커널과 불투명도를 구분한다.

## 선수 지식

6단위 결과물과 기록을 이어 사용합니다. 가우시안 커널과 알파 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 커널

중심에서 멀어질수록 Gaussian의 가중치가 줄어듭니다. 픽셀 거리보다 공분산으로 정규화한 거리를 사용해야 타원이 유지됩니다.

### 불투명도

opacity는 커널 가중치와 결합해 픽셀 알파를 만듭니다. 같은 총량처럼 보이더라도 크기와 opacity 변경은 같은 효과가 아닙니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. kernel.js에서 exp(-0.5*r²)를 계산하는 함수를 만드세요.
2. r=0,1,2,3의 가중치를 표로 출력하고 opacity를 곱하세요.
3. Canvas ImageData에 한 타원을 그려 중심과 가장자리 알파를 읽으세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| opacity | 0.5 | 1.0 | 중심 알파는 두 배가 되지만 타원의 정규화 거리 구조는 유지될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 중심 가중치가 1이며 거리 증가에 따라 네 값이 감소한다.
- [ ] opacity 변경 전후 중심 알파의 비율을 기록한다.
