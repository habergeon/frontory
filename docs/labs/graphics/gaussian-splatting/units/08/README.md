# Gaussian Splatting · 08 알파 합성과 순서

## 목표와 학습 후 역량

- 투명 합성을 수치로 추적한다.
- 알파 규칙을 일관되게 적용한다.

## 선수 지식

7단위 결과물과 기록을 이어 사용합니다. 알파 합성과 순서 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 합성

서로 다른 색의 반투명 splat은 그리는 순서에 따라 색이 달라집니다. 색만 더하는 방식으로는 가림을 재현할 수 없습니다.

### 표현 일치

premultiplied alpha 여부는 색 저장 방식과 합성식을 함께 결정합니다. 서로 다른 규칙을 섞으면 경계가 어둡거나 밝아집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. blend.js에 명시적인 source-over 합성 함수를 작성하세요.
2. 빨강·파랑 알파 0.5 두 픽셀을 두 순서로 합성하세요.
3. premultiplied 입력 변환을 추가하고 동일 결과가 나오는지 비교하세요.

## 관찰할 변수

| 변수        | 기준 조건      | 바꿀 조건      | 예상할 변화·검증 가설                         |
| ----------- | -------------- | -------------- | --------------------------------------------- |
| 그리기 순서 | 빨강 다음 파랑 | 파랑 다음 빨강 | 알파는 같아도 RGB가 달라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 두 순서의 RGB와 alpha를 수치로 기록한다.
- [ ] 일관된 두 알파 표현의 결과 차이가 채널당 1e-6 이하이다.

2. 정렬과 알파 표현 오류를 어떻게 구분하나요?
