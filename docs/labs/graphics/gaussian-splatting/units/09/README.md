## 핵심 개념과 설명

### 중심 정렬

중심 깊이 정렬은 간단하지만 넓고 겹치는 타원체의 모든 픽셀 순서를 보장하지 않습니다. 카메라 회전 시 순서가 바뀌는 순간을 관찰해야 합니다.

### 안정성

같은 깊이의 항목에 안정적인 보조 키를 두면 불필요한 순서 흔들림을 줄일 수 있습니다. 이것이 기하학적 정렬 오류를 해결하는 것은 아닙니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. sort.js에 view-space 깊이와 원래 id를 사용하는 비교 함수를 만드세요.
2. 겹치는 긴 Gaussian 세 개의 카메라 각도를 10도 간격으로 바꾸세요.
3. 각 각도의 id 순서와 합성 이미지를 기록하세요.

## 관찰할 변수

| 변수        | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                                 |
| ----------- | --------- | --------- | --------------------------------------------------------------------- |
| 카메라 각도 | 0도       | 90도      | 중심 깊이 순서가 바뀌며 일부 겹침 영역의 색이 변할 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
