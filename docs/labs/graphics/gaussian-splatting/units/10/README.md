## 목표와 학습 후 역량

## 선수 지식

9단위 결과물과 기록을 이어 사용합니다. PLY 헤더 검사 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 컨테이너

PLY는 여러 종류의 점·면 속성을 담는 형식입니다. 확장자만 보고 GS 파라미터가 있다고 가정하면 안 됩니다.

### 속성 계약

학습 코드마다 scale·회전·색의 저장 규약이 다를 수 있습니다. 지원하는 필드 이름과 인코딩을 파서의 계약으로 선언합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. plyHeader.js에 ASCII 헤더의 format·element·property 읽기를 작성하세요.
2. 위치만 있는 PLY와 명시한 GS 속성을 가진 작은 문자열 fixture를 만드세요.
3. 필수 속성 누락·binary 형식·과도한 vertex 수를 구분해 거절하세요.
