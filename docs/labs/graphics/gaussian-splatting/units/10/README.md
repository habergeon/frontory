## 목표와 학습 후 역량

- PLY와 GS 데이터를 구분한다.
- 헤더 계약을 검증한다.

## 선수 지식

9단위 결과물과 기록을 이어 사용합니다. PLY 헤더 검사 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 컨테이너

PLY는 여러 종류의 점·면 속성을 담는 형식입니다. 확장자만 보고 GS 파라미터가 있다고 가정하면 안 됩니다.

### 속성 계약

학습 코드마다 scale·회전·색의 저장 규약이 다를 수 있습니다. 지원하는 필드 이름과 인코딩을 파서의 계약으로 선언합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. plyHeader.js에 ASCII 헤더의 format·element·property 읽기를 작성하세요.
2. 위치만 있는 PLY와 명시한 GS 속성을 가진 작은 문자열 fixture를 만드세요.
3. 필수 속성 누락·binary 형식·과도한 vertex 수를 구분해 거절하세요.

## 관찰할 변수

| --------- | ------------------- | ----------------- | -------------------------------------------------------- |
| 속성 집합 | 위치와 GS 필수 속성 | 위치 x/y/z만 유지 | 점 구름으로 판별하고 GS 로딩은 거절할 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
