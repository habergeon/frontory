# Gaussian Splatting · 11 값 디코딩과 유효성

단계: 파일 검증과 뷰어 통합 · 편집 가능한 예제 · 저장 ID: `gaussian-splatting-step-11`

## 목표와 학습 후 역량

- 저장값과 렌더값을 구분한다.
- 디코딩 오류를 위치와 함께 보고한다.

## 선수 지식

10단위 결과물과 기록을 이어 사용합니다. 값 디코딩과 유효성 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 활성화 함수

학습용 파일은 scale이나 opacity를 변환된 공간에 저장할 수 있습니다. 파일 생산자의 규약을 확인한 뒤에만 exp·sigmoid 같은 복원을 적용합니다.

### 비정상값

유한하지 않은 수는 정렬과 투영을 망가뜨릴 수 있습니다. 변환 후에도 범위와 quaternion 길이를 검사합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. decode.js에 encoding 설정을 받아 scale·opacity를 복원하는 함수를 작성하세요.
2. raw와 log-scale 두 fixture에 같은 실제 scale을 넣고 디코딩 결과를 비교하세요.
3. NaN·매우 큰 값·0 quaternion 입력을 넣고 필드 위치가 담긴 오류를 출력하세요.

## 관찰할 변수

| 변수         | 기준 조건 | 바꿀 조건           | 예상할 변화·검증 가설                          |
| ------------ | --------- | ------------------- | ---------------------------------------------- |
| scale 인코딩 | raw 0.1   | log(0.1)와 log 설정 | 두 입력의 복원 scale이 같을 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 두 인코딩 결과의 차이가 1e-6 이하이다.
- [ ] 세 잘못된 값이 렌더 이전에 거절된다.
