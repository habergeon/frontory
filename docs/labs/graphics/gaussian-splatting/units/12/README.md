## 목표와 학습 후 역량

- SH의 시점 의존성을 설명한다.
- 차수와 품질 주장을 구분한다.

## 선수 지식

11단위 결과물과 기록을 이어 사용합니다. 구면조화 색상 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 시점 의존성

SH 계수는 방향에 따라 변하는 색을 표현합니다. 상수항만 쓰면 시점에 따른 변화가 사라집니다.

### 차수와 근거

차수를 높여도 원본에 유효한 계수가 없으면 품질이 좋아지지 않습니다. 메모리·계산량과 실제 관찰 품질을 함께 비교해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. sh.js에 상수항과 합성한 1차 방향 항만 계산하는 함수를 만드세요.
2. 계수의 정규화·방향 규약을 notes.md에 쓰고 여섯 축 방향을 입력하세요.
3. 고정 Gaussian 주위로 카메라 위치를 이동하며 Gaussian에서 카메라로 향하는 방향별 색을 표로 출력하세요. 같은 위치에서 카메라 방향만 회전한 대조군도 비교하고 합성 데이터임을 표시하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 사용 SH 항 | 상수항만 | 합성 1차 항 포함 | 방향별 색이 달라지지만 학습 품질 향상의 증거는 아닐 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
