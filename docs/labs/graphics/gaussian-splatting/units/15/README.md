## 선수 지식

## 핵심 개념과 설명

### 거리 기준

투영 중심에 가장 가까운 항목을 고르는 방식은 구현이 단순합니다. 큰 splat의 실제 보이는 경계나 투명 가림을 정확히 반영하지는 않습니다.

### 선택 모호성

겹친 Gaussian에서 사용자 의도는 하나로 정해지지 않을 수 있습니다. 후보와 선택 기준을 표시하면 근사의 한계를 확인할 수 있습니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. pick.js에서 pointer를 canvas 로컬 픽셀로 변환하세요.
2. 투영 중심까지의 거리와 화면 반경으로 후보를 거르고 id를 표시하세요.
3. 두 Gaussian이 겹친 장면에서 임계 반경을 바꾸며 후보 목록을 기록하세요.
