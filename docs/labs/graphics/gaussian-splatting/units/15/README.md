## 선수 지식

## 핵심 개념과 설명

### 거리 기준

투영 중심에 가장 가까운 항목을 고르는 방식은 구현이 단순합니다. 큰 splat의 실제 보이는 경계나 투명 가림을 정확히 반영하지는 않습니다.

### 선택 모호성

겹친 Gaussian에서 사용자 의도는 하나로 정해지지 않을 수 있습니다. 후보와 선택 기준을 표시하면 근사의 한계를 확인할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. pick.js에서 pointer를 canvas 로컬 픽셀로 변환하세요.
2. 투영 중심까지의 거리와 화면 반경으로 후보를 거르고 id를 표시하세요.
3. 두 Gaussian이 겹친 장면에서 임계 반경을 바꾸며 후보 목록을 기록하세요.
