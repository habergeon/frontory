## 선수 지식

15단위 결과물과 기록을 이어 사용합니다. 가시 범위와 보수적 제외 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 경계 사용

중심만으로 화면 밖 항목을 제거하면 가장자리에 걸친 splat이 사라집니다. 화면 타원의 경계를 이용해 보수적으로 제외합니다.

### 수치 안전

너무 가까운 Gaussian은 화면 반경이 커질 수 있습니다. 무한 영역을 반복하지 않도록 클리핑과 작업량 제한을 분리합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. cull.js에 화면 bounding box와 viewport의 교차 검사를 추가하세요.
2. 중심이 화면 밖이지만 타원 일부가 들어오는 fixture를 만드세요.
3. 제외 수와 픽셀 평가 수를 로그로 남기고 결과 이미지를 비교하세요.
