## 선수 지식

18단위 결과물과 기록을 이어 사용합니다. Gaussian 수 줄이기 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 부분 선택

항목 수를 줄이면 저장량과 정렬량이 줄어듭니다. 무작위 제거는 얇은 구조나 낮은 불투명도 영역을 불균형하게 훼손할 수 있습니다.

### 재현성

매번 다른 난수를 쓰면 감축 전략끼리 비교하기 어렵습니다. seed와 선택 id를 저장해 같은 부분집합을 사용합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. subset.js에 seed 기반 선택과 opacity 순 선택을 각각 구현하세요.
2. 256개 합성 fixture에서 128개를 고르고 id 목록을 저장하세요.
3. 같은 세 시점의 빈 영역·정렬 시간·파일 바이트를 비교하세요.

## 관찰할 변수

| 변수    | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                    |
| ------- | --------- | --------- | -------------------------------------------------------- |
| 유지 수 | 256       | 128       | 정렬량은 줄지만 일부 영역에 구멍이 늘 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
