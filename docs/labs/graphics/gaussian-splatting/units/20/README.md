19단위 결과물과 기록을 이어 사용합니다. 색 공간과 배경 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 색 계산

선형 공간의 합성과 화면 표시용 색 변환은 서로 다른 작업입니다. 색 변환을 중복 적용하면 밝기 비교가 왜곡됩니다.

### 배경 의존성

투명 영역은 배경색에 따라 다르게 보입니다. 품질 비교에는 배경과 알파 표시 정책도 고정해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. color.js에 합성 공간과 최종 표시 변환 위치를 주석으로 명시하세요.
2. 회색 반투명 fixture를 검정·흰색 배경 위에 합성하세요.
3. 입력 RGB·합성 RGB·표시 RGB를 단계별 표로 저장하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                     |
| ---- | --------- | --------- | --------------------------------------------------------- |
| 배경 | 검정      | 흰색      | 같은 splat도 투과 영역의 밝기가 달라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
