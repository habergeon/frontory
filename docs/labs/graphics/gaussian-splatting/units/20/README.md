## 선수 지식

19단위 결과물과 기록을 이어 사용합니다. 색 공간과 배경 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 색 계산

선형 공간의 합성과 화면 표시용 색 변환은 서로 다른 작업입니다. 색 변환을 중복 적용하면 밝기 비교가 왜곡됩니다.

### 배경 의존성

투명 영역은 배경색에 따라 다르게 보입니다. 품질 비교에는 배경과 알파 표시 정책도 고정해야 합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. color.js에 합성 공간과 최종 표시 변환 위치를 주석으로 명시하세요.
2. 회색 반투명 fixture를 검정·흰색 배경 위에 합성하세요.
3. 입력 RGB·합성 RGB·표시 RGB를 단계별 표로 저장하세요.
