## 핵심 개념과 설명

### 기준 이미지

비교 대상이 합성 기준인지 실제 관측 사진인지에 따라 해석이 달라집니다. 정답 사진 없이 계산한 이미지 차이를 복원 정확도로 부르지 않습니다.

### 다중 관찰

평균 오차 하나는 얇은 구조나 깜빡임을 숨길 수 있습니다. 지정 영역과 카메라 경로를 함께 평가합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. evaluation.json에 세 시점·두 관심 영역·배경을 정의하세요.
2. baseline 모드와 감축 모드의 같은 크기 ImageData를 저장하세요.
3. 채널 평균 절대 차이와 관심 영역 손실 설명을 report.md에 작성하세요.
