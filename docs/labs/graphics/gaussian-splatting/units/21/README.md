## 핵심 개념과 설명

### 기준 이미지

비교 대상이 합성 기준인지 실제 관측 사진인지에 따라 해석이 달라집니다. 정답 사진 없이 계산한 이미지 차이를 복원 정확도로 부르지 않습니다.

### 다중 관찰

평균 오차 하나는 얇은 구조나 깜빡임을 숨길 수 있습니다. 지정 영역과 카메라 경로를 함께 평가합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. evaluation.json에 세 시점·두 관심 영역·배경을 정의하세요.
2. baseline 모드와 감축 모드의 같은 크기 ImageData를 저장하세요.
3. 채널 평균 절대 차이와 관심 영역 손실 설명을 report.md에 작성하세요.

## 관찰할 변수

| 평가 영역 | 전체 화면 | 얇은 구조 ROI | 전체 평균보다 국소 손실이 더 크게 드러날 것으로 예상합니다. |
