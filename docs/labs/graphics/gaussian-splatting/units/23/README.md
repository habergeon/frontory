## 핵심 개념과 설명

### 소유권

장면 객체를 제거하는 것과 관련 자원을 해제하는 것은 별개입니다. 누가 만든 buffer·texture·listener인지 목록으로 관리합니다.

### 반복 사용

한 번 정상 동작한 뷰어도 교체와 종료를 반복하면 누수가 드러납니다. 렌더러별 해제 API는 해당 버전 문서로 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. lifecycle.js에 생성한 자원과 해제 함수를 등록하세요.
2. 작은 fixture A/B를 열 번 교체하고 마지막에 dispose를 두 번 호출하세요.
3. 활성 listener·animation loop·객체 수를 기록하고 참조를 비우세요.
