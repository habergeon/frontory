## 선수 지식

23단위 결과물과 기록을 이어 사용합니다. 키보드와 카메라 복구 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 조작 경로

카메라 조작을 포인터에만 묶으면 일부 사용자는 장면을 탐색하기 어렵습니다. 키보드 이동과 명시적인 reset 버튼을 제공합니다.

### 범위 제한

카메라가 데이터 내부로 과도하게 들어가면 장면이 이해하기 어려워집니다. 이동 범위를 데이터 경계와 함께 정합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. controls.js에 방향키 이동·확대 축소·reset 동작을 정의하세요.
2. 입력 중인 폼에서는 카메라 단축키가 작동하지 않게 하세요.
3. 키보드만으로 세 시점 이동과 reset을 수행하고 camera.json을 비교하세요.

## 관찰할 변수

| 변수      | 기준 조건      | 바꿀 조건 | 예상할 변화·검증 가설                                          |
| --------- | -------------- | --------- | -------------------------------------------------------------- |
| 이동 속도 | 경계 크기의 1% | 10%       | 탐색은 빨라지지만 작은 특징을 지나치기 쉬울 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
