## 선수 지식

24단위 결과물과 기록을 이어 사용합니다. 실패 상태 통합 시험 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 오류 분류

형식·값·용량·지원 환경 오류는 대응 방법이 다릅니다. 한 가지 실패 문구로 합치면 사용자가 수정할 수 없습니다.

### 복구 경로

실패 후 다시 정상 파일을 열 수 있어야 합니다. 실패 상태가 렌더 루프와 입력 처리를 영구히 막지 않도록 설계합니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. cases.json에 빈 파일·누락 속성·비정상값·초과 크기·정상 입력을 적으세요.
2. loader.js에 각 case를 순서대로 주입하고 상태와 오류 코드를 저장하세요.
3. 각 오류 뒤 정상 fixture를 열어 카메라와 선택 기능을 확인하세요.
