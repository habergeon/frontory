# Gaussian Splatting · 26 재현 가능한 카메라 벤치마크

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 측정 가능한 GS 전시 뷰어 · 문서 기반 직접 구현 · 저장 ID: `gaussian-splatting-step-26`

## 목표와 학습 후 역량

- 고정 경로 벤치마크를 구성한다.
- 프레임 분포를 해석한다.

## 선수 지식

25단위 결과물과 기록을 이어 사용합니다. 재현 가능한 카메라 벤치마크 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 고정 경로

입력 경로가 달라지면 같은 품질 설정도 다른 비용을 만듭니다. 시간별 카메라 변환과 데이터 id를 고정해 비교합니다.

### 프레임 분포

평균만 기록하면 드물게 긴 프레임이 숨겨집니다. 중앙값과 상위 지연 구간을 함께 남깁니다.

## 실습 준비

별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. benchmark.js에 camera-path.json을 시간 기반으로 재생하는 함수를 만드세요.
2. 기준 설정과 해상도 감소 설정을 같은 길이로 각각 세 번 실행하세요.
3. 프레임 간격의 중앙값·95백분위·관심 시점 이미지를 결과 JSON에 저장하세요.
