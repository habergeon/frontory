## 핵심 개념과 설명

### 제공 범위

구현한 기능과 문서로만 검토한 후보를 구분해야 결과물을 재현할 수 있습니다. CPU 원리 실험을 대규모 GPU 제품으로 소개하지 않습니다.

### 배포 근거

원본 데이터의 허가와 변환 이력을 결과 보고서에 연결합니다. 큰 데이터 대신 재생성 가능한 작은 fixture를 제공할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 프로젝트의 문서 안내 실습입니다. 직접 만든 소형 데이터 또는 사용 허가를 확인한 로컬 파일만 사용합니다. 기존 미리보기는 1 MiB·512개 이하 .splat/ASCII GS PLY를 다루는 CPU 교육 뷰어이며 Spark GPU 렌더러가 아닙니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. README.md에 실행 환경·CPU 또는 Spark 경로·지원 형식·제한을 적으세요.
2. manifest와 fixtures 생성 절차를 연결하고 큰 원본 파일이 저장소 대상에 없는지 확인하세요.
3. 새 실행 세션에서 로딩·reset·오류 복구·선택·벤치마크 순서로 인수 기록을 작성하세요.
