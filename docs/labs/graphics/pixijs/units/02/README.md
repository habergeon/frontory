## 핵심 개념과 설명

### 텍스처 표현

Sprite는 Texture와 변환을 결합한 표시 객체입니다. 같은 Texture를 여러 Sprite가 사용할 수 있습니다.

### 앵커

anchor는 텍스처 크기에 대한 정규화된 기준점입니다. pivot의 로컬 픽셀 기준과 혼동하지 않아야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-02.js와 index.html을 준비하세요. Assets.load로 로컬 이미지를 읽어 Sprite 세 개를 만드세요.
2. anchor를 0,0.5,1로 바꾸고 같은 position에서 회전시켜 기준점을 표시하세요.
3. 입력 조건 0,0에서 출력을 저장한 뒤 0.5,0.5 조건으로 다시 실행하세요. 예상: position이 이미지 왼쪽 위 대신 중심을 가리킵니다. 실제 화면·로그와 대조하고 day-02-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| anchor | 0,0 | 0.5,0.5 | position이 이미지 왼쪽 위 대신 중심을 가리킵니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
