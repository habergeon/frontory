## 핵심 개념과 설명

### 중첩 변환

부모의 scale과 rotation은 자식의 global 위치에 영향을 줍니다. 로컬 좌표와 global 좌표를 나눠 출력하면 변환 경로를 추적할 수 있습니다.

### 좌표 역변환

toLocal은 global 점을 해당 컨테이너의 좌표로 바꿉니다. 화면 입력을 데이터 위치로 변환할 때 유용합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-03.js와 index.html을 준비하세요. 중첩 Container 두 개에 Sprite를 넣고 각 축을 Graphics로 표시하세요.
2. getGlobalPosition과 toLocal 결과를 HTML output에 나란히 기록하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 2 조건으로 다시 실행하세요. 예상: 같은 자식 로컬 이동이 화면에서 두 배로 보입니다. 실제 화면·로그와 대조하고 day-03-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| ---------- | --------- | --------- | ----------------------------------------------- |
| 부모 scale | 1         | 2         | 같은 자식 로컬 이동이 화면에서 두 배로 보입니다 |
