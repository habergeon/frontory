## 핵심 개념과 설명

### 도형 뒤 스타일

PixiJS 8 Graphics는 rect나 circle로 경로를 만든 뒤 fill과 stroke를 적용합니다. 이전 버전의 작성 순서를 그대로 복사하지 않도록 설치 버전을 확인합니다.

### 객체 변환

이미 만든 도형은 위치·회전으로 움직일 수 있습니다. 이동마다 clear하고 경로를 다시 만드는 작업은 불필요할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-04.js와 index.html을 준비하세요. new Graphics().roundRect(...).fill(...).stroke(...)로 카드 배경을 그리세요.
2. 경로 재생성과 position 이동 두 방식으로 같은 카드를 움직이고 호출 횟수를 기록하세요.
3. 입력 조건 매 프레임 clear·재생성에서 출력을 저장한 뒤 position만 변경 조건으로 다시 실행하세요. 예상: 경로 재구성 횟수를 줄일 수 있습니다. 실제 화면·로그와 대조하고 day-04-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수
