## 선수 지식

선수 개념: 텍스트 생성, 갱신 비용. 5단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 자식 순서

컨테이너의 자식 순서는 가려지는 순서에 영향을 줍니다. 배경·월드·UI를 분리하면 계층을 관리하기 쉽습니다.

### zIndex 정렬

sortableChildren을 켜면 zIndex를 이용해 정렬할 수 있습니다. 잦은 순서 변경은 비용과 선택 결과에도 영향을 줍니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-06.js와 index.html을 준비하세요. background,world,hud Container를 stage에 순서대로 추가하세요.
2. world.sortableChildren을 켜고 선택 Sprite의 zIndex를 바꾸세요.
3. 입력 조건 모두 0에서 출력을 저장한 뒤 선택 객체 10 조건으로 다시 실행하세요. 예상: 선택 객체가 같은 컨테이너의 다른 객체 앞에 표시됩니다. 실제 화면·로그와 대조하고 day-06-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| zIndex | 모두 0 | 선택 객체 10 | 선택 객체가 같은 컨테이너의 다른 객체 앞에 표시됩니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
