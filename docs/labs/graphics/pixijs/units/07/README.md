## 핵심 개념과 설명

### 논리 크기

app.screen은 렌더러의 논리 화면 크기를 나타냅니다. resolution은 버퍼의 픽셀 밀도를 조절합니다.

### CSS 밀도

autoDensity는 resolution과 CSS 크기를 맞추는 데 도움을 줍니다. 고해상도 설정 후 입력 좌표도 같은 논리 공간인지 확인해야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-07.js와 index.html을 준비하세요. app.init에 resizeTo:container,autoDensity:true,resolution 값을 설정하세요.
2. 컨테이너 폭을 바꾸며 app.screen과 canvas 버퍼 크기, Sprite 중심 위치를 출력하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 2 조건으로 다시 실행하세요. 예상: 논리 크기는 같고 버퍼의 픽셀 수는 네 배가 됩니다. 실제 화면·로그와 대조하고 day-07-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| resolution | 1 | 2 | 논리 크기는 같고 버퍼의 픽셀 수는 네 배가 됩니다 |
