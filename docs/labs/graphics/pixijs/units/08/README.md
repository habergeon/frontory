## 핵심 개념과 설명

### 콜백 인자

PixiJS 8 ticker 콜백은 Ticker 객체를 받습니다. 인자를 숫자 delta로 가정하면 이동 계산이 잘못됩니다.

### 밀리초 변환

deltaMS는 시간 기반 이동에 사용할 수 있습니다. px/s 속도에 곱할 때는 1000으로 나눠 초로 바꿉니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-08.js와 index.html을 준비하세요. app.ticker.add(ticker=>...)에서 deltaMS/1000으로 Sprite를 이동시키세요.
2. 속도 입력과 이동거리 output을 추가하고 두 프레임 간격에서 누적 이동을 비교하세요.
3. 입력 조건 50px/s에서 출력을 저장한 뒤 100px/s 조건으로 다시 실행하세요. 예상: 같은 누적 시간에 이동거리가 두 배가 됩니다. 실제 화면·로그와 대조하고 day-08-notes.md에 실제 결과와 차이의 원인을 남기세요.
