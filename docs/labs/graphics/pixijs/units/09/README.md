## 선수 지식

선수 개념: 콜백 인자, 밀리초 변환. 8단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### Ticker 소유

Application은 자체 또는 공유 ticker를 사용할 수 있습니다. 다른 화면도 쓰는 공유 ticker를 임의로 멈추면 영향을 줄 수 있습니다.

### 함수 참조

ticker.remove에는 등록한 콜백 참조가 필요합니다. 같은 모양의 새 함수를 넘기면 기존 등록이 제거되지 않습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-09.js와 index.html을 준비하세요. 이름 있는 update 함수를 ticker에 등록하고 pause/resume 버튼을 구현하세요.
2. 장면 생성·제거를 반복하며 add/remove 수와 프레임당 update 횟수를 기록하세요.
3. 입력 조건 1회에서 출력을 저장한 뒤 재생성 5회 조건으로 다시 실행하세요. 예상: 정리가 맞으면 한 프레임의 update 횟수는 늘지 않습니다. 실제 화면·로그와 대조하고 day-09-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 등록 횟수 | 1회 | 재생성 5회 | 정리가 맞으면 한 프레임의 update 횟수는 늘지 않습니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
