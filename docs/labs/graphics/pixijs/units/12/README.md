## 목표와 학습 후 역량

- 클릭 불가능한 장식과 버튼을 구분한다.
- 히트 영역을 화면에 디버그 표시한다.

## 선수 지식

선수 개념: 공유 소스, 프레임 사각형. 11단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 이벤트 모드

eventMode는 객체의 상호작용 처리 방식을 정합니다. 클릭 가능한 정적 객체에는 static을 지정해 의도를 명확히 합니다.

### 히트 영역

hitArea는 시각적 경계와 다른 입력 범위를 줄 수 있습니다. 작은 아이콘도 충분히 넓은 선택 영역을 가질 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-12.js와 index.html을 준비하세요. Sprite에 eventMode='static'과 pointertap을 연결하세요.
2. Rectangle hitArea를 추가하고 경계 바깥·안쪽 클릭의 선택 로그를 비교하세요.
3. 입력 조건 이미지 크기에서 출력을 저장한 뒤 각 방향 10px 확장 조건으로 다시 실행하세요. 예상: 보이는 크기를 바꾸지 않고 선택 범위가 넓어집니다. 실제 화면·로그와 대조하고 day-12-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| hitArea | 이미지 크기 | 각 방향 10px 확장 | 보이는 크기를 바꾸지 않고 선택 범위가 넓어집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
