## 선수 지식

선수 개념: 이벤트 모드, 히트 영역. 12단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 부모 좌표

Sprite 위치는 부모의 로컬 좌표입니다. global 포인터를 부모 toLocal로 바꿔야 확대된 그룹에서도 맞게 움직입니다.

### 종료 이벤트

객체 바깥에서 손을 놓을 수 있습니다. pointerupoutside와 취소 경로를 처리해야 드래그가 남지 않습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-13.js와 index.html을 준비하세요. pointerdown에서 선택 id와 로컬 offset을 저장하세요.
2. globalpointermove에서 부모 toLocal로 위치를 계산하고 pointerup·pointerupoutside·pointercancel로 상태를 비우세요.
3. 입력 조건 1에서 출력을 저장한 뒤 2 조건으로 다시 실행하세요. 예상: 변환이 맞으면 포인터 아래 잡은 지점이 유지됩니다. 실제 화면·로그와 대조하고 day-13-notes.md에 실제 결과와 차이의 원인을 남기세요.
