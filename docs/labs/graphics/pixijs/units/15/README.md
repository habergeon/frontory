## 선수 지식

## 핵심 개념과 설명

### 픽셀 밖 의미

렌더링된 Sprite는 자동으로 HTML 버튼이 되지 않습니다. 접근성 확장이나 별도 DOM 제어로 이름과 조작을 연결해야 합니다.

### 같은 명령

키보드와 포인터가 같은 selectItem을 호출하면 동작이 일치합니다. 시각적 tint 외에 텍스트 선택 상태도 필요합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-15.js와 index.html을 준비하세요. HTML 버튼 목록에 Sprite id와 이름을 연결하세요.
2. Tab·Enter 선택과 화살표 이동을 같은 명령 함수에 연결하고 화면 강조와 설명을 갱신하세요.
3. 입력 조건 포인터에서 출력을 저장한 뒤 키보드 조건으로 다시 실행하세요. 예상: 동일 Sprite와 위치 변경을 선택할 수 있습니다. 실제 화면·로그와 대조하고 day-15-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                        |
| ---- | --------- | --------- | -------------------------------------------- |
| 입력 | 포인터    | 키보드    | 동일 Sprite와 위치 변경을 선택할 수 있습니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
