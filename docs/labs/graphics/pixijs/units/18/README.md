## 선수 지식

선수 개념: 프레임 순서, 시간 인덱스. 17단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 표시 제한

mask는 객체가 보이는 영역을 제한합니다. 데이터나 자식 위치를 삭제하지 않고 일부만 보이게 만들 수 있습니다.

### 입력 정책

가려진 콘텐츠의 입력 처리도 확인해야 합니다. 화면 밖 객체를 선택할 수 있으면 사용자에게 혼란을 줍니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-18.js와 index.html을 준비하세요. Graphics 사각형을 mask로 지정한 카드 목록 Container를 만드세요.
2. 스크롤 입력으로 콘텐츠 y를 바꾸고 가려진 카드의 선택 로그를 검사하세요.
3. 입력 조건 0에서 출력을 저장한 뒤 목록 절반 조건으로 다시 실행하세요. 예상: 같은 카드 데이터의 다른 구간이 마스크 안에 보입니다. 실제 화면·로그와 대조하고 day-18-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수        | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                               |
| ----------- | --------- | --------- | --------------------------------------------------- |
| 스크롤 위치 | 0         | 목록 절반 | 같은 카드 데이터의 다른 구간이 마스크 안에 보입니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
