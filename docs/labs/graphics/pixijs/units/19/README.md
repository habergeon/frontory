## 핵심 개념과 설명

### 필터 패스

블러 같은 필터는 중간 렌더링 작업을 요구할 수 있습니다. 객체 수뿐 아니라 처리 면적과 품질 설정이 비용에 영향을 줍니다.

### 그룹 효과

부모에 필터를 적용하면 묶인 결과에 작용합니다. 자식마다 적용한 결과와 가장자리·겹침이 다를 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-19.js와 index.html을 준비하세요. BlurFilter({strength:3,quality:4})를 만들어 Container에 연결하세요.
2. 같은 Sprite 목록에 개별 필터와 부모 필터를 번갈아 적용하고 화면과 프레임 간격을 기록하세요.
3. 입력 조건 부모 한 개에서 출력을 저장한 뒤 Sprite마다 조건으로 다시 실행하세요. 예상: 효과 경계와 중간 처리 비용이 달라질 수 있습니다. 실제 화면·로그와 대조하고 day-19-notes.md에 실제 결과와 차이의 원인을 남기세요.
