## 핵심 개념과 설명

### 합성 순서

반투명 그림은 앞뒤 순서에 따라 결과가 달라집니다. 배칭을 위해 임의로 순서를 바꾸면 이미지 의미가 바뀔 수 있습니다.

### 혼합 규칙

blendMode는 배경과 색을 합치는 방식을 정합니다. add와 multiply는 서로 다른 밝기 효과를 만듭니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-20.js와 index.html을 준비하세요. 겹친 Sprite에 normal,add,multiply를 적용해 비교 화면을 만드세요.
2. 배경색과 자식 순서를 바꾸고 겹침 영역의 결과를 캡처하세요.
3. 입력 조건 normal에서 출력을 저장한 뒤 add 조건으로 다시 실행하세요. 예상: 겹치는 영역이 더 밝아질 수 있습니다. 실제 화면·로그와 대조하고 day-20-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| blendMode | normal | add | 겹치는 영역이 더 밝아질 수 있습니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
