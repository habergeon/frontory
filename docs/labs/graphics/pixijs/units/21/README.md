## 핵심 개념과 설명

### 텍스처 캐시

cacheAsTexture는 컨테이너 그림을 재사용 가능한 텍스처로 만듭니다. 정적 장식에 도움이 될 수 있지만 별도 메모리가 필요합니다.

### 명시적 갱신

자식 내용이 바뀌면 updateCacheTexture로 캐시를 갱신해야 합니다. 캐시를 켰다는 이유만으로 모든 변경이 자동 반영된다고 가정하지 않습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-21.js와 index.html을 준비하세요. 복잡한 카드 배경 Container에 cacheAsTexture()를 적용하세요.
2. 라벨을 수정한 뒤 갱신 전후를 비교하고 updateCacheTexture를 변경 이벤트에 연결하세요.
3. 입력 조건 갱신 호출 없음에서 출력을 저장한 뒤 내용 변경 시 호출 조건으로 다시 실행하세요. 예상: 오래된 라벨 대신 새 내용이 나타납니다. 실제 화면·로그와 대조하고 day-21-notes.md에 실제 결과와 차이의 원인을 남기세요.
