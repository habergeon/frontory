## 핵심 개념과 설명

### 자원 계층

Sprite·Texture·TextureSource는 같은 객체가 아닙니다. 프레임 Texture를 지워도 공유 소스는 다른 곳에서 계속 쓸 수 있습니다.

### Assets 소유권

Assets가 관리하는 자원은 사용 종료 후 unload로 정리할 수 있습니다. 다른 장면의 사용자까지 끝났는지 먼저 확인해야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-22.js와 index.html을 준비하세요. 공유 atlas를 쓰는 두 Container를 만들고 사용자 수를 장부로 기록하세요.
2. 한 화면 종료 시 Sprite만 정리하고 마지막 사용자 종료 뒤 Assets.unload를 호출하세요.
3. 입력 조건 2개 화면에서 출력을 저장한 뒤 0개 화면 조건으로 다시 실행하세요. 예상: 마지막 사용자가 끝난 시점에만 공유 atlas를 해제합니다. 실제 화면·로그와 대조하고 day-22-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| --- | --- | --- | --- |
| 사용자 수 | 2개 화면 | 0개 화면 | 마지막 사용자가 끝난 시점에만 공유 atlas를 해제합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
