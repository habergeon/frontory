## 핵심 개념과 설명

### 경량 입자

v8 ParticleContainer는 Particle을 담는 별도 경량 경로입니다. 일반 Sprite의 자식·이벤트·필터 기능을 그대로 기대하면 안 됩니다.

### 동적 속성

변하는 속성만 dynamicProperties로 지정할 수 있습니다. 정적 속성이나 목록 변경 뒤에는 update가 필요할 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. pixi.js 8.x의 설치 버전을 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-23.js와 index.html을 준비하세요. 설치한 8.x 버전의 Particle API를 확인하고 ParticleContainer와 addParticle로 같은 텍스처의 입자를 만드세요.
2. position만 동적으로 지정해 이동시키고 정적 색 변경 뒤 container.update() 전후를 비교하세요.
3. 입력 조건 정적에서 출력을 저장한 뒤 동적 조건으로 다시 실행하세요. 예상: 회전이 매 프레임 변할 때 갱신 경로와 업로드 범위가 달라집니다. 실제 화면·로그와 대조하고 day-23-notes.md에 실제 결과와 차이의 원인을 남기세요.
