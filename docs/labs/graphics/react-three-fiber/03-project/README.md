## 선수 지식

28단위는 27단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 공유 수명

공유 geometry·material은 여러 객체가 함께 사용합니다. 마지막 소비자가 끝날 때 해제하도록 소유권과 자동 dispose 정책을 맞춥니다.

### 프레임 정책

정지 장면은 demand로 프레임을 줄일 수 있습니다. 직접 변경과 애니메이션에는 시작·진행·종료에 맞는 invalidate가 필요합니다.

## 실습 준비

별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다. 기존 react-three-fiber-03 미리보기는 출발점입니다. 본문의 확장 결과물은 별도 프로젝트에서 구현합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/StudyScene.jsx에서 공유 grid와 instanced 대조군을 같은 배치로 준비하세요.
