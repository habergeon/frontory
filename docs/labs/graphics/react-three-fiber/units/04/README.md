## 목표와 학습 후 역량

- 자식 position.x가 2로 유지된다.
- 월드 위치와 화면 이동 방향을 대응해 기록한다.

## 선수 지식

4단위는 3단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 장면 계층

group은 자식 변환의 기준 좌표계를 만듭니다. 자식의 position은 부모에 대한 로컬 위치입니다.

### 변환 순서

부모 회전은 자식 위치와 방향 모두에 영향을 줍니다. 월드 좌표를 확인하면 단순 숫자 대입과 실제 위치의 차이를 볼 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/OrbitGroup.jsx에 group과 x=2인 자식 큐브를 만드세요.
2. group rotation-y를 0에서 Math.PI/2로 바꾸세요.
3. getWorldPosition 결과를 로그로 적고 화면 이동과 대조하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 부모 회전 | 0 | Math.PI/2 | 자식 로컬 x는 유지되지만 월드 위치가 이동한다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
