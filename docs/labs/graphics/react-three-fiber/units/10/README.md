## 선수 지식

10단위는 9단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### raycast 이벤트

R3F 포인터 이벤트는 3D 객체와의 교차를 기준으로 전달됩니다. event.point는 교차한 월드 위치 정보를 담습니다.

### 선택 상태

선택 id는 UI와 공유할 저빈도 상태입니다. 움직이는 좌표를 매 포인터 이동마다 React state에 복사할 필요는 없습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/SelectableBox.jsx의 onClick에서 id를 부모에 전달하세요.
2. 선택 색과 DOM 상세 패널을 같은 selectedId에서 계산하세요.
3. 세 큐브를 차례로 클릭하고 id·event.point를 기록하세요.
