## 핵심 개념과 설명

### 포인터 캡처

캡처는 포인터가 객체 밖으로 움직여도 드래그를 이어 가는 데 사용합니다. R3F 캡처는 교차 목록 처리와 함께 동작하므로 DOM과 차이를 확인합니다.

### 좌표 평면

화면 이동량을 그대로 월드 위치에 더하면 카메라에 따라 속도가 달라집니다. 정한 평면과 ray의 교차로 이동 좌표를 구합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/DraggableBox.jsx에서 pointerdown에 pointerId를 캡처하세요.
2. pointermove에서 ray와 z=0 평면의 교차를 ref 위치에 적용하세요.
3. pointerup·취소에서 캡처를 해제하고 객체 밖 이동도 시험하세요.
