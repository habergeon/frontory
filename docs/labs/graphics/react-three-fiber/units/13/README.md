## 목표와 학습 후 역량

- 목표가 고정되면 각도 오차가 감소한다.
- 프레임 경로에 setState가 없다.

## 선수 지식

13단위는 12단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 목표 상태

슬라이더의 목표 각도는 React 상태로 표현할 수 있습니다. 실제 프레임 보간값은 ref의 객체 속성에 둡니다.

### 보간

현재값을 목표값으로 점진적으로 이동시키면 부드러운 전환을 만들 수 있습니다. 시간 의존 계수를 사용해 프레임 수 차이를 줄입니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/SmoothBox.jsx에 targetAngle prop을 전달하세요.
2. useFrame에서 1-exp(-k*delta) 계수로 현재 각도를 목표에 접근시키세요.
3. 목표 0→1과 k 2→8을 각각 바꾸고 도달 오차를 기록하세요.

## 관찰할 변수

| 변수   | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                 |
| ------ | --------- | --------- | ------------------------------------- |
| 보간 k | 2         | 8         | 같은 시간 뒤 목표와의 오차가 더 작다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
