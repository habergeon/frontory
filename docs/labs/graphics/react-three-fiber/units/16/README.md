## 목표와 학습 후 역량

- 두 인스턴스가 서로 다른 위치에 동시에 보인다.
- 객체와 geometry/material의 공유 여부를 기록한다.

## 선수 지식

16단위는 15단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 장면 객체

같은 Object3D를 두 부모에 동시에 붙일 수 없습니다. 여러 인스턴스가 필요하면 복제 전략과 공유 자원을 구분합니다.

### 복제 범위

scene.clone은 객체 계층을 복제해도 geometry·material을 공유할 수 있습니다. 골격 모델은 별도의 적절한 복제 방식을 확인합니다.

## 실습 준비

별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/ModelPair.jsx에서 비골격 GLB scene을 두 번 쓰는 대조를 만드세요.
2. 각 인스턴스에 scene.clone()을 한 번씩 만들고 다른 위치에 배치하세요.
3. 객체·geometry·material uuid를 비교하고 색상 변경의 공유 영향을 적으세요.
