## 목표와 학습 후 역량

- 텍스처 종류와 색 공간 설정을 기록한다.

## 선수 지식

17단위는 16단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 텍스처 의미

색상 텍스처와 normal·roughness 같은 데이터 텍스처는 의미가 다릅니다. 색 공간 설정을 종류에 맞게 확인해야 합니다.

### 메모리 비용

텍스처 해상도는 다운로드 크기뿐 아니라 GPU 메모리에도 영향을 줍니다. 화면에서 얻는 품질과 함께 비교합니다.

## 실습 준비

별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. public/textures에 권한을 확인한 작은 색상 텍스처를 준비하세요.
2. src/TexturedBox.jsx에서 TextureLoader와 material map을 연결하세요.
3. 256과 1024 해상도 버전을 같은 카메라에서 비교하고 치수·파일 크기를 기록하세요.
