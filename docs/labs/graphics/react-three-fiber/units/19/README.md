## 목표와 학습 후 역량

- 재사용 경로의 프레임 내부 new Vector3가 0개다.
- 동일 조건 두 성능 기록에 평균과 긴 프레임을 남긴다.

## 선수 지식

19단위는 18단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 할당 비용

프레임마다 Vector3 같은 객체를 만들면 가비지 수집 압력이 늘 수 있습니다. 재사용 가능한 임시 객체를 프레임 밖에 준비합니다.

### 측정

짧은 프레임 지연은 평균 FPS에 잘 드러나지 않을 수 있습니다. 같은 장면에서 프레임 시간 분포와 할당을 함께 관찰합니다.

## 실습 준비

별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/MovingCloud.jsx에서 프레임마다 생성하는 Vector3 대조군을 만드세요.
2. 재사용 Vector3를 ref나 안정된 초기화 경로에 두고 set·copy로 갱신하세요.
3. 동일 500개 객체로 두 방식의 10초 성능 기록을 비교하세요.
