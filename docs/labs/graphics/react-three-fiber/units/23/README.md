# React Three Fiber · 23 demand와 움직임의 종료

## 목표와 학습 후 역량

- 최종 각도 오차가 0.001 이하이다.
- 수렴 후 3초 동안 연속 프레임이 누적되지 않는다.

## 선수 지식

23단위는 22단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 연속 동작

demand에서도 애니메이션 중에는 다음 프레임이 필요합니다. 목표에 도달할 때까지 invalidate를 이어 요청하고 끝나면 멈춥니다.

### 수렴 조건

보간은 정확히 목표에 닿지 않을 수 있습니다. 허용 오차 이하에서 목표로 맞추고 루프를 종료합니다.

## 실습 준비

별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/DemandMotion.jsx에서 목표 각도와 현재 각도 오차를 계산하세요.
2. useFrame에서 보간 후 오차가 0.001 이상이면 invalidate를 호출하세요.
3. 버튼으로 새 목표를 주고 움직임 종료 전후 프레임 수를 기록하세요.
