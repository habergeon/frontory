## 선수 지식

24단위는 23단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 픽셀 수

DPR이 커지면 같은 CSS 영역의 렌더 픽셀 수가 늘어납니다. 화면 품질과 GPU 비용을 같은 카메라에서 비교해야 합니다.

### 그림자 패스

그림자는 별도 렌더 작업과 shadow map을 요구할 수 있습니다. 모든 객체와 조명에 켜기보다 필요한 범위를 정합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/QualityScene.jsx에 dpr 1·2 선택을 추가하세요.
2. 그림자를 만드는 조명 하나와 castShadow·receiveShadow 대상을 지정하세요.
3. DPR만 바꾼 실험과 그림자만 바꾼 실험을 나누어 10초씩 기록하세요.
