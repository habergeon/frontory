## 목표와 학습 후 역량

- 10회 전환의 자원 수 추세를 기록한다.
- 공유·외부 primitive·선언 자원의 해제 주체가 명시된다.

## 선수 지식

25단위는 24단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### 보이기와 제거

visible=false는 객체를 장면에 남겨 둡니다. unmount는 트리에서 제거하므로 재생성 비용과 해제 정책이 달라집니다.

### 자원 추적

renderer.info의 메모리 수는 내부 캐시 때문에 즉시 0이 아닐 수 있습니다. 반복 전환의 증가 추세와 소유자별 dispose 기록을 함께 봅니다.

## 실습 준비

별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다. Frontory 내장 실행 예제가 없는 확장 단위이며 아래 파일은 외부 실습 프로젝트에 작성합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. src/SceneSwitcher.jsx에 두 장면과 visible·unmount 전환 정책을 만드세요.
2. 같은 장면을 10회 교대하며 geometry·texture 수와 dispose 기록을 수집하세요.
3. 공유 자원과 primitive 자원의 소유자 표를 작성하세요.
