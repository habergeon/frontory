## 선수 지식

26단위는 25단위 결과물과 실험 기록을 이어 사용합니다.

## 핵심 개념과 설명

### DOM 조작 경로

3D 클릭만으로 모든 기능을 제공하면 키보드 사용자가 접근하기 어렵습니다. 같은 선택 상태를 바꾸는 DOM 목록을 함께 제공합니다.

### 지원 실패

Canvas fallback은 지원되지 않는 GL 환경의 안내에 사용합니다. 런타임 로딩 실패는 별도 오류 경계로 다뤄야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/App.jsx에 mesh id와 연결된 DOM 선택 버튼을 추가하세요.
2. Canvas fallback과 모델 오류 메시지를 구분해 구현하세요.
3. 키보드만으로 선택·해제하고 지원 실패 대체 화면의 설명을 검토하세요.
