## 핵심 개념과 설명

### 분리된 지표

React 커밋·draw call·프레임 시간·자원 수는 서로 다른 비용을 설명합니다. 하나의 숫자로 전체 성능을 단정하지 않습니다.

### 단일 변수

객체 수·DPR·frameloop을 동시에 바꾸면 원인을 구분하기 어렵습니다. 기준 장면을 고정하고 한 조건씩 비교합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 React Vite 프로젝트에서 JSX를 사용합니다. React와 @react-three/fiber의 호환 메이저 버전, Three.js 버전과 lockfile을 기록하세요. 이 과정은 WebGL 기반 안정 버전 API를 사용하며 alpha WebGPU API를 혼용하지 않습니다. 프레임 갱신은 useFrame과 ref로 처리합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. src/StudyScene.jsx에 선택·모델·instanced grid·DOM 필기를 통합하세요.
2. 100·1000개 객체의 동일 조작을 always와 demand에서 별도 실행하세요.
3. notes/bench.md에 조건·프레임 시간·draw call·자원 수와 실패를 기록하세요.
