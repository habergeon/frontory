## 핵심 개념과 설명

### 공통 선택 상태

SVG 요소는 이벤트 대상이지만 선택 의미는 직접 정의해야 합니다. 포인터와 HTML 버튼이 같은 id 상태를 사용하면 결과가 일치합니다.

### 키보드 경로

시각적 path만으로 버튼 동작이 생기지 않습니다. 네이티브 버튼 목록을 제공하면 키보드와 접근 가능한 이름을 안정적으로 연결할 수 있습니다.

## 실습 준비

기존 내장 예제는 출발점만 제공합니다. 확장 요구사항 전체가 구현된 예제가 아니며 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-14.js와 index.html을 준비하세요. 기존 svg-02 예제를 읽고 노드 지도와 대응하는 HTML button 목록을 구성하세요.
2. click과 버튼 활성화를 selectNode(id)에 연결하고 선택 테두리·설명·aria-pressed를 갱신하세요.
3. 입력 조건 노드 클릭에서 출력을 저장한 뒤 Tab과 Enter 조건으로 다시 실행하세요. 동일 노드 id와 설명이 선택됩니다라는 가설을 화면·로그와 대조하고 day-14-notes.md에 실제 결과와 차이의 원인을 남기세요.
