## 목표와 학습 후 역량

기능·접근성·성능의 장단점을 근거로 선택한다. 이를 자신의 말로 설명하고 작은 결과물로 재현하는 것이 목표입니다.

## 선수 지식

이 시리즈 2단위의 결과물과 기록.

## 핵심 개념과 설명

SVG는 개별 DOM 객체, Canvas는 그린 픽셀 중심입니다. 요소 수와 상호작용 요구에 따라 비용이 달라집니다.

## 실습 준비

현재 단위에 연결된 예제를 실행하고 아래 과제를 진행합니다. 코드 편집기 자체는 JS/TS 모듈이며 JSX·Vue SFC를 직접 컴파일하지 않습니다.

## 실습 과제

1. 공식 참고에서 이번 개념과 API의 입력·출력을 찾아 필기에 요약합니다.
2. 동일한 점 분포를 SVG와 Canvas로 그리고 선택·확대 비용을 비교하세요.
3. 아래 변수 중 하나만 바꾸기 전에 예상 결과를 적고, 실행 후 스크린샷·로그 또는 측정값과 비교합니다.
4. 원래 조건으로 되돌려 같은 결과를 재현하고 오류·지원 제한도 남깁니다.

## 관찰할 변수

점 개수, 확대 배율. 비교 시 다른 변수와 브라우저·viewport 조건은 고정합니다.
