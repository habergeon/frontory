## 핵심 개념과 설명

### 표현 모델

SVG는 개별 요소를 DOM으로 유지합니다. Canvas는 픽셀을 갱신하며 객체의 의미를 별도로 관리합니다.

### 선택 근거

성능만으로 표현 방식을 결정하기 어렵습니다. 접근성·편집·내보내기·구현 복잡도까지 요구사항과 함께 평가합니다.

## 실습 준비

기존 내장 예제는 출발점만 제공합니다. 확장 요구사항 전체가 구현된 예제가 아니며 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-28.js와 index.html을 준비하세요. 기존 svg-03 비교 예제를 출발점으로 같은 점 분포·선택·확대를 갖춘 두 구현을 완성하세요.
2. 노드 지도의 접근성 점검과 성능 표, 내보내기 결과를 모아 렌더러 선택 보고서를 작성하세요.
3. 입력 조건 SVG DOM에서 출력을 저장한 뒤 Canvas 픽셀 조건으로 다시 실행하세요. 요소 접근과 히트 테스트의 구현 방식이 달라지며 성능은 장면별로 검증해야 합니다라는 가설을 화면·로그와 대조하고 day-28-notes.md에 실제 결과와 차이의 원인을 남기세요.
