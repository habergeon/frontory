## 핵심 개념과 설명

### 기하 속성

rect의 x,y,width,height는 도형의 위치와 크기를 정합니다. CSS 배치 속성과 역할을 구분해야 합니다.

### 칠과 선

fill은 내부를 채우고 stroke는 윤곽을 그립니다. fill을 none으로 지정해도 선은 남길 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-02.js와 index.html을 준비하세요. rect,circle,ellipse를 서로 다른 fill과 stroke로 배치하세요.
2. 입력 폼에서 radius와 stroke-width를 바꾸고 실제 속성값을 output에 표시하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 12 조건으로 다시 실행하세요. 윤곽이 도형 경계 양쪽으로 두꺼워집니다라는 가설을 화면·로그와 대조하고 day-02-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| stroke-width | 1 | 12 | 윤곽이 도형 경계 양쪽으로 두꺼워집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
