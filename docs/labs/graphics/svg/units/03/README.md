## 선수 지식

선수 개념: 기하 속성, 칠과 선. 2단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 절대·상대 좌표

대문자 경로 명령은 절대 좌표를 사용합니다. 소문자는 현재 점을 기준으로 움직입니다.

### 경로 닫기

Z는 시작점까지 연결해 경로를 닫습니다. 마지막 점을 수동으로 시작점에 놓는 것과 선 결합이 달라질 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-03.js와 index.html을 준비하세요. M,L,H,V,Z로 화살표 path를 작성하고 꼭짓점에 원을 덧그리세요.
2. 같은 모양을 상대 명령으로 다시 쓰고 시작점을 이동시키세요.
3. 입력 조건 20,20에서 출력을 저장한 뒤 80,20 조건으로 다시 실행하세요. 상대 명령 도형은 전체 모양을 유지하며 이동합니다라는 가설을 화면·로그와 대조하고 day-03-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수   | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                            |
| ------ | --------- | --------- | ------------------------------------------------ |
| 시작점 | 20,20     | 80,20     | 상대 명령 도형은 전체 모양을 유지하며 이동합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
