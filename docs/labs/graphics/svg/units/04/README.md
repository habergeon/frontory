## 선수 지식

## 핵심 개념과 설명

### 제어점

Q는 한 제어점을 사용하는 이차 곡선입니다. 제어점은 보통 곡선이 직접 통과하는 점이 아닙니다.

### 접선

C의 두 제어점은 시작과 끝의 접선 방향에 영향을 줍니다. 연결 지점의 방향을 맞추면 곡선의 꺾임을 줄일 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-04.js와 index.html을 준비하세요. Q와 C 경로를 만들고 제어점을 작은 circle과 보조선으로 표시하세요.
2. 슬라이더로 제어점 y를 바꾸고 path의 d 속성을 갱신하세요.
3. 입력 조건 20에서 출력을 저장한 뒤 120 조건으로 다시 실행하세요. 곡선의 휘어지는 방향과 높이가 달라집니다라는 가설을 화면·로그와 대조하고 day-04-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 제어점 y | 20 | 120 | 곡선의 휘어지는 방향과 높이가 달라집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
