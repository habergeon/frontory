## 목표와 학습 후 역량

- 절반을 넘는 비율을 올바르게 그린다.
- 0과 100의 경계 사례를 처리한다.

## 선수 지식

선수 개념: 제어점, 접선. 4단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 호 플래그

A 명령은 반지름과 두 플래그로 타원호를 선택합니다. 같은 끝점에도 큰 호와 작은 호가 가능합니다.

### 각도 데이터

비율을 각도로 바꾼 뒤 원 위 좌표를 계산합니다. 전체 원은 시작점과 끝점이 같아 별도 경로 구성이 필요합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-05.js와 index.html을 준비하세요. sin과 cos로 원 위 두 점을 계산하고 A 명령으로 진행률 호를 만드세요.
2. 0%,50%,99%,100% 입력을 각각 처리하고 큰 호 플래그를 표시하세요.
3. 입력 조건 25%에서 출력을 저장한 뒤 75% 조건으로 다시 실행하세요. large-arc-flag를 바꿔 더 긴 호를 선택해야 합니다라는 가설을 화면·로그와 대조하고 day-05-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 진행률 | 25% | 75% | large-arc-flag를 바꿔 더 긴 호를 선택해야 합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
