## 선수 지식

선수 개념: 호 플래그, 각도 데이터. 5단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 그룹 변환

g의 transform은 자식들에게 함께 적용됩니다. 아이콘 내부 좌표를 유지한 채 여러 위치에 배치할 수 있습니다.

### 행렬 순서

이동과 회전은 순서에 민감합니다. 회전 중심을 명시하면 의도하지 않은 공전을 줄입니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-06.js와 index.html을 준비하세요. g 안에 바늘과 중심점을 만들고 transform으로 회전시키세요.
2. 이동 그룹과 회전 그룹을 중첩한 버전과 단일 transform 버전을 비교하세요.
3. 입력 조건 0,0에서 출력을 저장한 뒤 100,100 조건으로 다시 실행하세요. 바늘이 도는 기준점이 달라집니다라는 가설을 화면·로그와 대조하고 day-06-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 회전 중심 | 0,0 | 100,100 | 바늘이 도는 기준점이 달라집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
