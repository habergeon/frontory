## 핵심 개념과 설명

### 정의와 인스턴스

defs의 내용은 그 자체로 보이지 않습니다. use가 정의를 참조할 때 같은 도형을 여러 곳에 표시합니다.

### 식별자 범위

id는 문서 안에서 충돌하지 않아야 합니다. 여러 SVG를 합치면 같은 이름의 gradient나 symbol 참조가 엉킬 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-07.js와 index.html을 준비하세요. symbol에 배지를 정의하고 use href로 세 크기의 인스턴스를 만드세요.
2. 접두사를 붙인 id 규칙을 정하고 두 SVG를 같은 HTML에 배치하세요.
3. 입력 조건 모두 badge에서 출력을 저장한 뒤 각 SVG별 접두사 조건으로 다시 실행하세요. 다른 정의를 잘못 참조하는 충돌을 피합니다라는 가설을 화면·로그와 대조하고 day-07-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| id 규칙 | 모두 badge | 각 SVG별 접두사 | 다른 정의를 잘못 참조하는 충돌을 피합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
