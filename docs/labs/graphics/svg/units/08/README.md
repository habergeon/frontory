## 핵심 개념과 설명

### 캐스케이드

SVG 표현 속성은 CSS의 영향을 받습니다. 속성값만 읽어서는 최종 색을 알 수 없는 경우가 있습니다.

### 상속 색상

currentColor는 주변 color를 사용합니다. 아이콘 테마를 페이지 텍스트 색과 맞추기 쉽습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-08.js와 index.html을 준비하세요. stroke와 fill에 currentColor를 사용하는 아이콘을 작성하세요.
2. 테마 버튼으로 CSS 변수를 전환하고 getComputedStyle로 최종 fill을 기록하세요.
3. 입력 조건 fill 속성만에서 출력을 저장한 뒤 CSS fill 규칙 추가 조건으로 다시 실행하세요. 캐스케이드에 따라 화면 색이 속성 문자열과 달라질 수 있습니다라는 가설을 화면·로그와 대조하고 day-08-notes.md에 실제 결과와 차이의 원인을 남기세요.
