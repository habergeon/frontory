## 핵심 개념과 설명

### 경계 상자 단위

objectBoundingBox는 도형의 경계 상자를 기준으로 합니다. 같은 정의도 도형 비율에 따라 다르게 보일 수 있습니다.

### 사용자 공간

userSpaceOnUse는 사용자 좌표로 그라디언트를 정의합니다. 여러 도형에 걸쳐 연속된 색 띠를 만들 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-09.js와 index.html을 준비하세요. linearGradient를 defs에 만들고 서로 다른 폭의 사각형에 적용하세요.
2. gradientUnits를 전환하고 시작·끝 좌표를 함께 조정하세요.
3. 입력 조건 objectBoundingBox에서 출력을 저장한 뒤 userSpaceOnUse 조건으로 다시 실행하세요. 도형마다 늘어나던 색 띠가 공통 좌표에 정렬됩니다라는 가설을 화면·로그와 대조하고 day-09-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| gradientUnits | objectBoundingBox | userSpaceOnUse | 도형마다 늘어나던 색 띠가 공통 좌표에 정렬됩니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
