## 선수 지식

선수 개념: 경계 상자 단위, 사용자 공간. 9단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 클리핑

clipPath는 보이는 기하 영역을 제한합니다. 경계 안팎을 잘라내는 데 적합합니다.

### 마스크 농도

mask는 알파나 밝기로 가시성을 조절합니다. 흐린 경계를 만들 때 단순 클리핑과 다른 결과를 줍니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-10.js와 index.html을 준비하세요. 원형 clipPath로 이미지를 잘라 아바타를 만드세요.
2. 별도 mask에 그라디언트를 넣어 같은 이미지가 서서히 사라지게 하세요.
3. 입력 조건 단색 흰색에서 출력을 저장한 뒤 흰색에서 검정 그라디언트 조건으로 다시 실행하세요. 휘도 마스크에서 가시성이 점진적으로 줄어듭니다라는 가설을 화면·로그와 대조하고 day-10-notes.md에 실제 결과와 차이의 원인을 남기세요.
