## 선수 지식

선수 개념: 클리핑, 마스크 농도. 10단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 필터 그래프

필터 primitive는 입력 이미지를 받아 출력으로 이어집니다. 입력을 잘못 연결하면 원본 대신 이전 효과가 처리됩니다.

### 필터 경계

블러는 도형 바깥으로 번집니다. 필터 영역이 좁으면 가장자리가 잘릴 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-11.js와 index.html을 준비하세요. filter에 feGaussianBlur와 feOffset을 연결해 그림자를 만드세요.
2. stdDeviation과 필터 x,y,width,height를 조절해 잘림 전후를 저장하세요.
3. 입력 조건 2에서 출력을 저장한 뒤 12 조건으로 다시 실행하세요. 그림자가 넓어져 기존 필터 영역 밖에서 잘릴 수 있습니다라는 가설을 화면·로그와 대조하고 day-11-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수         | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                  |
| ------------ | --------- | --------- | ------------------------------------------------------ |
| stdDeviation | 2         | 12        | 그림자가 넓어져 기존 필터 영역 밖에서 잘릴 수 있습니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
