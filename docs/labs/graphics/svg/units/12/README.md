## 선수 지식

선수 개념: 필터 그래프, 필터 경계. 11단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 글자 배치

text-anchor는 x좌표에 대한 정렬 기준입니다. 문자열 폭이 달라도 데이터 점에 라벨을 맞출 수 있습니다.

### 대체 정보

그림 속 텍스트가 복잡한 데이터 전체를 설명하지 못할 수 있습니다. 표나 설명을 함께 두면 정보를 다른 방식으로 탐색할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-12.js와 index.html을 준비하세요. text와 tspan으로 노드 이름과 수치를 표시하세요.
2. 긴 이름을 입력하고 겹치는 라벨의 위치를 조정한 뒤 같은 데이터를 HTML 표로 출력하세요.
3. 입력 조건 짧은 이름에서 출력을 저장한 뒤 긴 한글 이름 조건으로 다시 실행하세요. 고정 간격에서는 겹침이 생겨 배치 정책이 필요합니다라는 가설을 화면·로그와 대조하고 day-12-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| --------- | --------- | ------------ | -------------------------------------------------- |
| 라벨 길이 | 짧은 이름 | 긴 한글 이름 | 고정 간격에서는 겹침이 생겨 배치 정책이 필요합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
