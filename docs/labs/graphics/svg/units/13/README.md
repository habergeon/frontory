## 핵심 개념과 설명

### 역행렬

getScreenCTM은 SVG 좌표를 화면으로 옮기는 행렬입니다. inverse로 변환하면 포인터 위치를 사용자 좌표로 돌릴 수 있습니다.

### 변환 합성

viewBox와 그룹 변환이 모두 좌표에 영향을 줍니다. 선택 대상 그룹의 행렬을 사용하면 수동 비율 계산을 줄일 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-13.js와 index.html을 준비하세요. DOMPoint(clientX,clientY).matrixTransform(group.getScreenCTM().inverse())로 포인터를 변환하세요.
2. 그룹을 회전·확대하고 포인터 위치에 로컬 좌표 십자선을 추가하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 2 조건으로 다시 실행하세요. 화면 이동량의 절반이 그룹 로컬 이동량이 됩니다라는 가설을 화면·로그와 대조하고 day-13-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| --- | --- | --- | --- |
| 그룹 scale | 1 | 2 | 화면 이동량의 절반이 그룹 로컬 이동량이 됩니다 |
