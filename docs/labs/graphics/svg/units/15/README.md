## 핵심 개념과 설명

### 이름 연결

title은 SVG의 짧은 설명에 사용됩니다. aria-labelledby로 연결할 때 id가 정확해야 이름을 찾을 수 있습니다.

### 장식 구분

의미 없는 장식은 보조기술 탐색에서 제외할 수 있습니다. 의미 있는 데이터 그림까지 숨기면 정보가 사라집니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-15.js와 index.html을 준비하세요. 정보용 SVG에 title,desc와 aria-labelledby를 연결하세요.
2. 같은 배지를 장식용 aria-hidden 버전과 정보용 버전으로 나누고 접근성 트리를 검사하세요.
3. 입력 조건 정보용 이름 있음에서 출력을 저장한 뒤 장식용 aria-hidden 조건으로 다시 실행하세요. 장식은 탐색에서 제외되고 정보용 이름은 남습니다라는 가설을 화면·로그와 대조하고 day-15-notes.md에 실제 결과와 차이의 원인을 남기세요.
