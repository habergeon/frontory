## 선수 지식

선수 개념: 이름 연결, 장식 구분. 15단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 페인트와 입력

pointer-events는 어떤 영역이 이벤트를 받을지 정합니다. 보이는 선이 가늘면 선택 영역도 좁아 조작이 어려울 수 있습니다.

### 버블링

자식 이벤트는 부모로 전달됩니다. 그룹 단위 선택에서는 target과 currentTarget을 구분해야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-16.js와 index.html을 준비하세요. 얇은 연결선 위에 투명한 굵은 hit path를 추가하세요.
2. 부모 g에서 이벤트를 받고 target과 currentTarget의 id를 로그로 출력하세요.
3. 입력 조건 2px에서 출력을 저장한 뒤 16px 조건으로 다시 실행하세요. 보이는 선은 그대로 두면서 조작 가능한 범위가 넓어집니다라는 가설을 화면·로그와 대조하고 day-16-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 선택 폭 | 2px | 16px | 보이는 선은 그대로 두면서 조작 가능한 범위가 넓어집니다 |
