## 선수 지식

선수 개념: 페인트와 입력, 버블링. 16단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 드래그 오프셋

포인터와 노드 중심의 차이를 저장하면 시작 시 점프를 막습니다. 좌표는 같은 사용자 공간에서 계산해야 합니다.

### 취소 경로

pointercancel은 정상 종료와 다를 수 있습니다. 캡처 해제와 임시 상태 정리를 공통 함수로 묶습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-17.js와 index.html을 준비하세요. pointerdown에서 역행렬 좌표와 노드 위치 차이를 저장하고 캡처하세요.
2. pointermove로 transform을 갱신하며 pointerup·pointercancel에서 종료하세요.
3. 입력 조건 노드 중앙에서 출력을 저장한 뒤 노드 가장자리 조건으로 다시 실행하세요. 오프셋을 유지하면 노드가 갑자기 이동하지 않습니다라는 가설을 화면·로그와 대조하고 day-17-notes.md에 실제 결과와 차이의 원인을 남기세요.
