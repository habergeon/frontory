## 핵심 개념과 설명

### 카메라 그룹

콘텐츠 그룹에 변환을 주면 전체 지도를 이동할 수 있습니다. 화면 위 컨트롤은 그룹 밖에 둬 같은 크기로 유지합니다.

### 포인터 중심 확대

확대 전후 같은 로컬 점이 같은 화면 위치에 있어야 자연스럽습니다. 배율만 바꾸면 그림이 원점 쪽으로 튑니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-18.js와 index.html을 준비하세요. 콘텐츠 g의 translate와 scale을 상태로 관리하세요.
2. 확대 버튼과 wheel 입력에서 포인터 아래 로컬 점을 계산해 이동량을 보정하세요.
3. 입력 조건 원점에서 출력을 저장한 뒤 포인터 위치 조건으로 다시 실행하세요. 포인터 아래 노드가 확대 후에도 같은 화면 점에 머뭅니다라는 가설을 화면·로그와 대조하고 day-18-notes.md에 실제 결과와 차이의 원인을 남기세요.
