## 핵심 개념과 설명

### 안정적인 id

데이터 id는 DOM 요소와 데이터의 연결점입니다. 배열 순서가 바뀌어도 같은 객체를 식별할 수 있습니다.

### 증분 갱신

전체 innerHTML 교체는 포커스와 이벤트 연결을 잃을 수 있습니다. 필요한 속성과 요소만 수정하면 상태를 보존하기 쉽습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-19.js와 index.html을 준비하세요. id→SVGElement Map으로 노드 생성·수정·삭제를 구현하세요.
2. 데이터 순서를 바꾸고 한 노드를 제거한 뒤 선택·포커스 유지 여부를 기록하세요.
3. 입력 조건 전체 교체에서 출력을 저장한 뒤 id 기반 속성 수정 조건으로 다시 실행하세요. 변경되지 않은 요소의 정체성과 포커스가 유지됩니다라는 가설을 화면·로그와 대조하고 day-19-notes.md에 실제 결과와 차이의 원인을 남기세요.
