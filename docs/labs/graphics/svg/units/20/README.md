## 핵심 개념과 설명

### 파생 경로

연결선은 두 노드의 좌표에서 계산되는 데이터입니다. 별도로 저장하면 이동 후 좌표가 오래된 상태로 남을 수 있습니다.

### 레이어 순서

SVG는 문서 순서로 그립니다. 연결선을 먼저 두면 노드와 라벨 아래에 표시할 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-20.js와 index.html을 준비하세요. 노드 배열과 sourceId,targetId 간선 배열로 작은 학습 지도를 만드세요.
2. 드래그마다 양 끝 좌표로 path d를 갱신하고 연결선 그룹을 노드 앞에 배치하세요.
3. 입력 조건 고정에서 출력을 저장한 뒤 한 노드 80단위 이동 조건으로 다시 실행하세요. 해당 노드와 연결된 경로만 새 위치를 향합니다라는 가설을 화면·로그와 대조하고 day-20-notes.md에 실제 결과와 차이의 원인을 남기세요.
