## 선수 지식

선수 개념: 파생 경로, 레이어 순서. 20단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 보간

시작값과 끝값 사이를 시간 비율로 계산하면 이동을 부드럽게 만들 수 있습니다. 프레임 수를 기준으로 하면 주사율에 따라 속도가 달라집니다.

### 동작 선호

prefers-reduced-motion은 불필요한 움직임을 줄이는 신호입니다. 상태 변화는 애니메이션 없이도 전달되어야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-21.js와 index.html을 준비하세요. requestAnimationFrame 시간으로 노드 transform을 보간하세요.
2. matchMedia로 동작 줄이기를 감지해 즉시 최종 상태를 적용하는 경로를 추가하세요.
3. 입력 조건 일반에서 출력을 저장한 뒤 reduced-motion 조건으로 다시 실행하세요. 중간 이동 없이 최종 배치와 선택 상태가 표시됩니다라는 가설을 화면·로그와 대조하고 day-21-notes.md에 실제 결과와 차이의 원인을 남기세요.
