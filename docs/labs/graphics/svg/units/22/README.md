## 핵심 개념과 설명

### 직렬화

XMLSerializer는 DOM을 문자열로 만듭니다. 외부 CSS만으로 지정된 스타일은 파일에 함께 포함되지 않을 수 있습니다.

### 독립 자원

내보낸 SVG는 원래 페이지와 떨어져 열립니다. 폰트와 이미지 참조가 상대 경로라면 결과가 달라질 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-22.js와 index.html을 준비하세요. 복제한 SVG에 xmlns와 필요한 스타일을 넣고 XMLSerializer로 저장하세요.
2. Blob URL로 다운로드한 파일을 별도 문서에서 열어 색·텍스트·이미지 참조를 확인하세요.
3. 입력 조건 페이지 CSS만에서 출력을 저장한 뒤 SVG 내부 style 조건으로 다시 실행하세요. 독립 파일에서도 지정한 색과 선이 유지됩니다라는 가설을 화면·로그와 대조하고 day-22-notes.md에 실제 결과와 차이의 원인을 남기세요.
