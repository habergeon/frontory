## 선수 지식

선수 개념: DOM 규모, 측정 구간. 23단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 가시 영역

보이지 않는 노드를 생략하면 작업 대상을 줄일 수 있습니다. 선택된 노드의 의미 정보까지 사라지지 않도록 정책이 필요합니다.

### 세부 수준

확대 수준에 따라 라벨이나 장식을 줄일 수 있습니다. 데이터 자체를 삭제하는 것과 표시만 줄이는 것은 다릅니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-24.js와 index.html을 준비하세요. 현재 viewBox와 노드 경계로 가시 노드를 계산하세요.
2. 축소 시 라벨을 숨기되 HTML 목록과 선택 설명은 유지하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 0.2 조건으로 다시 실행하세요. 라벨을 줄이면 겹침이 완화되고 DOM 작업이 줄 수 있습니다라는 가설을 화면·로그와 대조하고 day-24-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 축척 | 1         | 0.2       | 라벨을 줄이면 겹침이 완화되고 DOM 작업이 줄 수 있습니다 |
