## 핵심 개념과 설명

### 공통 데이터

렌더러가 같은 데이터와 좌표 변환을 사용해야 공정하게 비교할 수 있습니다. 난수 분포가 다르면 성능과 선택 조건도 달라집니다.

### 선택 구현

SVG는 DOM 대상을 제공하지만 Canvas는 별도 히트 테스트가 필요합니다. 기능 수준을 맞춰야 구현 비용을 비교할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-25.js와 index.html을 준비하세요. 동일 점 배열을 SVG circle과 Canvas arc로 각각 그리세요.
2. 같은 확대·선택 상태를 두 렌더러에 전달하고 Canvas에는 거리 기반 히트 테스트를 구현하세요.
3. 입력 조건 SVG에서 출력을 저장한 뒤 Canvas 2D 조건으로 다시 실행하세요. 선택 기능의 구현 책임과 DOM 수가 달라집니다라는 가설을 화면·로그와 대조하고 day-25-notes.md에 실제 결과와 차이의 원인을 남기세요.
