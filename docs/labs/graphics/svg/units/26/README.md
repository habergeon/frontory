# SVG · 26 지도 편집기 통합

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 내보내기·대규모 비교 · 편집 가능한 예제 · 저장 ID: `svg-step-26`

## 목표와 학습 후 역량

- 불완전한 데이터가 기존 장면을 덮지 않는다.
- 키보드로 가져오기 오류에서 복구할 수 있다.

## 선수 지식

선수 개념: 공통 데이터, 선택 구현. 25단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 상태 일관성

선택·배율·노드 데이터는 서로 영향을 줍니다. 상태 변경을 명령 함수로 모으면 입력 경로별 차이를 줄일 수 있습니다.

### 복구 가능성

잘못된 가져오기가 기존 작업을 망가뜨리지 않아야 합니다. 검증된 새 데이터를 한 번에 적용하는 방식이 도움이 됩니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-26.js와 index.html을 준비하세요. JSON 가져오기·노드 드래그·키보드 선택·SVG 내보내기를 결합하세요.
2. 없는 간선 id와 중복 노드를 입력해 오류 표시와 기존 장면 보존을 확인하세요.
3. 입력 조건 정상 그래프에서 출력을 저장한 뒤 중복 id 조건으로 다시 실행하세요. 새 데이터 적용을 거부하고 편집 상태를 유지합니다라는 가설을 화면·로그와 대조하고 day-26-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수            | 기준 조건   | 바꿀 조건 | 예상할 변화·검증 가설                            |
| --------------- | ----------- | --------- | ------------------------------------------------ |
| 가져오기 데이터 | 정상 그래프 | 중복 id   | 새 데이터 적용을 거부하고 편집 상태를 유지합니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
