## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-27.js와 index.html을 준비하세요. 동일 데이터로 초기 생성과 확대·선택 시나리오를 자동 순서로 재생하세요.
2. 브라우저 프로파일과 frame 간격을 수집하고 중앙값·긴 프레임·DOM 수를 표로 남기세요.
3. 입력 조건 1000점에서 출력을 저장한 뒤 5000점 조건으로 다시 실행하세요. 렌더러별 비용 증가 양상이 다를 수 있습니다라는 가설을 화면·로그와 대조하고 day-27-notes.md에 실제 결과와 차이의 원인을 남기세요.
