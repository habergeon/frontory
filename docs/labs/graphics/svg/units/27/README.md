## 핵심 개념과 설명

### 비교 계약

점 수·크기·색·입력 기능이 같아야 렌더러 차이를 해석할 수 있습니다. 어느 한쪽만 라벨이나 필터가 있으면 별도 조건으로 기록합니다.

### 분포 기록

한 번의 시간값보다 여러 표본의 분포가 유용합니다. 초기 생성과 연속 확대를 별도 시나리오로 나눕니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. 브라우저 버전과 viewport, DPR을 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-27.js와 index.html을 준비하세요. 동일 데이터로 초기 생성과 확대·선택 시나리오를 자동 순서로 재생하세요.
2. 브라우저 프로파일과 frame 간격을 수집하고 중앙값·긴 프레임·DOM 수를 표로 남기세요.
3. 입력 조건 1000점에서 출력을 저장한 뒤 5000점 조건으로 다시 실행하세요. 렌더러별 비용 증가 양상이 다를 수 있습니다라는 가설을 화면·로그와 대조하고 day-27-notes.md에 실제 결과와 차이의 원인을 남기세요.
