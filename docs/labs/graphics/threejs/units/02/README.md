## 핵심 개념과 설명

### 버퍼 크기

렌더러의 drawing buffer는 CSS 표시 크기와 다릅니다. pixelRatio를 올리면 같은 화면에 더 많은 픽셀을 처리합니다.

### 종횡비

PerspectiveCamera의 aspect는 viewport 비율입니다. 크기를 바꾼 뒤 updateProjectionMatrix를 호출해야 새 투영이 적용됩니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-02.js와 index.html을 준비하세요. ResizeObserver로 컨테이너를 읽어 renderer.setSize(w,h,false)를 호출하세요.
2. camera.aspect와 투영을 갱신하고 CSS 크기·버퍼 크기를 output으로 비교하세요.
3. 입력 조건 1:1에서 출력을 저장한 뒤 2:1 조건으로 다시 실행하세요. 예상: aspect를 갱신하면 구가 타원처럼 늘어나지 않습니다. 실제 화면·로그와 대조하고 day-02-notes.md에 실제 결과와 차이의 원인을 남기세요.
