## 목표와 학습 후 역량

- geometry 수정 없이 피벗을 구현한다.
- 부모 축과 자식 축을 구별한다.

## 선수 지식

선수 개념: 원근 투영, 직교 투영. 3단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 피벗 그룹

회전 기준을 바꾸려면 부모 그룹과 자식 오프셋을 나눌 수 있습니다. geometry 자체를 매번 수정할 필요는 없습니다.

### Euler 순서

여러 축의 회전은 적용 순서에 따라 결과가 달라집니다. 복잡한 자세에서는 quaternion 표현도 검토해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-04.js와 index.html을 준비하세요. 문 경첩 위치에 Group을 만들고 문 Mesh를 절반 폭만큼 이동시키세요.
2. 회전 슬라이더로 문을 열고 두 축 회전 순서를 바꾼 결과를 비교하세요.
3. 입력 조건 문 중심에서 출력을 저장한 뒤 문 가장자리 조건으로 다시 실행하세요. 예상: 문이 중심 회전 대신 경첩을 따라 움직입니다. 실제 화면·로그와 대조하고 day-04-notes.md에 실제 결과와 차이의 원인을 남기세요.
