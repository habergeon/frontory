## 선수 지식

선수 개념: 피벗 그룹, Euler 순서. 4단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 정점 속성

BufferGeometry는 position과 normal 같은 배열을 묶습니다. itemSize는 한 정점을 구성하는 성분 수입니다.

### 인덱스 공유

인덱스는 정점을 재사용해 삼각형을 연결합니다. 같은 위치라도 UV나 normal이 다르면 별도 정점이 필요할 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-05.js와 index.html을 준비하세요. Float32Array와 BufferAttribute로 사각형의 정점을 작성하세요.
2. setIndex로 두 삼각형을 연결하고 wireframe 재질로 winding과 면 방향을 확인하세요.
3. 입력 조건 반시계에서 출력을 저장한 뒤 시계 조건으로 다시 실행하세요. 예상: 기본 앞면 판단이 바뀌어 면이 사라질 수 있습니다. 실제 화면·로그와 대조하고 day-05-notes.md에 실제 결과와 차이의 원인을 남기세요.
