## 선수 지식

## 핵심 개념과 설명

### 법선 역할

법선은 빛이 표면에 닿는 방향을 계산하는 데 쓰입니다. 위치가 같아도 법선이 다르면 경계가 다르게 보입니다.

### 평활화

공유 정점의 법선을 평균내면 면 사이가 부드럽게 보입니다. 날카로운 모서리를 유지하려면 속성을 분리해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-06.js와 index.html을 준비하세요. 직접 만든 geometry에 computeVertexNormals를 적용하세요.
2. MeshNormalMaterial과 조명 재질을 번갈아 사용하고 정점 공유 여부를 비교하세요.
3. 입력 조건 면별 분리에서 출력을 저장한 뒤 모서리 공유 조건으로 다시 실행하세요. 예상: 평균 법선 때문에 모서리가 부드럽게 보일 수 있습니다. 실제 화면·로그와 대조하고 day-06-notes.md에 실제 결과와 차이의 원인을 남기세요.
