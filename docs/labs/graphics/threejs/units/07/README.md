## 핵심 개념과 설명

### 참조 공유

여러 Mesh가 하나의 geometry나 material을 참조할 수 있습니다. 공유 자원을 바꾸면 모든 참조 객체가 영향을 받습니다.

### 소유권

객체 복제는 모든 GPU 자원을 독립 복사한다는 뜻이 아닙니다. 수정·해제 전에 공유 범위를 확인해야 합니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-07.js와 index.html을 준비하세요. 같은 geometry와 material을 쓰는 큐브 세 개를 배치하세요.
2. 한 큐브의 material 색을 바꾼 뒤 material.clone으로 분리한 버전을 비교하세요.
3. 입력 조건 공유 참조에서 출력을 저장한 뒤 clone된 개별 재질 조건으로 다시 실행하세요. 예상: 한 큐브의 색 수정이 다른 큐브에 전파되지 않습니다. 실제 화면·로그와 대조하고 day-07-notes.md에 실제 결과와 차이의 원인을 남기세요.
