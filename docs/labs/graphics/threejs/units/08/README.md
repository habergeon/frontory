## 핵심 개념과 설명

### 방향광

DirectionalLight는 일정 방향에서 오는 빛을 표현합니다. 위치뿐 아니라 target이 빛의 방향에 영향을 줍니다.

### 점광원

PointLight는 한 지점에서 여러 방향으로 빛을 냅니다. 물체와의 거리에 따른 변화도 관찰해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-08.js와 index.html을 준비하세요. 바닥과 구를 만들고 방향광과 점광원을 전환하세요.
2. 광원 위치를 슬라이더로 움직이며 하이라이트와 밝기 변화를 기록하세요.
3. 입력 조건 DirectionalLight에서 출력을 저장한 뒤 PointLight 조건으로 다시 실행하세요. 예상: 거리와 위치 변화에 대한 표면 반응이 달라집니다. 실제 화면·로그와 대조하고 day-08-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 광원 종류 | DirectionalLight | PointLight | 거리와 위치 변화에 대한 표면 반응이 달라집니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
