## 선수 지식

선수 개념: 방향광, 점광원. 8단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 거칠기

roughness는 미세 표면에 의한 반사 퍼짐을 조절합니다. 낮은 값은 선명한 하이라이트를 만들기 쉽습니다.

### 금속성

metalness는 금속과 비금속의 반응을 구분합니다. 환경 반사가 부족하면 금속이 기대보다 어둡게 보일 수 있습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-09.js와 index.html을 준비하세요. MeshStandardMaterial 구를 roughness와 metalness 격자로 배치하세요.
2. 광원과 카메라를 고정하고 두 값 중 하나만 바꿔 스크린샷을 남기세요.
3. 입력 조건 0.1에서 출력을 저장한 뒤 0.8 조건으로 다시 실행하세요. 예상: 반사 하이라이트가 더 넓고 흐려집니다. 실제 화면·로그와 대조하고 day-09-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| roughness | 0.1 | 0.8 | 반사 하이라이트가 더 넓고 흐려집니다 |
