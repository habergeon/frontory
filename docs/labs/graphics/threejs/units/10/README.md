## 핵심 개념과 설명

### UV 매핑

UV는 정점과 이미지 위치를 연결합니다. geometry를 늘리면 텍스처도 함께 늘어날 수 있습니다.

### 반복 설정

repeat만 바꾸어도 wrapping 설정이 맞지 않으면 반복되지 않습니다. 원본 텍스처 크기와 표면 비율을 함께 고려합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-10.js와 index.html을 준비하세요. 로컬 체크 이미지를 TextureLoader로 읽어 평면 map에 지정하세요.
2. wrapS와 wrapT를 RepeatWrapping으로 바꾸고 repeat.set 값을 입력받으세요.
3. 입력 조건 1,1에서 출력을 저장한 뒤 4,2 조건으로 다시 실행하세요. 예상: 표면 위 체크 패턴이 가로 네 번 세로 두 번 반복됩니다. 실제 화면·로그와 대조하고 day-10-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| repeat | 1,1 | 4,2 | 표면 위 체크 패턴이 가로 네 번 세로 두 번 반복됩니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
