## 선수 지식

선수 개념: UV 매핑, 반복 설정. 10단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 색 데이터

색 텍스처와 수치 데이터 텍스처는 의미가 다릅니다. 색 이미지는 적절한 colorSpace를 지정해야 조명 계산이 맞습니다.

### 출력 변환

렌더러의 출력 색 공간은 화면 표시 단계에 해당합니다. 입력과 출력을 혼동해 이중 변환하면 색이 달라집니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-11.js와 index.html을 준비하세요. 컬러 체크 텍스처에 SRGBColorSpace를 지정하고 중성 조명에서 표시하세요.
2. 같은 재질에 잘못된 입력 색 공간을 적용한 비교를 만들고 설정값을 표로 기록하세요.
3. 입력 조건 SRGBColorSpace에서 출력을 저장한 뒤 NoColorSpace 조건으로 다시 실행하세요. 예상: 동일 이미지의 밝기 해석이 달라질 수 있습니다. 실제 화면·로그와 대조하고 day-11-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 색 텍스처 colorSpace | SRGBColorSpace | NoColorSpace | 동일 이미지의 밝기 해석이 달라질 수 있습니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
