## 핵심 개념과 설명

### 추가 렌더링

그림자는 광원 시점의 깊이 렌더링을 필요로 합니다. 광원과 캐스터 수에 따라 추가 비용이 생깁니다.

### 그림자 범위

shadow camera의 범위는 그림자가 계산되는 영역입니다. 범위를 과도하게 넓히면 같은 지도 크기의 해상도가 희석됩니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-12.js와 index.html을 준비하세요. renderer.shadowMap.enabled와 castShadow·receiveShadow를 설정하세요.
2. DirectionalLight의 shadow camera helper를 띄우고 범위를 좁힌 전후를 비교하세요.
3. 입력 조건 넓은 영역에서 출력을 저장한 뒤 대상 주변 작은 영역 조건으로 다시 실행하세요. 예상: 동일 mapSize에서 대상 부근 그림자가 더 세밀해질 수 있습니다. 실제 화면·로그와 대조하고 day-12-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| ----------- | --------- | ------------------- | ----------------------------------------------------------- |
| shadow 범위 | 넓은 영역 | 대상 주변 작은 영역 | 동일 mapSize에서 대상 부근 그림자가 더 세밀해질 수 있습니다 |
