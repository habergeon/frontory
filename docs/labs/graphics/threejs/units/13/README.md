## 핵심 개념과 설명

### NDC 입력

Raycaster.setFromCamera는 정규화 장치 좌표를 받습니다. canvas 사각형을 기준으로 x는 -1부터 1, y는 위쪽이 1이 되게 계산합니다.

### 교차 결과

intersectObjects는 거리순 교차 정보를 반환합니다. 복합 모델은 하위 Mesh에서 업무상 선택 대상까지 올라가는 규칙이 필요합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-13.js와 index.html을 준비하세요. pointerdown의 client 좌표를 NDC로 바꾸고 raycaster.setFromCamera를 호출하세요.
2. 겹친 두 Mesh의 교차 거리와 이름을 HTML 목록으로 표시하세요.
3. 입력 조건 캔버스 중앙에서 출력을 저장한 뒤 왼쪽 상단 조건으로 다시 실행하세요. 예상: NDC는 대략 0,0에서 -1,1로 바뀝니다. 실제 화면·로그와 대조하고 day-13-notes.md에 실제 결과와 차이의 원인을 남기세요.
