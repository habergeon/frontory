## 핵심 개념과 설명

### 경계 상자

모델마다 단위와 중심이 다릅니다. world 경계 상자로 크기와 중심을 계산하면 일관된 관찰 기준을 만들 수 있습니다.

### 카메라 프레이밍

대상 크기와 FOV를 이용해 거리를 계산할 수 있습니다. aspect가 좁으면 가로 방향도 고려해야 합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-15.js와 index.html을 준비하세요. Box3.setFromObject로 로딩된 모델의 중심과 크기를 구하세요.
2. controls.target을 중심으로 옮기고 모델 크기를 기준으로 카메라 거리와 near·far를 조정하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 10 조건으로 다시 실행하세요. 예상: 프레이밍 후 화면 점유율이 비슷하게 유지됩니다. 실제 화면·로그와 대조하고 day-15-notes.md에 실제 결과와 차이의 원인을 남기세요.
