## 핵심 개념과 설명

### 믹서 시간

AnimationMixer.update는 초 단위 delta를 받습니다. 밀리초를 그대로 전달하면 애니메이션이 지나치게 빨라집니다.

### 클립과 액션

AnimationClip은 키프레임 데이터이고 action은 재생 상태입니다. 여러 action이 같은 모델에 영향을 줄 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-17.js와 index.html을 준비하세요. 애니메이션이 포함된 로컬 glb에서 clip 목록을 HTML select로 표시하세요.
2. mixer.clipAction으로 재생하고 timeScale과 정지 버튼을 연결하세요.
3. 입력 조건 1에서 출력을 저장한 뒤 0.5 조건으로 다시 실행하세요. 예상: 같은 클립이 절반 속도로 재생됩니다. 실제 화면·로그와 대조하고 day-17-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| timeScale | 1 | 0.5 | 같은 클립이 절반 속도로 재생됩니다 |
