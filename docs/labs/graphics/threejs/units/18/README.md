## 핵심 개념과 설명

### 깊이 쓰기

depthWrite는 깊이 버퍼 기록 여부입니다. 반투명 물체가 뒤쪽 물체를 가리는 문제가 생길 수 있습니다.

### 정렬 한계

투명 객체는 순서에 민감합니다. 객체 단위 정렬만으로 교차하는 모든 표면을 완벽히 처리하기 어렵습니다.

## 실습 준비

새 단원의 내장 실행 예제는 제공하지 않습니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-18.js와 index.html을 준비하세요. 반투명 평면 두 개와 불투명 큐브를 교차 배치하세요.
2. transparent,opacity,depthWrite를 바꾸고 카메라를 한 바퀴 돌려 오류를 기록하세요.
3. 입력 조건 true에서 출력을 저장한 뒤 false 조건으로 다시 실행하세요. 예상: 가림 양상이 바뀌지만 모든 투명 정렬 문제가 해결되지는 않습니다. 실제 화면·로그와 대조하고 day-18-notes.md에 실제 결과와 차이의 원인을 남기세요.
