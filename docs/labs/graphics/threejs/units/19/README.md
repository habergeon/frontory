## 핵심 개념과 설명

### 공유 드로잉

InstancedMesh는 같은 geometry와 material을 여러 변환으로 그립니다. 객체마다 Mesh를 만드는 것보다 draw call을 줄일 수 있습니다.

### 인스턴스 버퍼

setMatrixAt은 CPU 쪽 인스턴스 데이터를 변경합니다. instanceMatrix.needsUpdate를 설정해야 변경을 업로드합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-19.js와 index.html을 준비하세요. 동일 큐브 500개를 Mesh 목록과 InstancedMesh로 각각 구성하세요.
2. 같은 좌표 배열을 setMatrixAt으로 채우고 renderer.info.render.calls를 비교하세요.
3. 입력 조건 개별 Mesh에서 출력을 저장한 뒤 InstancedMesh 조건으로 다시 실행하세요. 예상: 같은 재질 조건에서 draw call이 줄어듭니다. 실제 화면·로그와 대조하고 day-19-notes.md에 실제 결과와 차이의 원인을 남기세요.
