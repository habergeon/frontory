## 핵심 개념과 설명

### 절두체 컬링

렌더러는 경계가 카메라 밖에 있는 객체를 생략할 수 있습니다. 잘못된 경계는 보이는 물체가 사라지는 원인이 됩니다.

### 상세도

멀리 있는 물체는 적은 정점으로도 비슷하게 보일 수 있습니다. 전환 시 튀는 정도와 삼각형 감소를 함께 비교합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-21.js와 index.html을 준비하세요. 가까운 구와 먼 구에 서로 다른 세그먼트 수를 적용하세요.
2. 카메라 거리를 바꾸며 화면 품질과 renderer.info.render.triangles를 기록하세요.
3. 입력 조건 64에서 출력을 저장한 뒤 12 조건으로 다시 실행하세요. 예상: 삼각형 수는 줄지만 윤곽 품질은 거리별로 달라집니다. 실제 화면·로그와 대조하고 day-21-notes.md에 실제 결과와 차이의 원인을 남기세요.

| --- | --- | --- | --- |
| 먼 구 세그먼트 | 64 | 12 | 삼각형 수는 줄지만 윤곽 품질은 거리별로 달라집니다 |
