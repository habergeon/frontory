## 선수 지식

선수 개념: 절두체 컬링, 상세도. 21단위의 결과 파일과 관찰 기록을 준비하세요.

## 핵심 개념과 설명

### 오프스크린 출력

WebGLRenderTarget은 화면 대신 텍스처에 렌더링합니다. 다른 카메라의 결과를 화면 안 표면에 사용할 수 있습니다.

### 상태 복원

setRenderTarget(null)은 기본 화면으로 돌아갑니다. 이를 놓치면 이후 렌더도 계속 타깃에 기록됩니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-22.js와 index.html을 준비하세요. 위에서 내려다보는 카메라로 render target에 장면을 그리세요.
2. 타깃 텍스처를 미니맵 평면에 연결하고 메인 장면에서 그 평면이 미니맵 카메라에 다시 보이지 않게 분리하세요.
3. 입력 조건 256×256에서 출력을 저장한 뒤 512×512 조건으로 다시 실행하세요. 예상: 미니맵 선명도와 처리 픽셀 수가 함께 늘어납니다. 실제 화면·로그와 대조하고 day-22-notes.md에 실제 결과와 차이의 원인을 남기세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                          |
| --------- | --------- | --------- | ---------------------------------------------- |
| 타깃 크기 | 256×256   | 512×512   | 미니맵 선명도와 처리 픽셀 수가 함께 늘어납니다 |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
