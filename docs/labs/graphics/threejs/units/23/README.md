## 핵심 개념과 설명

### 명시적 해제

scene.remove는 장면 연결만 끊습니다. geometry·material·texture의 GPU 관련 자원은 별도 dispose가 필요합니다.

### 공유 수명

한 자원을 여러 객체가 쓸 수 있습니다. 마지막 사용자가 끝나기 전에 해제하지 않도록 소유자와 참조 범위를 기록합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-23.js와 index.html을 준비하세요. 생성한 geometry,material,texture를 Set으로 추적하는 resourceTracker를 작성하세요.
2. 공유 재질 두 Mesh 중 하나만 제거한 뒤 나머지 렌더를 유지하고 최종 종료 때 한 번씩 해제하세요.
3. 입력 조건 한 사용자만에서 출력을 저장한 뒤 모든 사용자 조건으로 다시 실행하세요. 예상: 공유 자원은 마지막 사용자 종료 뒤 해제해야 합니다. 실제 화면·로그와 대조하고 day-23-notes.md에 실제 결과와 차이의 원인을 남기세요.
