## 핵심 개념과 설명

### 대체 조작

3D 픽셀만으로 개별 물체 의미가 전달되지는 않습니다. HTML 객체 목록과 버튼으로 선택과 카메라 이동을 제공할 수 있습니다.

### 상태 알림

선택 이름과 로딩 오류는 텍스트로 전달해야 합니다. 매 프레임 좌표를 알리면 중요한 알림이 묻힐 수 있습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-25.js와 index.html을 준비하세요. 객체별 HTML 버튼과 선택 설명 영역을 만들고 raycast와 같은 selectObject를 호출하세요.
2. 키보드로 객체 선택·카메라 맞춤·일시정지를 실행하고 포커스 복귀를 확인하세요.
3. 입력 조건 포인터에서 출력을 저장한 뒤 키보드만 조건으로 다시 실행하세요. 예상: 같은 객체와 카메라 목표를 선택할 수 있습니다. 실제 화면·로그와 대조하고 day-25-notes.md에 실제 결과와 차이의 원인을 남기세요.
