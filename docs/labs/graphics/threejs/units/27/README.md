## 핵심 개념과 설명

### 기능 계약

로딩·선택·카메라·애니메이션을 한 상태 모델로 연결해야 합니다. 각각의 오류 경로가 다른 기능까지 멈추지 않도록 나눕니다.

### 재실행 검증

정리 누락은 첫 실행에서 드러나지 않을 수 있습니다. 생성과 종료를 반복하며 이벤트와 자원 수의 추세를 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 로컬 HTTP 개발 서버의 HTML·ES 모듈 프로젝트에서 직접 구현합니다. three와 addons를 같은 설치 버전으로 고정하고 기록하세요.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 외부 실습 프로젝트의 day-27.js와 index.html을 준비하세요. 모델 검사기에 로컬 로딩·fallback·선택 목록·미니맵·통계 패널을 결합하세요.
2. 생성→선택→모델 교체→오류→종료를 5회 반복하고 루프와 controls·observer 정리를 기록하세요.
3. 입력 조건 1회에서 출력을 저장한 뒤 5회 조건으로 다시 실행하세요. 예상: 수명 관리가 맞으면 이벤트와 활성 루프가 누적되지 않습니다. 실제 화면·로그와 대조하고 day-27-notes.md에 실제 결과와 차이의 원인을 남기세요.
