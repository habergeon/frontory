## 목표

JavaScript와 shader 사이 데이터 경로를 설명하고 시간 변화를 만든다.

## 선수 지식

08~09, 경과 시간과 delta.

## 핵심 개념과 설명

uniform은 한 draw의 shader 호출들이 공유하는 입력이고 attribute는 정점별 입력입니다. varying은 vertex에서 fragment로 전달되어 삼각형 내부에서 보간되는 값입니다. GLSL3에서는 해당 단계의 in/out 문법을 사용합니다.

uniforms.uTime.value를 초 단위로 갱신합니다. sin(uTime*uSpeed)의 -1~1 범위를 0.5+0.5*sin(...)으로 0~1에 매핑할 수 있습니다. 매 프레임 material을 새로 만들지 않고 기존 value를 바꿉니다.

## 실습 과제

1. uTime과 uSpeed를 JavaScript와 GLSL 양쪽에 정의합니다.
2. 한 색 채널을 시간에 따라 바꾸고 uSpeed=0,1,3을 같은 관찰 시간으로 비교합니다.
3. 정지/재개 시 누적 시간을 멈출지 실제 시각을 사용할지 결정해 기록합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

uTime, uSpeed, 진폭·오프셋. 카메라·geometry는 고정합니다.
