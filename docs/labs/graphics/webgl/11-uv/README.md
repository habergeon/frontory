# 11 · UV와 Texture Sampling

2주 차 / 원문 Day 11 · 문서 제공 / 실행 예제 준비 중 · 고정된 하루 분량이 아닌 학습 순서입니다.

[전체 로드맵](../README.md) · [학습 화면 사용법](../../../../learning-workspace.md)

## 목표

표면 UV와 화면 좌표를 구분하고 샘플링의 의미를 설명한다.

## 선수 지식

08~10, 보간과 0~1 범위.

## 핵심 개념과 설명

UV는 geometry 표면에 붙은 2차원 좌표입니다. world x/y나 화면 좌표와 같지 않으며 mesh를 이동해도 일반적으로 표면에 붙어 있습니다. 정점의 UV는 fragment로 보간되어 전달됩니다.

UV를 색으로 출력한 뒤 texture를 샘플링합니다. wrapping은 범위 밖 좌표, filtering은 확대/축소된 샘플링을 다룹니다. 작은 자체 체크무늬로 시작해 데이터 출처 문제와 셰이더 문제를 분리합니다.

## 학습 후 얻을 역량

- 표면 UV와 화면 좌표를 구분하고 샘플링의 의미를 설명한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. vUv=uv를 전달하고 RGB=(u,v,0)으로 출력합니다.
2. 표면의 세 모서리 색을 예상하고 좌표 방향을 확인합니다.
3. 작은 텍스처 또는 절차적 체크무늬의 반복을 2,8,24로 바꾸고 평면을 회전합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

UV repeat, filtering, mesh transform. FOV를 고정합니다.

## 완료 조건

- [ ] UV 양 끝의 색을 설명했다.
- [ ] 반복 수를 바꿔 관찰했다.
- [ ] UV와 화면 좌표 차이를 예로 들었다.
