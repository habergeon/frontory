## 목표

UI 입력과 uniform을 연결한 작은 효과를 완성하고 설명한다.

## 선수 지식

08~13, React 입력 이벤트.

## 핵심 개념과 설명

UI 슬라이더의 값은 JavaScript에서 검증해 uniform으로 전달합니다. 화면의 숫자와 실제 shader 값이 일치해야 하며 UI를 만드는 것만으로 효과가 구현되었다고 보지 않습니다.

하나의 효과에 너무 많은 변수를 노출하면 원인을 추적하기 어렵습니다. 먼저 진폭·속도 두 개와 정지 기능으로 제한하고 오류·리사이즈·cleanup을 포함해 재현 가능한 결과를 남깁니다.

## 학습 후 얻을 역량

- UI 입력과 uniform을 연결한 작은 효과를 완성하고 설명한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 파동에 진폭·속도 입력과 정지를 연결합니다.
2. 최솟값·기본값·최댓값에서 UI 값과 실제 결과를 비교합니다.
3. 짧은 시연 순서와 코드 설명, 예상과 다른 결과를 정리합니다.

## 관찰할 변수

진폭, 속도, viewport. 기본 geometry·카메라를 고정합니다.

## 완료 조건

- [ ] 입력 변경이 uniform과 화면에 반영된다.
- [ ] 리사이즈와 정리 동작을 확인했다.
- [ ] 효과의 데이터 흐름을 설명한다.

## 자가 점검 질문

1. UI 숫자는 바뀌는데 화면이 안 바뀌면 어느 경로를 확인하나요?
2. 실험 변수를 줄이면 무엇을 얻나요?
