## 핵심 개념과 설명

원래 NeRF는 위치와 방향에 대해 밀도와 색을 예측하는 연속 표현을 신경망으로 학습하고 광선을 따라 샘플링하여 영상을 합성합니다. 3DGS는 위치·퍼짐·색·불투명도 등을 가진 가우시안 집합을 최적화하고 splatting으로 렌더링합니다.

두 방법 모두 여러 시점의 영상과 카메라 정보에 관계되지만 저장 표현과 렌더 비용이 다릅니다. 다양한 후속 변형이 있으므로 모든 NeRF/GS가 같은 속도나 용량을 가진다고 일반화하지 않습니다. 여기서는 이미 만들어진 데이터의 렌더링이 우선입니다.

## 실습 과제

1. 두 원 논문의 개요를 읽고 입력/표현/렌더링/결과 표를 만듭니다.
2. 새 시점의 영상을 만드는 과정에서 카메라 정보가 하는 역할을 적습니다.
3. 학습 비용과 브라우저 렌더링 비용을 분리해 이번 학습 범위를 정합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

표현 방식, 시점, 해상도. 다른 논문의 FPS를 같은 환경 실측처럼 비교하지 않습니다.
