## 핵심 개념과 설명

원래 NeRF는 위치와 방향에 대해 밀도와 색을 예측하는 연속 표현을 신경망으로 학습하고 광선을 따라 샘플링하여 영상을 합성합니다. 3DGS는 위치·퍼짐·색·불투명도 등을 가진 가우시안 집합을 최적화하고 splatting으로 렌더링합니다.

두 방법 모두 여러 시점의 영상과 카메라 정보에 관계되지만 저장 표현과 렌더 비용이 다릅니다. 다양한 후속 변형이 있으므로 모든 NeRF/GS가 같은 속도나 용량을 가진다고 일반화하지 않습니다. 여기서는 이미 만들어진 데이터의 렌더링이 우선입니다.
