## 핵심 개념과 설명

가우시안은 중심에서 멀어질수록 기여도가 줄어드는 퍼짐으로 생각할 수 있습니다. 중심만 있는 점과 달리 방향별 범위를 가지며 anisotropic한 형태는 축마다 퍼짐이 다릅니다.

공분산은 방향별 퍼짐과 방향 사이의 관계를 표현합니다. scale과 rotation으로 설명할 수도 있습니다. opacity는 합성에 기여하는 정도이며 크기와 같은 값이 아닙니다. 논문의 수식과 사용하는 라이브러리의 파라미터 표현은 구분합니다.

## 학습 후 얻을 역량

- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 중심이 같은 구형과 긴 타원체를 그립니다.
2. center 이동, 한 축 scale 증가, rotation, opacity 감소의 결과를 각각 예상합니다.
3. 원 논문 용어와 Spark의 center/scales/quaternion/opacity를 대응하는 표로 적습니다.


## 관찰할 변수

position, scales, rotation, opacity. 다른 값은 고정한 가상 비교부터 시작합니다.
