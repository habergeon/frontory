# 17 · Spherical Harmonics와 시점별 색상

3주 차 / 원문 Day 17 · 문서·예제 제공 · 고정된 하루 분량이 아닌 학습 순서입니다.

[전체 로드맵](../README.md) · [학습 화면 사용법](../../../../learning-workspace.md)

## 목표

고정 RGB와 방향 의존 색 표현의 차이를 설명한다.

## 선수 지식

15~16, 방향 벡터와 색상.

## 핵심 개념과 설명

SH는 구면 위 방향에 따라 달라지는 함수를 기저 함수의 계수로 표현하는 방법입니다. GS 데이터는 시선 방향에 따른 색 변화에 SH 성분을 사용할 수 있습니다. 고정 RGB와 달리 카메라 방향을 바꾸면 색이 달라질 수 있습니다.

계수 차수가 높을수록 더 복잡한 방향 변화를 표현할 수 있지만 데이터와 계산 비용도 달라집니다. 모든 파일·렌더러가 같은 차수와 저장 형식을 지원하지 않습니다. 이번 단위는 SH 학습 알고리즘 구현보다 데이터와 화면의 관계를 설명하는 것이 목표입니다.

## 학습 후 얻을 역량

- 고정 RGB와 방향 의존 색 표현의 차이를 설명한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 같은 표면을 보는 두 시선 방향을 그려 고정 색과 방향 의존 색의 차이를 적습니다.
2. 선택한 데이터와 렌더러가 SH를 어떻게 지원하는지 공식 문서에서 확인합니다.
3. 로딩 후 카메라만 돌려 관찰할 경로를 정하고 색 변화와 조명 변화의 가능성을 구분합니다.


## 관찰할 변수

view direction, SH 차수/지원 여부. 광원과 데이터는 고정합니다.

## 완료 조건

- [ ] 방향 함수와 계수의 의미를 설명했다.
- [ ] 데이터의 SH 지원 여부를 기록했다.
- [ ] 카메라만 바꾸는 관찰 조건을 정했다.

## 자가 점검 질문

1. 카메라를 돌려 색이 바뀌면 항상 광원 때문일까요?
2. RGB만 있는 파일을 SH 계수가 있는 파일과 동일하게 취급해도 될까요?
