## 목표

화면 footprint와 순서 의존 합성을 설명한다.

## 선수 지식

02 투영, 16~17, RGB와 alpha.

## 핵심 개념과 설명

3D 가우시안의 퍼짐은 카메라를 통해 화면 공간의 footprint로 투영됩니다. 같은 개수의 splat도 거리와 화면 크기에 따라 덮는 픽셀 수가 달라질 수 있습니다.

투명한 색을 합성할 때 순서는 중요합니다. C=alpha*C앞+(1-alpha)*C뒤를 두 색에 적용하고 앞뒤를 바꾸어 보세요. 실제 GS 렌더러는 가시성·정렬·누적 투과율 등을 다룹니다. 이번 단계에서 자체 GPU 정렬기를 만들 필요는 없습니다.

## 학습 후 얻을 역량

- 화면 footprint와 순서 의존 합성을 설명한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 빨강/파랑 두 층과 alpha=0.5로 검정 배경 위 결과를 순서별 계산합니다.
2. 가까운 splat과 먼 splat의 footprint를 그립니다.
3. 로딩 실습에서 겹침 경계를 관찰할 카메라 경로와 기록 항목을 정합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

깊이 순서, alpha, 거리, 해상도. 비용 변화는 측정 전에는 가설입니다.

## 완료 조건

- [ ] 앞뒤 합성의 다른 결과를 수치로 적었다.
- [ ] 개수와 footprint를 구분한다.
- [ ] 겹침 경계 관찰 계획을 세웠다.
