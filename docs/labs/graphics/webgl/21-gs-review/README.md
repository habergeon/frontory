## 목표

작은 GS 뷰어의 범위와 라이브러리 선택 근거를 정리한다.

## 선수 지식

15~20.

## 핵심 개념과 설명

원문 후보인 GaussianSplats3D와 huggingface/gsplat.js는 참고 후보로 유지합니다. 현재 문서가 Spark를 우선 검토하는 이유는 Three.js 장면·WebGL2·SplatMesh의 변환과 수명을 연결해 배우기 좋기 때문입니다. 가장 빠르다는 실측 결론이나 최종 채택 결정은 아닙니다.

후보 비교는 지원 형식, Three.js 호환 버전, SH 지원, 로딩/정리 API, 선택 기능, 라이선스와 유지 상태를 같은 표에 적어 수행합니다. 이번 범위에서 세 라이브러리를 모두 설치하거나 큰 데이터로 벤치마크하지 않습니다.

## 학습 후 얻을 역량

- 작은 GS 뷰어의 범위와 라이브러리 선택 근거를 정리한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 후보 세 개의 공식 README를 읽고 비교 표를 만듭니다.
2. 작은 데이터 하나로 로딩·조작·오류·정리의 최소 뷰어 수용 조건을 정합니다.
3. GS 원리와 구현에서 이해한 점·남은 질문을 정리하고 데이터는 Git에 넣지 않습니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

후보 라이브러리의 기능과 버전. 성능은 동일 조건 실측 전까지 미확인입니다.
