## 핵심 개념과 설명

원문 후보인 GaussianSplats3D와 huggingface/gsplat.js는 참고 후보로 유지합니다. 현재 문서가 Spark를 우선 검토하는 이유는 Three.js 장면·WebGL2·SplatMesh의 변환과 수명을 연결해 배우기 좋기 때문입니다. 가장 빠르다는 실측 결론이나 최종 채택 결정은 아닙니다.

후보 비교는 지원 형식, Three.js 호환 버전, SH 지원, 로딩/정리 API, 선택 기능, 라이선스와 유지 상태를 같은 표에 적어 수행합니다. 이번 범위에서 세 라이브러리를 모두 설치하거나 큰 데이터로 벤치마크하지 않습니다.

## 연결된 예제와 실행 범위

[원본 실행 코드](../../../../../src/labs/21-gs-review/example.js) · 화면 단위 ID: `21-gs-review`

소형 .splat 및 ASCII GS PLY를 읽는 CPU Canvas 교육용 뷰어입니다. 최대 1 MiB·512 splat이며 binary PLY와 일반 mesh PLY는 지원하지 않습니다. Spark, GPU tile 렌더링, 고차 SH, GS picking은 구현 범위 밖입니다. 기본 장면은 직접 생성한 데이터이며 측정값은 이 CPU 예제에만 해당합니다.

기존에 저장한 코드가 있으면 그대로 유지합니다. 새 원본을 사용하려면 먼저 전체 JSON으로 백업한 뒤 **원본 코드로**를 선택하세요. 필기는 지워지지 않습니다.
