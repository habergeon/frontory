## 목표

UI 상태와 매 프레임 장면 상태를 나누고 실습 계약을 만든다.

## 선수 지식

React state/ref/effect, 07과 21.

## 핵심 개념과 설명

선택 실습·입력 값·오류 메시지는 React 상태로 관리하고, 매 프레임 회전·행렬은 Three.js에서 관리할 수 있습니다. 책임을 나누면 UI 갱신이 장면을 불필요하게 다시 만들지 않습니다.

실습 공통 계약은 mount/update/dispose처럼 최소화합니다. 실제 중복이 생긴 코드부터 shared로 옮깁니다. 비동기 응답에는 실행 식별자를 붙여 이전 실습의 응답이 현재 UI를 덮어쓰지 못하게 합니다.

## 학습 후 얻을 역량

- UI 상태와 매 프레임 장면 상태를 나누고 실습 계약을 만든다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 현재 앱의 메뉴·저장·미리보기 코드를 읽고 상태 소유자 표를 만듭니다.
2. mesh와 GS를 연결할 최소 인터페이스를 정의합니다.
3. A의 느린 응답 중 B로 전환하는 시나리오를 작성하고 오래된 응답을 무시합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

선택 단위, 실행 id, 응답 순서, UI 입력.
