02, 06, 20.

## 핵심 개념과 설명

OrbitControls의 target은 카메라가 도는 중심입니다. pan은 카메라와 중심의 관계를 옮기고 dolly/zoom은 카메라 종류에 따라 동작이 다릅니다. 거리·각도 제한으로 물체 내부나 불필요한 영역으로 들어가는 것을 줄일 수 있습니다.

감쇠가 켜져 있으면 입력 후에도 변화가 남습니다. 초기화 시 남은 감쇠가 초기 위치를 다시 밀지 않는지 검사합니다. pointer/touch 조작 안내와 키보드로 접근 가능한 초기화 버튼을 제공합니다.

## 학습 후 얻을 역량

- 조작 범위와 초기화 동작을 일관되게 만든다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 대표 장면의 시작 위치와 target을 저장합니다.
2. min/max 거리와 각도 범위를 정하고 극단값에서 조작합니다.
3. 드래그 직후 초기화, 줌 후 초기화, 리사이즈 후 초기화를 비교합니다.

## 관찰할 변수

position, target, min/max 거리·각도, damping.

## 완료 조건

- [ ] 시작 시점으로 안정적으로 복구된다.
- [ ] 조작 한계의 이유를 설명한다.
- [ ] 다른 입력 장치의 미검증 범위를 적었다.

## 자가 점검 질문

2. 감쇠 중 reset 뒤에도 카메라가 움직일 수 있나요?
