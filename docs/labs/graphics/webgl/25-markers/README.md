## 목표

선택 좌표의 의미를 정하고 마커를 배치한다.

## 선수 지식

06, 20, 24.

## 핵심 개념과 설명

마커에는 world 위치와 화면에 표시할 위치가 필요합니다. 카메라가 움직이면 world 좌표를 다시 투영하여 DOM 마커 위치를 갱신할 수 있습니다. 물체 뒤에 가려졌는지와 화면 밖에 있는지를 별도로 판단합니다.

mesh의 교차점과 GS 전용 picking의 결과가 동일한 표면 의미를 갖는다고 가정하지 않습니다. 선택 결과가 center 근사인지 보이는 표면인지 명시하고 마커가 가리키는 의미를 UI와 문서에 씁니다.

## 학습 후 얻을 역량

- 선택 좌표의 의미를 정하고 마커를 배치한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. mesh의 raycast 교차점에 작은 마커를 놓습니다.
2. 카메라 이동·줌·리사이즈에서 마커 위치가 맞는지 확인합니다.
3. GS에서는 선택 API의 기준을 확인하고 선택 불가/불확실한 경우의 표시를 정합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.

## 관찰할 변수

교차 위치, camera 변환, occlusion, picking 기준.
