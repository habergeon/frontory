## 목표

재현 가능한 조건에서 성능 기준선을 기록한다.

## 선수 지식

07, 18, 22.

## 핵심 개념과 설명

기기·브라우저·viewport·DPR·데이터·카메라 경로·워밍업·측정 시간을 고정합니다. 평균 FPS뿐 아니라 프레임 시간 분포와 긴 프레임을 관찰합니다. JavaScript 실행 시간은 GPU 시간과 같지 않습니다.

renderer.info.render.calls와 triangles는 렌더 작업의 일부 지표입니다. renderer.info.memory.geometries/textures는 객체 카운터이며 실제 총 GPU VRAM 측정이 아닙니다. 브라우저·드라이버 캐시도 있어 해제 직후 OS 메모리가 줄지 않을 수 있습니다.

## 학습 후 얻을 역량

- 재현 가능한 조건에서 성능 기준선을 기록한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. pnpm build 후 pnpm preview에서 대표 경로를 정합니다.
2. docs/performance.md의 조건과 관찰 도구를 채웁니다.
3. 동일 경로를 여러 번 측정하고 로딩·CPU 갱신·렌더링 구간을 구분합니다.

이 단위의 실행 예제는 아직 준비 중입니다. 현재 화면에서는 문서를 읽고 단위별 필기를 쓸 수 있습니다. 01 예제에서 수행할 수 있는 작은 변수 실험은 그 화면에서 진행하고, 새 shader/GS 등의 코드 과제는 후속 로컬 실습으로 추가합니다. 제공되지 않은 기능을 완료된 것으로 표시하지 않습니다.
