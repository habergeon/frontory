## 목표

한 변수만 바꾼 전후 비교로 병목 가설을 검증한다.

## 선수 지식

26 기준선, 12 정점 수, 18 footprint.

## 핵심 개념과 설명

해상도를 낮출 때 개선되면 픽셀 처리 비용을 의심할 수 있지만 그것만으로 모든 GPU 병목을 증명하지는 못합니다. 파싱·정렬 같은 CPU 비용이라면 다른 실험이 필요합니다.

DPR, 정점 분할 수, 보이는 splat 수, shader 비용 중 하나만 바꿉니다. 속도에는 화질·정확도·메모리·구현 복잡도의 대가가 있을 수 있습니다. 차이가 반복 측정 오차 안이면 개선을 확정하지 않습니다.

## 학습 후 얻을 역량

- 한 변수만 바꾼 전후 비교로 병목 가설을 검증한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 기준선에서 느린 구간 하나를 골라 가설을 적습니다.
2. 예를 들어 DPR 상한 2 → 1만 바꾸고 같은 경로·시간으로 재측정합니다.
3. 전후 값, 화질 변화, 가설을 지지/불충분/반박하는 근거와 다음 실험을 기록합니다.


## 관찰할 변수

선택 변수 하나. 기기·데이터·카메라·측정법은 고정합니다.

- [ ] 가설과 측정 지표가 연결된다.
- [ ] 화질 대가를 함께 적었다.
- [ ] 실패한 가설도 기록했다.
