## 목표

재현 가능한 결과와 남은 질문을 정리하고 배포 조건을 문서로 검토한다.

## 선수 지식

01~27 중 실제 수행한 단위의 기록.

## 핵심 개념과 설명

학습 결과는 완성 화면뿐 아니라 목표·변수·예상·실제·배운 점·남은 질문을 함께 남깁니다. 구현 완료와 개념을 설명할 수 있는 역량은 구분하며 한 달만으로 특정 실무 수준을 보장하지 않습니다.

배포는 이번 작업에서 실행하지 않습니다. 향후 공개한다면 데이터 라이선스·개인 정보·public 에셋 포함·크기·브라우저 호환·저장 오리진 변경을 검토해야 합니다. Git 제외는 Vite의 public 복사 제외가 아닙니다.

## 학습 후 얻을 역량

- 재현 가능한 결과와 남은 질문을 정리하고 배포 조건을 문서로 검토한다.
- 아래 완료 조건을 재현하고 자가 점검 질문에 자신의 말로 답할 수 있습니다.

## 실습 과제

1. 수행한 실습만 완료 표시하고 재현 명령과 버전을 정리합니다.
2. 필기를 Markdown으로 다운로드하여 해당 docs/labs 문서에 반영합니다.
3. 선택적 배포 체크리스트와 미완료 조건을 문서로 작성하되 실제 배포·push는 별도 결정으로 둡니다.


## 관찰할 변수

재현 환경, 데이터 출처, 저장 오리진, 공개 범위. 이번에는 배포하지 않습니다.

## 완료 조건

- [ ] 실행법과 실측 결과·미검증 범위가 명확하다.
- [ ] 학습 기록을 백업했다.
- [ ] 배포 계획과 실제 실행을 구분했다.
