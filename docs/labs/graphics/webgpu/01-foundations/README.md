## 목표와 학습 후 역량

- 지원 조건을 점검한다.
- 초기화 실패를 복구 가능한 상태로 처리한다.

## 선수 지식

TypedArray, 비동기 JavaScript와 WebGL 파이프라인

## 핵심 개념과 설명

### 지원 조건

WebGPU는 보안 컨텍스트와 브라우저·장치 지원을 함께 요구합니다. navigator.gpu가 있어도 adapter 요청이 null이 될 수 있습니다.

### 초기화

adapter에서 device를 얻고 그 device로 자원과 pipeline을 만듭니다. 초기화 실패는 렌더 루프 시작 전에 화면 상태로 처리합니다.

## 실습 준비

기존 webgpu-01 미리보기는 출발점입니다. 이후 과제 전체의 구현이나 검증을 대신하지 않습니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. main.js에 isSecureContext·navigator.gpu 확인과 상태 표시를 작성하세요.
2. requestAdapter와 requestDevice를 순서대로 호출하고 실패 이유를 기록하세요.
3. 정상·API 없음·adapter null을 주입 가능한 함수로 분리하고 각 화면 출력을 확인하세요.

| ------------ | --------- | --------- | ----------------------------------------------------------- |
| adapter 응답 | 정상 객체 | null 주입 | 예외나 빈 화면 대신 미지원 안내가 표시될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
