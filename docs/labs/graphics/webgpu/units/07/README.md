# WebGPU · 07 인덱스와 primitive

## 목표와 학습 후 역량

- 인덱스로 정점을 재사용한다.
- 도형과 앞면 설정을 검증한다.

## 선수 지식

6단위 결과물과 기록을 이어 사용합니다. 인덱스와 primitive 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 재사용

index buffer는 같은 정점 데이터를 여러 삼각형에서 재사용합니다. 인덱스 값은 실제 정점 수 안에 있어야 합니다.

### 도형 해석

primitive topology와 front face 설정은 정점 연결과 앞면 판정에 영향을 줍니다. 같은 데이터도 설정에 따라 다른 결과가 나옵니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. quad.js에 정점 네 개와 Uint16Array 인덱스 여섯 개를 작성하세요.
2. INDEX|COPY_DST buffer와 setIndexBuffer('uint16')를 연결해 drawIndexed를 호출하세요.
3. 삼각형 하나의 순서를 뒤집고 cullMode를 바꿔 결과를 비교하세요.

## 관찰할 변수

| 변수     | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                          |
| -------- | --------- | --------- | ---------------------------------------------- |
| cullMode | none      | back      | 반대로 감긴 삼각형만 사라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
