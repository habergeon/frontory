# WebGPU · 10 행렬과 카메라

단계: 렌더 자원과 화면 구성 · 문서 기반 직접 구현 · 저장 ID: `webgpu-step-10`

## 목표와 학습 후 역량

- 카메라 변환을 구성한다.
- 깊이 좌표 규약을 검증한다.

## 선수 지식

9단위 결과물과 기록을 이어 사용합니다. 행렬과 카메라 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 변환 순서

월드·뷰·투영 행렬의 곱 순서는 위치 해석을 결정합니다. 같은 행렬도 곱하는 순서를 바꾸면 회전 중심과 이동이 달라집니다.

### 깊이 범위

WebGPU의 clip 깊이 범위는 WebGL과 다릅니다. 사용한 projection 함수가 목표 API의 깊이 규약에 맞는지 확인합니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. camera.js에 model·view·projection 행렬을 분리하세요.
2. mat4x4f uniform 64바이트를 올리고 vertex에서 곱한 위치를 반환하세요.
3. 근평면과 원평면에 놓은 표식의 clip z/w를 출력해 0..1 범위를 검사하세요.
