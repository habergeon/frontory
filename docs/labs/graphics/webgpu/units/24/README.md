## 선수 지식

23단위 결과물과 기록을 이어 사용합니다. 시간 측정의 범위 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 전체 지연

CPU 기준의 시작부터 readback 완료까지는 전송과 대기를 포함합니다. 이를 compute kernel 실행 시간과 동일하게 해석하지 않습니다.

### 선택 측정

timestamp-query는 지원과 요청을 확인한 경우에만 사용합니다. 미지원이면 GPU 구간을 미측정으로 남기고 CPU 경과 시간을 제공합니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. benchmark.js에 입력 생성·업로드·제출·map 완료 구간을 나누세요.
2. timestamp-query 지원 여부를 기록하고 지원 시에만 pass timestamp와 resolve 경로를 구성하세요.
3. 예열 후 다섯 실행의 전체 지연과 가능한 GPU 구간 값을 별도 열로 저장하세요.
