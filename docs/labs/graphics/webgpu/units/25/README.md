## 목표와 학습 후 역량

- CPU 기준을 작성한다.
- 수치 오차를 명시적으로 판정한다.

## 선수 지식

24단위 결과물과 기록을 이어 사용합니다. CPU 기준과 오차 예산 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 부동소수점

CPU의 JavaScript number와 GPU f32는 연산 정밀도가 다릅니다. 결합 순서가 바뀌는 합 연산에서는 작은 오차가 생길 수 있습니다.

### 검증 기준

절대 오차와 상대 오차는 값의 크기에 따라 역할이 다릅니다. 결과를 보기 전에 허용 기준과 특수값 처리를 정합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. reference.js에 입자 갱신 CPU 함수를 작성하고 고정 seed 입력을 생성하세요.
2. readback 결과와 절대·상대 오차를 원소별로 계산하세요.
3. 0·음수·작은 값·큰 값을 포함한 입력에서 최대 오차와 실패 인덱스를 출력하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건         | 예상할 변화·검증 가설                                                       |
| --------- | --------- | ----------------- | --------------------------------------------------------------------------- |
| 검증 입력 | 작은 양수 | 0·음수·큰 값 혼합 | 규모가 다른 값에서 상대 오차만 쓰는 기준의 한계가 드러날 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건
