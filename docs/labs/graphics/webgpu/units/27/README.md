## 목표와 학습 후 역량

- 전체 프로젝트 계약을 문서화한다.
- 실패와 재시작을 포함해 인수한다.

## 선수 지식

26단위 결과물과 기록을 이어 사용합니다. 통합 입자 실험 인수 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 구성 분리

초기 데이터·커널·렌더·readback·UI를 분리하면 오류 위치가 명확해집니다. 모듈 간 계약에는 buffer 크기와 수명이 포함됩니다.

### 인수 증거

보이는 애니메이션만으로 계산의 정확성을 증명할 수 없습니다. 실패 복구와 CPU 비교 결과를 함께 남깁니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. README.md에 모듈별 입력·출력·자원 소유권을 표로 적으세요.
2. 지원 실패·device loss·resize·N=0·N=1003 다섯 시나리오를 실행하세요.
3. 현재 설정 JSON과 CPU 비교 결과를 내보내고 새 세션에서 복원하세요.
