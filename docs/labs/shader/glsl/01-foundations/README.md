## 핵심 개념과 설명

### 단계 역할

vertex shader는 clip 위치와 다음 단계에 전달할 값을 계산합니다. fragment shader는 보간된 입력에서 픽셀 후보의 출력을 만듭니다.

### 버전 계약

WebGL1의 GLSL ES 1.00과 WebGL2의 3.00 문법은 구분해야 합니다. 3.00에서는 첫 줄의 #version 300 es와 in/out 및 명시적인 fragment 출력을 사용합니다.

## 실습 준비

기존 glsl-01 미리보기는 출발점입니다. 이후 과제 전체의 구현이나 검증을 대신하지 않습니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. main.js에서 webgl2 context를 만들고 vertex.glsl·fragment.glsl 소스를 분리하세요.
2. 위치만 반환하는 vertex와 고정색 fragment를 compileShader·linkProgram으로 연결하세요.
3. 한 소스의 문법 오류와 두 단계의 인터페이스 오류를 따로 넣고 로그를 비교하세요.
