# GLSL · 14 UV·Uniform·파동

[시리즈 목차](../README.md) · [전체 기술 지도](../../../README.md)

단계: 좌표·질감·시간 표현 · 편집 가능한 예제 · 저장 ID: `glsl-02`

## 목표와 학습 후 역량

- 파동 변수를 독립적으로 조절한다.
- 색 왜곡과 기하 변형을 구분한다.

## 선수 지식

13단위 결과물과 기록을 이어 사용합니다. UV·Uniform·파동 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 변수 역할

진폭은 변위 크기이고 주파수는 반복 간격을 정합니다. 시간 속도는 정지된 형태가 아니라 변화율에 영향을 줍니다.

### 변형 위치

fragment의 UV 왜곡은 표면의 색을 바꾸지만 실제 실루엣을 바꾸지 않습니다. vertex 변형은 정점 수와 분포에 따라 실루엣이 달라집니다.

## 실습 준비

기존 glsl-02 미리보기는 출발점입니다. 이후 과제 전체의 구현이나 검증을 대신하지 않습니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. 먼저 uv를 색으로 출력한 뒤 uTime을 추가하고 sin 파형을 연결하세요.
2. vertex.glsl에서 y에 amplitude*sin(x*frequency-time*speed)를 더하세요.
3. 진폭·주파수·속도를 하나씩 바꾸고 정지 이미지와 한 주기 시간을 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                            |
| ---- | --------- | --------- | ---------------------------------------------------------------- |
| 진폭 | 0.05      | 0.2       | 파장과 주기는 유지되고 최대 변위가 네 배가 될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
