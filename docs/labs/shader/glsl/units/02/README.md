- 타입과 생성자를 사용한다.

## 선수 지식

1단위 결과물과 기록을 이어 사용합니다. 스칼라와 벡터 타입 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 명시적 타입

float·int·bool은 용도가 다르고 암묵 변환에 의존하면 오류가 생기기 쉽습니다. 생성자를 통해 의도한 타입과 성분 수를 표현합니다.

### 벡터 연산

벡터 곱은 성분별 계산이며 dot은 하나의 스칼라를 만듭니다. 같은 기호처럼 보여도 결과 타입과 의미를 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. types.glsl에 vec2·vec3·vec4 생성과 swizzle 예제를 작성하세요.
2. 입력 색에 성분별 곱과 dot을 각각 적용해 화면 두 영역에 출력하세요.
3. 잘못된 성분 수를 넣고 compile 로그의 줄을 찾아 수정하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 계산 방식 | color*color | vec3(dot(color,color)) | 전자는 채널별 값이고 후자는 같은 회색 채널이 될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
