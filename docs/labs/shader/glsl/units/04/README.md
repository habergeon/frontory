## 목표와 학습 후 역량

- 정점 데이터를 shader에 연결한다.
- 보간으로 생성되는 값을 설명한다.

## 선수 지식

3단위 결과물과 기록을 이어 사용합니다. Attribute와 보간 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 정점 입력

attribute는 buffer에서 정점별 값을 공급합니다. shader 위치와 vertexAttribPointer의 크기·stride·offset이 맞아야 합니다.

### 보간

vertex의 출력은 삼각형 내부 fragment로 보간됩니다. 정점에 없는 중간 색이 나타나는 이유를 이 데이터 흐름으로 설명할 수 있습니다.

## 실습 준비

별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. attributes.js에 위치와 RGB가 섞인 정점 세 개를 작성하세요.
2. layout(location=0/1) in과 stride 20·offset 0/8을 연결하세요.
3. vertex의 out color를 fragment in color로 받고 세 꼭짓점과 중심을 관찰하세요.
