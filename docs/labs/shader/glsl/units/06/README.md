# GLSL · 06 Uniform 조회와 갱신

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 셰이더 언어와 데이터 흐름 · 편집 가능한 예제 · 저장 ID: `glsl-step-06`

## 목표와 학습 후 역량

- draw 공통 입력을 갱신한다.
- uniform location 수명을 관리한다.

## 선수 지식

5단위 결과물과 기록을 이어 사용합니다. Uniform 조회와 갱신 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 공통 입력

uniform은 하나의 draw에서 공통으로 사용하는 입력입니다. 정점별로 다른 값을 전달하려면 attribute 같은 다른 경로가 필요합니다.

### 프로그램 소유

uniform location은 특정 연결된 program에 속합니다. 프로그램을 다시 link한 뒤에는 location을 다시 조회합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. uniforms.js에 getUniformLocation과 uniform1f·uniform3fv 호출을 모으세요.
2. uGain과 uColor 슬라이더를 연결하고 draw 전에 값을 업로드하세요.
3. program을 다시 link한 뒤 location 캐시를 갱신하는 경로를 확인하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| uGain | 0.5 | 1.0 | 다른 조건이 같으면 선형 색 출력이 두 배가 될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 두 uniform이 독립적으로 화면에 반영된다.
- [ ] 재링크 후 location을 새로 조회하고 입력이 계속 동작한다.
