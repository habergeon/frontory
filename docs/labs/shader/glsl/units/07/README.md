# GLSL · 07 디버그 출력과 최소 재현

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 셰이더 언어와 데이터 흐름 · 편집 가능한 예제 · 저장 ID: `glsl-step-07`

## 목표와 학습 후 역량

- 중간값을 시각화한다.
- 최소 재현으로 오류 위치를 좁힌다.

## 선수 지식

6단위 결과물과 기록을 이어 사용합니다. 디버그 출력과 최소 재현 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 시각 디버그

복잡한 색 대신 UV·법선·마스크를 직접 출력하면 잘못된 단계가 드러납니다. 수치 범위는 표시 가능한 0..1로 매핑해서 봅니다.

### 최소 사례

여러 효과를 동시에 고치면 오류 원인을 놓치기 쉽습니다. 고정 입력과 단색 출력으로 줄인 뒤 한 단계씩 복원합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. debug.glsl에 mode uniform으로 단색·UV·중간값 출력을 선택하게 하세요.
2. 의도적으로 UV 성분을 교환하고 어느 모드에서 드러나는지 기록하세요.
3. 정상 소스로 복구한 뒤 한 삼각형만 남긴 최소 재현 소스를 저장하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| debug mode | 최종 색 | UV 직접 출력 | 조명이나 색 합성에 가려진 좌표 오류가 보일 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 세 디버그 모드가 각각 다른 중간값을 보여 준다.
- [ ] 오류를 재현하는 최소 입력과 복구 소스를 함께 보관한다.
