# GLSL · 09 Step과 Smoothstep 마스크

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 좌표·질감·시간 표현 · 편집 가능한 예제 · 저장 ID: `glsl-step-09`

## 목표와 학습 후 역량

- 구간 마스크를 구성한다.
- 안전한 경계 조건을 설정한다.

## 선수 지식

8단위 결과물과 기록을 이어 사용합니다. Step과 Smoothstep 마스크 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 구간 선택

step은 경계에서 값을 급히 바꾸는 마스크를 만듭니다. smoothstep은 두 경계 사이를 부드럽게 연결합니다.

### 경계 조건

smoothstep의 edge0는 edge1보다 작아야 합니다. 경계를 뒤집어 반전을 만들기보다 1에서 결과를 빼는 식으로 의도를 표현합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. mask.glsl에 원 거리와 step 기반 내부 마스크를 작성하세요.
2. 반전은 1.0-smoothstep(r-w,r+w,d)로 구현하세요.
3. w를 바꾸며 경계 픽셀과 전체 원 크기를 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 경계 폭 | 0.001 | 0.03 | 중심과 외곽 반경은 유지하면서 전이 구간이 넓어질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] edge0<edge1 조건을 모든 입력에서 유지한다.
- [ ] 두 폭의 경계 단면 색을 다섯 지점에서 비교한다.

## 자가 점검

1. smoothstep 폭을 키우는 것과 원 반경을 키우는 것은 어떻게 다른가요?
2. step 경계가 움직일 때 어떤 떨림이 보이나요?
