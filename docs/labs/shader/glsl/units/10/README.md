## 목표와 학습 후 역량

- 반복 좌표를 구성한다.
- 셀별 정보와 내부 패턴을 분리한다.

## 선수 지식

9단위 결과물과 기록을 이어 사용합니다. 타일링과 반복 좌표 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 반복

fract는 좌표의 소수 부분으로 반복 타일을 만듭니다. 타일 개수를 바꾸면 좌표 변화율과 경계 빈도도 달라집니다.

### 식별

floor로 얻은 셀 번호는 타일마다 다른 값을 정하는 데 쓸 수 있습니다. 셀 내부 좌표와 셀 id를 분리하면 패턴을 조합하기 쉽습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. tiles.glsl에 floor(uv*count)와 fract(uv*count)를 분리하세요.
2. 셀 내부 원과 셀 id 기반 교대 색을 출력하세요.
3. count=4와 16에서 경계 연속성과 화면 축소 시 깜빡임을 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 타일 수 | 4 | 16 | 반복이 촘촘해져 작은 화면에서 aliasing이 늘 수 있다고 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 셀 id와 내부 좌표를 각각 디버그 모드로 출력한다.
- [ ] 두 타일 수를 같은 크기 화면에서 비교한다.
