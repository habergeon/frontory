# GLSL · 13 시간과 주기

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 좌표·질감·시간 표현 · 편집 가능한 예제 · 저장 ID: `glsl-step-13`

## 목표와 학습 후 역량

- 시간을 안정적으로 전달한다.
- 공간 주기와 시간 속도를 분리한다.

## 선수 지식

12단위 결과물과 기록을 이어 사용합니다. 시간과 주기 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 시간 단위

requestAnimationFrame timestamp를 초로 바꾸면 프레임 수와 시간의 역할을 분리할 수 있습니다. 누적 프레임 횟수를 시간처럼 쓰면 주사율에 따라 속도가 달라집니다.

### 주파수

sin의 입력 위상은 공간 주파수와 시간 속도의 합으로 만들 수 있습니다. 두 입력을 분리해야 파장과 이동 속도를 독립적으로 조절합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. time.js에서 (timestamp-start)/1000을 uTime으로 전달하세요.
2. wave.glsl에 sin(uv.x*frequency-time*speed)를 색으로 출력하세요.
3. 재생·일시정지·고정 시간 입력을 추가해 t=0과 t=1 결과를 저장하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 시간 속도 | 1 | 2 | 공간 파장은 같고 같은 시간 동안 위상 이동이 두 배가 될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
