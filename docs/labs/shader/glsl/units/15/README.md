## 핵심 개념과 설명

### 부호 거리

SDF는 경계까지의 거리와 안팎 부호를 표현합니다. 거리값을 마스크로 바꾸면 같은 도형에 채우기와 테두리를 적용할 수 있습니다.

### 조합

min과 max를 사용하면 합집합과 교집합을 구성할 수 있습니다. 조합 결과가 모든 위치에서 정확한 거리라는 보장은 따로 검토합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. sdf.glsl에 원과 축 정렬 상자의 거리 함수를 작성하세요.
2. min·max·max(a,-b)로 합집합·교집합·차집합을 출력하세요.
3. 거리 0 등고선과 abs(d) 기반 테두리를 겹쳐 확인하세요.

| 상자 위치 | 원 중심 | x 방향 0.2 이동 | 겹침 영역과 차집합의 잘린 경계가 이동할 것으로 예상합니다. |
