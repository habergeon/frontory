# GLSL · 16 Value noise의 구성

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 조명과 절차적 표면 · 문서 기반 직접 구현 · 저장 ID: `glsl-step-16`

## 목표와 학습 후 역량

- Noise의 격자와 보간을 구현한다.
- 결정성과 경계 연속성을 확인한다.

## 선수 지식

15단위 결과물과 기록을 이어 사용합니다. Value noise의 구성 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 격자 값

value noise는 셀 꼭짓점의 값을 보간해 연속적인 변화를 만듭니다. 셀 id용 의사난수와 셀 내부 보간을 별도 함수로 나눕니다.

### 보간 곡선

선형 보간과 완만한 보간은 셀 경계의 미분 특성이 다릅니다. 거친 경계가 보이는지 확대해서 확인합니다.

## 실습 준비

별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. noise.glsl에 결정적인 hash와 네 꼭짓점 보간 함수를 작성하세요.
2. 같은 seed 상수로 선형 보간과 smooth 곡선 보간을 나란히 출력하세요.
3. 셀 경계 확대 보기와 고정 좌표 5개의 값을 기록하세요.
