# GLSL · 17 옥타브와 대역 제한

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 조명과 절차적 표면 · 문서 기반 직접 구현 · 저장 ID: `glsl-step-17`

## 목표와 학습 후 역량

- 다중 주파수 noise를 구성한다.
- 추가 세부의 비용과 한계를 판단한다.

## 선수 지식

16단위 결과물과 기록을 이어 사용합니다. 옥타브와 대역 제한 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 다중 주파수

여러 noise 주파수를 진폭을 줄이며 더하면 넓은 형태와 세부를 함께 만들 수 있습니다. 반복 수가 늘면 연산량도 증가합니다.

### 과도한 세부

화면 픽셀보다 작은 변화는 안정적으로 표현하기 어렵습니다. 높은 주파수를 무조건 더하면 품질 대신 aliasing이 늘 수 있습니다.

## 실습 준비

별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. fbm.glsl에서 고정 최대 반복과 octave 수 입력을 분리하세요.
2. 주파수 두 배·진폭 절반 규칙으로 1·3·5 octave를 합치세요.
3. 작은 화면과 큰 화면에서 세부·깜빡임·프레임 간격을 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| octave 수 | 1 | 5 | 세부와 계산량이 늘지만 작은 화면에서는 aliasing이 생길 수 있다고 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
