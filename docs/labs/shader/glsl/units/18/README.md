## 목표와 학습 후 역량

- 법선을 올바른 공간으로 변환한다.
- 확산 조명을 계산한다.

## 선수 지식

17단위 결과물과 기록을 이어 사용합니다. 법선과 확산 조명 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 법선 공간

법선과 광원 방향은 같은 좌표 공간에 있어야 합니다. 비균일 scale에는 단순 모델 행렬 대신 적절한 inverse-transpose 변환을 사용합니다.

### 확산 항

정규화한 법선과 광원 방향의 dot은 입사 방향 관계를 나타냅니다. 음수 구간을 제거해 뒤쪽 면의 음수 색을 막습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. lighting.glsl에서 normal matrix로 법선을 변환하고 fragment에서 normalize하세요.
2. max(dot(N,L),0)로 단색 표면의 확산 항을 계산하세요.
3. 비균일 scale을 적용해 올바른 normal matrix와 단순 변환을 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| scale | [1,1,1] | [2,1,0.5] | 잘못된 법선 변환에서 밝은 영역 방향이 어긋날 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
