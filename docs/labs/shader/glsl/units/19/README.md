# GLSL · 19 반사광과 시선 벡터

## 목표와 학습 후 역량

- 시선 의존 반사광을 구현한다.
- 교육용 조명 모형의 한계를 설명한다.

## 선수 지식

18단위 결과물과 기록을 이어 사용합니다. 반사광과 시선 벡터 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 시선 방향

반사광은 광원뿐 아니라 카메라 방향에도 영향을 받습니다. 카메라를 이동해도 하이라이트가 고정되면 공간이나 방향 부호를 점검합니다.

### 모형의 한계

간단한 Blinn-Phong 항은 교육용 반사 모형입니다. 이를 에너지 보존을 갖춘 PBR 전체 구현으로 부르지 않습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. specular.glsl에 normalize(L+V)와 pow(max(dot(N,H),0),shininess)를 작성하세요.
2. 광원은 고정하고 카메라를 두 위치로 이동하세요.
3. shininess 8·64에서 하이라이트 폭을 같은 시점으로 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| shininess | 8 | 64 | 하이라이트가 좁아지지만 재질의 모든 물리 특성을 설명하지는 못할 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 카메라 두 위치에서 하이라이트 이동을 확인한다.
- [ ] 두 shininess 값의 하이라이트 폭을 픽셀로 기록한다.

## 자가 점검

1. L과 V가 거의 반대일 때 normalize 입력은 어떻게 되나요?
2. 거칠기와 shininess를 같은 값이라고 할 수 있나요?
