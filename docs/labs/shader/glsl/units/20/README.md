# GLSL · 20 변형 표면의 법선

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 조명과 절차적 표면 · 편집 가능한 예제 · 저장 ID: `glsl-step-20`

## 목표와 학습 후 역량

- 변형에 맞는 법선을 계산한다.
- 미분을 수치 기준으로 검증한다.

## 선수 지식

19단위 결과물과 기록을 이어 사용합니다. 변형 표면의 법선 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 형태와 조명

정점 위치를 바꿔도 기존 법선이 자동 갱신되는 것은 아닙니다. 파동 표면의 기울기에서 새 법선을 계산해야 조명이 형태를 따릅니다.

### 해석 미분

sin 변위의 미분은 cos를 이용해 구할 수 있습니다. 수치 차분과 비교하면 부호와 축 오류를 찾기 좋습니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. surface.glsl에서 y=A*sin(k*x-t)의 x 미분을 계산하세요.
2. 접선과 법선을 구성해 정규화하고 기존 법선 모드와 비교하세요.
3. CPU 중앙 차분으로 세 x 지점의 기울기를 검증하세요.

## 관찰할 변수

| 변수 | 기준 조건      | 바꿀 조건        | 예상할 변화·검증 가설                                                |
| ---- | -------------- | ---------------- | -------------------------------------------------------------------- |
| 법선 | 원래 평면 법선 | 파동 기울기 법선 | 실루엣은 같고 조명의 밝고 어두운 띠가 파동을 따를 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 세 지점의 해석·수치 미분 차이가 1e-3 이하이다.
- [ ] 형태를 고정한 두 법선 모드의 조명을 비교한다.
