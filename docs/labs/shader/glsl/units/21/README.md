## 목표와 학습 후 역량

- 알파 출력과 합성 상태를 맞춘다.
- 투명 가림 문제를 진단한다.

## 선수 지식

20단위 결과물과 기록을 이어 사용합니다. Alpha와 합성 상태 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 출력 알파

fragment가 반환하는 alpha와 WebGL blend 상태는 함께 결과를 결정합니다. alpha 값을 낮추기만 해서는 기대한 투명 합성이 나오지 않을 수 있습니다.

### 깊이 쓰기

반투명 표면은 불투명 표면과 다른 정렬·깊이 쓰기 정책이 필요할 수 있습니다. 뒤쪽 물체가 사라지면 색 식뿐 아니라 depth 상태도 확인합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. alpha.js에서 두 반투명 평면과 명시적인 blendFunc를 설정하세요.
2. straight alpha 출력과 이에 맞는 합성 상태를 유지하세요.
3. draw 순서와 depthMask를 각각 바꾸며 겹친 영역 색을 기록하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| draw 순서 | 앞 평면 먼저 | 뒤 평면 먼저 | 겹친 반투명 영역의 색이 달라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] blend 식과 출력 alpha 규칙을 문서화한다.
- [ ] 두 순서와 두 depthMask의 결과를 구분해 기록한다.
