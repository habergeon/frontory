# GLSL · 23 Texel 크기와 필터

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 상호작용·후처리·비용 평가 · 편집 가능한 예제 · 저장 ID: `glsl-step-23`

## 목표와 학습 후 역량

- Texel 기준 필터를 작성한다.
- 커널 밝기 보존을 검증한다.

## 선수 지식

22단위 결과물과 기록을 이어 사용합니다. Texel 크기와 필터 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 이웃 샘플

화면 필터의 한 픽셀 이동은 입력 texture 크기의 역수로 표현합니다. 출력 해상도로 offset을 계산하면 필터 반경이 달라질 수 있습니다.

### 커널 합

블러 가중치 합이 1이면 일정한 입력의 밝기를 유지할 수 있습니다. 경계 wrap 방식도 최종 결과에 영향을 줍니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. blur.glsl에 uTexel=1.0/inputSize를 사용한 3탭 수평 필터를 작성하세요.
2. 가중치 [0.25,0.5,0.25]를 적용하고 일정 회색 texture를 입력하세요.
3. 수직 pass를 추가해 분리형 블러와 원본을 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 샘플 간격 | 1 texel | 3 texel | 흐림 반경이 넓어지며 미세한 패턴이 더 섞일 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 일정 회색 입력의 평균 밝기가 1/255 이내로 유지된다.
- [ ] 입력 texture 크기를 바꿔도 1 texel offset 계산이 맞다.
