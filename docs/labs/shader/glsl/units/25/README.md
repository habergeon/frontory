## 선수 지식

24단위 결과물과 기록을 이어 사용합니다. 분기와 반복의 비용 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 조건 실행

분기의 비용은 조건의 분포와 수행 작업에 따라 달라집니다. if를 모두 mix로 바꾸는 것이 항상 최적화는 아닙니다.

### 실험 통제

반복 수·샘플 수·해상도를 동시에 바꾸면 어떤 변화가 원인인지 알기 어렵습니다. 하나씩 바꾸고 같은 정지 입력을 사용합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 프로젝트에서 WebGL2와 GLSL ES 3.00으로 직접 구현하는 문서 안내 실습입니다. 기존 예제의 GLSL 버전을 먼저 확인하고 1.00 문법을 혼용하지 않습니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. cost.glsl에 noise 반복과 texture sample 수를 독립 설정으로 노출하세요.
2. 동일 uTime·uPointer에서 반복 1·4·8을 비교하세요.
3. 해상도 고정 후 프레임 간격을 기록하고 다음 실험에서만 해상도를 바꾸세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 반복 수 | 1 | 8 | 추가 연산이 늘지만 실제 프레임 차이는 병목에 따라 달라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
