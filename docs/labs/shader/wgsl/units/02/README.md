# WGSL · 02 리터럴과 명시적 수치 타입

## 목표와 학습 후 역량

- 수치 타입을 선택한다.
- 타입 변환을 명시한다.

## 선수 지식

1단위 결과물과 기록을 이어 사용합니다. 리터럴과 명시적 수치 타입 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 추상 수치

타입이 확정되지 않은 리터럴은 문맥에 따라 구체적인 타입으로 결정될 수 있습니다. 변수와 함수 경계에서는 의도한 f32·i32·u32를 명확히 합니다.

### 변환

부호 있는 정수와 없는 정수는 범위와 연산 의미가 다릅니다. index와 계산값 사이 변환을 명시해 예상하지 않은 값 해석을 피합니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. types.wgsl에 i32·u32·f32 변수와 명시적 변환 함수를 작성하세요.
2. 양수·음수·소수 입력을 작은 compute 출력 buffer에 기록하세요.
3. 서로 다른 구체 타입을 직접 더한 오류 사례를 만들고 변환 후 결과를 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 입력 타입 | i32(3) | f32(3.5) | 연산 결과의 소수 부분과 사용 가능한 변환이 달라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
