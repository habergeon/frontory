# WGSL · 03 벡터·행렬 생성과 곱

## 목표와 학습 후 역량

- 벡터·행렬 연산을 작성한다.
- 행렬 저장 규약을 검증한다.

## 선수 지식

2단위 결과물과 기록을 이어 사용합니다. 벡터·행렬 생성과 곱 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 벡터 구성

vec2f·vec3f·vec4f는 성분을 묶어 계산합니다. swizzle을 읽는 경우와 쓰는 경우의 허용 규칙을 구분합니다.

### 행렬 의미

WGSL 행렬은 열 벡터로 구성됩니다. CPU가 기록한 열 순서와 shader의 행렬 곱을 맞춰야 변환이 의도대로 됩니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. math.wgsl에 벡터 생성·swizzle·dot 결과를 출력하는 함수를 만드세요.
2. mat2x2f의 두 열과 vec2f 입력을 정하고 수작업 곱을 계산하세요.
3. CPU 배열 순서를 바꾼 입력과 올바른 입력의 결과를 readback으로 비교하세요.

## 관찰할 변수

| 변수    | 기준 조건    | 바꿀 조건         | 예상할 변화·검증 가설                                    |
| ------- | ------------ | ----------------- | -------------------------------------------------------- |
| 행렬 열 | 정상 열 순서 | 행·열을 바꾼 배열 | 비대칭 행렬에서 다른 변환 결과가 나올 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
