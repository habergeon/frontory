## 목표와 학습 후 역량

- 명시적인 제어 흐름을 작성한다.
- 안전한 접근 조건을 유지한다.

## 선수 지식

5단위 결과물과 기록을 이어 사용합니다. 조건·반복과 종료 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 제어 흐름

if·switch·for·loop는 계산 경로와 반복 횟수를 표현합니다. 종료 조건을 입력과 연결할 때 상한을 두어 의도치 않은 긴 작업을 막습니다.

### 분기 의미

select는 일반적인 단락 평가 if와 같지 않습니다. 안전하지 않은 메모리 접근을 select의 한쪽 인자에 숨기지 않습니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. flow.wgsl에 상한 8의 누적 for 루프와 mode switch를 작성하세요.
2. 길이가 부족한 경우 if로 buffer 접근 전에 분기하세요.
3. mode 두 개와 반복 0·1·8의 결과를 CPU 함수와 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 반복 수 | 1 | 8 | 누적 결과와 작업량이 늘고 0에서는 초기값을 반환할 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건
