# WGSL · 07 보간과 Stage 인터페이스

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 타입과 셰이더 인터페이스 · 문서 기반 직접 구현 · 저장 ID: `wgsl-step-07`

## 목표와 학습 후 역량

- 단계 사이 보간을 설정한다.
- 시스템 좌표의 의미를 구분한다.

## 선수 지식

6단위 결과물과 기록을 이어 사용합니다. 보간과 Stage 인터페이스 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 보간 규칙

정점 출력의 부동소수 값은 fragment 단계에서 보간됩니다. 정수 식별자는 평평한 보간 규칙을 명시해야 합니다.

### 시스템 좌표

vertex의 position 출력과 fragment의 position 입력은 같은 의미의 좌표가 아닙니다. fragment 위치를 사용할 때 화면 좌표 규약을 확인합니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. interface.wgsl에서 색과 @interpolate(flat) 정수 id를 함께 출력하세요.
2. fragment에서 id별 색과 보간 색을 별도 모드로 표시하세요.
3. fragment position을 해상도로 정규화한 화면 UV와 정점 UV를 비교하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 색 보간 | 기본 보간 | flat 보간 | 삼각형 내부 색 변화가 사라지고 지정 정점의 값으로 채워질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
