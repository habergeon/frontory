# WGSL · 12 Uniform의 추가 배치 제약

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 자원 선언과 메모리 배치 · 문서 기반 직접 구현 · 저장 ID: `wgsl-step-12`

## 목표와 학습 후 역량

- uniform 호환 배치를 설계한다.
- 명시적 padding을 호스트에 반영한다.

## 선수 지식

11단위 결과물과 기록을 이어 사용합니다. Uniform의 추가 배치 제약 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### Uniform 규칙

uniform 주소 공간에는 배열과 중첩 구조체에 추가 배치 제약이 적용될 수 있습니다. 기본 호환 경로에서는 배열 간격을 16바이트 단위로 설계하고 실제 지원 규칙을 확인합니다.

### 명시적 padding

호스트와 shader가 같은 padding을 선언하면 호환 배치를 만들 수 있습니다. @size·@align을 사용하더라도 호스트 바이트를 자동으로 만들어 주지는 않습니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. uniform-array.wgsl에 @size(16) value:f32 멤버를 갖는 Element 구조체와 고정 배열을 작성하세요.
2. host.js에서 각 값이 16바이트 간격에 놓이도록 DataView로 기록하세요.
3. 빽빽한 4바이트 배열과 호환 배치의 읽기 결과·진단을 비교하세요.
