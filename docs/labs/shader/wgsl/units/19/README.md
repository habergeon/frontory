## 선수 지식

18단위 결과물과 기록을 이어 사용합니다. Atomic과 카운터 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 원자 연산

atomicAdd는 같은 위치에 대한 충돌하는 갱신을 원자적으로 처리합니다. 이것만으로 여러 필드의 일관된 상태나 전역 장벽이 생기지는 않습니다.

### 정수 제약

일반적인 WGSL atomic은 지정된 정수 타입과 주소 공간을 사용합니다. 부동소수 합을 단순히 atomic<f32>로 바꾸지 않습니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. atomic.wgsl에 storage atomic<u32> 카운터를 선언하세요.
2. 양수 원소만 atomicAdd로 세고 매 실행 전 카운터를 0으로 초기화하세요.
3. 같은 입력을 다섯 번 실행해 CPU 개수와 비교하세요.
