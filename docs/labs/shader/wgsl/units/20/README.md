# WGSL · 20 부분합 Reduction

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 병렬 계산과 동기화 · 문서 기반 직접 구현 · 저장 ID: `wgsl-step-20`

## 목표와 학습 후 역량

- 협력 감소 연산을 작성한다.
- 그룹 간 계산 단계를 나눈다.

## 선수 지식

19단위 결과물과 기록을 이어 사용합니다. 부분합 Reduction 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 트리 계산

감소 연산은 여러 원소를 단계적으로 합칩니다. 각 단계에서 읽기와 쓰기의 의존성이 있으므로 공유 메모리와 barrier 위치를 맞춥니다.

### 다중 단계

workgroup별 부분합을 얻은 뒤에는 추가 dispatch나 CPU 합으로 마무리합니다. 그룹 사이에서 같은 dispatch의 완료를 기다리지 않습니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. reduce.wgsl에 64 lane 공유 배열과 32·16·8·4·2·1 감소 단계를 작성하세요.
2. 각 단계의 조건부 덧셈 뒤 공통 barrier를 배치하세요.
3. 1003개 입력의 부분합을 readback해 CPU 합과 비교하세요.
