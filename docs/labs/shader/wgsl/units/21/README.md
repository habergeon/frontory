## 목표와 학습 후 역량

- 데이터 경쟁을 피한다.
- 시간 단계별 상태를 분리한다.

## 선수 지식

20단위 결과물과 기록을 이어 사용합니다. Ping-pong과 데이터 경쟁 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 이웃 참조

각 원소가 이웃의 이전 값을 읽는 계산은 제자리 갱신과 충돌할 수 있습니다. 실행 순서에 의존하지 않으려면 입력·출력 배열을 나눕니다.

### 시간 단계

한 dispatch가 한 시점의 상태를 다음 시점으로 바꿉니다. 다음 dispatch에서는 두 buffer의 역할을 교환합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며, 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. stencil.wgsl에 이전 좌우 이웃의 평균을 새 배열에 쓰는 함수를 작성하세요.
2. A→B와 B→A binding을 호스트에서 교대하세요.
3. 세 단계 계산을 CPU의 복사 기반 구현과 비교하고 끝점 정책을 명시하세요.

## 관찰할 변수

| 변수 | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설 |
| --- | --- | --- | --- |
| 끝점 처리 | 고정 경계 | 순환 경계 | 배열 양끝의 전파 양상이 달라질 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.
