## 목표와 학습 후 역량

- 데이터 경쟁을 피한다.
- 시간 단계별 상태를 분리한다.

## 선수 지식

20단위 결과물과 기록을 이어 사용합니다. Ping-pong과 데이터 경쟁 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 이웃 참조

각 원소가 이웃의 이전 값을 읽는 계산은 제자리 갱신과 충돌할 수 있습니다. 실행 순서에 의존하지 않으려면 입력·출력 배열을 나눕니다.

### 시간 단계

한 dispatch가 한 시점의 상태를 다음 시점으로 바꿉니다. 다음 dispatch에서는 두 buffer의 역할을 교환합니다.

## 실습 준비

별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

이 단위에는 내장 실행 예제가 없습니다. 아래 절차에 따라 별도 실습 파일을 만들고 실행 결과를 필기에 남기세요. 코드 파일은 작업 폴더에서 따로 보관하고 Frontory 필기는 JSON 또는 Markdown으로 백업하세요.

## 실습 과제

1. stencil.wgsl에 이전 좌우 이웃의 평균을 새 배열에 쓰는 함수를 작성하세요.
2. A→B와 B→A binding을 호스트에서 교대하세요.
3. 세 단계 계산을 CPU의 복사 기반 구현과 비교하고 끝점 정책을 명시하세요.
