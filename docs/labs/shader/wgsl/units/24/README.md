# WGSL · 24 수치 안정성과 특수 입력

[시리즈 목차](../../README.md) · [전체 기술 지도](../../../../README.md)

단계: 수치 검증과 커널 설계 · 편집 가능한 예제 · 저장 ID: `wgsl-step-24`

## 목표와 학습 후 역량

- 불안정 입력을 처리한다.
- 입력 규모에 따른 오차를 검증한다.

## 선수 지식

23단위 결과물과 기록을 이어 사용합니다. 수치 안정성과 특수 입력 실험에 앞서 이전 입력과 기준 출력을 보관합니다.

## 핵심 개념과 설명

### 불안정 연산

0 길이 벡터 정규화나 작은 수로 나누기는 불안정한 결과를 만들 수 있습니다. 유효 범위를 검사하고 의미 있는 대체 값을 정의합니다.

### 알고리즘 안정성

수학적으로 같은 식도 부동소수 계산에서는 다른 오차를 낼 수 있습니다. 결과만 가까운지 보지 말고 입력 규모를 바꾸며 비교합니다.

## 실습 준비

예제 화면의 실행 범위 안내를 먼저 확인하세요. 다음은 과제를 별도 프로젝트로 확장할 때의 준비 환경입니다. 별도 localhost 또는 HTTPS 프로젝트에서 직접 구현하는 문서 안내 실습입니다. secure context, navigator.gpu, adapter 요청 결과를 확인하고 미지원 안내를 제공합니다. device.lost 처리와 자원 해제를 유지합니다.

연결된 예제는 출발점입니다. 아래 과제 전체가 완성된 코드는 아니며 예제의 지원 범위를 넘는 작업은 별도 프로젝트에서 수행하세요.

## 실습 과제

1. numeric.wgsl에 길이 제곱이 임계값보다 작을 때 대체 방향을 쓰는 함수를 작성하세요.
2. 0·1e-8·1·큰 좌표 벡터를 입력해 CPU 기준과 비교하세요.
3. NaN 또는 무한 입력은 호스트에서 거절하고 실패 위치를 기록하세요.

## 관찰할 변수

| 변수      | 기준 조건 | 바꿀 조건 | 예상할 변화·검증 가설                                       |
| --------- | --------- | --------- | ----------------------------------------------------------- |
| 벡터 길이 | 1         | 0과 1e-8  | 정규화 경로 대신 정한 대체 방향이 사용될 것으로 예상합니다. |

표의 예상은 측정 결과가 아닙니다. 한 번에 한 조건만 바꾸고 실제 결과가 다르면 원인을 기록하세요.

## 완료 조건

- [ ] 네 유효 입력에서 출력이 유한하고 규칙에 맞는다.
- [ ] 잘못된 입력은 GPU 제출 전에 필드 위치와 함께 거절된다.
