# Playwright · 03 시각 회귀와 흔들림

[시리즈 목차](../README.md) · [전체 기술 지도](../../../README.md)

단계: 응용과 검증 · 문서·필기·예제 제공

## 목표와 학습 후 역량

재현 가능한 기준과 비결정적 장면의 별도 검증 전략을 남긴다. 이를 자신의 말로 설명하고 작은 결과물로 재현하는 것이 목표입니다.

## 선수 지식

이 시리즈 2단위의 결과물과 기록.

## 핵심 개념과 설명

GPU 장면·시간·폰트 차이는 스크린샷 비교를 불안정하게 합니다. 동일 조건과 허용 차이의 이유를 기록해야 합니다.

## 실습 준비

현재 단위에 연결된 예제를 실행하고 아래 과제를 진행합니다. 코드 편집기 자체는 JS/TS 모듈이며 JSX·Vue SFC를 직접 컴파일하지 않습니다.

## 실습 과제

1. 공식 참고에서 이번 개념과 API의 입력·출력을 찾아 필기에 요약합니다.
2. 회전을 정지하고 고정 viewport에서 UI 스크린샷 기준을 만드세요. trace로 실패 시 입력과 네트워크를 확인하세요.
3. 아래 변수 중 하나만 바꾸기 전에 예상 결과를 적고, 실행 후 스크린샷·로그 또는 측정값과 비교합니다.
4. 원래 조건으로 되돌려 같은 결과를 재현하고 오류·지원 제한도 남깁니다.

## 관찰할 변수

viewport, animation, DPR. 비교 시 다른 변수와 브라우저·viewport 조건은 고정합니다.

## 완료 조건

- [ ] 재현 가능한 기준과 비결정적 장면의 별도 검증 전략을 남긴다.
- [ ] 최소 두 조건의 예상과 실제 결과를 구분해 기록했다.
- [ ] 오류 또는 경계 조건 한 가지를 재현하고 복구 방법을 적었다.
- [ ] 실제로 수행한 내용을 기준으로 완료 상태를 직접 표시했다.

## 자가 점검

1. 시각 회귀와 흔들림에서 입력이 결과로 이어지는 경로를 설명할 수 있나요?
2. viewport, animation, DPR 중 어떤 변수가 예상과 다르게 동작했으며 이유는 무엇인가요?
3. 재현 가능한 기준과 비결정적 장면의 별도 검증 전략을 남긴다. 이 조건이 깨지는 사례와 확인 방법은 무엇인가요?
