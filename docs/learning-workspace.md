# Frontory 학습 화면 사용법과 저장

## 시작

Frontory에서 **시리즈 둘러보기**를 열어 학습할 기술을 선택하세요. 단계를 선택하고 학습 문서를 읽은 뒤 과제를 수행하며 필기를 남깁니다. 처음이라면 WebGL 첫 장면에서 큐브 색상이나 카메라 위치를 바꿔 보세요. 설치나 로그인 없이 브라우저에서 학습할 수 있습니다.

로컬 개발은 [README](../README.md), 웹 게시는 [배포 가이드](deployment.md)를 참고하세요. 같은 브라우저·프로필·주소로 접속해야 같은 저장 기록을 복원합니다.

## 세 영역과 문서

**시리즈 둘러보기**에서 분야 또는 기술 이름으로 23개 시리즈를 탐색합니다. 선택한 시리즈의 단계 카드에는 순서와 완료 수가 표시됩니다. 단계별 목차를 펼쳐 단위를 고르거나 이전·다음 버튼으로 이동하세요. **나의 학습 상태**에서 미시작·진행 중·완료를 직접 표시합니다. 완료율은 직접 완료로 표시한 단위만 셉니다. 기존 필기에는 자동으로 완료 상태를 부여하지 않습니다.

- **실습 결과**: 실제 편집 코드를 별도 sandbox iframe에서 실행합니다. 예제의 주석에 따라 버튼·키보드·카메라를 조작합니다. OrbitControls 장면은 드래그/휠로 카메라를 움직입니다.
- **실행 코드**: Monaco Editor에서 JavaScript/TypeScript 모듈을 편집합니다. 입력이 600ms 멈추면 문법·타입 검사 후 반영합니다. 오류는 밑줄과 클릭 가능한 오류 목록으로 표시하고 마지막 정상 장면을 유지합니다. 실행 중 오류는 결과 영역에 표시합니다.
- **Markdown 필기**: 편집/미리보기 전환과 .md 다운로드를 제공합니다. 목표·핵심 개념·변수와 예상·실제 결과·배운 점·남은 질문을 기록합니다.

1100px 이상에서는 세 영역을 함께, 작은 화면에서는 결과/코드/필기 탭으로 보여 줍니다. 상단 **학습 문서**에서 현재 단위, 전체 로드맵과 이 사용법을 열 수 있습니다. 문서 기반 실습 단위는 별도 프로젝트에서 구현하며 내장 코드 편집·실행은 비활성화합니다. 해당 단위의 필기와 학습 상태는 동일하게 저장됩니다.

각 시리즈는 4단계, 28개 단위입니다. WebGL 외 시리즈의 기존 01·02·03 예제는 1·14·28번째에 연결되어 있습니다. 주소와 저장 ID는 그대로이므로 이전 북마크·필기·수정 코드는 유지됩니다. 완료율은 새 28단위 기준으로 계산되어 확장 전보다 낮게 표시될 수 있습니다.

## 실행 코드 계약

원본은 src/labs/<단위ID>/example.js입니다. [예제별 환경과 제한](examples.md)을 확인하세요. export function mount({ THREE, OrbitControls, container })가 장면을 만들고 정리 함수를 반환합니다. 라이브러리는 lockfile의 버전을 전달받으므로 에디터 안에서 npm 설치나 외부 import를 하지 않습니다. JavaScript/TypeScript의 구문 강조·자동 완성·문법 및 타입 진단을 지원합니다. TypeScript는 브라우저 worker에서 JavaScript로 변환한 실제 결과가 실행됩니다. JSX/TSX, 여러 파일, 외부 패키지, GLSL 전용 진단은 아직 지원하지 않습니다.

Ctrl+Space는 자동 완성, F8은 다음 진단, Shift+Alt+F는 서식 정리입니다. 오류 목록을 클릭하면 해당 줄로 이동합니다. 학습 진입을 위해 strict 검사는 끄고 JavaScript checkJs는 켰습니다. DOM과 명시한 기본 타입은 검사하지만 주입되는 THREE/OrbitControls는 any이므로 Three.js API 전체 타입 검사·자동 완성을 보장하지 않습니다. mount 인자에 `: StudyContext`를 붙일 수 있습니다. Monaco 내장 TypeScript 엔진은 프로젝트의 pnpm typecheck와 별개입니다.

입력·검사 중이나 검사 오류가 있으면 마지막 정상 결과를 계속 보입니다. 오류 코드도 저장합니다. 새로고침 시 저장 코드에 오류가 있으면 수정할 때까지 장면은 표시하지 않습니다. **다시 실행**은 마지막 검사 통과 코드를 새 프레임에서 실행합니다. **코드 원본 복원**은 확인 후 코드와 언어를 원본 JavaScript로 바꾸고 필기는 유지합니다.

## 전체 학습 JSON 내보내기·가져오기

**학습 아카이브**를 펼쳐 **JSON 내보내기**로 644개 목차 전체를 하나의 실제 `.json` 파일로 다운로드합니다. 각 목차의 코드 원문, Markdown 필기, JavaScript/TypeScript 선택, 학습 진행 상태, 저장 시간과 현재 보고 있는 목차가 포함됩니다. 편집하지 않은 단위도 현재 기본값을 포함합니다. 문서 기반 실습 단위의 기본 코드는 빈 문자열이며, 별도 프로젝트에서 작성한 파일은 이 백업에 자동 포함되지 않습니다.

다른 브라우저나 컴퓨터에서 같은 프로젝트를 실행하고 **JSON 가져오기**로 파일을 선택하세요. 파일 검사 후 백업 날짜와 복원할 목차·범위가 표시됩니다. **전체 교체하여 복원**을 누르면 해당 범위의 내용이 파일 내용으로 바뀌고 저장된 목차로 이동합니다. 취소하거나 파일 검사가 실패하면 기존 내용은 바뀌지 않습니다. 필요한 기존 작업은 먼저 내보내세요. 파일의 예제 코드는 기존 Monaco 검사와 sandbox 실행 경로를 거칩니다.

새 형식은 `format: "frontory"`, `version: 3`이며 644개 단위 전체를 교체합니다. 빈 필기도 그대로 복원합니다. 기존 Frontory `version: 2` 파일은 원래 94개 단위만 교체하고 새 550개 단위의 기록은 보존합니다. 기존 `format: "web-gl-study"`, `version: 1` 파일은 WebGL 28개 단위만 교체하고 나머지 단위의 현재 내용을 보존합니다. 각 버전의 단위가 모두 있어야 하며 누락·중복·알 수 없는 단위, 잘못된 타입이나 버전, 10 MiB 초과 파일은 거부합니다. 미래 카탈로그 추가 시에도 별도 호환 처리가 필요합니다. 브라우저 저장 용량은 파일 크기 제한보다 작을 수 있습니다.

전체 가져오기는 `web-gl-study:all:v1` 키에 한 번에 저장하여 실패 시 일부 목차만 교체되지 않도록 합니다. 성공 후에는 이 전체 저장본이 기존 단위별 키보다 우선하며 이후 편집도 전체 저장본에 반영합니다. 기존 단위별 저장 형식은 계속 읽을 수 있습니다. 저장 공간·권한 문제로 가져오기에 실패하면 기존 내용이 유지되고 오류가 표시됩니다.

내보내기는 현재 탭이 읽은 데이터를 사용합니다. 저장소 읽기/쓰기 경고가 있는 경우 다운로드 후 경고를 표시하므로 이전 백업도 보관하고 파일 내용을 확인하세요. 여러 탭의 동시 변경을 자동으로 합치지 않습니다. JSON은 암호화하지 않은 텍스트이며 서버로 업로드하지 않습니다. 프로젝트의 학습 문서·설치 패키지·GS 파일·카메라의 일시적인 조작 상태는 포함하지 않습니다. 같은 학습 프로젝트에서 내용을 이어가는 용도이며 독립 실행 앱은 아닙니다.

## localStorage 저장

작은 텍스트를 저장하므로 IndexedDB보다 단순한 localStorage를 선택했습니다. 키는 web-gl-study:unit:v1:<단위ID>, 데이터는 version=1, code, notes, updatedAt, 선택 언어 language, 학습 상태 progress입니다. 저장 키와 WebGL ID는 호환 목적으로 유지합니다. language가 없으면 JavaScript, progress가 없으면 미시작으로 읽습니다. 각 편집 이벤트에서 저장을 시도합니다. 단위 전환과 새로고침 후 복원하고 저장 시간·실패 상태를 표시합니다.

저장 실패 시에도 현재 페이지 메모리에는 사본을 유지하여 단위 전환 후 돌아올 수 있습니다. **실패 상태에서 새로고침하거나 닫으면 유실될 수 있으므로 필기를 다운로드하고 코드도 복사해 두세요.** 다시 저장 버튼으로 재시도할 수 있습니다. 손상된 JSON은 자동 삭제하지 않습니다. 해당 단위에서 새 편집을 저장하면 기존 손상값이 교체될 수 있음을 경고합니다.

### 한계

- 브라우저·프로필·오리진(protocol/host/port)별입니다. localhost와 127.0.0.1, 개발과 preview 포트는 서로 다릅니다.
- 브라우저 데이터 삭제·비공개 모드 종료·용량 제한·접근 거부로 저장이 실패하거나 내용이 사라질 수 있습니다. 영구 백업이 아닙니다.
- 브라우저 저장은 프로젝트 소스나 docs를 자동 수정하지 않습니다. 내려받은 Markdown을 문서에 직접 합칩니다.
- 여러 탭 실시간 동기화나 서버 동기화는 없습니다. 같은 단위를 여러 탭에서 편집하면 마지막 저장이 이길 수 있습니다.
- 큰 데이터·이미지·GS 파일은 저장하지 않습니다. 큰 텍스트도 동기 저장과 렌더링을 느리게 할 수 있습니다.

## 격리와 Markdown 안전성

iframe은 sandbox=allow-scripts만 사용하며 allow-same-origin을 부여하지 않습니다. 부모 DOM/localStorage 접근을 분리하고 필요한 실행 bootstrap과 blob module 외 외부 네트워크·form·중첩 프레임을 CSP로 제한합니다. 기존 브라우저 보안 설정이나 Vite CORS를 완화하지 않습니다.

react-markdown에서 raw HTML을 건너뛰고 위험한 URL을 제한합니다. HTML script/event handler를 실행하지 않으며 외부 이미지는 자동 요청하지 않습니다.

이 구조는 일반 문법·실행 오류를 편집 UI로부터 분리합니다. 악의적 코드 실행 서비스나 CPU/GPU 사용량 제한을 보장하지 않습니다. 무한 루프나 과도한 메모리 할당은 브라우저를 멈추게 할 수 있으므로 자신의 짧은 학습 코드만 실행하세요. 멈춘 경우 탭을 닫아야 할 수 있습니다.
