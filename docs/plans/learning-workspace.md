# 구현 범위와 후속 계획

## 제공 범위

문서 기반 학습 탐색, 단계별 진행 상태, JS/TS 편집, 격리된 WebGL 첫 장면, Markdown 필기, 전체 JSON 백업을 제공합니다. 나머지 기술 실행기는 준비 중입니다.

## 다음 작업

1. 카메라·좌표·선택 예제를 작은 단위로 추가합니다.
2. 실행기별 언어와 의존성을 명시하고 GLSL·DOM·프레임워크 실습으로 확장합니다.
3. 카탈로그 추가에 대응하는 백업 버전 마이그레이션을 구현합니다.
4. 초기 다운로드를 측정하고 문서·편집기 번들을 분할합니다.
5. 계정 동기화 수요가 확인되면 Auth와 RLS를 포함한 서버 저장을 설계합니다.

실제 사용자 성능 결과와 학습 기록은 제공하지 않으며 사용자가 직접 작성합니다.
