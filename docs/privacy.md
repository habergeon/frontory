# 저장 및 개인정보 안내

마지막 수정: 2026-10-22

Frontory는 계정 없이 학습 문서를 읽고 코드를 실험할 수 있는 사이트입니다. 학습 기록은 현재 브라우저에 저장합니다. 사이트 이용 분석에는 Google Analytics를, 일부 공개 학습 문서에는 Google AdSense 광고 태그를 사용합니다. 소스 코드를 공개한 저장소와 운영 사이트의 데이터 처리는 별개입니다.

## 운영 및 문의

Frontory는 [habergeon/frontory 공개 저장소](https://github.com/habergeon/frontory)를 통해 관리합니다. 개인정보 관련 문의와 문의 정보의 삭제 요청은 [hefa91@gmail.com](mailto:hefa91@gmail.com)으로 보내주세요. 문의할 때는 답변에 필요한 내용만 보내고 비밀번호·인증 코드·비밀 키·전체 학습 백업은 첨부하지 마세요.

일반적인 오류 제보와 문서 수정 제안은 [GitHub Issues](https://github.com/habergeon/frontory/issues)에서도 받습니다. GitHub 이슈는 공개되며 작성에 GitHub 계정이 필요합니다. 개인정보가 포함된 문의는 이메일을 이용하세요. 이메일과 GitHub에 직접 보내는 정보는 해당 서비스에서도 처리됩니다.

## 브라우저에 저장하는 학습 기록

편집한 코드, Markdown 필기, 선택한 언어, 진행 상태와 수정 시각을 브라우저의 localStorage에 저장합니다. 학습 기록을 Frontory 서버에 업로드하거나 계정으로 동기화하는 기능은 없습니다. 저장이 실패하면 현재 탭에서만 기록이 유지될 수 있습니다.

저장 코드에는 일정 기간 뒤 기록을 자동 삭제하는 기능이 없습니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있으며, 삭제 전에 JSON 내보내기로 백업하세요. 사이트 데이터를 지워도 이미 내려받은 파일이나 Google·호스팅 서비스가 처리한 정보까지 삭제되는 것은 아닙니다.

브라우저 데이터 삭제, 시크릿 모드 종료, 저장 용량 부족으로 기록이 사라질 수 있습니다. 다른 기기·브라우저·프로필·사이트 주소의 기록은 자동으로 합쳐지지 않습니다. 도메인을 옮길 때는 이전 주소에서 내보낸 JSON을 새 주소에서 가져오세요.

## 파일 가져오기와 내보내기

JSON과 Markdown 내보내기는 기기에 파일을 만듭니다. JSON 가져오기는 브라우저에서 파일을 읽고 확인을 받은 뒤 해당 범위의 기록을 교체합니다. 가져온 파일을 Frontory 서버로 업로드하지 않습니다. 백업 파일은 암호화되지 않으므로 공유 전에 개인정보와 비밀을 제거하세요.

## 이용 분석

홈과 코드 실습 화면에서 Google Analytics 4를 사용해 사이트 이용 현황을 파악합니다. Google 태그는 방문한 페이지, 브라우저·기기 등 이용 정보를 처리하고 분석용 쿠키를 사용할 수 있습니다. Google 서버로 요청을 전달하는 과정에서도 접속 정보가 처리됩니다.

Frontory 코드에는 편집한 코드·Markdown 필기·JSON 백업 내용을 분석 이벤트에 담아 보내는 기능이 없습니다. 다만 Google 서비스의 자동 수집과 운영 계정 설정은 별개입니다. 문서나 필기에 비밀을 입력하지 말고, URL에도 개인정보를 넣지 마세요.

자세한 처리 방식은 [Google이 파트너 사이트의 정보를 사용하는 방법](https://policies.google.com/technologies/partner-sites?hl=ko)과 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)을 참고하세요. 브라우저의 쿠키·추적 방지 설정으로 수집을 제한할 수 있으며, [Google Analytics 차단 브라우저 부가 기능](https://tools.google.com/dlpage/gaoptout?hl=ko)도 제공합니다.

## 광고와 제3자 쿠키

일부 공개 학습 문서에 Google AdSense 광고 태그를 사용합니다. 홈과 코드 편집·필기 화면, 사이트 소개, 이 안내와 오류 페이지에는 AdSense 실행 스크립트를 넣지 않습니다. 광고 표시 여부와 형식은 Google의 사이트 승인, 광고 설정, 방문 환경 등에 따라 달라집니다. 화면에 광고가 보이지 않아도 광고 태그가 실행되면 Google 서버로 요청이 전달될 수 있습니다.

Google 등 제3자 제공업체는 쿠키, 웹 비콘, IP 주소 또는 다른 식별자를 사용해 광고를 제공하고 효과를 측정할 수 있습니다. Google의 광고 쿠키는 이 사이트와 다른 사이트의 이전 방문 정보를 바탕으로 광고를 맞춤설정하는 데 쓰일 수 있습니다. [Google 광고 설정](https://adssettings.google.com/)에서 개인 맞춤 광고를 관리할 수 있습니다. 이는 모든 광고나 다른 서비스의 데이터 처리를 중단하는 기능은 아닙니다.

쿠키와 광고 데이터 처리에 관한 자세한 내용은 [Google 광고 기술 안내](https://policies.google.com/technologies/ads?hl=ko)와 [파트너 사이트의 정보 사용 안내](https://policies.google.com/technologies/partner-sites?hl=ko)를 확인하세요. 동의 선택 화면이 제공되는 경우 그 화면의 목적·파트너 목록과 선택 변경 방법도 확인해 주세요. 이 안내 자체가 쿠키나 개인 맞춤 광고에 대한 동의를 대신하지는 않습니다.

## 호스팅과 외부 서비스

Cloudflare Pages가 정적 파일을 전달합니다. 이 과정에서 IP 주소 등 요청 정보가 처리될 수 있습니다. 구체적인 처리는 [Cloudflare 개인정보처리방침](https://www.cloudflare.com/privacypolicy/)과 적용된 서비스 설정에 따릅니다.

외부 공식 문서, GitHub, Google 등의 링크를 열면 해당 서비스의 정책이 적용됩니다. 미리보기는 sandbox로 격리하고 네트워크를 제한하지만 CPU·GPU 사용량까지 제한하지는 않습니다. 출처를 신뢰할 수 없는 코드는 실행하지 마세요.

## 변경 안내

사이트의 저장 방식이나 분석·광고 사용이 바뀌면 이 문서의 내용과 수정일을 갱신합니다. 설명과 실제 동작이 다르거나 개인정보 관련 확인이 필요하면 위 이메일로 알려주세요.
