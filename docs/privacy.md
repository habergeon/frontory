# 저장 및 개인정보 안내

Frontory는 계정 없이 사용할 수 있는 정적 웹 앱입니다. 앱은 코드, Markdown 필기, 언어, 진행 상태와 수정 시각을 현재 브라우저의 localStorage에 저장합니다. 학습 기록의 서버 저장과 광고는 제공하지 않습니다. 호스팅 제공자는 정적 파일 전달 과정에서 IP 주소 등 요청 정보를 처리할 수 있으며 이는 Cloudflare의 정책과 운영 계정 설정에 따릅니다.

사이트 이용 현황을 파악하기 위해 Google Analytics 4(GA4, 측정 ID `G-4SB5H1L3G5`)를 사용합니다. Google 태그는 페이지 방문과 브라우저·기기 등 이용 정보를 처리하고 분석용 쿠키를 사용할 수 있습니다. Frontory는 편집한 코드, Markdown 필기, JSON 백업 내용을 분석 이벤트에 담아 전송하지 않습니다. Google의 데이터 처리에 관한 내용은 [Google 개인정보처리방침](https://policies.google.com/privacy)을 참고하세요. 브라우저의 쿠키 및 추적 방지 설정에 따라 분석 수집이 제한될 수 있습니다.

브라우저 데이터 삭제·시크릿 모드 종료·저장 용량 부족으로 기록이 사라지거나 저장에 실패할 수 있습니다. 주소가 바뀌면 기존 기록이 자동으로 이동하지 않습니다. JSON 내보내기로 백업한 후 새 주소에서 가져오세요. 다른 탭의 동시 편집은 충돌을 자동 해결하지 않습니다.

JSON과 Markdown 다운로드는 로컬 파일을 만듭니다. JSON 가져오기는 브라우저에서 처리하며 파일을 서버로 업로드하지 않습니다. 파일은 암호화되지 않습니다. 공유 전에 개인정보와 비밀을 제거하세요. 가져오기는 확인 후 해당 범위의 기록을 교체합니다. 기존 데이터를 먼저 내보내세요.

기록을 삭제하려면 브라우저의 해당 사이트 저장 데이터 삭제 기능을 사용하세요. 이 작업은 모든 학습 기록을 지우므로 먼저 백업하세요. GitHub에 이슈를 작성할 때 개인 기록이나 비밀 키를 첨부하지 마세요.

미리보기는 sandbox로 격리하지만 CPU/GPU 사용량을 제한하지 않습니다. 출처를 신뢰할 수 없는 코드는 실행하지 마세요. 외부 공식 문서와 GitHub 링크를 열면 해당 서비스의 정책이 적용됩니다.
