# Frontory 로드맵

[23개 시리즈 기술 지도](labs/README.md) · [진행 중인 WebGL 28단위](labs/graphics/webgl/README.md) · [실습·저장 사용법](learning-workspace.md)

## Foundation — 지금의 기반

기술별 문서·목차, 직접 표시하는 진행 상태, WebGL 실시간 코드 실습과 필기, 전체 JSON 백업을 제공합니다. 새 기술의 문서 준비 상태와 실행 예제 준비 상태를 구분합니다.

## Interactive — 다음 구현

Canvas 2D와 JavaScript의 작은 실행 예제를 추가하고 mount/dispose 계약을 검증합니다. React/Vue/Svelte는 각 컴파일러와 의존성의 격리 방식을 먼저 설계합니다. 프레임워크 코드를 기존 WebGL 실행기에 억지로 주입하지 않습니다.

## Advanced — 확장 방향

Shader 전용 진단, WebGPU/WGSL, GS 데이터 로딩과 성능 관찰을 점진적으로 추가합니다. 지원 여부·실패 경로·자원 정리를 먼저 검증합니다. 공개 배포는 별도 결정이며 현재 작업에서 실행하지 않습니다.

학습 기간이나 실무 수준을 보장하지 않습니다. 각 단위의 완료 조건과 실험 기록이 기준입니다.
