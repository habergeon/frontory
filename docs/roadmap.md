## 학습 경로 선택

각 시리즈는 28개 단위와 네 단계로 구성됩니다. 하루 한 단위를 끝내야 하는 일정은 아닙니다. 선수 지식을 설명할 수 있으면 필요한 단위부터 시작하고 완료 조건을 확인한 뒤 다음 과제로 넘어가세요.

- 웹 기초: HTML → CSS → JavaScript → TypeScript. 의미 있는 문서와 입력, 상태 변경, 비동기 작업, 타입 경계를 익힙니다.
- UI 설계: React·Vue·Svelte 중 하나를 먼저 선택합니다. 같은 목록·필기 문제를 다른 프레임워크로 구현하며 상태와 자원의 소유권을 비교합니다.
- 그래픽스: Canvas 2D·SVG → WebGL Journey → Three.js·GLSL. 2D 좌표, 장면 그래프, 카메라, 셰이더를 연결합니다. PixiJS는 2D 렌더링, React Three Fiber는 React와 Three.js 결합을 다룹니다.
- GPU 심화: WebGPU와 WGSL을 함께 진행합니다. 파이프라인·메모리 배치·compute의 경계를 나누어 학습합니다. Gaussian Splatting은 카메라·투영·합성을 이해한 뒤 시작합니다.
- 인터랙션: GSAP·Motion에서 시간과 상태의 관계, 중단·복구, 키보드와 모션 감소 환경을 다룹니다.
- 실행 구조와 검증: Web Workers → OffscreenCanvas, 필요할 때 WebAssembly를 선택합니다. Playwright는 실제 사용자 흐름과 저장·복원을 반복 검증하는 경로입니다.

## 네 단계의 결과물

1. **기초:** 기술의 실행 모델과 입력·출력을 작은 예제로 설명합니다.
2. **핵심 기능:** 상태·좌표·자원 등 해당 기술의 주요 경계를 분리하고 기존 02 예제까지 확장합니다.
3. **응용:** 실패·취소·크기 변경·지원 제한을 재현하고 기준 조건과 바꾼 조건을 비교합니다.
4. **통합:** 기존 03 예제를 출발점으로 결과물을 완성하고 실행 방법·검증 기록·남은 제한을 정리합니다.

시리즈 목차에는 이 흐름을 해당 기술에 맞게 구체화한 단계 이름과 28개 문서가 있습니다. WebGL Journey는 기존 장면 → GLSL → GS → 통합 뷰어 흐름을 유지합니다.

## 현재 제공 범위

644개 단위에 문서·예제·필기를 제공합니다. 기존 94개 예제를 유지하고 신규 550개 단위에도 개념별 예제를 연결합니다. 브라우저 실험과 별도 실행 파일을 구분하며 예제만 열어 보고 과제를 완료한 것으로 판단하지 않습니다. 별도 실행 환경과 내장 예제의 제한은 각 문서와 [예제 안내](examples.md)에 적혀 있습니다.

학습 기간이나 실무 수준을 보장하지 않습니다. 각 단위의 완료 조건과 실험 기록이 기준입니다.
