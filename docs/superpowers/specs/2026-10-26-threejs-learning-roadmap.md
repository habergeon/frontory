# Three.js 전체 학습 로드맵

2026-10-26 기준 계획이다. 사용자가 확인한 첫 4개 단원 우선 개선에 이어, 이후 배울 내용을 먼저 정리했다. 아래 번호는 기존 28개 학습 단원의 순서이며, 사이트의 4개 큰 단계나 구현 작업 번호와 구별한다.

현재 모든 단원의 제목과 기본 자료는 존재한다. ‘우선 개선’과 ‘후속 개선’은 사이트 안에서 필수 과제를 끝낼 수 있도록 개편하는 상태이며, 아직 완료됐다는 뜻이 아니다. 기존 단원 ID·URL·코드·필기·진도를 보존한다.

## 개편 순서와 기능 준비 시점

학습 순서는 01~28을 유지한다. 구현은 필요한 실행 기능을 먼저 준비한 뒤 해당 강의를 자체 완결로 바꾼다.

| 묶음                   | 개편할 단원 | 시작 전에 준비할 것                                                                         |
| ---------------------- | ----------- | ------------------------------------------------------------------------------------------- |
| 첫 과정                | 01~04       | HTML 실행, 표준 module import, Prettier, 오류·콘솔, 저장·백업                               |
| 도형과 조명            | 05~09       | 첫 과정 기능을 재사용하고 관찰값·힌트·API 참고 보강                                         |
| 이미지와 표면          | 10~13       | 이미지 자산 선택·샘플·실패 처리. 실행 격리와 저장 범위 별도 설계                            |
| 모델과 움직임          | 14~18       | GLTFLoader, GLB 샘플·파일 선택, 애니메이션 fixture. 외부 참조 glTF·압축 형식 지원 범위 명시 |
| 많은 물체와 여러 화면  | 19~22       | 인스턴스·경계·렌더 통계·render target 관찰                                                  |
| 안정성과 완성 프로젝트 | 23~28       | 지연·실패 실험, 자원 정리 기록, 접근성, 비교 가능한 통계                                    |

첫 4개를 공개할 때 이 전체 목록도 사이트에 제공한다. 시리즈 학습 계획과 04번 단원 끝에서 다음 단원·선수 지식·개선 상태를 확인할 수 있어야 한다. 05~28의 기존 강의는 숨기거나 막지 않는다. ‘개선 예정’은 기존 자료가 없다는 뜻이 아니라 사이트 내 실습 완결성 검증이 남았다는 뜻으로 설명한다.

완료 상태는 구현·실제 실습·설명 검토가 끝난 단원만 갱신한다. 나중에 학습 범위를 바꾸면 이 목록과 사이트 표시를 함께 갱신한다. 구현 상태와 사용자의 학습 진도는 별개다.

공식 매뉴얼은 설명과 실험 주제, API 문서는 각 단원에서 쓰는 계약을 대조하는 기준이다. [Three.js Manual](https://threejs.org/manual/)과 [Three.js Docs](https://threejs.org/docs/)의 내용을 통째로 복제하지 않는다. 학습 목표에 필요한 설명을 직접 작성하고 출처·검증 버전을 남긴다.
