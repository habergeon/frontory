# 미디어·자막·실패 경로

이 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000/index.html 을 여세요. file:// 로 열면 자막이 제한될 수 있습니다.

1. 6초 무음 sample.mp4를 재생하고 한국어 자막 메뉴를 선택합니다. 3초에서 파랑이 주황으로 바뀝니다.
2. 없는 파일 전환 버튼으로 404와 대본 대체 경로를 확인합니다. 정상 복원도 검사합니다.
3. captions.vtt의 시간·텍스트를 바꾸고 새로고침해 비교합니다.

무음 합성 영상은 실제 발화의 자막 품질 평가용이 아닙니다. 사용자가 소유한 발화 영상으로 바꿀 때 자막과 대본도 함께 고치세요.

재생 자원은 FFmpeg의 color 소스로 생성했습니다. 외부 영상·음원은 사용하지 않았습니다. 생성 명령은 저장소의 generate-foundations-examples.mjs 설명을 참고하세요.
