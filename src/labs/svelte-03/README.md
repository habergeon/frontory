# 동일 요구사항 비교

내장 예제는 실제 React, Vue, Svelte store를 사용하지만 Svelte 열의 DOM은 직접 작성한 어댑터입니다. 따라서 이 열의 DOM 코드 양을 Svelte 컴포넌트 코드 양으로 비교하면 안 됩니다.

Svelte 5 Vite 프로젝트의 `src/App.svelte`를 동봉 파일로 교체하여 실제 컴포넌트를 실행하세요. 동일한 세 카드에서 1번 완료 → 미완료 필터 켜기 → 필터 끄기를 반복합니다. 세 구현에서 완료 개수와 카드 표시가 일치하는지 기록하세요.

비교 표에는 상태 선언, 파생 값, 이벤트, 명시적 구독 정리 유무를 기록하세요. 선호도와 관찰 사실은 따로 적습니다. 이 예제는 속도 우열을 측정하지 않습니다.
